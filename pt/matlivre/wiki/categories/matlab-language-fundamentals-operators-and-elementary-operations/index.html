Language Fundamentals > Operators and Elementary Operations

62 funções em MATLAB › Language Fundamentals > Operators and Elementary Operations.

Logical (Boolean) Operations

&Operador E lógico elemento a elemento.
allTesta se todos os elementos são diferentes de zero (verdadeiros).
anyTesta se algum elemento é diferente de zero (verdadeiro).
findEncontra os índices dos elementos diferentes de zero.
logicalConverte valores em lógico verdadeiro ou falso.
Short-Circuit &&E lógico com curto-circuito: o segundo operando só é avaliado se necessário.
Short-Circuit ||OU lógico com curto-circuito: o segundo operando só é avaliado se necessário.
xorOU exclusivo lógico.
|Operador OU lógico elemento a elemento.
~Operador NÃO lógico.

Arithmetic Operations

'Operador de transposta conjugada.
*Operador de multiplicação de matrizes.
+Operador de adição: soma números, arrays e outros valores elemento a elemento.
-Operador de subtração e negação.
.'Operador de transposta sem conjugação.
.*Operador de multiplicação elemento a elemento.
./Operador de divisão à direita elemento a elemento.
.\Operador de divisão à esquerda elemento a elemento.
.^Operador de potência elemento a elemento.
/Operador de divisão à direita: a / b divide, ou resolve x*B = A para matrizes.
\Operador de divisão à esquerda: resolve o sistema linear A*x = B.
^Operador de potência de matrizes.
bsxfunAplica uma função binária expandindo dimensões singleton.
ceilArredonda em direção a mais infinito.
cumprodProduto cumulativo dos elementos de um array.
cumsumSoma cumulativa dos elementos de um array.
diffDiferenças entre elementos adjacentes.
fixArredonda em direção a zero, descartando a parte fracionária.
floorArredonda em direção a menos infinito.
idivideDivisão de inteiros com uma regra de arredondamento à escolha.
modResto da divisão, com o sinal do divisor (módulo).
movsumSoma móvel sobre uma janela deslizante.
pagectransposeTranspõe e conjuga cada página de um array N-D.
pagemldivideResolve sistemas lineares página a página, A \ B para cada página.
pagemrdivideDivisão à direita página a página, A / B para cada página.
pagemtimesMultiplicação de matrizes página a página para arrays N-D.
pagetransposeTranspõe cada página de um array N-D.
prodProduto dos elementos de um array.
remResto da divisão, com o sinal do dividendo.
roundArredonda para o inteiro mais próximo, ou para um número de dígitos.
tensorprodProduto tensorial e contração de arrays ao longo de dimensões escolhidas.
uminusMenos unário: troca o sinal de cada elemento.
uplusMais unário: retorna o argumento, com a conversão numérica de uma operação.

Relational Operations

<Operador menor que: testa elemento a elemento se A é menor que B.
<=Operador menor ou igual: testa elemento a elemento se A é no máximo B.
==Operador de igualdade: testa elemento a elemento se A e B são iguais.
>Operador maior que: testa elemento a elemento se A é maior que B.
>=Operador maior ou igual: testa elemento a elemento se A é no mínimo B.
isequalTesta se arrays são iguais em tamanho e conteúdo.
isequalnTesta a igualdade de arrays, tratando valores NaN como iguais.
isequalwithequalnansTesta a igualdade de arrays com NaN igual a NaN (nome antigo de isequaln).
~=Operador de diferença: testa elemento a elemento se dois valores são diferentes.

Bit-Wise Operations

bitandE bit a bit de inteiros.
bitcmpComplemento bit a bit de um inteiro.
bitgetLê bits de um inteiro em posições indicadas.
bitorOU bit a bit de inteiros.
bitsetLiga ou desliga bits de um inteiro em posições indicadas.
bitshiftDesloca os bits de um inteiro para a esquerda ou para a direita.
bitxorOU exclusivo bit a bit de inteiros.
swapbytesInverte a ordem dos bytes de inteiros (troca de endianness).

Set Operations

ismembertolTesta pertinência a um conjunto de valores de ponto flutuante dentro de uma tolerância.
uniquetolValores únicos de um array de ponto flutuante dentro de uma tolerância.

Boundary Value Problems

bvp4cResolve problemas de valor de contorno para equações diferenciais ordinárias.
bvp5cResolve problemas de valor de contorno com um método de quarta ordem que controla o erro verdadeiro.
bvpgetLê uma opção nomeada de uma estrutura de opções de problema de valor de contorno.
bvpinitConstrói a malha inicial e o palpite para um solver de problema de valor de contorno.
bvpsetCria ou atualiza a estrutura de opções usada pelos solvers de problemas de valor de contorno.
bvpxtendEstende a solução de um problema de valor de contorno para uma nova extremidade do intervalo.

Ordinary Differential Equations

decicEncontra condições iniciais consistentes para uma equação diferencial totalmente implícita.
devalAvalia em pontos dados uma estrutura de solução de equação diferencial.
ode113Solver de Adams-Bashforth-Moulton de ordem variável para equações diferenciais não rígidas.
ode15iSolver de ordem variável para equações diferenciais totalmente implícitas f(t, y, y') = 0.
ode15sSolver de ordem variável para equações diferenciais rígidas e sistemas algébricos de índice 1.
ode23Solver de Runge-Kutta de baixa ordem para equações diferenciais não rígidas.
ode23sSolver de passo único para equações diferenciais rígidas, baseado em uma fórmula de Rosenbrock modificada.
ode23tSolver de regra do trapézio para equações moderadamente rígidas e sistemas algébrico-diferenciais.
ode23tbSolver TR-BDF2 para equações diferenciais rígidas em tolerâncias grosseiras.
ode45Solver de Runge-Kutta padrão para equações diferenciais ordinárias não rígidas.

odegetLê uma opção nomeada de uma estrutura de opções de EDO.

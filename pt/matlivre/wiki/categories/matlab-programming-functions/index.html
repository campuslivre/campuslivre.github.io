inputnameRetorna o nome da variável passada como um dado argumento da função atual.

mfilenameRetorna o nome do arquivo em execução.

mustBeInRangeVerifica se todos os elementos estão entre dois limites.
mustBeIntegerVerifica se todos os elementos são números inteiros.
mustBeLessThanVerifica se todos os elementos são estritamente menores que um limite.
mustBeLessThanOrEqualVerifica se todos os elementos são menores ou iguais a um limite.
mustBeMemberVerifica se um valor é um dos elementos de um conjunto.
mustBeNegativeVerifica se todos os elementos são menores que zero.
mustBeNonemptyVerifica se um array tem pelo menos um elemento.

mustBePositiveVerifica se todos os elementos são maiores que zero.

mustBeScalarOrEmptyVerifica se um valor tem um único elemento ou nenhum.

mustBeTextVerifica se um valor é texto: caracteres, array de strings ou cell array de vetores de caracteres.

Error Handling

assertGera um erro se uma condição for falsa.
errorLança um erro, interrompendo o código em execução a menos que seja capturado.
lasterrRetorna a mensagem do erro mais recente.

lastwarnRetorna ou define a mensagem de aviso mais recente.

warningExibe uma mensagem de aviso e a registra, sem interromper o programa.

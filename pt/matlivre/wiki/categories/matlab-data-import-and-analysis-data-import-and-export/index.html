Standard File Formats

audioinfoLê os metadados de um arquivo de áudio sem carregar as amostras.
audioreadLê um arquivo de áudio em uma matriz de amostras e retorna a taxa de amostragem.
audiowriteGrava uma matriz de amostras em um arquivo de áudio.
closeFecha janelas de figura.
csvreadLê um arquivo numérico separado por vírgulas em uma matriz.
csvwriteGrava uma matriz numérica em um arquivo separado por vírgulas.
delimitedTextImportOptionsCria um objeto de opções que descreve como importar um arquivo de texto delimitado.
dlmreadLê um arquivo numérico delimitado em uma matriz.
dlmwriteGrava uma matriz numérica em um arquivo de texto delimitado.
filereadLê um arquivo de texto inteiro em um vetor de caracteres.
getLê uma propriedade de um objeto gráfico.
imfinfoRetorna informações sobre um arquivo de imagem.
importdataCarrega dados de um arquivo, escolhendo o leitor pelo tipo do arquivo.
imreadLê um arquivo de imagem em um array.
imwriteGrava um array em um arquivo de imagem.
jsondecodeConverte texto JSON em valores do MATLAB.
jsonencodeConverte valores do MATLAB em texto JSON.
lin2muConverte amostras de áudio lineares para mu-law de 8 bits.
mu2linConverte códigos mu-law de 8 bits de volta para amostras de áudio lineares.
readcellLê uma planilha ou arquivo de texto delimitado em um cell array.
readlinesLê as linhas de um arquivo de texto em um array de strings.
readmatrixLê uma matriz numérica de um arquivo de texto ou de planilha.
readstructLê um arquivo estruturado em XML para uma struct escalar.
readvarsLê as colunas de um arquivo em variáveis separadas.
setDefine propriedades de um objeto gráfico.
sheetnamesLista os nomes das planilhas de um arquivo de planilha.
textreadLê dados formatados de um arquivo de texto em variáveis separadas.
textscanLê dados formatados de um arquivo ou texto em um cell array de colunas.
Tiff.closeFecha o arquivo TIFF mantido por um objeto Tiff.
Tiff.computeStripRetorna o índice da faixa (strip) que contém uma linha da imagem.
Tiff.computeTileRetorna o índice do tile que contém uma posição da imagem.
Tiff.currentDirectoryRetorna o número do diretório de imagem atual no arquivo.
Tiff.getTagLê o valor de uma tag TIFF do diretório atual.
Tiff.getTagNamesRetorna os nomes das tags que a classe Tiff suporta.
Tiff.getVersionRetorna o texto de versão da biblioteca TIFF em uso.
Tiff.isTiledInforma se a imagem atual é armazenada em tiles.
Tiff.lastDirectoryInforma se o diretório atual é o último do arquivo.
Tiff.nextDirectoryMove para o próximo diretório de imagem do arquivo.
Tiff.numberOfStripsRetorna o número de faixas (strips) da imagem atual.
Tiff.numberOfTilesRetorna o número de tiles da imagem atual.
Tiff.readLê a imagem atual inteira em um array.
Tiff.readEncodedStripLê uma faixa (strip) da imagem atual, como armazenada.
Tiff.readEncodedTileLê um tile da imagem atual, como armazenado.
Tiff.readRGBAImageLê a imagem inteira convertida em dados de cor RGB.
Tiff.readRGBAStripLê uma faixa (strip) convertida em dados de cor RGB.
Tiff.readRGBATileLê um tile convertido em dados de cor RGB.
Tiff.rewriteDirectoryAtualiza o diretório atual de um arquivo com tags alteradas.
Tiff.setDirectoryTorna um diretório de imagem específico o atual.
Tiff.setSubDirectoryMove para uma subimagem cujo deslocamento no arquivo é dado por uma tag SubIFD.
Tiff.setTagDefine o valor de uma tag TIFF antes de gravar uma imagem.
Tiff.writeMétodo de um objeto Tiff: grava uma imagem no diretório atual de um arquivo TIFF aberto para escrita.
Tiff.writeDirectoryMétodo de um objeto Tiff: fecha o diretório de imagem atual e inicia um novo, para arquivos TIFF com várias imagens.
Tiff.writeEncodedStripMétodo de um objeto Tiff: grava uma faixa (strip) de uma imagem TIFF organizada em faixas a partir de um array de pixels.
Tiff.writeEncodedTileMétodo de um objeto Tiff: grava um bloco (tile) de uma imagem TIFF organizada em blocos a partir de um array de pixels.
typeExibe o conteúdo de um arquivo de texto na janela de comandos.
writecellGrava um cell array em um arquivo de texto delimitado ou em uma planilha.
writelinesGrava linhas de texto em um arquivo, uma string por linha.
writematrixGrava uma matriz numérica em um arquivo de texto delimitado ou em uma planilha.
writestructGrava uma struct em um arquivo XML ou JSON.
xlsfinfoInforma se um arquivo é uma planilha legível e lista suas abas.
xlsreadLê números e texto de uma planilha do Excel.
xlswriteGrava uma matriz ou cell array em uma planilha do Excel.

Workspace Variables and MAT-Files

clearRemove variáveis do workspace.
clearvarsLimpa variáveis escolhidas do workspace, com opções para manter algumas.
dispExibe um valor na janela de comandos sem imprimir o nome.
formattedDisplayTextRetorna, como string, o texto que a exibição de um valor imprimiria.
loadCarrega variáveis de um arquivo MAT ou dados numéricos de um arquivo de texto.
matfileAcessa variáveis de um arquivo MAT sem carregar o arquivo inteiro.
saveSalva variáveis do workspace em um arquivo MAT ou de texto.
whoLista os nomes das variáveis do workspace atual.

Low-Level File I/O

fcloseFecha um arquivo aberto.
feofTesta se a posição de leitura está no fim de um arquivo.
ferrorRetorna a mensagem e o código de erro da última operação de arquivo.
fgetlLê uma linha de um arquivo e descarta a quebra de linha.
fgetsLê uma linha de um arquivo e mantém o caractere de quebra de linha.
fopenAbre um arquivo e retorna um identificador de arquivo.
fprintfGrava texto formatado na janela de comandos ou em um arquivo.
freadLê dados binários de um arquivo.
frewindMove a posição de leitura de um arquivo de volta ao início.
fscanfLê dados formatados de um arquivo de texto.
fseekMove a posição do arquivo para um deslocamento em bytes.
ftellRetorna a posição atual, em bytes, em um arquivo.
fwriteGrava dados binários em um arquivo.

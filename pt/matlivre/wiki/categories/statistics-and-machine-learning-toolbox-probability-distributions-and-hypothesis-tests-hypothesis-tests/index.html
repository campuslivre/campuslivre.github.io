Probability Distributions and Hypothesis Tests > Hypothesis Tests

18 funções em Statistics and Machine Learning Toolbox › Probability Distributions and Hypothesis Tests > Hypothesis Tests.

ansaribradley próxima versãoTeste de Ansari-Bradley para duas amostras: verifica se elas vêm de distribuições com a mesma dispersão, sem supor normalidade.
barttest próxima versãoTeste de Bartlett para o número de dimensões de um conjunto de dados: verifica se os menores componentes principais podem ser tratados como tendo a mesma variância.
dwtest próxima versãoTeste de Durbin-Watson para autocorrelação de primeira ordem nos resíduos de uma regressão linear.
fishertest próxima versãoTeste exato de Fisher para uma tabela de contingência 2 por 2: verifica se as duas variáveis categóricas são independentes.
friedman próxima versãoTeste não paramétrico de Friedman para diferenças entre as colunas (tratamentos) de uma matriz, com as linhas como blocos.
jbtest próxima versãoTeste de Jarque-Bera para verificar se uma amostra vem de uma distribuição normal, com base na assimetria e na curtose.
kruskalwallis próxima versãoTeste de Kruskal-Wallis: teste não paramétrico de uma via para verificar se vários grupos vêm da mesma distribuição.
kstest próxima versãoTeste de Kolmogorov-Smirnov de uma amostra: compara a distribuição empírica de uma amostra com uma distribuição de referência (normal padrão por padrão).
kstest2 próxima versãoTeste de Kolmogorov-Smirnov de duas amostras: verifica se duas amostras vêm da mesma distribuição contínua.
lillietest próxima versãoTeste de Lilliefors para verificar se uma amostra vem de uma distribuição normal, exponencial ou de valor extremo, com parâmetros estimados dos dados.
ranksum próxima versãoTeste da soma de postos de Wilcoxon (Mann-Whitney U): teste não paramétrico para verificar se duas amostras independentes têm medianas iguais.
runstest próxima versãoTeste de sequências (runs) para aleatoriedade: verifica se a sequência de valores acima e abaixo de um limiar parece aleatória.
signrank próxima versãoTeste dos postos sinalizados de Wilcoxon: teste não paramétrico de que as diferenças pareadas (ou uma amostra) têm mediana zero.
signtest próxima versãoTeste do sinal para amostras pareadas ou para a mediana: testa se a mediana das diferenças, ou de uma amostra, é zero ou um valor dado.
vartest próxima versãoTeste qui-quadrado de que a variância de uma amostra normal é igual a um valor dado, com intervalo de confiança para a variância.
vartest2 próxima versãoTeste F de que duas amostras normais têm a mesma variância, com intervalo de confiança para a razão das variâncias.
vartestn próxima versãoTesta se vários grupos têm a mesma variância (Bartlett por padrão, ou um dos testes do tipo Levene).
ztest próxima versãoTeste z para a média de uma amostra quando o desvio padrão da população é conhecido, com intervalo de confiança para a média.

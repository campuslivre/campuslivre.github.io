Data Type Identification

isaTesta se um valor pertence a uma classe ou a uma categoria de classes.
isenumTesta se um valor é instância de uma classe de enumeração.
isgraphicsTesta se um valor é um handle válido de objeto gráfico.
isjavaTesta se um valor é um objeto Java.
islogicalTesta se um array é da classe logical.
isobjectTesta se um valor é um objeto de uma classe do MATLAB.
issparseTesta se um array usa armazenamento esparso.
isstrTeste obsoleto para arrays de caracteres; use ischar.
isUnderlyingTypeTesta se um valor tem um dado tipo de dado subjacente.
underlyingTypeClasse dos dados guardados dentro de um array, vendo através de contêineres como gpuArray.
validateattributesVerifica se um valor tem a classe e as propriedades exigidas, gerando erro caso contrário.
whosLista as variáveis do workspace com tamanho, memória e classe.

Dictionaries

configureDictionaryCria um dicionário vazio com tipos fixos de chave e valor.
dictionaryTabela de consulta que associa chaves a valores.
entriesTodas as chaves e valores de um dicionário, como tabela.
insertAdiciona uma chave e um valor a um dictionary e retorna o dictionary atualizado.
isConfiguredTesta se um dictionary tem definidos os tipos de chave e valor.
isKeyTesta se chaves estão presentes em um containers.Map ou dictionary.
keyHashCalcula o código hash usado para localizar uma chave em um dictionary.
keyMatchTesta se duas chaves são iguais para fins de dictionary.
keysRetorna as chaves de um containers.Map ou dictionary.
lookupLê o valor de uma chave em um dictionary, com um valor alternativo opcional.
numEntriesNúmero de entradas chave-valor em um dictionary.
removeApaga uma entrada de um dictionary ou de um containers.Map pela chave.
typesTipos das chaves e dos valores de um dictionary.
valuesValores guardados em um containers.Map ou dictionary.

Map Containers

containers.MapObjeto de mapeamento que guarda valores associados a chaves de texto ou número.

Function Handles

fevalChama uma função dada por handle ou por nome.
func2strConverte um function handle em texto.
functionsInformações sobre um function handle: nome, tipo e arquivo.
localfunctionsRetorna handles das funções locais definidas no arquivo atual.
str2funcCria um handle de função a partir de um texto.

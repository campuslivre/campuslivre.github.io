lognlike próxima versão

Log-verossimilhança negativa da distribuição lognormal para mu, sigma e dados dados, com a covariância assintótica das estimativas.

Categoria: Probability Distributions and Hypothesis Tests > Univariate Continuous Distributions

Sintaxe

nlogL = lognlike(params, data)

Log-verossimilhança negativa em params = [mu sigma].

[nlogL, avar] = lognlike(params, data)

Retorna também a matriz de covariância aproximada 2 por 2 das estimativas.

nlogL = lognlike(params, data, censoring)

Trata como censuradas à direita as observações marcadas em censoring.

nlogL = lognlike(params, data, censoring, freq)

Pondera cada observação por freq.

Descrição

lognlike avalia a quantidade que lognfit minimiza. Use-a para comparar parâmetros candidatos ou modelos ajustados aos mesmos dados: o menor valor ajusta melhor.

Como os dados entram pelo logaritmo, todas as observações devem ser positivas.

Argumentos de entrada

params
Vetor [mu sigma] com a média e o desvio padrão do logaritmo.
data
Vetor de observações positivas.
censoring
Vetor opcional, 1 para observação censurada à direita e 0 para observação exata.
freq
Vetor opcional de frequências.

Argumentos de saída

nlogL
Log-verossimilhança negativa. Menor significa melhor ajuste.
avar
Matriz de covariância 2 por 2 das estimativas, na ordem mu, sigma. Tem sentido no ponto de máxima verossimilhança.

Exemplos

Verossimilhança nos parâmetros ajustados

x = [0.8 1.1 1.5 2.0 2.4 3.1 3.9 4.6 5.8 7.5 9.9 13.2];
p = lognfit(x);
fprintf('%.4f\n', lognlike(p, x))
Saída
29.4544

Erros padrão e um valor censurado

x = [0.8 1.1 1.5 2.0 2.4 3.1 3.9 4.6 5.8 7.5 9.9 13.2];
p = lognfit(x);
[nl, avar] = lognlike(p, x);
disp(round(sqrt(diag(avar))'*10000)/10000)
cens = zeros(size(x)); cens(end) = 1;
fprintf('%.4f\n', lognlike(p, x, cens))
Saída
    0.2530    0.1912
27.6960

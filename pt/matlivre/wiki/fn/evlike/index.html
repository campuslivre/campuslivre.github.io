evlike próxima versão

Log-verossimilhança negativa de dados sob a distribuição de valor extremo (mínimo), com a covariância assintótica das estimativas.

Categoria: Probability Distributions and Hypothesis Tests > Univariate Continuous Distributions

Sintaxe

nlogL = evlike(params, data)

Log-verossimilhança negativa em params = [mu sigma].

[nlogL, avar] = evlike(params, data)

Retorna também a matriz de covariância assintótica 2 por 2.

[nlogL, avar] = evlike(params, data, censoring, freq)

Aceita indicadores de censura e frequências.

Descrição

evlike calcula o objetivo que a evfit minimiza. Use para comparar valores de parâmetros, calcular estatísticas baseadas na verossimilhança ou obter a covariância das estimativas.

A covariância usa os dados e os parâmetros que você passa, então forneça os valores ajustados por evfit para obter erros-padrão.

Argumentos de entrada

params
Vetor [mu sigma] de dois elementos, com sigma positivo.
data
Vetor de observações.
censoring
Vetor opcional; 1 marca uma observação censurada.
freq
Vetor opcional de contagens.

Argumentos de saída

nlogL
Log-verossimilhança negativa escalar. Quanto menor, melhor o ajuste.
avar
Matriz de covariância assintótica 2 por 2 de [mu sigma], com sentido nas estimativas de máxima verossimilhança.

Exemplo

Verossimilhança e covariância nos valores ajustados

d = [-1.2 -0.4 0 0.3 0.8 1.1 1.5 -0.7 0.2 0.5];
p = evfit(d);
[nl, av] = evlike(p, d);
fprintf('%.4f\n', nl);
disp(round(av*1e4)/1e4)
Saída
11.9742
    0.0559   -0.0132
   -0.0132    0.0291

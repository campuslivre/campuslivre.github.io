robustfit próxima versão

Regressão linear robusta por mínimos quadrados reponderados iterativamente, que reduz a influência de valores atípicos no ajuste.

Categoria: Regression > Linear Regression > Multiple Linear Regression

Sintaxe

b = robustfit(X, y)

Coeficientes robustos, com um intercepto acrescentado como primeiro elemento.

[b, stats] = robustfit(X, y)

Retorna também uma estrutura com estatísticas do ajuste.

b = robustfit(X, y, wfun, tune, const)

Escolhe a função de peso, sua constante de ajuste, e se o intercepto é acrescentado ('on' ou 'off').

Descrição

Os mínimos quadrados ordinários deixam um ponto extremo puxar a reta na sua direção. robustfit reajusta várias vezes com pesos que diminuem para pontos com resíduos grandes, de modo que eles contam menos. Veja stats.w para saber quais observações tiveram o peso reduzido.

O intercepto é acrescentado automaticamente; não inclua uma coluna de uns em X.

Argumentos de entrada

X
Matriz de preditores n por p, sem coluna de uns.
y
Vetor de resposta com n elementos.
wfun
Nome da função de peso: 'bisquare' (padrão), 'andrews', 'cauchy', 'fair', 'huber', 'logistic', 'ols', 'talwar', 'welsch', ou um handle de função dos resíduos padronizados.
tune
Constante de ajuste da função de peso. Vazio seleciona o padrão.
const
'on' (padrão) acrescenta um intercepto, 'off' não.

Argumentos de saída

b
Vetor de coeficientes, com o intercepto primeiro quando const é 'on'.
stats
Estrutura com campos como s (estimativa robusta de escala), w (pesos finais, perto de 0 para valores atípicos), resid, se, t, p, covb e dfe.

Exemplos

Um valor atípico, ajuste robusto e ordinário

x = (1:8)';
y = [2.1 3.9 6.2 7.8 10.1 12.2 13.8 40]';
b = robustfit(x, y);
b0 = [ones(8, 1) x] \ y;
disp(round(b' * 1000) / 1000)
disp(round(b0' * 1000) / 1000)
Saída
    0.0730    1.9850
   -5.9390    3.9890

Pesos do ajuste

x = (1:8)';
y = [2.1 3.9 6.2 7.8 10.1 12.2 13.8 40]';
[b, s] = robustfit(x, y);
disp(round(s.w' * 1000) / 1000)
Saída
    0.9970    0.9710    0.9640    0.9460    0.9880    0.9430    0.9590         0

Observações

Com entradas em precisão simples, o MATLAB itera em precisão simples e o MatLivre em precisão dupla, então os resultados concordam só até cerca de 1e-5 relativo.

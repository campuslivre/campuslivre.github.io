firpm

Projeta um filtro FIR equiripple de fase linear com o algoritmo de Parks-McClellan, minimizando o maior erro ponderado.

Categoria: FIR design

Sintaxe

b = firpm(n,f,a)

Filtro de ordem n que ajusta a amplitude a nas bordas de banda f.

b = firpm(n,f,a,w)

Acrescenta um peso w por banda.

[b,err] = firpm(___)

Retorna também o erro ponderado máximo.

b = firpm(n,f,a,'hilbert')

Projeta um transformador de Hilbert (ou 'differentiator').

Descrição

firpm produz o filtro de uma dada ordem com o menor erro de pior caso possível, distribuído como ondulações de mesma altura em todas as bandas. Para uma ordem fixa, é a melhor escolha quando o limite é o desvio máximo. Para estimar a ordem a partir de uma especificação, use firpmord.

Os pesos definem como o erro é repartido: com pesos [1 5], a segunda banda recebe um quinto do erro da primeira.

Argumentos de entrada

n
Ordem do filtro. O resultado tem n+1 coeficientes.
f
Bordas de banda em pares, crescentes, de 0 a 1 (1 é metade da taxa de amostragem).
a
Amplitude desejada em cada borda de banda.
w
Peso opcional por banda. Um peso maior dá menor ondulação nessa banda.

Argumentos de saída

b
Vetor linha com n+1 coeficientes.
err
Erro ponderado máximo do projeto (a altura das ondulações iguais).

Exemplo

Passa-baixas, depois com peso maior na banda de rejeição

b = firpm(20,[0 0.3 0.4 1],[1 1 0 0]);
disp(round(b*10000)/10000)
[b,err] = firpm(20,[0 0.3 0.4 1],[1 1 0 0],[1 5]);
fprintf('%.4f\n', err)

Observações

Ajustes sem banda de rejeição, como firpm(20,[0 0.5],[0 1]), são quase singulares: os coeficientes (de até 1400) dependem de onde a troca termina, e diferem dos do MATLAB por volta do sexto dígito.

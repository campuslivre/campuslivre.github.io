kmeans próxima versão

Divide as linhas de uma matriz de dados em k clusters pelo método k-means, retornando rótulos, centroides e distâncias.

Categoria: Cluster Analysis and Anomaly Detection > k-Means and k-Medoids Clustering

Sintaxe

idx = kmeans(X, k)

Índice do cluster de cada linha, usando distância euclidiana ao quadrado.

[idx, C] = kmeans(X, k)

Retorna também os k centroides.

[idx, C, sumd, D] = kmeans(X, k)

Retorna também as somas de distâncias dentro de cada cluster e a distância de cada ponto a cada centroide.

[...] = kmeans(X, k, Name, Value)

Opções como 'Start', 'Replicates', 'Distance' e 'MaxIter'.

Descrição

kmeans alterna entre atribuir cada ponto ao centroide mais próximo e mover cada centroide para a média de seus pontos, até a atribuição parar de mudar. O resultado depende dos centroides iniciais e pode ser um ótimo local, então use 'Replicates' ou informe sua própria matriz em 'Start' quando o resultado importar.

Os números dos clusters são rótulos arbitrários. Com a inicialização padrão 'plus' os centroides iniciais são aleatórios, então chamadas repetidas podem numerar os clusters de outra forma.

Argumentos de entrada

X
Matriz de dados, uma observação por linha.
k
Número de clusters.
'Start'
Centroides iniciais: 'plus' (padrão), 'sample', 'uniform', 'cluster', ou uma matriz k por p.
'Replicates'
Quantas vezes repetir o agrupamento a partir de novos pontos iniciais. Fica o melhor resultado (menor distância total). O padrão é 1.
'Distance'
'sqeuclidean' (padrão), 'cosine' ou 'correlation'.

Argumentos de saída

idx
Vetor coluna com o número do cluster (1 a k) de cada linha.
C
Matriz k por p com os centroides dos clusters.
sumd
Vetor coluna com a soma das distâncias dos pontos ao centroide em cada cluster.
D
Matriz n por k com as distâncias de cada ponto a cada centroide.

Exemplos

Centroides iniciais fixos, para um resultado reprodutível

X = [1 2; 1.3 1.8; 0.8 2.4; 5 5; 5.5 4.9; 4.6 5.3; 9 1; 9.2 1.5];
[idx, C, sumd] = kmeans(X, 3, 'Start', X([1 4 7],:));
disp(idx')
disp(round(C*1000)/1000)
disp(round(sumd'*1000)/1000)
Saída
     1     1     1     2     2     2     3     3
    1.0330    2.0670
    5.0330    5.0670
    9.1000    1.2500
    0.3130    0.4930    0.1450

Inicializações aleatórias com réplicas: só os tamanhos são exibidos

X = [1 2; 1.3 1.8; 0.8 2.4; 5 5; 5.5 4.9; 4.6 5.3; 9 1; 9.2 1.5];
[idx, C] = kmeans(X, 2, 'Replicates', 5);
disp(size(idx))
disp(size(C))
disp(sort(unique(idx))')
Saída
     8     1
     2     2
     1     2

Observações

As distâncias 'cityblock' e 'hamming' não estão implementadas e geram um erro. Os pontos iniciais aleatórios ('plus', 'sample', 'uniform') não seguem os fluxos aleatórios do MATLAB, então os resultados com inicialização aleatória não coincidem com os do MATLAB mesmo com a mesma semente; informe uma matriz em 'Start' para uma execução reprodutível. Com a distância 'correlation' e dados com empates exatos, a atribuição dos pontos empatados pode diferir do MATLAB.

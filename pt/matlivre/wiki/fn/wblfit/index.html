wblfit próxima versão

Ajusta uma distribuição de Weibull aos dados por máxima verossimilhança, com intervalos de confiança e censura opcional.

Categoria: Probability Distributions and Hypothesis Tests > Univariate Continuous Distributions

Sintaxe

phat = wblfit(x)

Escala e forma estimadas como [a b].

[phat, pci] = wblfit(x)

Retorna também intervalos de confiança de 95 por cento.

[phat, pci] = wblfit(x, alpha)

Usa o nível de confiança de 100*(1-alpha) por cento.

phat = wblfit(x, alpha, censoring, freq)

Trata observações censuradas à direita e frequências.

Descrição

wblfit encontra a escala e a forma que tornam os dados mais prováveis sob um modelo de Weibull. Uma forma próxima de 1 sugere taxa de falha constante, e acima de 1 uma taxa de falha que cresce com a idade.

Use censoring para ensaios que terminaram antes de todos os itens falharem: desses itens se sabe apenas que duraram pelo menos o tempo registrado.

Argumentos de entrada

x
Vetor de dados positivos.
alpha
Nível de significância dos intervalos. O padrão é 0.05.
censoring
Vetor do mesmo tamanho de x: 1 para observação censurada, 0 para observada.
freq
Vetor de contagens, quantas vezes cada elemento de x ocorre.

Argumentos de saída

phat
Vetor linha [a b] com as estimativas de escala e forma.
pci
Matriz 2 por 2. A primeira coluna é o intervalo da escala, a segunda o da forma; a primeira linha tem os limites inferiores e a segunda os superiores.

Exemplos

Ajuste com intervalos de confiança

w = [1.2 2.3 0.8 3.1 1.9 2.7 1.5 2.2];
[p, ci] = wblfit(w);
fprintf('%.4f %.4f\n', p)
disp(round(ci*10000)/10000)
Saída
2.2022 3.0612
    1.7355    1.7427
    2.7943    5.3772

Última observação censurada

w = [1.2 2.3 0.8 3.1 1.9 2.7 1.5 2.2];
p = wblfit(w, 0.05, [0 0 0 0 0 0 0 1]);
fprintf('%.4f %.4f\n', p)
Saída
2.2896 2.8971

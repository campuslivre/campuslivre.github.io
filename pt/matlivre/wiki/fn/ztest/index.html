ztest próxima versão

Teste z para a média de uma amostra quando o desvio padrão da população é conhecido, com intervalo de confiança para a média.

Categoria: Probability Distributions and Hypothesis Tests > Hypothesis Tests

Sintaxe

h = ztest(x, m, sigma)

Testa se a média de x é igual a m, dado o desvio padrão populacional sigma.

[h, p, ci, zval] = ztest(x, m, sigma)

Retorna também o valor-p, um intervalo de confiança para a média e a estatística z.

[h, p, ci, zval] = ztest(x, m, sigma, 'Name', Value)

Define 'Alpha', 'Tail' ou 'Dim'.

Descrição

ztest supõe que sigma seja uma constante conhecida. Quando você só tem o desvio padrão amostral, use ttest, que considera essa incerteza adicional.

Um abs(zval) grande significa que a média amostral está longe de m, medida em erros padrão. As opções unilaterais testam se a média é maior ('right') ou menor ('left') que m.

Argumentos de entrada

x
Vetor da amostra. Para uma matriz, cada coluna é testada separadamente.
m
Média hipotética.
sigma
Desvio padrão populacional conhecido, um escalar positivo.
'Alpha'
Nível de significância. O padrão é 0.05.
'Tail'
'both' (padrão), 'right' ou 'left'.
'Dim'
Dimensão ao longo da qual testar uma matriz.

Argumentos de saída

h
0 quando a hipótese nula é mantida, 1 quando é rejeitada.
p
Valor-p.
ci
Intervalo de confiança para a média, em uma coluna com os limites inferior e superior.
zval
Valor da estatística z, (mean(x) - m) / (sigma / sqrt(n)).

Exemplos

Testar uma média com sigma conhecido

a = [4.1 5.2 3.8 6.0 5.5 4.7 5.9 4.4];
[h, p, ci, z] = ztest(a, 5, 1);
fprintf('h = %d, p = %.4f, z = %.4f\n', h, p, z)
fprintf('ci = [%.4f %.4f]\n', ci)
Saída
h = 0, p = 0.8875, z = -0.1414
ci = [4.2570 5.6430]

Teste unilateral à esquerda

a = [4.1 5.2 3.8 6.0 5.5 4.7 5.9 4.4];
[h, p] = ztest(a, 5, 1, 'Tail', 'left');
fprintf('h = %d, p = %.4f\n', h, p)
Saída
h = 0, p = 0.4438

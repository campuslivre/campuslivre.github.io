hypergeom

Função hipergeométrica generalizada.

Categoria: Mathematics > Mathematical Functions

Sintaxe

F = hypergeom(a, b, z)

Avalia pFq com parâmetros de numerador a e de denominador b.

Descrição

A função é a série cuja razão entre termos é uma função racional do índice: sum( prod(pochhammer(a,k)) / prod(pochhammer(b,k)) * z^k / k! ). Muitas funções especiais são casos particulares: hypergeom([], [], z) é exp(z), e com a = [a1 a2], b = c resulta a função de Gauss 2F1. A convergência da série para p = q + 1 exige abs(z) < 1, mas a função é prolongada analiticamente.

Argumentos de entrada

a
Vetor de p parâmetros superiores; pode ser vazio.
b
Vetor de q parâmetros inferiores; pode ser vazio.
z
Argumento, numérico ou simbólico.

Argumentos de saída

F
Array do mesmo tamanho de z.

Exemplo

Função de Gauss e exp

hypergeom([1 2], 3, 0.5)
hypergeom([], [], 1)
exp(1)
Saída

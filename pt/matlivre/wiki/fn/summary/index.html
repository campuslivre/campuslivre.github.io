summary

Imprime um resumo estatístico das variáveis de uma tabela.

Categoria: Language Fundamentals > Data Types

Sintaxe

summary(T)

Mostra o tipo e as principais estatísticas de cada variável de T.

S = summary(T)

Retorna o resumo como um valor em vez de imprimir.

Descrição

Para cada variável, summary informa o tamanho e a classe. Variáveis numéricas também mostram mínimo, mediana e máximo; as categóricas mostram a contagem por categoria. Dá uma visão rápida de um conjunto de dados desconhecido antes da análise.

Use height, width e varfun quando precisar de números individuais, e não de um relatório.

Argumentos de entrada

T
Tabela ou timetable (também arrays categóricos).

Argumentos de saída

S
O resumo, quando uma saída é solicitada.

Exemplo

Resumo de uma tabela

T = table([1;2;3], [4;5;9], 'VariableNames', {'a','b'});
summary(T)
Saída
ans = 
    'Variables:
     
         a: 3×1 double
             Min: 1   Median: 2   Max: 3
         b: 3×1 double
             Min: 4   Median: 5   Max: 9
     '

Observações

O relatório é retornado como um bloco de texto com mínimo, mediana e máximo das variáveis numéricas; seu formato é mais simples que o do MATLAB.

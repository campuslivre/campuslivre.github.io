vartest próxima versão

Teste qui-quadrado de que a variância de uma amostra normal é igual a um valor dado, com intervalo de confiança para a variância.

Categoria: Probability Distributions and Hypothesis Tests > Hypothesis Tests

Sintaxe

h = vartest(x, v)

Testa se a variância de x é igual a v.

[h, p, ci, stats] = vartest(x, v)

Retorna também o valor-p, um intervalo de confiança para a variância e as estatísticas do teste.

[h, p, ci, stats] = vartest(x, v, 'Name', Value)

Define 'Alpha', 'Tail' ou 'Dim'.

Descrição

A estatística é (n-1)*s^2/v, comparada com uma distribuição qui-quadrado com n-1 graus de liberdade. O teste é sensível a desvios da normalidade, então verifique os dados antes.

O intervalo ci é para a variância, não para o desvio padrão: tire a raiz quadrada dos limites se quiser um intervalo para o desvio padrão.

Argumentos de entrada

x
Vetor da amostra. Para uma matriz, cada coluna é testada separadamente.
v
Variância hipotética, um escalar positivo.
'Alpha'
Nível de significância. O padrão é 0.05.
'Tail'
'both' (padrão), 'right' ou 'left'.
'Dim'
Dimensão ao longo da qual testar uma matriz.

Argumentos de saída

h
0 quando a hipótese nula é mantida, 1 quando é rejeitada.
p
Valor-p.
ci
Intervalo de confiança para a variância, em uma coluna com os limites inferior e superior.
stats
Estrutura com chisqstat (a estatística) e df (graus de liberdade).

Exemplos

A variância é igual a 1?

a = [4.1 5.2 3.8 6.0 5.5 4.7 5.9 4.4];
[h, p, ci, st] = vartest(a, 1);
fprintf('h = %d, p = %.4f, chi2 = %.4f, df = %d\n', h, p, st.chisqstat, st.df)
fprintf('ci = [%.4f %.4f]\n', ci)
Saída
h = 0, p = 0.6264, chi2 = 4.7800, df = 7
ci = [0.2985 2.8286]

Teste unilateral

a = [4.1 5.2 3.8 6.0 5.5 4.7 5.9 4.4];
[h, p] = vartest(a, 1, 'Tail', 'right', 'Alpha', 0.1);
fprintf('h = %d, p = %.4f\n', h, p)
Saída
h = 0, p = 0.6868

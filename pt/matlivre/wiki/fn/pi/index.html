pi

A constante pi, razão entre a circunferência de um círculo e seu diâmetro.

Categoria: Mathematics > Elementary Math

Sintaxe

x = pi

Retorna o valor em precisão dupla mais próximo de pi, 3.141592653589793.

X = pi(n)

Retorna uma matriz n-por-n em que todo elemento é pi.

X = pi(sz1, ..., szN)

Retorna um array do tamanho dado em que todo elemento é pi.

Descrição

pi é uma função, não uma constante verdadeira, mas em uso normal não recebe argumentos e é escrita sem parênteses. É uma aproximação em ponto flutuante: sin(pi) vale cerca de 1.2246e-16, não zero, porque o próprio pi é ligeiramente impreciso. Quando resultados exatos em múltiplos de pi importam, use as funções em graus (sind, cosd) ou sinpi e cospi.

Como pi pode ser sobrescrita ao atribuir uma variável com esse nome, evite usá-la como variável.

Argumentos de entrada

n, sz1, ..., szN
Dimensões opcionais do resultado.

Argumentos de saída

x
Valor double ou array preenchido com pi.

Exemplo

Área, conversão de ângulo e erro de arredondamento

r = 2;
area = pi * r^2
rad2deg(pi/3)
sin(pi)
sinpi(1)
Saída
area = 12.5664
ans = 60.0000
ans = 1.2246e-16
ans = 0

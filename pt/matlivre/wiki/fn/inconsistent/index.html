inconsistent próxima versão

Calcula o coeficiente de inconsistência de cada ligação de uma árvore de clusters hierárquica, comparando sua altura com a das ligações vizinhas.

Categoria: Cluster Analysis and Anomaly Detection > Hierarchical Clustering

Sintaxe

Y = inconsistent(Z)

Usa cada ligação e as ligações abaixo dela até a profundidade 2.

Y = inconsistent(Z, d)

Olha d níveis para baixo na árvore.

Descrição

O coeficiente de uma ligação diz quanto a altura dela se afasta da altura média das ligações logo abaixo, em unidades do desvio padrão delas. Uma ligação que une clusters muito diferentes tem coeficiente alto, o que a torna um bom ponto para cortar a árvore. Uma ligação entre duas observações isoladas tem coeficiente 0 porque não há com o que comparar.

Use o resultado com cluster e sua opção 'cutoff', ou use clusterdata, para cortar a árvore por inconsistência.

Argumentos de entrada

Z
Matriz de ligação de linkage, com m-1 linhas.
d
Profundidade: quantos níveis da árvore abaixo de cada ligação entram no cálculo. O padrão é 2.

Argumentos de saída

Y
Matriz com m-1 linhas e quatro colunas: altura média das ligações consideradas, desvio padrão, quantas ligações foram usadas e o coeficiente de inconsistência.

Exemplos

Profundidade padrão 2

X = [1 2; 1.3 1.8; 0.8 2.4; 5 5; 5.5 4.9; 4.6 5.3; 9 1; 9.2 1.5];
Z = linkage(pdist(X), 'average');
I = inconsistent(Z);
disp(round(I*1000)/1000)

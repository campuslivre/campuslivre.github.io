gettsafteratevent

Parte de uma timeseries a partir de um evento, incluindo o instante do evento.

Categoria: Language Fundamentals > Data Types

Sintaxe

tsout = gettsafteratevent(ts, event)

Retorna as amostras no instante do evento ou depois dele, nomeado por event (ou seu índice).

Descrição

Os eventos são adicionados com addevent. O resultado é uma nova timeseries; seus Time e Data guardam as amostras selecionadas. São mantidas as amostras cujo tempo é igual ou maior que o do evento. Compare com gettsafterevent, que mantém apenas amostras estritamente posteriores.

Argumentos de entrada

ts
timeseries com ao menos um evento.
event
Nome do evento como texto, ou o índice do evento.

Argumentos de saída

tsout
timeseries com as amostras selecionadas.

Exemplo

Amostras a partir de um evento

ts = timeseries((10:10:50)', (0:4)');
ts = addevent(ts, 'start', 1.5);
ts = addevent(ts, 'stop', 3.5);
r = gettsafteratevent(ts, 'start');
disp(r.Time')
disp(r.Data')
Saída
     2     3     4
    30    40    50

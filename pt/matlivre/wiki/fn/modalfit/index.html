modalfit

Identifica frequências naturais, razões de amortecimento e formas modais a partir de uma função de resposta em frequência pelo método LSCE.

Categoria: Vibration analysis

Sintaxe

[fn, dr] = modalfit(frf, f, fs, mnum)

Frequências naturais e razões de amortecimento de mnum modos.

[fn, dr, ms] = modalfit(frf, f, fs, mnum)

Retorna também as formas modais.

[fn, dr, ms, ofrf] = modalfit(frf, f, fs, mnum)

Retorna também a FRF reconstruída a partir dos modos identificados.

Descrição

A FRF é convertida em resposta ao impulso por uma FFT inversa, um modelo de predição linear (Prony) é ajustado às primeiras amostras, e os polos desse modelo fornecem as frequências naturais e as razões de amortecimento. Os resíduos são então obtidos por mínimos quadrados contra a FRF.

O ajuste pode ser ruim quando mnum é pequeno demais para os dados: no exemplo, dois modos precisam de mnum = 3 para serem bem encontrados, e a entrada extra é NaN. Compare sempre ofrf com frf, ou tente um mnum maior.

Argumentos de entrada

frf
Função de resposta em frequência, um vetor coluna complexo com um valor por frequência (de 0 até fs/2), como o produzido por modalfrf.
f
Frequências de frf em hertz, igualmente espaçadas a partir de 0.
fs
Taxa de amostragem em hertz.
mnum
Número de modos a ajustar, um inteiro positivo.

Argumentos de saída

fn
Frequências naturais em hertz, uma coluna com mnum entradas. Entradas não encontradas são NaN.
dr
Razões de amortecimento, do mesmo tamanho de fn.
ms
Formas modais, uma linha para a FRF única e uma coluna por modo.
ofrf
FRF sintetizada a partir dos modos identificados, com o mesmo tamanho de frf. Compare-a com frf para avaliar o ajuste.

Exemplo

Dois modos em 50 Hz e 120 Hz

fs = 1000; N = 512; f = (0:N/2)'*fs/N; w = 2*pi*f;
H = zeros(size(f));
w1 = 2*pi*50;  H = H + 1  ./(w1^2 - w.^2 + 2i*0.02*w1*w);
w2 = 2*pi*120; H = H + 0.5./(w2^2 - w.^2 + 2i*0.03*w2*w);
[fn, dr, ms, ofrf] = modalfit(H, f, fs, 3);
disp(round(fn'*10)/10)
disp(round(dr'*100)/100)
fprintf('relative fit error %.2f\n', max(abs(ofrf - H))/max(abs(H)));
Saída
    50   120   NaN
    0.0200    0.0300       NaN
relative fit error 0.03

Observações

Só o método LSCE sobre uma única FRF está implementado: 'FitMethod' 'lsrf' e 'pp', 'FreqRange' e várias FRFs ao mesmo tempo geram erro. As formas modais ms concordam com o MATLAB até cerca de 1e-5 quando o ajuste é bom e podem diferir quando é ruim, e com 'PhysFreq' o MATLAB reajusta as formas para os modos selecionados, o que não é feito aqui. Entradas em precisão simples são resolvidas em precisão dupla (diferenças próximas de 1e-5).

tfridge

Encontra as cristas de um mapa tempo-frequência, as curvas de maior energia ao longo do tempo, com uma penalidade opcional para saltos de frequência.

Categoria: Time-frequency analysis

Sintaxe

[fridge, iridge] = tfridge(tfm, f)

Encontra a crista mais forte.

[fridge, iridge] = tfridge(tfm, f, penalty)

Penaliza saltos de frequência entre colunas vizinhas.

[fridge, iridge, lridge] = tfridge(___, 'NumRidges', nr)

Encontra nr cristas; lridge guarda os índices lineares delas.

Descrição

Uma crista é o caminho de um componente cuja frequência varia com o tempo, como um chirp ou o harmônico de uma máquina rotativa. tfridge a encontra por programação dinâmica: escolhe, coluna a coluna, o caminho que reúne mais energia pagando um preço por grandes saltos de frequência.

Uma penalidade 0 apenas toma o máximo de cada coluna, o que pode saltar no ruído. Aumentar a penalidade deixa o caminho mais suave. Combine iridge com ifsst para extrair o componente como sinal.

Argumentos de entrada

tfm
Mapa tempo-frequência, uma matriz real com a frequência nas linhas e o tempo nas colunas, por exemplo abs(s) de spectrogram ou stft. A crista segue o máximo, então maior significa mais energia.
f
Frequência de cada linha de tfm.
penalty
Escalar não negativo. Cada salto de d linhas entre colunas vizinhas custa penalty*d^2. Padrão: 0, que apenas escolhe o maior valor de cada coluna.
'NumRidges'
Número de cristas a extrair. Depois de cada uma, as linhas a até 'NumFrequencyBins' dela são zeradas. Padrão: 1.
'NumFrequencyBins'
Linhas zeradas de cada lado de uma crista extraída antes da busca seguinte. Padrão: 4.

Argumentos de saída

fridge
Frequências das cristas, uma linha por coluna de tempo de tfm e uma coluna por crista.
iridge
Índice de linha da crista em cada coluna, com o mesmo tamanho de fridge.
lridge
Índice linear de cada ponto da crista em tfm.

Exemplo

Seguir um chirp em um espectrograma

fs = 1000; t = (0:511)'/fs;
x = cos(2*pi*(50*t + 100*t.^2));
[s, f, tt] = spectrogram(x, hann(64), 48, 64, fs);
[fr, ir] = tfridge(abs(s), f);
disp(size(fr))
disp(round(fr(1:4:end)'))
disp(round(50 + 200*tt(1:4:end)))
Saída
    29     1
    63    63    78    94   109   125   141   141
    56    69    82    95   108   120   133   146

firpmord

Estima a ordem, as bordas de banda, as amplitudes e os pesos a passar para firpm a partir de um conjunto de tolerâncias.

Categoria: FIR design

Sintaxe

[n,fo,ao,w] = firpmord(f,a,dev)

Estima os parâmetros para frequências normalizadas.

[n,fo,ao,w] = firpmord(f,a,dev,fs)

Recebe as frequências em hertz para a taxa de amostragem fs.

Descrição

firpmord transforma uma especificação (bordas e tolerâncias) nos argumentos de firpm. A ordem é uma estimativa, então verifique a resposta do filtro obtido: se ele não cumprir a tolerância, aumente n em um ou dois e projete de novo.

Os pesos devolvidos são inversamente proporcionais às tolerâncias, então uma tolerância menor recebe um peso maior.

Argumentos de entrada

f
Bordas de banda: as bordas vizinhas de cada par de bandas adjacentes, sem incluir 0 e a frequência de Nyquist.
a
Amplitude desejada em cada banda, um valor por banda (por exemplo [1 0] para um passa-baixas).
dev
Maior desvio permitido em cada banda, como valor linear.
fs
Taxa de amostragem. Padrão: 2, de modo que f fica normalizada.

Argumentos de saída

n
Ordem estimada do filtro.
fo
Bordas de banda normalizadas, incluindo 0 e 1, para passar a firpm.
ao
Amplitudes nas bordas fo, para passar a firpm.
w
Peso de cada banda, para passar a firpm.

Exemplo

Passa-baixas para taxa de 8 kHz

[n,fo,ao,w] = firpmord([1500 2000],[1 0],[0.01 0.001],8000);
fprintf('order %d\n', n);
disp(fo.')
disp(ao.')
disp(round(w.'*1000)/1000)
b = firpm(n,fo,ao,w);
fprintf('%d coefficients\n', numel(b));
Saída
order 40
         0    0.3750    0.5000    1.0000
     1     1     0     0
     1    10
41 coefficients

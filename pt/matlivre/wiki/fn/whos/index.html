whos

Lista as variáveis do workspace com tamanho, memória e classe.

Categoria: Language Fundamentals > Data Types

Sintaxe

whos

Imprime uma tabela com todas as variáveis do workspace atual.

whos name1 name2

Lista apenas as variáveis indicadas; curingas como a* são permitidos.

s = whos(___)

Retorna um array de structs com um elemento por variável, em vez de imprimir.

Descrição

whos é a forma longa de who. Para cada variável mostra as dimensões, o armazenamento em bytes, a classe e atributos como complex. Chamado com uma saída, retorna as mesmas informações como dados, útil para scripts que inspecionam o workspace.

Dentro de uma função, a listagem se refere ao workspace da própria função.

Argumentos de entrada

name
Nome de variável ou padrão com curinga *.

Argumentos de saída

s
Array de structs com os campos name, size, bytes, class, global, sparse, complex, nesting e persistent.

Exemplos

Inspecionar variáveis escolhidas

x = 1:3;
y = 'hi';
z = int8([1 2; 3 4]);
whos x y z
Saída
  Name      Size            Bytes  Class     Attributes

  x         1x3                24  double    
  y         1x2                 4  char      
  z         2x2                 4  int8

Obter os dados como struct

a = ones(3, 4, 'single');
info = whos('a');
info.size
info.bytes
info.class
Saída
ans = 1×2

     3     4
ans = 48
ans = 'single'

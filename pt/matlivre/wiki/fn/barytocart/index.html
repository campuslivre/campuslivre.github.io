baryToCart

Forma antiga de barycentricToCartesian para objetos TriRep e DelaunayTri.

Categoria: Mathematics > Computational Geometry

Sintaxe

C = baryToCart(TR, T, B)

Converte as coordenadas baricêntricas B nos simplexes T em pontos cartesianos.

Descrição

baryToCart faz a soma ponderada dos vértices do simplex que define as coordenadas baricêntricas, exatamente como barycentricToCartesian faz para as classes novas. Foi mantida para código escrito para a API antiga TriRep e DelaunayTri.

Código novo deve usar delaunayTriangulation e barycentricToCartesian.

Argumentos de entrada

TR
Um objeto DelaunayTri ou TriRep.
T
Vetor coluna de índices de simplexes.
B
Coordenadas baricêntricas, uma linha por simplex em T.

Argumentos de saída

C
Coordenadas cartesianas, uma linha por linha de B.

Exemplo

Ponto baricêntrico para cartesiano

x = [0 1 1 0 0.5]';
y = [0 0 1 1 0.5]';
DL = DelaunayTri(x, y);
c = baryToCart(DL, 1, [0.2 0.3 0.5])
Saída
c = 1×2

    0.9000    0.6000

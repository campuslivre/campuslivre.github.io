deg2rad

Converte ângulos de graus para radianos.

Categoria: Mathematics > Elementary Math

Sintaxe

Y = deg2rad(X)

Multiplica cada elemento de X por pi/180.

Descrição

deg2rad(X) equivale a X*pi/180. A inversa é rad2deg. Lembre que sin, cos e tan esperam radianos, enquanto sind, cosd e tand esperam graus.

Argumentos de entrada

X
Array numérico de qualquer tamanho.

Argumentos de saída

Y
Array do mesmo tamanho de X, em radianos.

Exemplo

Graus para radianos

deg2rad([0 90 180 360])
Saída
ans = 1×4

         0    1.5708    3.1416    6.2832

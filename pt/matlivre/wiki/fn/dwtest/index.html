dwtest próxima versão

Teste de Durbin-Watson para autocorrelação de primeira ordem nos resíduos de uma regressão linear.

Categoria: Probability Distributions and Hypothesis Tests > Hypothesis Tests

Sintaxe

p = dwtest(r, X)

Retorna o valor-p para o vetor de resíduos r de uma regressão com matriz de projeto X.

[p, dw] = dwtest(r, X)

Retorna também a estatística de Durbin-Watson.

[p, dw] = dwtest(r, X, method)

Escolhe 'exact' ou 'approximate' para o valor-p.

[p, dw] = dwtest(r, X, 'Method', method, 'Tail', tail)

Define o método e a hipótese alternativa com pares nome-valor.

Descrição

Os mínimos quadrados ordinários supõem que os erros não são correlacionados entre si. A estatística de Durbin-Watson compara cada resíduo com o anterior, então só faz sentido quando as observações têm uma ordem natural, como o tempo.

Passe os resíduos e a mesma matriz de projeto usada no ajuste, pois a distribuição da estatística sob a hipótese nula depende de X.

Argumentos de entrada

r
Resíduos da regressão, um vetor com um valor por observação, em ordem temporal.
X
Matriz de projeto da regressão, com uma linha por observação. Inclua uma coluna de uns se o modelo tiver intercepto.
'Method'
'exact' ou 'approximate'. O padrão é 'exact' com menos de 400 observações e 'approximate' caso contrário.
'Tail'
Hipótese alternativa: 'both' (padrão), 'right' para autocorrelação positiva ou 'left' para autocorrelação negativa.

Argumentos de saída

p
Valor-p do teste.
dw
Estatística de Durbin-Watson, entre 0 e 4. Valores perto de 2 indicam ausência de autocorrelação de primeira ordem, valores perto de 0 indicam autocorrelação positiva e valores perto de 4 indicam autocorrelação negativa.

Exemplos

Resíduos com uma tendência restante

t = (1:20)';
y = 2 + 0.5*t + sin(0.7*t);
X = [ones(20,1) t];
r = y - X*(X\y);
[p, dw] = dwtest(r, X);
fprintf('dw = %.4f, p = %.2g\n', dw, p);
Saída
dw = 0.4292, p = 1.1e-06

Resíduos que alternam de sinal

t = (1:20)';
e = [0.3 -0.2 0.4 -0.5 0.1 -0.3 0.5 -0.1 0.2 -0.4 0.3 -0.2 0.4 -0.3 0.1 -0.5 0.2 0.3 -0.2 0.1]';
X = [ones(20,1) t];
y = 2 + 0.5*t + e;
r = y - X*(X\y);
[p, dw] = dwtest(r, X, 'approximate');
fprintf('dw = %.4f, p = %.4f\n', dw, p);
Saída
dw = 3.3102, p = 0.0043

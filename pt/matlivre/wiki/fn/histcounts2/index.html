histcounts2

Conta quantos pares de valores caem em cada intervalo bidimensional.

Categoria: Data Import and Analysis > Preprocessing Data

Sintaxe

[N, xedges, yedges] = histcounts2(X, Y)

Distribui os pares (X, Y) em intervalos automáticos.

N = histcounts2(X, Y, nbins)

Usa nbins intervalos em cada direção.

N = histcounts2(X, Y, xedges, yedges)

Usa as bordas fornecidas para cada eixo.

Descrição

histcounts2 é a versão bidimensional de histcounts. A primeira dimensão do resultado segue X e a segunda segue Y. A mesma regra de intervalo fechado à esquerda e aberto à direita vale para cada eixo, e os pontos fora das bordas são ignorados.

As contagens servem para distribuições conjuntas, mapas de densidade e para ver como duas variáveis variam juntas.

Argumentos de entrada

X, Y
Arrays numéricos do mesmo tamanho; o elemento k de cada um forma o ponto k.
xedges, yedges
Vetores crescentes de bordas dos intervalos.

Argumentos de saída

N
Matriz de contagens; N(i,j) conta os pontos com X no intervalo i e Y no intervalo j.
xedges, yedges
As bordas usadas em cada eixo.

Exemplo

Contando pontos em células

x = [1 2 3 3];
y = [1 2 3 1];
N = histcounts2(x, y, [0 2 4], [0 2 4])
Saída
N = 2×2

     1     0
     1     2

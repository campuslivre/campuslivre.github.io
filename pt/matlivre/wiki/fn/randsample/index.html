randsample próxima versão

Amostra aleatória de inteiros de 1 a n ou dos elementos de um vetor, com ou sem reposição e opcionalmente com pesos.

Categoria: Probability Distributions and Hypothesis Tests > Resampling Techniques

Sintaxe

y = randsample(n, k)

k inteiros distintos de 1:n, sem reposição.

y = randsample(population, k)

k elementos do vetor population, sem reposição.

y = randsample(n, k, replace)

Com replace verdadeiro, sorteia com reposição.

y = randsample(n, k, true, w)

Sorteia com reposição usando os pesos w.

Descrição

randsample(n, k) é um jeito rápido de escolher um subconjunto aleatório de índices, por exemplo para dividir os dados em treino e teste. Sortear com reposição é a base do bootstrap.

Com um vetor de pesos, um elemento de peso 2 tem o dobro da chance de ser sorteado de um de peso 1. Os pesos só são comparados entre si.

Argumentos de entrada

n
Inteiro positivo: a população é 1:n.
population
Vetor numérico de onde sortear.
k
Quantidade de valores a sortear. Sem reposição, não pode exceder o tamanho da população.
replace
true para sortear com reposição, false (padrão) sem reposição.
w
Pesos não negativos, um por elemento da população, proporcionais à chance de cada um.

Argumentos de saída

y
Vetor coluna com os k valores sorteados.

Exemplos

Quatro índices distintos

r = randsample(10, 4);
fprintf('size %d x %d, distinct %d, in range %d\n', size(r), numel(unique(r)), all(r >= 1 & r <= 10))
Saída
size 4 x 1, distinct 4, in range 1

Sorteio com pesos e com reposição

r = randsample(5, 6, true, [0 0 1 0 0]);
disp(r')
Saída
     3     3     3     3     3     3

Observações

Os resultados vêm do gerador de números aleatórios do próprio MatLivre, então os números não coincidem com os do MATLAB para a mesma semente. Pesos junto com sorteio sem reposição não são suportados e geram um erro. Um vetor de caracteres como population retorna os códigos dos caracteres em uma coluna do tipo double, não caracteres.

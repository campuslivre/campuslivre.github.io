pagemtimes

Multiplicação de matrizes página a página para arrays N-D.

Categoria: Language Fundamentals > Operators and Elementary Operations

Sintaxe

C = pagemtimes(A, B)

Multiplica cada página A(:,:,k) pela página correspondente B(:,:,k).

C = pagemtimes(A, transpA, B, transpB)

Transpõe as páginas antes. Os modos são 'none', 'transpose' ou 'ctranspose'.

Descrição

É um A*B em lote: para entrada 3-D equivale a um laço C(:,:,k) = A(:,:,k) * B(:,:,k), mas em uma só chamada. Uma dimensão de página de tamanho 1 é reutilizada em todas as páginas, então uma única matriz pode multiplicar toda uma pilha.

É útil para girar muitos pontos com a mesma matriz, ou calcular muitos produtos pequenos de uma vez.

Argumentos de entrada

A, B
Arrays numéricos cujas páginas são conformes para multiplicação de matrizes. As dimensões além da segunda devem coincidir ou valer 1.
transpA, transpB
Operação aplicada a cada página antes de multiplicar.

Argumentos de saída

C
Array com size(C,1) = size(A,1) e size(C,2) = size(B,2), com os produtos página a página.

Exemplo

A = cat(3, [1 2; 3 4], [0 1; 1 0]);
B = cat(3, [1 0; 0 1], [2 3; 4 5]);
C = pagemtimes(A, B);
C(:, :, 1)
C(:, :, 2)
size(pagemtimes(ones(2, 3, 4), ones(3, 5, 4)))
Saída
ans = 2×2

     1     2
     3     4
ans = 2×2

     4     5
     2     3
ans = 1×3

     2     5     4

wbllike próxima versão

Log-verossimilhança negativa de um modelo de Weibull para os dados, com a covariância assintótica das estimativas.

Categoria: Probability Distributions and Hypothesis Tests > Univariate Continuous Distributions

Sintaxe

nll = wbllike(params, data)

Log-verossimilhança negativa em params = [a b].

[nll, avar] = wbllike(params, data)

Retorna também a matriz de covariância aproximada.

[nll, avar] = wbllike(params, data, censoring, freq)

Com observações censuradas e frequências.

Descrição

wbllike avalia o quanto um modelo de Weibull dado se ajusta aos dados, o que serve para comparar parâmetros candidatos ou montar testes da razão de verossimilhanças. Nas estimativas de máxima verossimilhança de wblfit o valor é o menor possível.

A covariância faz sentido quando params são as estimativas ajustadas.

Argumentos de entrada

params
Vetor de dois elementos [a b]: escala e forma, ambas positivas.
data
Vetor de observações não negativas.
censoring
Vetor do mesmo tamanho de data: 1 para censurada, 0 para observada.
freq
Vetor de contagens de cada observação.

Argumentos de saída

nll
Log-verossimilhança negativa. Quanto menor, melhor os parâmetros explicam os dados.
avar
Matriz de covariância aproximada 2 por 2 das estimativas de escala e forma, obtida da inversa da matriz de informação em params.

Exemplo

Verossimilhança nos parâmetros ajustados

w = [1.2 2.3 0.8 3.1 1.9 2.7 1.5 2.2];
p = wblfit(w);
[nll, avar] = wbllike(p, w);
fprintf('%.4f\n', nll)
disp(round(avar*10000)/10000)
Saída
8.5870
    0.0716    0.0731
    0.0731    0.7742

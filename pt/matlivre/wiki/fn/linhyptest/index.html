linhyptest próxima versão

Testa uma hipótese linear H*b = c sobre coeficientes estimados, dada a sua covariância, e retorna um valor-p.

Categoria: Regression > Linear Regression > Multiple Linear Regression

Sintaxe

p = linhyptest(b, covb, c, h)

Teste qui-quadrado de h*b = c.

[p, t, r] = linhyptest(b, covb, c, h, dfe)

Teste F com dfe graus de liberdade do erro; retorna também a estatística e o posto.

Descrição

Com h = [1 -1] e c = 0, você testa se dois coeficientes são iguais; com h = eye(p) e c = zeros(p,1), testa se todos são zero. Um p pequeno indica que os dados contradizem a hipótese.

Os coeficientes e sua covariância vêm de um modelo ajustado, por exemplo mdl.Coefficients.Estimate e mdl.CoefficientCovariance, com mdl.DFE como dfe.

Argumentos de entrada

b
Vetor de p coeficientes estimados.
covb
Matriz de covariância p por p das estimativas.
c
Vetor (ou escalar) de valores hipotéticos, um por linha de h.
h
Matriz de hipótese com p colunas. Cada linha é uma combinação linear dos coeficientes.
dfe
Graus de liberdade do erro. Se omitido, usa-se um teste qui-quadrado em vez de um teste F.

Argumentos de saída

p
Valor-p da hipótese.
t
Estatística do teste: qui-quadrado sem dfe, F com ele.
r
Posto de h, o número de restrições independentes testadas.

Exemplos

Testar se dois coeficientes são iguais

b = [1; 2];
C = [1 0.2; 0.2 2];
[p, t, r] = linhyptest(b, C, 0, [1 -1]);
fprintf('p = %.4f, chi2 = %.4f, rank = %d\n', p, t, r)
Saída
p = 0.5351, chi2 = 0.3846, rank = 1

Testar uma reta ajustada contra intercepto 0 e inclinação 2

x = (1:8)';
y = [2.1 3.9 6.2 7.8 10.1 12.2 13.8 16.1]';
m = fitlm(x, y);
[p, t, r] = linhyptest(m.Coefficients.Estimate, m.CoefficientCovariance, [0; 2], eye(2), m.DFE);
fprintf('p = %.4f, F = %.4f, rank = %d\n', p, t, r)
Saída
p = 0.9235, F = 0.0807, rank = 2

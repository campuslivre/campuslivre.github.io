Category names follow the MATLAB function reference. A function listed here runs with MATLAB’s semantics, display format and error messages, checked against MATLAB R2023b. Language keywords (if, for, while, switch, try, classdef, function and so on) are part of the language and not listed.

Uma função listada aqui executa com a semântica, o formato de exibição e as mensagens de erro do MATLAB, conferidos contra o MATLAB R2023b. As palavras-chave da linguagem (if, for, while, switch, try, classdef, function e outras) fazem parte da linguagem e não aparecem na lista.

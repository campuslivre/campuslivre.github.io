Getting started

MatLivre runs on Windows 10 and 11. Download the installer or the portable ZIP from the download section. The installer needs no administrator rights and keeps itself up to date from the project’s GitHub releases. The ZIP runs from any folder: unzip it and start MatLivre.exe. If Windows shows a warning about an unknown publisher, see Troubleshooting.

Your first live script

  1. Start MatLivre. It opens an empty live script named untitled.mlx.
  2. Click in the code area and type a few lines, for example:
x = linspace(0, 2*pi, 200);
plot(x, sin(x))
title('Sine')
  1. Press Ctrl+Enter to run the current section. The figure appears right below the code. Press F5 to run the whole script.
  2. Open … › Getting started for a sample live script with text, tables, plots and functions, ready to run and edit.

Statements without a semicolon show their value, exactly as in MATLAB.

16 functions in MATLAB › Graphics > Images.

16 funções em MATLAB › Graphics > Images.

cmap2grayConverts a colormap to grayscale.Converte um mapa de cores para tons de cinza.
cmpermuteReorders the colors of a colormap and updates the indexed image to match.Reordena as cores de um mapa de cores e atualiza a imagem indexada para combinar.
cmuniqueRemoves duplicate colors from a colormap and reindexes the image.Remove cores repetidas de um mapa de cores e reindexa a imagem.
ditherConverts an image to fewer colors using error-diffusion dithering.Converte uma imagem para menos cores usando dithering por difusão de erro.
getrangefromclassReturns the minimum and maximum values of an image's data class.Retorna os valores mínimo e máximo da classe de dados de uma imagem.
im2doubleConverts an image to class double, rescaling integer data to the range 0 to 1.Converte uma imagem para a classe double, reescalando dados inteiros para o intervalo de 0 a 1.
im2grayConverts an RGB image to grayscale, leaving grayscale images as they are.Converte uma imagem RGB para tons de cinza, mantendo as imagens que já são cinza.
imageDisplays an array as an image, with each value taken as a colormap index or a color.Exibe um array como imagem, com cada valor tomado como índice do mapa de cores ou como cor.
imagescDisplays a matrix as an image with values scaled to the full colormap.Exibe uma matriz como imagem com os valores escalados para todo o mapa de cores.
imformatsLists the image file formats that can be read and written.Lista os formatos de arquivo de imagem que podem ser lidos e gravados.
imresizeResizes an image by a scale factor or to a given size.Redimensiona uma imagem por um fator de escala ou para um tamanho dado.
imshowDisplays an image with the right scale, colormap and aspect ratio.Exibe uma imagem com a escala, o mapa de cores e a proporção adequados.
imtileCombines several images into one tiled image.Combina várias imagens em uma única imagem em mosaico.
ind2rgbConverts an indexed image and its colormap to an RGB image.Converte uma imagem indexada e seu mapa de cores em uma imagem RGB.
rgb2grayConverts an RGB image or a colormap to grayscale.Converte uma imagem RGB ou um mapa de cores para tons de cinza.
rgb2indConverts an RGB image to an indexed image using a given colormap.Converte uma imagem RGB em imagem indexada usando um mapa de cores dado.

Probability Distributions and Hypothesis Tests > Hypothesis Tests

18 functions in Statistics and Machine Learning Toolbox › Probability Distributions and Hypothesis Tests > Hypothesis Tests.

ansaribradley next releaseAnsari-Bradley two-sample test that two samples come from distributions with the same dispersion, with no assumption of normality about the shape.
barttest next releaseBartlett's test for the number of dimensions of a data set: tests whether the smallest principal components can be treated as having equal variance.
dwtest next releaseDurbin-Watson test for first-order autocorrelation in the residuals of a linear regression.
fishertest next releaseFisher's exact test for a 2-by-2 contingency table: tests whether the two categorical variables are independent.
friedman next releaseFriedman's nonparametric test for differences among columns (treatments) of a matrix, with rows as blocks.
jbtest next releaseJarque-Bera test of whether a sample comes from a normal distribution, based on its skewness and kurtosis.
kruskalwallis next releaseKruskal-Wallis test: a nonparametric one-way test of whether several groups come from the same distribution.
kstest next releaseOne-sample Kolmogorov-Smirnov test: compares the empirical distribution of a sample with a reference distribution (standard normal by default).
kstest2 next releaseTwo-sample Kolmogorov-Smirnov test: tests whether two samples come from the same continuous distribution.
lillietest next releaseLilliefors test of whether a sample comes from a normal, exponential or extreme value distribution with parameters estimated from the data.
ranksum next releaseWilcoxon rank sum test (Mann-Whitney U): a nonparametric test of whether two independent samples have equal medians.
runstest next releaseRuns test for randomness: checks whether the sequence of values above and below a threshold looks random.
signrank next releaseWilcoxon signed rank test: a nonparametric test that paired differences (or one sample) have a median of zero.
signtest next releaseSign test for a paired sample or for a median: tests whether the median of the differences, or of one sample, equals zero or a given value.
vartest next releaseChi-square test that the variance of a normal sample equals a given value, with a confidence interval for the variance.
vartest2 next releaseF test that two normal samples have the same variance, with a confidence interval for the ratio of variances.
vartestn next releaseTests whether several groups have the same variance (Bartlett by default, or one of the Levene-type tests).
ztest next releaseZ test for the mean of a sample when the standard deviation of the population is known, with a confidence interval for the mean.

Boundary Value Problems

bvp4cSolves boundary value problems for ordinary differential equations.
bvp5cSolves boundary value problems with a fourth-order method that controls the true error.
bvpgetReads a named option from a boundary value problem options structure.
bvpinitBuilds the initial mesh and guess for a boundary value problem solver.
bvpsetCreates or updates the options structure used by the boundary value problem solvers.
bvpxtendExtends a boundary value problem solution to a new interval end.

Delay Differential Equations

dde23Solves delay differential equations with constant delays.
ddegetReads a named option from a delay differential equation options structure.
ddensdSolves neutral delay differential equations with state-dependent delays.
ddesdSolves delay differential equations with time- or state-dependent delays.

Ordinary Differential Equations

decicFinds consistent initial conditions for a fully implicit differential equation.
devalEvaluates a differential equation solution structure at given points.
ode113Variable-order Adams-Bashforth-Moulton solver for nonstiff differential equations.
ode15iVariable-order solver for fully implicit differential equations f(t, y, y') = 0.
ode15sVariable-order solver for stiff differential equations and index-1 algebraic systems.
ode23Low-order Runge-Kutta solver for nonstiff differential equations.
ode23sOne-step solver for stiff differential equations, based on a modified Rosenbrock formula.
ode23tTrapezoidal-rule solver for moderately stiff equations and differential-algebraic systems.
ode23tbTR-BDF2 solver for stiff differential equations at crude tolerances.
ode45Default Runge-Kutta solver for nonstiff ordinary differential equations.
ode78Seventh- and eighth-order Runge-Kutta solver for nonstiff equations with tight tolerances.
ode89Eighth- and ninth-order Runge-Kutta solver for nonstiff equations with very tight tolerances.

Define Classes

addlistenerAttaches a callback to an event or property change of a handle object.Associa um callback a um evento ou a uma mudança de propriedade de um objeto handle.
enumerationLists the members of an enumeration class.Lista os membros de uma classe de enumeração.
eqEquality test, the function form of the == operator.Teste de igualdade, a forma em função do operador ==.
event.hasListenerTests whether an event of an object has listeners.Testa se um evento de um objeto tem listeners.
eventsLists the events defined by a class.Lista os eventos definidos por uma classe.
importAdds a package or class name to the import list so it can be used with a short name.Adiciona um nome de pacote ou classe à lista de importação para poder usá-lo com um nome curto.
ismethodTests whether an object has a method of a given name.Testa se um objeto tem um método com determinado nome.
ispropTests whether an object has a property of a given name.Testa se um objeto tem uma propriedade com determinado nome.
listenerCreates an event listener without attaching it to the life of the source object.Cria um listener de evento sem prendê-lo à vida do objeto de origem.
methodsLists the methods of a class or object.Lista os métodos de uma classe ou objeto.
notifyTriggers an event of a handle object and runs the listeners attached to it.Dispara um evento de um objeto handle e executa os listeners ligados a ele.
propertiesLists the public properties of a class or object.Lista as propriedades públicas de uma classe ou objeto.
superclassesLists the superclasses of a class, from the nearest to the farthest.Lista as superclasses de uma classe, da mais próxima à mais distante.

Class Customization

builtinCalls the built-in version of a function, ignoring any overriding file.Chama a versão embutida de uma função, ignorando qualquer arquivo que a substitua.
numArgumentsFromSubscriptMethod a class can overload to say how many outputs an indexing expression returns.Método que uma classe pode sobrecarregar para dizer quantas saídas uma expressão de indexação retorna.
subsasgnAssignment through an index structure, the function behind A(i) = v, A.f = v and A{i} = v.Atribuição por meio de uma estrutura de índices, a função por trás de A(i) = v, A.f = v e A{i} = v.
subsindexMethod a class overloads so that its objects can be used as array indices.Método que uma classe sobrecarrega para que seus objetos possam servir de índices de array.
subsrefReads through an index structure, the function behind A(i), A.f and A{i}.Lê por meio de uma estrutura de índices, a função por trás de A(i), A.f e A{i}.
substructBuilds the index structure expected by subsref and subsasgn.Monta a estrutura de índices esperada por subsref e subsasgn.

System Objects

cloneCreates an independent copy of a System object.Cria uma cópia independente de um objeto System.
isDoneTests whether a System object has finished producing data.Testa se um objeto System terminou de produzir dados.
isLockedTests whether a System object, or a function, is locked.Testa se um objeto System, ou uma função, está bloqueado.
releaseReleases the resources of a System object and unlocks it.Libera os recursos de um objeto System e o destrava.
setupPrepares a System object for execution, locking it, before the first call to step.Prepara um objeto System para execução, travando-o, antes da primeira chamada a step.
stepRuns one processing step of a System object.Executa um passo de processamento de um objeto System.

Construct and Work with Object Arrays

emptyCreates an empty array of a given class.Cria um array vazio de uma determinada classe.

Class Introspection and Metadata

meta.class.fromNameReturns the meta.class object that describes a class, given its name.Retorna o objeto meta.class que descreve uma classe, dado o seu nome.
metaclassReturns the meta.class object that describes the class of an object.Retorna o objeto meta.class que descreve a classe de um objeto.

Search Path

addpathAdds folders to the top of the search path.Adiciona pastas ao início do caminho de busca.
genpathReturns a path string listing a folder and all of its subfolders.Retorna um texto de path com uma pasta e todas as suas subpastas.
pathShows or sets the search path.Mostra ou define o caminho de busca.
pathsepReturns the character that separates folders in a path string.Retorna o caractere que separa pastas em um texto de path.
rehashRefreshes the program's cache of the folders on the path.Atualiza o cache do programa sobre as pastas do path.
restoredefaultpathResets the search path to its default folders.Restaura o caminho de busca para as pastas padrão.
rmpathRemoves folders from the search path.Remove pastas do caminho de busca.
userpathReturns or sets the user's default working folder.Retorna ou define a pasta de trabalho padrão do usuário.

File Operations

cdShows or changes the current folder.Mostra ou muda a pasta atual.
copyfileCopies a file or a folder.Copia um arquivo ou uma pasta.
dirLists the files and folders that match a name or pattern.Lista os arquivos e pastas que correspondem a um nome ou padrão.
existChecks whether a variable, file, folder or function exists, and what kind it is.Verifica se existe uma variável, arquivo, pasta ou função, e de que tipo.
fileattribReads the attributes of a file or folder.Lê os atributos de um arquivo ou pasta.
isdirTests whether a name is a folder (superseded by isfolder).Testa se um nome é uma pasta (substituída por isfolder).
isfileTests whether a name is an existing file.Testa se um nome é um arquivo existente.
isfolderTests whether a name is an existing folder.Testa se um nome é uma pasta existente.
lsLists the names of the files and folders in a folder.Lista os nomes dos arquivos e pastas de uma pasta.
mkdirCreates a folder, including any missing parent folders.Cria uma pasta, inclusive as pastas pai que faltarem.
movefileMoves or renames a file or folder.Move ou renomeia um arquivo ou pasta.
pwdReturns the current folder.Retorna a pasta atual.
recycleGets or sets whether deleted files go to the recycle bin.Consulta ou define se arquivos apagados vão para a lixeira.
rmdirRemoves a folder.Remove uma pasta.
whatLists the MATLAB files in a folder, grouped by type.Lista os arquivos MATLAB de uma pasta, agrupados por tipo.
whichLocates a function, script, file or variable.Localiza uma função, script, arquivo ou variável.

File Name Construction

filemarkerReturns the character that separates a file name from a local function name.Retorna o caractere que separa o nome de um arquivo do nome de uma função local.
filepartsSplits a file path into folder, name and extension.Divide um caminho de arquivo em pasta, nome e extensão.
filesepReturns the file separator of the platform.Retorna o separador de arquivos da plataforma.
fullfileBuilds a file path from folder and file name parts.Monta um caminho de arquivo a partir de partes de pasta e nome.
matlabrootReturns the folder where the program is installed.Retorna a pasta onde o programa está instalado.
tempdirReturns the folder for temporary files.Retorna a pasta para arquivos temporários.
tempnameReturns a unique name for a temporary file.Retorna um nome único para um arquivo temporário.
toolboxdirReturns the folder of a toolbox.Retorna a pasta de um toolbox.

File Compression

gunzipDecompresses files compressed with gzip.Descomprime arquivos compactados com gzip.
gzipCompresses files individually into gzip files.Compacta arquivos, um a um, em arquivos gzip.
tarPacks files and folders into a tar archive.Reúne arquivos e pastas em um arquivo tar.
untarExtracts the files of a tar archive.Extrai os arquivos de um arquivo tar.
unzipExtracts the files of a zip archive.Extrai os arquivos de um arquivo zip.
zipCompresses files and folders into a zip archive.Compacta arquivos e pastas em um arquivo zip.

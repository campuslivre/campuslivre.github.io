Standard File Formats

audiowriteWrites a matrix of samples to an audio file.Grava uma matriz de amostras em um arquivo de áudio.
closeCloses figure windows.Fecha janelas de figura.

delimitedTextImportOptionsCreates an options object that describes how to import a delimited text file.Cria um objeto de opções que descreve como importar um arquivo de texto delimitado.
dlmreadReads a delimited numeric file into a matrix.Lê um arquivo numérico delimitado em uma matriz.
dlmwriteWrites a numeric matrix to a delimited text file.Grava uma matriz numérica em um arquivo de texto delimitado.
filereadReads a whole text file into a character vector.Lê um arquivo de texto inteiro em um vetor de caracteres.

importdataLoads data from a file, choosing the loader by file type.Carrega dados de um arquivo, escolhendo o leitor pelo tipo do arquivo.
imreadReads an image file into an array.Lê um arquivo de imagem em um array.
imwriteWrites an array to an image file.Grava um array em um arquivo de imagem.
jsondecodeConverts JSON text into MATLAB values.Converte texto JSON em valores do MATLAB.

readlinesReads the lines of a text file into a string array.Lê as linhas de um arquivo de texto em um array de strings.
readmatrixReads a numeric matrix from a text or spreadsheet file.Lê uma matriz numérica de um arquivo de texto ou de planilha.
readstructReads an XML file into a scalar struct.Lê um arquivo estruturado em XML para uma struct escalar.

setSets properties of a graphics object.Define propriedades de um objeto gráfico.
sheetnamesLists the sheet names of a spreadsheet file.Lista os nomes das planilhas de um arquivo de planilha.
textreadReads formatted text-file data into separate variables.Lê dados formatados de um arquivo de texto em variáveis separadas.
textscanReads formatted data from a file or text into a cell array of columns.Lê dados formatados de um arquivo ou texto em um cell array de colunas.
Tiff.closeCloses the TIFF file held by a Tiff object.Fecha o arquivo TIFF mantido por um objeto Tiff.
Tiff.computeStripReturns the index of the strip that contains a given image row.Retorna o índice da faixa (strip) que contém uma linha da imagem.
Tiff.computeTileReturns the index of the tile that contains a given image position.Retorna o índice do tile que contém uma posição da imagem.
Tiff.currentDirectoryReturns the number of the current image directory in the file.Retorna o número do diretório de imagem atual no arquivo.
Tiff.getTagReads the value of a TIFF tag of the current directory.Lê o valor de uma tag TIFF do diretório atual.
Tiff.getTagNamesReturns the names of the tags that the Tiff class supports.Retorna os nomes das tags que a classe Tiff suporta.
Tiff.getVersionReturns the version text of the TIFF library in use.Retorna o texto de versão da biblioteca TIFF em uso.
Tiff.isTiledTells whether the current image is stored in tiles.Informa se a imagem atual é armazenada em tiles.
Tiff.lastDirectoryTells whether the current directory is the last one in the file.Informa se o diretório atual é o último do arquivo.
Tiff.nextDirectoryMoves to the next image directory in the file.Move para o próximo diretório de imagem do arquivo.
Tiff.numberOfStripsReturns the number of strips in the current image.Retorna o número de faixas (strips) da imagem atual.
Tiff.numberOfTilesReturns the number of tiles in the current image.Retorna o número de tiles da imagem atual.
Tiff.readReads the whole current image into an array.Lê a imagem atual inteira em um array.
Tiff.readEncodedStripReads one strip of the current image, still as stored.Lê uma faixa (strip) da imagem atual, como armazenada.
Tiff.readEncodedTileReads one tile of the current image, still as stored.Lê um tile da imagem atual, como armazenado.
Tiff.readRGBAImageReads the whole image converted to RGB color data.Lê a imagem inteira convertida em dados de cor RGB.
Tiff.readRGBAStripReads one strip converted to RGB color data.Lê uma faixa (strip) convertida em dados de cor RGB.
Tiff.readRGBATileReads one tile converted to RGB color data.Lê um tile convertido em dados de cor RGB.
Tiff.rewriteDirectoryUpdates the current directory of a file with changed tags.Atualiza o diretório atual de um arquivo com tags alteradas.
Tiff.setDirectoryMakes a given image directory the current one.Torna um diretório de imagem específico o atual.
Tiff.setSubDirectoryMoves to a sub-image whose file offset is given by a SubIFD tag.Move para uma subimagem cujo deslocamento no arquivo é dado por uma tag SubIFD.
Tiff.setTagSets the value of a TIFF tag before writing an image.Define o valor de uma tag TIFF antes de gravar uma imagem.
Tiff.writeMethod of a Tiff object: writes an image to the current directory of a TIFF file opened for writing.Método de um objeto Tiff: grava uma imagem no diretório atual de um arquivo TIFF aberto para escrita.
Tiff.writeDirectoryMethod of a Tiff object: closes the current image directory and starts a new one, for multi-image TIFF files.Método de um objeto Tiff: fecha o diretório de imagem atual e inicia um novo, para arquivos TIFF com várias imagens.
Tiff.writeEncodedStripMethod of a Tiff object: writes one strip of a stripped TIFF image from an array of pixels.Método de um objeto Tiff: grava uma faixa (strip) de uma imagem TIFF organizada em faixas a partir de um array de pixels.
Tiff.writeEncodedTileMethod of a Tiff object: writes one tile of a tiled TIFF image from an array of pixels.Método de um objeto Tiff: grava um bloco (tile) de uma imagem TIFF organizada em blocos a partir de um array de pixels.

writecellWrites a cell array to a delimited text file or spreadsheet.Grava um cell array em um arquivo de texto delimitado ou em uma planilha.
writelinesWrites text lines to a file, one string per line.Grava linhas de texto em um arquivo, uma string por linha.
writematrixWrites a numeric matrix to a delimited text file or spreadsheet.Grava uma matriz numérica em um arquivo de texto delimitado ou em uma planilha.
writestructWrites a structure to an XML or JSON file.Grava uma struct em um arquivo XML ou JSON.
xlsfinfoReports whether a file is a readable spreadsheet and lists its sheets.Informa se um arquivo é uma planilha legível e lista suas abas.
xlsreadReads numbers and text from an Excel spreadsheet.Lê números e texto de uma planilha do Excel.
xlswriteWrites a matrix or cell array to an Excel spreadsheet.Grava uma matriz ou cell array em uma planilha do Excel.

dispDisplays a value in the command window without printing its name.Exibe um valor na janela de comandos sem imprimir o nome.

fgetsReads one line from a file and keeps the newline character.Lê uma linha de um arquivo e mantém o caractere de quebra de linha.

fprintfWrites formatted text to the command window or to a file.Grava texto formatado na janela de comandos ou em um arquivo.
freadReads binary data from a file.Lê dados binários de um arquivo.
frewindMoves the read position of a file back to its beginning.Move a posição de leitura de um arquivo de volta ao início.
fscanfReads formatted data from a text file.Lê dados formatados de um arquivo de texto.
fseekMoves the file position to a given byte offset.Move a posição do arquivo para um deslocamento em bytes.
ftellReturns the current byte position in a file.Retorna a posição atual, em bytes, em um arquivo.

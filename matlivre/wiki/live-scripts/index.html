Live scripts

Live scripts

A live script (.mlx) mixes formatted text, code and results in one document. It is divided into sections, and each section can be run on its own.

Um live script (.mlx) mistura texto formatado, código e resultados em um só documento. Ele é dividido em seções, e cada seção pode ser executada sozinha.

Running code

Executando o código

  • Ctrl+Enter: run the current section.
  • Ctrl+Enter: executar a seção atual.
  • Ctrl+Shift+Enter: run the current section and move to the next one.
  • Ctrl+Shift+Enter: executar a seção atual e passar para a próxima.
  • F5: run the whole script.
  • F5: executar o script inteiro.
  • Ctrl+C or the Stop button: stop. A script stops between statements.
  • Ctrl+C ou o botão Stop: parar. O script para entre um comando e outro.

Code runs on its own engine thread, so the editor never freezes while a script is running. Results appear below the code or on its right, and figures are drawn inline.

O código roda em uma thread própria do motor, então o editor nunca trava durante a execução. Os resultados aparecem abaixo do código ou à direita dele, e as figuras são desenhadas na própria página.

Building a document

Montando um documento

Use the Insert menu to add a block:

Use o menu Insert para adicionar um bloco:

  • Text, Title, Heading and Subheading for the prose.
  • Text, Title, Heading e Subheading para o texto.
  • Code for a block of code.
  • Code para um bloco de código.
  • Section break (Ctrl+Alt+Enter) to split a section in two.
  • Section break (Ctrl+Alt+Enter) para dividir uma seção em duas.
  • Control for interactive controls (next section).
  • Control para controles interativos (próxima seção).

Saving and exporting

Salvando e exportando

Save (Ctrl+S) and Save as (Ctrl+Shift+S) write a .mlx file. Export as script (.m) writes the code as a plain script. PDF export is not available yet.

Save (Ctrl+S) e Save as (Ctrl+Shift+S) gravam um arquivo .mlx. Export as script (.m) grava o código como um script comum. A exportação para PDF ainda não está disponível.

Good to know: outputs saved inside an .mlx file are not restored when you open it (run the script to regenerate them) and are not written back. Rich text such as bold runs, links, equations and images is shown as plain text.

Bom saber: as saídas salvas dentro de um arquivo .mlx não são restauradas ao abri-lo (execute o script para gerá-las de novo) e não são gravadas de volta. Texto formatado, como negrito, links, equações e imagens, aparece como texto simples.

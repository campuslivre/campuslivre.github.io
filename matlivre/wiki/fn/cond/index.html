cond

Condition number of a matrix with respect to inversion.

Número de condição de uma matriz em relação à inversão.

Category:Categoria: Mathematics > Linear Algebra

Syntax

Sintaxe

c = cond(A)

Returns the 2-norm condition number, the ratio of the largest to the smallest singular value.

Retorna o número de condição na norma 2, a razão entre o maior e o menor valores singulares.

c = cond(A, p)

Uses the norm p: 1, 2, Inf or 'fro'.

Usa a norma p: 1, 2, Inf ou 'fro'.

Description

Descrição

The condition number measures how much a relative error in the data of a linear system A*x = b can be amplified in the solution. As a rule of thumb, you lose about log10(cond(A)) decimal digits of accuracy. Orthogonal matrices have condition 1; a singular matrix has an infinite one.

The condition number is a property of the matrix, not of the algorithm, and it is not the same as the size of the determinant. For large sparse matrices use condest, which estimates it cheaply.

O número de condição mede quanto um erro relativo nos dados de um sistema linear A*x = b pode ser ampliado na solução. Como regra prática, perdem-se cerca de log10(cond(A)) dígitos decimais de precisão. Matrizes ortogonais têm condição 1; uma matriz singular tem condição infinita.

O número de condição é uma propriedade da matriz, não do algoritmo, e não tem relação com o tamanho do determinante. Para matrizes esparsas grandes, use condest, que o estima a baixo custo.

Input arguments

Argumentos de entrada

A
Matrix. For p other than 2 it must be square.
Matriz. Para p diferente de 2, deve ser quadrada.
p
Norm type, default 2.
Tipo de norma, padrão 2.

Output arguments

Argumentos de saída

c
The condition number, at least 1. It is Inf for a singular matrix.
O número de condição, no mínimo 1. Vale Inf para uma matriz singular.

Example

Exemplo

Different norms

Normas diferentes

A = [1 2; 3 4];
cond(A)
cond(A, 1)
cond(A, 'fro')
cond([1 2; 2 4])
OutputSaída
ans = 14.9330
ans = 21.0000
ans = 15.0000
ans = Inf

Veja também

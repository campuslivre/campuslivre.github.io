table2timetable

Converts a table with a time variable into a timetable.

Converte uma tabela com uma variável de tempo em uma timetable.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

TT = table2timetable(T)

Uses the first datetime or duration variable of T as the row times.

Usa a primeira variável datetime ou duration de T como tempos das linhas.

Description

Descrição

A timetable requires its row times to be a datetime or duration vector. table2timetable takes that vector from the table and removes it from the data columns, so the number of variables falls by one. The row times are shown under the original name when it is available.

The inverse is timetable2table.

Uma timetable exige que os tempos das linhas sejam um vetor datetime ou duration. table2timetable retira esse vetor da tabela e o remove das colunas de dados, de modo que o número de variáveis diminui em um. Os tempos das linhas são exibidos sob o nome original quando ele está disponível.

A inversa é timetable2table.

Input arguments

Argumentos de entrada

T
Table whose first variable (or a chosen one) holds datetime or duration values.
Tabela cuja primeira variável (ou uma escolhida) contém valores datetime ou duration.

Output arguments

Argumentos de saída

TT
Timetable with the time variable moved to the row times; the other variables are kept.
Timetable com a variável de tempo movida para os tempos das linhas; as demais variáveis são mantidas.

Example

Exemplo

Duration column as row times

Coluna de duração como tempos das linhas

T = table(seconds([1;2;3]), [4;5;6], 'VariableNames', {'t','v'});
TT = table2timetable(T)
OutputSaída
TT = 3×1 timetable

      t      v
    _____    _

    1 sec    4
    2 sec    5
    3 sec    6

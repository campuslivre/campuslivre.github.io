svd

Singular value decomposition of a matrix.

Decomposição em valores singulares de uma matriz.

Category:Categoria: Mathematics > Linear Algebra

Syntax

Sintaxe

s = svd(A)

Returns the singular values as a column vector in descending order.

Retorna os valores singulares como vetor coluna em ordem decrescente.

[U, S, V] = svd(A)

Returns orthogonal U, V and a diagonal S with A = U*S*V'.

Retorna U e V ortogonais e S diagonal com A = U*S*V'.

[U, S, V] = svd(A, 'econ')

Economy size: drops the columns of U or V that multiply zero rows or columns of S.

Tamanho econômico: descarta as colunas de U ou V que multiplicam linhas ou colunas nulas de S.

[U, S, V] = svd(A, 0)

Like 'econ' for m > n; for m <= n it is equivalent to the full form.

Como 'econ' para m > n; para m <= n equivale à forma completa.

Description

Descrição

Every matrix factors as a rotation, a scaling along orthogonal axes, and another rotation. The singular values are the scaling factors: the largest equals norm(A), the ratio of largest to smallest is cond(A), and the number above a tolerance is rank(A).

Truncating the decomposition to the k largest singular values gives the best rank-k approximation of A, which underlies data compression and principal component analysis.

Toda matriz se fatora como uma rotação, uma escala ao longo de eixos ortogonais e outra rotação. Os valores singulares são os fatores de escala: o maior é norm(A), a razão entre o maior e o menor é cond(A), e o número deles acima de uma tolerância é rank(A).

Truncar a decomposição nos k maiores valores singulares dá a melhor aproximação de posto k de A, base da compressão de dados e da análise de componentes principais.

Input arguments

Argumentos de entrada

A
Numeric matrix of any shape. NaN or Inf entries cause an error.
Matriz numérica de qualquer formato. Entradas NaN ou Inf causam erro.
'econ' or 0
Request the economy-size decomposition.
Pedem a decomposição de tamanho econômico.

Output arguments

Argumentos de saída

s
Vector with min(size(A)) nonnegative singular values.
Vetor com min(size(A)) valores singulares não negativos.
U, S, V
U is m-by-m, S is m-by-n with the singular values on its diagonal, V is n-by-n.
U é m-por-m, S é m-por-n com os valores singulares na diagonal, V é n-por-n.

Example

Exemplo

Values and economy factors

Valores e fatores econômicos

A = [4 1; 2 3; 0 5];
s = svd(A)
[U, S, V] = svd(A, 'econ');
size(U)
norm(U*S*V' - A) < 1e-12
OutputSaída

    6.3246
    3.8730

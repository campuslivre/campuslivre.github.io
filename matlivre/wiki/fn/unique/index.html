unique

Distinct values of an array, sorted, with optional index maps.

Valores distintos de um array, ordenados, com mapas de índices opcionais.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

C = unique(A)

Returns the sorted distinct values of A.

Retorna os valores distintos de A, ordenados.

C = unique(A, 'stable')

Keeps the order of first appearance instead of sorting.

Mantém a ordem da primeira aparição em vez de ordenar.

[C, ia, ic] = unique(A)

Also returns index vectors: C = A(ia) and A = C(ic).

Também retorna vetores de índices: C = A(ia) e A = C(ic).

Description

Descrição

unique removes repeated values. Numbers are sorted ascending and text alphabetically. Several NaN values are all counted as different, so each NaN is kept.

The third output ic is especially useful: accumarray(ic, 1) counts how many times each distinct value occurs.

unique remove valores repetidos. Números são ordenados em ordem crescente e texto em ordem alfabética. Vários NaN são considerados todos diferentes, então cada NaN é mantido.

A terceira saída ic é especialmente útil: accumarray(ic, 1) conta quantas vezes cada valor distinto ocorre.

Input arguments

Argumentos de entrada

A
Numeric, logical, char, string array, cell array of character vectors, categorical or table.
Array numérico, lógico, de char, de strings, cell array de vetores de caracteres, categórico ou tabela.
'stable'
Return values in the order they first appear.
Retorna os valores na ordem em que aparecem pela primeira vez.

Output arguments

Argumentos de saída

C
The distinct values. For a row vector input the result is a row; for a cell array of text it is a column.
Os valores distintos. Para entrada em vetor linha, o resultado é uma linha; para um cell array de texto, é uma coluna.
ia
Indices of the first occurrence of each value of C in A.
Índices da primeira ocorrência de cada valor de C em A.
ic
Indices that rebuild A from C, one per element of A. It is also a way to number groups.
Índices que reconstroem A a partir de C, um por elemento de A. Também serve para numerar grupos.

Example

Exemplo

Values, indices and stable order

Valores, índices e ordem estável

[u, i, j] = unique([3 1 1 2 3])
unique({'b','a','b'})
unique([3 1 1 2 3], 'stable')

Notes

Observações

The 'rows' and 'last' options do not behave like MATLAB's in MatLivre ('rows' flattens the matrix, 'last' still reports first occurrences); use sortrows or 'first' semantics for now.

As opções 'rows' e 'last' não se comportam como as do MATLAB no MatLivre ('rows' achata a matriz e 'last' ainda informa as primeiras ocorrências); por ora, use sortrows ou a semântica 'first'.

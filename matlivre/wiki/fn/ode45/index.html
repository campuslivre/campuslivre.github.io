ode45

Default Runge-Kutta solver for nonstiff ordinary differential equations.

Solver de Runge-Kutta padrão para equações diferenciais ordinárias não rígidas.

Category:Categoria: Mathematics > Numerical Integration and Differential Equations

Syntax

Sintaxe

[t, y] = ode45(odefun, tspan, y0)

Integrates y' = odefun(t, y) over tspan from y0.

Integra y' = odefun(t, y) em tspan a partir de y0.

[t, y] = ode45(odefun, tspan, y0, options)

Also applies options from odeset (tolerances, events, output functions).

Aplica também opções de odeset (tolerâncias, eventos, funções de saída).

sol = ode45(___)

Returns a structure for use with deval.

Retorna uma estrutura para uso com deval.

[t, y, te, ye, ie] = ode45(___)

Also returns event times, states and indices when an event function is set.

Retorna também instantes, estados e índices de eventos quando uma função de eventos está definida.

Description

Descrição

ode45 uses the Dormand-Prince pair of fourth- and fifth-order formulas: the difference between the two estimates controls the step size. It is a good first attempt for most problems, as long as they are not stiff.

Higher-order equations are written as first-order systems: for x'' = -x, use y = [x; x'] and odefun = @(t,y) [y(2); -y(1)]. If the integration needs huge numbers of tiny steps, the problem is probably stiff and ode15s is the right tool.

ode45 usa o par de fórmulas de Dormand-Prince de quarta e quinta ordem: a diferença entre as duas estimativas controla o tamanho do passo. É uma boa primeira tentativa para a maioria dos problemas, desde que não sejam rígidos.

Equações de ordem superior se escrevem como sistemas de primeira ordem: para x'' = -x, use y = [x; x'] e odefun = @(t,y) [y(2); -y(1)]. Se a integração precisa de um número enorme de passos minúsculos, o problema provavelmente é rígido e ode15s é a ferramenta certa.

Input arguments

Argumentos de entrada

odefun
Handle dydt = odefun(t, y) returning a column vector the size of y.
Handle dydt = odefun(t, y) que retorna um vetor coluna do tamanho de y.
tspan
[t0 tf], or a vector of increasing (or decreasing) times to report.
[t0 tf], ou um vetor de instantes crescentes (ou decrescentes) a reportar.
y0
Vector of initial values.
Vetor de valores iniciais.
options
Structure from odeset. Default tolerances are RelTol = 1e-3 and AbsTol = 1e-6.
Estrutura de odeset. As tolerâncias padrão são RelTol = 1e-3 e AbsTol = 1e-6.

Output arguments

Argumentos de saída

t
Column vector of time points.
Vetor coluna de instantes.
y
Array with one row per time and one column per component.
Array com uma linha por instante e uma coluna por componente.

Example

Exemplo

Harmonic oscillator

Oscilador harmônico

[t, y] = ode45(@(t, y) [y(2); -y(1)], [0 pi/2], [0; 1]);
fprintf('%.3f %.3f\n', y(end, 1), y(end, 2))
OutputSaída
1.000 -0.000

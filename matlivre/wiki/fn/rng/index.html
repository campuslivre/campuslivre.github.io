rng

Controls the seed and generator of the global random number stream.

Controla a semente e o gerador do fluxo global de números aleatórios.

Category:Categoria: Mathematics > Random Number Generation

Syntax

Sintaxe

rng(seed)

Seeds the Mersenne Twister generator with a nonnegative integer.

Semeia o gerador Mersenne Twister com um inteiro não negativo.

rng('default')

Restores the startup settings: Mersenne Twister, seed 0.

Restaura as configurações iniciais: Mersenne Twister, semente 0.

rng('shuffle')

Seeds from the current time, giving a different sequence each run.

Semeia a partir do horário atual, gerando uma sequência diferente a cada execução.

rng(seed, generator)

Chooses the generator, for example 'twister'.

Escolhe o gerador, por exemplo 'twister'.

s = rng

Returns the current settings as a struct, to restore later with rng(s).

Retorna as configurações atuais como struct, para restaurar depois com rng(s).

Description

Descrição

rng sets the state of the global stream, which is what rand, randn, randi and randperm use. Seeding with the same value before a computation makes it reproducible: it is the first line of most scripts that use random data.

To run a piece of code and then go back to the previous random state, save s = rng first and call rng(s) afterward.

rng define o estado do fluxo global, que é o usado por rand, randn, randi e randperm. Semear com o mesmo valor antes de um cálculo o torna reproduzível: é a primeira linha da maioria dos scripts que usam dados aleatórios.

Para executar um trecho de código e depois voltar ao estado aleatório anterior, guarde s = rng antes e chame rng(s) depois.

Input arguments

Argumentos de entrada

seed
Nonnegative integer, 'default' or 'shuffle'.
Inteiro não negativo, 'default' ou 'shuffle'.
generator
Generator name: 'twister' (or 'mt19937ar').
Nome do gerador: 'twister' (ou 'mt19937ar').
s
Struct with fields Type, Seed and State, as returned by rng.
Struct com os campos Type, Seed e State, como retornada por rng.

Output arguments

Argumentos de saída

s
The settings in effect before the call.
As configurações em vigor antes da chamada.

Example

Exemplo

Reproducible numbers and saved state

Números reprodutíveis e estado salvo

rng(42);
a = rand;
rng(42);
b = rand;
a == b
s = rng;
x = rand(1, 2);
rng(s);
isequal(x, rand(1, 2))
rng('default');
rand
OutputSaída
ans = logical
   1
ans = logical
   1
ans = 0.8147

Notes

Observações

Only the Mersenne Twister generator ('twister') is available. The rand values for a given seed match MATLAB's; randn, randi and randperm may not.

Só o gerador Mersenne Twister ('twister') está disponível. Os valores de rand para uma dada semente coincidem com os do MATLAB; os de randn, randi e randperm podem não coincidir.

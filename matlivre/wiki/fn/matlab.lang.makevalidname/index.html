matlab.lang.makeValidName

Converts text into valid variable or field names.

Converte texto em nomes válidos de variável ou campo.

Category:Categoria: Programming > Functions

Syntax

Sintaxe

v = matlab.lang.makeValidName(str)

Returns str changed into a valid name.

Retorna str convertido em um nome válido.

[v, modified] = matlab.lang.makeValidName(str)

Also tells which strings had to change.

Também informa quais strings precisaram mudar.

Description

Descrição

Valid names are returned unchanged. Spaces are removed and the letter after each is capitalized ('my value' becomes 'myValue'), other illegal characters become underscores, and a name that starts with a digit or is a reserved word gets the prefix x. The function does not make names unique; combine it with matlab.lang.makeUniqueStrings for that.

Tables use this rule to turn column headings of imported files into variable names.

Nomes válidos são retornados sem alteração. Espaços são removidos e a letra seguinte é posta em maiúscula ('my value' vira 'myValue'), outros caracteres ilegais viram sublinhados, e um nome que começa com dígito ou é palavra reservada recebe o prefixo x. A função não torna os nomes únicos; combine com matlab.lang.makeUniqueStrings para isso.

Tabelas usam essa regra para transformar cabeçalhos de colunas de arquivos importados em nomes de variáveis.

Input arguments

Argumentos de entrada

str
Text, string array or cell array of text.
Texto, array de strings ou cell array de textos.

Output arguments

Argumentos de saída

v
Valid names, in the same shape as str.
Nomes válidos, com a mesma forma de str.
modified
Logical array: true where the name was changed.
Array lógico: true onde o nome foi alterado.

Example

Exemplo

Repairing names

Consertando nomes

[v, changed] = matlab.lang.makeValidName({'total cost', '3rd', 'a-b', 'ok'})
OutputSaída
v = 1×4 cell

    {'totalCost'}    {'x3rd'}    {'a_b'}    {'ok'}
changed = 1×4 logical array

   1   1   1   0

Notes

Observações

MatLivre ignores the 'ReplacementStyle' and 'Prefix' options: replacements are always underscores and the prefix is always x.

O MatLivre ignora as opções 'ReplacementStyle' e 'Prefix': as substituições são sempre sublinhados e o prefixo é sempre x.

Veja também

strread

Reads formatted data from a string (removed from recent MATLAB; use textscan).

Lê dados formatados de uma string (removida do MATLAB recente; use textscan).

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

[a, b, ...] = strread(str, format)

Parses str according to format, one output per conversion.

Interpreta str conforme format, com uma saída por conversão.

Description

Descrição

strread was an early text parser, later superseded by textscan and sscanf. Current MATLAB recommends textscan for delimited text and sscanf for simple formats, and MatLivre follows that advice: it reports that strread has been removed.

The equivalent of [a, b] = strread(s, '%d %d') is c = textscan(s, '%d %d'), which returns a cell array with one column per conversion.

strread foi um dos primeiros analisadores de texto, depois substituído por textscan e sscanf. O MATLAB atual recomenda textscan para texto delimitado e sscanf para formatos simples, e o MatLivre segue esse conselho: informa que strread foi removida.

O equivalente de [a, b] = strread(s, '%d %d') é c = textscan(s, '%d %d'), que retorna um cell array com uma coluna por conversão.

Input arguments

Argumentos de entrada

str
Text containing the data.
Texto contendo os dados.
format
Conversion specifiers such as %d, %f and %s.
Especificadores de conversão como %d, %f e %s.

Output arguments

Argumentos de saída

a, b, ...
One output for each conversion in format.
Uma saída para cada conversão em format.

Example

Exemplo

Use textscan instead

Use textscan no lugar

try
  [a, b] = strread('1 2 3 4', '%d %d');
catch err
  disp(err.message)
end
c = textscan('1 2 3 4', '%d %d');
c{1}'
c{2}'
OutputSaída
strread has been removed; use textscan or strsplit.
ans = 1×2 int32 row vector

   1   3
ans = 1×2 int32 row vector

   2   4

Notes

Observações

Calling strread in MatLivre always raises the error shown in the example. Use textscan or sscanf.

Chamar strread no MatLivre sempre gera o erro mostrado no exemplo. Use textscan ou sscanf.

Veja também

imshow

Displays an image with the right scale, colormap and aspect ratio.

Exibe uma imagem com a escala, o mapa de cores e a proporção adequados.

Category:Categoria: Graphics > Images

Syntax

Sintaxe

imshow(I)

Shows a grayscale, RGB or binary image.

Mostra uma imagem em tons de cinza, RGB ou binária.

imshow(I, [low high])

Displays grayscale data with low as black and high as white.

Exibe dados em tons de cinza com low como preto e high como branco.

imshow(X, map)

Shows an indexed image with the colormap map.

Mostra uma imagem indexada com o mapa de cores map.

h = imshow(___)

Returns the image object.

Retorna o objeto de imagem.

Description

Descrição

Unlike image, imshow sets pixels to be square, hides the axes ticks and chooses scaling by class, so a uint8 image looks right without further setup. Pass [] as the range to stretch the data's own minimum and maximum over the display.

Diferente de image, imshow torna os pixels quadrados, esconde as marcas dos eixos e escolhe a escala pela classe, então uma imagem uint8 aparece corretamente sem mais ajustes. Passe [] como faixa para esticar o mínimo e o máximo dos próprios dados sobre a exibição.

Input arguments

Argumentos de entrada

I
Image array. Integer images use their full class range; double data is read as [0, 1].
Array de imagem. Imagens inteiras usam a faixa completa da classe; dados double são lidos como [0, 1].
[low high]
Display range for grayscale data.
Faixa de exibição para dados em tons de cinza.

Output arguments

Argumentos de saída

h
Image object.
Objeto de imagem.

Example

Exemplo

Show a small gray image

Mostrar uma pequena imagem cinza

I = uint8([0 255; 128 64]);
h = imshow(I);
disp(class(h))
OutputSaída
matlab.graphics.primitive.Image

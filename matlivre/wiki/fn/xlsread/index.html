xlsread

Reads numbers and text from an Excel spreadsheet.

Lê números e texto de uma planilha do Excel.

Category:Categoria: Data Import and Analysis > Data Import and Export

Syntax

Sintaxe

num = xlsread(filename)

Reads the numeric data of the first sheet.

Lê os dados numéricos da primeira aba.

num = xlsread(filename, sheet)

Reads a sheet given by number or name.

Lê uma aba dada por número ou nome.

num = xlsread(filename, sheet, range)

Reads only the cells of range, such as 'B2:C3'.

Lê apenas as células de range, como 'B2:C3'.

[num, txt, raw] = xlsread(___)

Also returns the text cells and the unprocessed contents.

Também retorna as células de texto e o conteúdo bruto.

Description

Descrição

xlsread splits a sheet into its numeric part and its text part. A header row of labels followed by numbers gives a num without the header, and txt with the labels. Use raw when you need both kinds in their original positions.

The function is kept for older code. readmatrix, readcell and readtable are the recommended replacements, with more control over ranges and types.

xlsread separa a planilha em sua parte numérica e sua parte de texto. Uma linha de rótulos seguida de números dá um num sem o cabeçalho e um txt com os rótulos. Use raw quando precisar dos dois tipos nas posições originais.

A função é mantida para código antigo. readmatrix, readcell e readtable são as substitutas recomendadas, com mais controle sobre intervalos e tipos.

Input arguments

Argumentos de entrada

filename
Spreadsheet file name.
Nome do arquivo de planilha.
sheet
Sheet index or name.
Índice ou nome da aba.
range
Cell range in A1 notation.
Intervalo de células em notação A1.

Output arguments

Argumentos de saída

num
Numeric matrix. Cells without a number become NaN, and leading text rows or columns are trimmed away.
Matriz numérica. Células sem número viram NaN, e linhas ou colunas iniciais de texto são removidas.
txt
Cell array holding the text cells; numeric cells appear as empty text.
Cell array com as células de texto; as células numéricas aparecem como texto vazio.
raw
Cell array with every cell exactly as read, numbers and text together.
Cell array com todas as células exatamente como lidas, números e texto juntos.

Examples

Exemplos

Header text and numbers

Texto de cabeçalho e números

xlswrite('read_demo.xlsx', {'name','val'; 'a',1; 'b',2});
[num, txt, raw] = xlsread('read_demo.xlsx')
OutputSaída
num = 2×1

     1
     2
txt = 3×2 cell

    {'name'}    {'val'   }
    {'a'   }    {0×0 char}
    {'b'   }    {0×0 char}
raw = 3×2 cell

    {'name'}    {'val'}
    {'a'   }    {[  1]}
    {'b'   }    {[  2]}

A range of a sheet

Um intervalo de uma aba

xlswrite('range_demo.xlsx', magic(4));
xlsread('range_demo.xlsx', 1, 'B2:C3')
OutputSaída
ans = 2×2

    11    10
     7     6

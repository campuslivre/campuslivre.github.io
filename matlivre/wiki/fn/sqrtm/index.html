sqrtm

Matrix square root: a matrix X with X*X equal to A.

Raiz quadrada de matriz: uma matriz X tal que X*X é igual a A.

Category:Categoria: Mathematics > Linear Algebra

Syntax

Sintaxe

X = sqrtm(A)

Returns the principal square root of the square matrix A.

Retorna a raiz quadrada principal da matriz quadrada A.

Description

Descrição

This is a matrix function, not an element-wise one: sqrtm(A) differs from sqrt(A), which takes the square root of each entry. It is computed from the Schur form of A by a recurrence on the triangular factor.

A matrix with a negative real eigenvalue has no real square root, so the result is complex. If A is singular, the root may not exist or may be inaccurate, and a warning is issued.

É uma função de matriz, não elemento a elemento: sqrtm(A) difere de sqrt(A), que tira a raiz de cada entrada. É calculada a partir da forma de Schur de A, por uma recorrência sobre o fator triangular.

Uma matriz com autovalor real negativo não tem raiz quadrada real, então o resultado é complexo. Se A é singular, a raiz pode não existir ou ser imprecisa, e um aviso é emitido.

Input arguments

Argumentos de entrada

A
Square numeric matrix.
Matriz numérica quadrada.

Output arguments

Argumentos de saída

X
Matrix with X*X = A, whose eigenvalues have nonnegative real part. It may be complex even for a real A.
Matriz com X*X = A, cujos autovalores têm parte real não negativa. Pode ser complexa mesmo para A real.

Exemplo

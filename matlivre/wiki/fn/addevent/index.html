addevent

Adds events to a timeseries object.

Adiciona eventos a um objeto timeseries.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

ts = addevent(ts, e, time)

Attaches the event e to the time series ts at time.

Anexa o evento e à série temporal ts no instante time.

Description

Descrição

An event is a named marker, such as "peak" or "sensor reset", tied to an instant. It does not alter the data; it is metadata used to label plots or to select intervals of the series. Create events with tsdata.event(name, time).

Um evento é um marcador com nome, como "pico" ou "reinício do sensor", associado a um instante. Não altera os dados; é metadado usado para rotular gráficos ou selecionar intervalos da série. Crie eventos com tsdata.event(nome, tempo).

Input arguments

Argumentos de entrada

ts
A timeseries object.
Um objeto timeseries.
e
Event object created with tsdata.event, or an array of them.
Objeto de evento criado com tsdata.event, ou um array deles.
time
Time of the event, on the time scale of ts.
Instante do evento, na escala de tempo de ts.

Output arguments

Argumentos de saída

ts
The time series with the event stored.
A série temporal com o evento armazenado.

Example

Exemplo

Mark an instant

Marcar um instante

ts = timeseries([10 20 30]', [0 1 2]);
e = tsdata.event('peak', 1);
ts = addevent(ts, e, 1);
disp(size(ts.Events))
OutputSaída
     1     1

Notes

Observações

In MatLivre the stored events are returned as a cell array rather than an array of event objects.

No MatLivre os eventos armazenados são retornados como cell array, e não como um array de objetos de evento.

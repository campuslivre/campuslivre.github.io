contour

Draws contour lines, the curves along which a function of two variables is constant.

Desenha curvas de nível, as curvas ao longo das quais uma função de duas variáveis é constante.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

contour(Z)

Contour lines of the matrix Z, using column and row indices as coordinates.

Curvas de nível da matriz Z, usando os índices de coluna e linha como coordenadas.

contour(X, Y, Z)

Uses the coordinates X and Y.

Usa as coordenadas X e Y.

contour(___, levels)

A scalar sets the number of levels; a vector sets the levels themselves.

Um escalar define o número de níveis; um vetor define os próprios níveis.

[C, h] = contour(___)

Also returns the contour matrix and the contour object.

Também retorna a matriz de contorno e o objeto de contorno.

Description

Descrição

A contour map shows a surface from above, like the lines of equal height on a topographic map. Closely spaced lines mean a steep slope. Use contourf to fill the regions between lines and contour3 to lift the lines to their height.

Um mapa de contorno mostra uma superfície vista de cima, como as linhas de mesma altitude de um mapa topográfico. Linhas próximas indicam declive acentuado. Use contourf para preencher as regiões entre as linhas e contour3 para elevar as linhas à sua altura.

Input arguments

Argumentos de entrada

Z
Matrix of values.
Matriz de valores.
X, Y
Coordinates of the grid: matrices the size of Z, or vectors matching its columns and rows.
Coordenadas da grade: matrizes do tamanho de Z, ou vetores correspondentes a suas colunas e linhas.
levels
Number of levels or vector of level values. A vector with one value draws a single line.
Número de níveis ou vetor com os valores dos níveis. Um vetor com um valor desenha uma única linha.

Output arguments

Argumentos de saída

C
Contour matrix, see contourc.
Matriz de contorno, veja contourc.
h
The Contour object; its LevelList property lists the levels drawn.
O objeto Contour; sua propriedade LevelList lista os níveis desenhados.

Example

Exemplo

Levels of a paraboloid

Níveis de um paraboloide

[X, Y] = meshgrid(-2:0.1:2);
Z = X.^2 + Y.^2;
[C, h] = contour(X, Y, Z, [1 2 3]);
disp(h.LevelList)
axis equal
OutputSaída
     1     2     3

Veja também

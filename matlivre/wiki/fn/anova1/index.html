anova1 next release

One-way analysis of variance: tests whether several groups share the same mean, and returns the p-value, the ANOVA table and group statistics.

Category: ANOVA > Analysis of Variance and Covariance

Syntax

p = anova1(y)

Treats each column of the matrix y as one group and returns the p-value of the F test.

p = anova1(y, group)

Takes a vector y and a vector group that labels each element.

[p, tbl, stats] = anova1(y, group, displayopt)

Also returns the ANOVA table as a cell array and a structure of group statistics. displayopt is 'on' or 'off'.

Description

anova1 splits the total variation of y into variation between the group means and variation inside the groups. The F statistic is the ratio of the two mean squares, and the p-value is the chance of an F at least that large if all groups had the same mean.

The test assumes independent observations, roughly normal errors and equal variances in the groups. When these assumptions are doubtful, kruskalwallis is a rank-based alternative.

Input arguments

y
Measurements. A matrix with one group per column (balanced data), or a vector when group is given.
group
Group label of each element of y: numeric vector or cell array of character vectors. For a matrix y use [], or a cell array with one name per column.
displayopt
'on' (default) or 'off'.

Output arguments

p
p-value of the F test of equal group means. A small value is evidence that at least one mean differs.
tbl
ANOVA table as a cell array with columns Source, SS, df, MS, F and Prob>F, and rows Columns (between groups), Error and Total.
stats
Structure with gnames, n (group sizes), means, df (error degrees of freedom) and s (pooled standard deviation).

Examples

Three groups in the columns of a matrix

y = [6 9 14; 8 11 13; 7 10 15; 5 12 12; 9 8 16];
[p, tbl, st] = anova1(y, [], 'off');
fprintf('F = %.4f, p = %.5f\n', tbl{2,5}, p)
disp(st.means)
Output
F = 24.6667, p = 0.00006
     7    10    14

Vector with text group labels

y = [6 8 7 5 9 9 11 10 12 8 14 13 15 12 16];
g = [repmat({'a'},1,5) repmat({'b'},1,5) repmat({'c'},1,5)];
[p, tbl, st] = anova1(y, g, 'off');
fprintf('p = %.5f\n', p)
disp(st.gnames')
Output
p = 0.00006
    {'a'}    {'b'}    {'c'}

Notes

The ANOVA table and box plot figures are not drawn, even with 'on': use the outputs. For single input the sums are computed in double and rounded to single, so results can differ from MATLAB's single arithmetic at about 1e-6.

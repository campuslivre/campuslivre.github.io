delimitedTextImportOptions

Creates an options object that describes how to import a delimited text file.

Cria um objeto de opções que descreve como importar um arquivo de texto delimitado.

Category:Categoria: Data Import and Analysis > Data Import and Export

Syntax

Sintaxe

opts = delimitedTextImportOptions

Returns default options for a delimited file.

Retorna as opções padrão para um arquivo delimitado.

opts = delimitedTextImportOptions('NumVariables', n)

Declares the number of columns.

Declara o número de colunas.

opts = delimitedTextImportOptions(..., Name, Value)

Sets properties such as VariableNames, VariableTypes and Delimiter at creation.

Define propriedades como VariableNames, VariableTypes e Delimiter na criação.

Description

Descrição

Import options give you full control over a text import: which columns exist, what type each one has, and which are selected. The object can be inspected, changed, and reused across many files with the same layout.

To let the library guess the layout instead, call detectImportOptions on a sample file and adjust only what it got wrong.

As opções de importação dão controle total sobre uma leitura de texto: quais colunas existem, o tipo de cada uma e quais são selecionadas. O objeto pode ser inspecionado, alterado e reutilizado em vários arquivos de mesmo formato.

Para deixar a biblioteca adivinhar o formato, chame detectImportOptions em um arquivo de amostra e ajuste só o que ela errou.

Input arguments

Argumentos de entrada

'NumVariables'
Number of columns in the file.
Número de colunas do arquivo.
'VariableNames'
Cell array of column names for the resulting table.
Cell array com os nomes das colunas da tabela resultante.
'VariableTypes'
Cell array of types: 'double', 'string', 'char', 'datetime', and so on.
Cell array de tipos: 'double', 'string', 'char', 'datetime' etc.
'Delimiter'
Character or cell array of characters that separate fields.
Caractere ou cell array de caracteres que separam os campos.

Output arguments

Argumentos de saída

opts
Import options object, passed as the second argument of readtable, readmatrix or readcell.
Objeto de opções de importação, passado como segundo argumento de readtable, readmatrix ou readcell.

Example

Exemplo

Read a headerless file with chosen types

Ler um arquivo sem cabeçalho com tipos escolhidos

fid = fopen('p.csv', 'w');
fprintf(fid, 'Ann,30\nBob,25\n');
fclose(fid);
opts = delimitedTextImportOptions('NumVariables', 2, ...
    'VariableNames', {'name', 'age'}, ...
    'VariableTypes', {'string', 'double'}, ...
    'Delimiter', ',');
T = readtable('p.csv', opts)
OutputSaída
T = 2×2 table

    name     age
    _____    ___

    "Ann"    30 
    "Bob"    25

Notes

Observações

In MatLivre, DataLines passed to the constructor is ignored, and assigning VariableNames to the object afterwards (opts.VariableNames = ...) makes readtable fail with an unknown-variable error. Pass names and types as constructor arguments, as in the example, and use header-free data.

No MatLivre, DataLines passado ao construtor é ignorado, e atribuir VariableNames ao objeto depois (opts.VariableNames = ...) faz readtable falhar com erro de variável desconhecida. Passe nomes e tipos como argumentos do construtor, como no exemplo, e use dados sem cabeçalho.

histcounts

Counts how many values fall into each bin.

Conta quantos valores caem em cada intervalo (bin).

Category:Categoria: Data Import and Analysis > Preprocessing Data

Syntax

Sintaxe

[N, edges] = histcounts(X)

Bins X with automatically chosen, equal-width bins.

Distribui X em intervalos de largura igual escolhidos automaticamente.

[N, edges] = histcounts(X, nbins)

Uses nbins equal-width bins.

Usa nbins intervalos de largura igual.

[N, edges] = histcounts(X, edges)

Uses the given bin edges.

Usa as bordas de intervalo fornecidas.

N = histcounts(___, 'Normalization', s)

Scales the counts, for example 'probability'.

Escala as contagens, por exemplo 'probability'.

N = histcounts(___, 'BinWidth', w)

Uses bins of width w.

Usa intervalos de largura w.

Description

Descrição

Each bin includes its left edge and excludes its right edge, except the last bin, which includes both. Values outside the range of the edges, and NaN, are not counted. The function returns numbers only; histogram draws the same data.

With 'probability' the counts are divided by the total number of elements, so they sum to 1 when all data fall inside the bins.

Cada intervalo inclui a borda esquerda e exclui a direita, exceto o último, que inclui as duas. Valores fora da faixa das bordas, e NaN, não são contados. A função retorna apenas números; histogram desenha os mesmos dados.

Com 'probability' as contagens são divididas pelo total de elementos, de modo que somam 1 quando todos os dados caem dentro dos intervalos.

Input arguments

Argumentos de entrada

X
Numeric array; the elements are counted regardless of shape.
Array numérico; os elementos são contados qualquer que seja o formato.
nbins
Number of bins.
Número de intervalos.
edges
Increasing vector of bin edges.
Vetor crescente de bordas dos intervalos.
'Normalization'
'count' (default), 'probability', 'countdensity', 'pdf', 'cumcount' or 'cdf'.
'count' (padrão), 'probability', 'countdensity', 'pdf', 'cumcount' ou 'cdf'.

Output arguments

Argumentos de saída

N
Row vector with one value per bin.
Vetor linha com um valor por intervalo.
edges
Bin edges; N has one fewer element.
Bordas dos intervalos; N tem um elemento a menos.

Example

Exemplo

Explicit edges

Bordas explícitas

x = [1 2 2 3 5 8];
N = histcounts(x, [0 2 4 10])
histcounts(x, [0 2 4 10], 'Normalization', 'probability')
[N, e] = histcounts(x)
OutputSaída
N = 1×3

     1     3     2
ans = 1×3

    0.1667    0.5000    0.3333
N = 1×8

     1     2     1     0     1     0     0     1
e = 1×9

    0.5000    1.5000    2.5000    3.5000    4.5000    5.5000    6.5000    7.5000    8.5000

chirp

Generates a swept-frequency cosine whose frequency moves from f0 to f1 over a given time, with a linear, quadratic or logarithmic sweep.

Category: Waveforms

Syntax

y = chirp(t, f0, t1, f1)

Linear sweep: the instantaneous frequency is f0 at t = 0 and f1 at t = t1.

y = chirp(t, f0, t1, f1, method)

Chooses the sweep with method: 'linear', 'quadratic' or 'logarithmic'.

y = chirp(t, f0, t1, f1, method, phi)

Adds an initial phase phi, in degrees.

y = chirp(t, f0, t1, f1, method, phi, 'complex')

Returns the complex exponential instead of the cosine.

Description

A chirp is a tone whose frequency changes steadily with time. chirp evaluates it at the instants you give, so you choose the sampling yourself: for t = (0:N-1)/fs the signal is valid as long as f0 and f1 stay below fs/2.

A linear sweep changes the frequency by a constant amount per second. A quadratic sweep changes it with the square of time, and 'concave' or 'convex' (after phi) picks which way the parabola bends. A logarithmic sweep changes it by a constant factor per second, so f0 must be positive.

Input arguments

t
Time instants at which to evaluate the signal, in seconds.
f0
Frequency at time 0, in hertz. Default 0 (1e-6 for the logarithmic sweep).
t1
Time at which the frequency reaches f1, in seconds. Default 1.
f1
Frequency at time t1, in hertz. Default 100.
method
Sweep law. A shorter prefix such as 'lin' is accepted. Default 'linear'.
phi
Initial phase in degrees. Default 0.

Output arguments

y
Signal with the same size as t.

Examples

Linear sweep from 0 to 10 Hz

t = 0:0.1:0.5;
y = chirp(t, 0, 0.5, 10);
disp(round(y*1000)/1000)
Output
    1.0000    0.8090   -0.8090    0.8090   -0.8090   -1.0000

Starting phase of 90 degrees

t = 0:0.1:0.5;
y = chirp(t, 0, 0.5, 10, 'linear', 90);
disp(round(y*1000)/1000)
Output
         0   -0.5880   -0.5880    0.5880    0.5880         0

month

Month number of a datetime.

Número do mês de um datetime.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

m = month(t)

Returns the month, 1 for January to 12 for December, of each element of t.

Retorna o mês, 1 para janeiro a 12 para dezembro, de cada elemento de t.

Description

Descrição

month is a shortcut for the month field of datetime. Its companions year, day, hour, minute and second return the other fields. The number is used to group data by month or to build date conditions such as month(t) == 12.

month é um atalho para o campo de mês de datetime. Seus companheiros year, day, hour, minute e second retornam os outros campos. O número serve para agrupar dados por mês ou montar condições de data como month(t) == 12.

Input arguments

Argumentos de entrada

t
datetime array.
Array datetime.

Output arguments

Argumentos de saída

m
Double array of the same size as t.
Array double do mesmo tamanho de t.

Example

Exemplo

Months of some dates

Meses de algumas datas

t = datetime(2024,3,5) + calmonths(0:3);
month(t)
month(datetime(2024,12,25)) == 12
OutputSaída
ans = 1×4

     3     4     5     6
ans = logical
   1

Notes

Observações

MatLivre accepts only datetime, duration or calendarDuration input. The 'name' and 'shortname' options of MATLAB return the month number instead of text, so build names with datestr or string(t, 'MMMM').

O MatLivre aceita apenas entrada datetime, duration ou calendarDuration. As opções 'name' e 'shortname' do MATLAB retornam o número do mês em vez de texto, então monte nomes com datestr ou string(t, 'MMMM').

glmfit next release

Fits a generalized linear model (normal, binomial, Poisson, gamma or inverse Gaussian response) and returns the coefficients, the deviance and statistics.

Category: Regression > Generalized Linear Models > Generalized Linear Regression

Syntax

b = glmfit(X, y)

Fits a linear regression with normal response and an intercept.

b = glmfit(X, y, distr)

Fits the model for the response distribution distr, with the default link of that distribution.

[b, dev, stats] = glmfit(X, y, distr, 'link', link)

Chooses the link function and returns the deviance and a structure of statistics.

[b, dev, stats] = glmfit(X, [k n], 'binomial')

Binomial model with k successes out of n trials per row.

Description

A generalized linear model relates the mean of the response to a linear combination of the predictors through a link function, and lets the response follow a distribution other than the normal. Use 'binomial' for yes/no or proportion data, 'poisson' for counts and 'gamma' for positive, skewed values.

The fit is found by iteratively reweighted least squares. The p field of stats tests each coefficient against zero.

Input arguments

X
Predictors, a matrix with one row per observation and one column per variable. Do not include a column of ones: the intercept is added automatically.
y
Response, a column vector. For 'binomial' it can also be a two-column matrix [k n].
distr
'normal' (default), 'binomial', 'poisson', 'gamma' or 'inverse gaussian'.
'link'
Link function, for example 'identity', 'log', 'logit' or 'probit'. Each distribution has its own default.
'constant'
'on' (default) to include an intercept or 'off' to fit without it.
'estdisp'
'on' to estimate the dispersion parameter for the binomial and Poisson models, where it is otherwise fixed at 1.

Output arguments

b
Coefficient estimates. The first is the intercept when 'constant' is on.
dev
Deviance of the fit, a measure of lack of fit that is smaller for better fits.
stats
Structure with beta, dfe, sfit, s, estdisp, covb, se (standard errors), coeffcorr, t, p (p-values of the coefficients), and the residuals resid, residp, residd, resida, plus the weights wts.

Examples

Logistic regression

X = (1:12)'/3;
y = [0 0 0 1 0 0 1 0 1 1 1 1]';
[b, dev, s] = glmfit(X, y, 'binomial');
fprintf('b = %.4f %.4f\n', b);
fprintf('deviance = %.4f\n', dev);
fprintf('se = %.4f %.4f\n', s.se);
Output
b = -3.8516 1.7777
deviance = 10.0543
se = 2.2042 0.9494

Poisson regression for counts

X = (1:12)'/3;
y = [1 0 2 1 3 2 4 3 6 5 8 9]';
[b, dev] = glmfit(X, y, 'poisson');
fprintf('b = %.4f %.4f\n', b);
fprintf('deviance = %.4f\n', dev);
Output
b = -0.4093 0.6618
deviance = 4.1774

Notes

The 'weights' and 'offset' options are not implemented and raise an error. With the identity link in a Poisson model the coefficients can differ from MATLAB by about 1e-6, because MATLAB stops the iteration one step earlier. For single precision input the fit is computed in double precision and rounded, so results can differ at about 1e-5.

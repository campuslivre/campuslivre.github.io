sortrows

Sorts the rows of a matrix or table by one or more columns.

Ordena as linhas de uma matriz ou tabela por uma ou mais colunas.

Category:Categoria: Language Fundamentals > Matrices and Arrays

Syntax

Sintaxe

B = sortrows(A)

Sorts rows in ascending order, using the first column as the main key and the next ones to break ties.

Ordena as linhas em ordem crescente, usando a primeira coluna como chave principal e as seguintes para desempatar.

B = sortrows(A, col)

Sorts by the columns listed in col. A negative number sorts that column in descending order.

Ordena pelas colunas listadas em col. Um número negativo ordena essa coluna em ordem decrescente.

B = sortrows(A, col, direction)

Applies 'ascend' or 'descend' to the chosen columns.

Aplica 'ascend' ou 'descend' às colunas escolhidas.

[B, I] = sortrows(___)

Also returns the row permutation.

Retorna também a permutação das linhas.

Description

Descrição

Rows are compared lexicographically: the first key column decides, and later columns are consulted only when earlier ones are equal. The sort is stable, so rows that tie on every key keep their original relative order.

Use the second output to apply the same reordering to other arrays, for example names(I).

As linhas são comparadas em ordem lexicográfica: a primeira coluna-chave decide, e as seguintes só são consultadas quando as anteriores empatam. A ordenação é estável, então linhas que empatam em todas as chaves mantêm a ordem original.

A segunda saída permite aplicar a mesma reordenação a outros arrays, por exemplo names(I).

Input arguments

Argumentos de entrada

A
Numeric matrix or table.
Matriz numérica ou tabela.
col
Vector of column indices. The sign gives the direction for each column.
Vetor de índices de colunas. O sinal indica a direção de cada coluna.
direction
'ascend' (default) or 'descend'.
'ascend' (padrão) ou 'descend'.

Output arguments

Argumentos de saída

B
A with its rows reordered. Each row stays intact.
A com as linhas reordenadas. Cada linha permanece inteira.
I
Index vector such that B = A(I,:).
Vetor de índices tal que B = A(I,:).

Example

Exemplo

Sorting by one or two keys

Ordenando por uma ou duas chaves

A = [3 1; 1 2; 1 1; 2 9];
sortrows(A)
[B, I] = sortrows(A, [1 -2]);
B
I'
OutputSaída
ans = 4×2

     1     1
     1     2
     2     9
     3     1
B = 4×2

     1     2
     1     1
     2     9
     3     1
ans = 1×4

     2     3     4     1

Notes

Observações

In MatLivre sortrows works on numeric matrices and tables. Cell arrays and string arrays are not supported yet.

No MatLivre, sortrows funciona com matrizes numéricas e tabelas. Cell arrays e arrays de strings ainda não são suportados.

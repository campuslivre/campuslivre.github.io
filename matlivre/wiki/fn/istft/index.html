istft

Inverts a short-time Fourier transform by overlap-adding the inverse FFT of each column, returning the signal and its time vector.

Category: Time-frequency analysis

Syntax

x = istft(s)

Rebuilds the signal from s, using the default window and overlap.

x = istft(s, fs)

Same, with the sample rate fs used for the time vector.

x = istft(___, Name, Value)

Sets the window, overlap, FFT length and other options.

[x, t] = istft(___)

Also returns the time of each sample.

Description

istft undoes stft. It takes the inverse FFT of every column, multiplies by the window if the method is 'wola', adds the overlapping pieces and divides by the summed window, so a window and overlap that satisfy the overlap-add condition give back the original signal.

Pass the same 'Window', 'OverlapLength', 'FFTLength' and 'FrequencyRange' that you gave to stft. You can check a window with iscola.

Input arguments

s
Short-time Fourier transform, with frequency along the rows and time along the columns (the output of stft).
fs
Sample rate in hertz, or a sample time as a duration. Only the time output t depends on it.
'Window'
Window vector; it must be the one used by stft. Default is a 128-sample periodic Hann window.
'OverlapLength'
Samples shared by consecutive frames. Default is floor(0.75*numel(window)).
'FFTLength'
Number of FFT points used by stft. It must be at least the window length.
'FrequencyRange'
'centered' (default), 'twosided' or 'onesided': how the rows of s are arranged.
'Method'
'wola' (default) or 'ola': whether frames are windowed again before overlap-adding.
'ConjugateSymmetric'
When true, each column is treated as the spectrum of a real frame, so the result is real.

Output arguments

x
Reconstructed signal, a column. For a stft made without padding it has the number of samples covered by the frames.
t
Time of each sample of x, starting at 0. In seconds when fs is given, in samples otherwise.

Example

Go through stft and back

fs = 1000; n = (0:255)';
x = sin(2*pi*100*n/fs) + 0.5*sin(2*pi*250*n/fs);
w = hann(64, 'periodic');
s = stft(x, fs, 'Window', w, 'OverlapLength', 48, 'FFTLength', 64);
[y, t] = istft(s, fs, 'Window', w, 'OverlapLength', 48, 'FFTLength', 64, 'ConjugateSymmetric', true);
fprintf('%d samples, t ends at %.3f s\n', numel(y), t(end));
fprintf('max error below 1e-10: %d\n', max(abs(y - x(1:numel(y)))) < 1e-10);
Output
256 samples, t ends at 0.255 s
max error below 1e-10: 1

Notes

With single-precision input the result agrees with MATLAB only to about 1e-5, because MatLivre computes in double precision and rounds.

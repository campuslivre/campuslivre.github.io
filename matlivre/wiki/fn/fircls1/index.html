fircls1

Designs a lowpass or highpass linear-phase FIR filter by constrained least squares, with the passband and stopband ripples as bounds.

Category: FIR design

Syntax

b = fircls1(n,wo,dp,ds)

Lowpass of order n, cutoff wo, passband ripple dp and stopband ripple ds.

b = fircls1(n,wo,dp,ds,'high')

Designs a highpass filter instead.

b = fircls1(n,wo,dp,ds,'trace')

Also prints progress text.

Description

fircls1 is the two-band special case of fircls: it minimizes the squared error of a lowpass (or highpass) filter subject to ripple bounds that you set directly. The optimization places the transition around wo; its width is not fixed in advance.

Use it when what you know is the allowed ripple rather than the transition width.

Input arguments

n
Filter order. The result has n+1 coefficients.
wo
Cutoff frequency from 0 to 1 (1 is half the sampling rate), between the passband and the stopband.
dp
Largest allowed deviation of the gain from 1 in the passband.
ds
Largest allowed gain in the stopband.

Output arguments

b
Row vector of n+1 coefficients.

Example

Lowpass with 2% and 1% ripple bounds

b = fircls1(30,0.4,0.02,0.01);
[h,w] = freqz(b,1,512);
pb = abs(h(w<0.3*pi));
sb = abs(h(w>0.5*pi));
fprintf('%d coefficients\n', numel(b));
fprintf('passband %.3f to %.3f, stopband max %.3f\n', min(pb), max(pb), max(sb));
Output
31 coefficients
passband 0.980 to 1.020, stopband max 0.010

Notes

MatLivre returns the exact constrained optimum, while MATLAB stops once the bounds are violated by less than about 5e-9, so the coefficients differ from MATLAB's by 1e-7 to 2e-6. The extra constraint edge and the weighted design (wp, ws, k) are not implemented and raise an error.

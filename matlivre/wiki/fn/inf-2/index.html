inf

Creates arrays filled with positive infinity.

Cria arrays preenchidos com infinito positivo.

Category:Categoria: Other public functions: elmat

Syntax

Sintaxe

x = inf

The scalar Inf.

O escalar Inf.

x = inf(n)

An n-by-n matrix of Inf.

Uma matriz n por n de Inf.

x = inf(sz1, ..., szN)

An array with the given dimensions.

Um array com as dimensões dadas.

x = inf(___, classname)

Creates the array as 'double' or 'single'.

Cria o array como 'double' ou 'single'.

x = inf(___, 'like', p)

Uses the class of the variable p.

Usa a classe da variável p.

Description

Descrição

Inf is the IEEE value that results from overflow or from dividing a nonzero number by zero, and it compares larger than every finite number. inf(2, 3) builds a 2-by-3 matrix of them, useful as a starting value for a running minimum: best = inf; best = min(best, v).

Use -inf for negative infinity. Inf is also a name that can be typed directly in an expression.

Inf é o valor IEEE que resulta de estouro ou da divisão de um número não nulo por zero, e é maior que qualquer número finito. inf(2, 3) cria uma matriz 2 por 3 desses valores, útil como valor inicial de um mínimo corrente: best = inf; best = min(best, v).

Use -inf para o infinito negativo. Inf também é um nome que pode ser digitado diretamente numa expressão.

Input arguments

Argumentos de entrada

n, sz1, ..., szN
Non-negative integers with the sizes. Zero gives an empty array.
Inteiros não negativos com os tamanhos. Zero gera um array vazio.
classname
'double' (default) or 'single'.
'double' (padrão) ou 'single'.

Output arguments

Argumentos de saída

x
Array of Inf values.
Array de valores Inf.

Exemplo

Infinity arrays

Arrays de infinito

inf

y = inf(1, 3, 'single');

modalfrf

Estimates the frequency response function between measured input and output signals with the H1, H2 or Hv estimator, plus the coherence.

Category: Vibration analysis

Syntax

[frf, f] = modalfrf(x, y, fs, window)

FRF with the H1 estimator, non-overlapping segments of the window length.

[frf, f, coh] = modalfrf(x, y, fs, window, noverlap)

Overlapping segments, plus the coherence.

[___] = modalfrf(___, 'Estimator', est, 'Sensor', sensor)

Selects the estimator and the sensor type.

Description

The signals are cut into segments, and the averaged cross and auto spectra give the FRF. H1 assumes noise on the output and is the usual choice, H2 assumes noise on the input, and Hv is a compromise for noise on both. The coherence tells how much of the output is explained by the input at each frequency: values near 1 mean a reliable estimate.

The result is the input for modalfit. Remember that the default 'Sensor' is 'acc', which changes the scale of the FRF; pass 'Sensor','dis' to get the raw ratio.

Input arguments

x
Measured input (excitation): a vector, or one column per input.
y
Measured output (response): a vector, or one column per output.
fs
Sample rate in hertz.
window
Window length (a rectangular window is used) or a window vector. It must be an integer length of at least 2 and not larger than the signals.
noverlap
Samples shared by consecutive segments, an integer smaller than the window length. Default 0.
'Estimator'
'h1' (default), 'h2' or 'hv'.
'Sensor'
'acc' (default), 'vel' or 'dis'. With 'acc' or 'vel' the estimate is converted to displacement over force by dividing by -(2*pi*f)^2 or by 1i*2*pi*f. Use 'dis' for the plain estimate.
'Measurement'
'fixed' (default), 'rovinginput' or 'rovingoutput': how the columns of x and y are paired.

Output arguments

frf
Complex frequency response function: one row per frequency, from 0 to fs/2.
f
Frequencies in hertz.
coh
Magnitude-squared coherence, between 0 and 1, same size as frf. It is NaN when there are fewer than two segments.

Example

Find a resonance at 100 Hz

fs = 1000; n = (0:2047)';
x = zeros(size(n));
for k = 1:40
  x = x + sin(2*pi*(7.3*k)*n/fs + k^2);
end
r = 0.95; th = 2*pi*100/fs;
y = filter(1, [1 -2*r*cos(th) r^2], x);
[frf, f, coh] = modalfrf(x, y, fs, 256, 128, 'Sensor', 'dis');
disp(size(frf))
[~, i] = max(abs(frf));
fprintf('peak at %.1f Hz, coherence there %.2f\n', f(i), coh(i));
Output
   129     1
peak at 101.6 Hz, coherence there 0.97

Notes

Not implemented: the 'subspace' estimator, several fixed inputs at once (MIMO), and non-integer window lengths or overlaps. The 'hv' estimator uses a total-least-squares form that differs from MATLAB in the fourth digit. Single-precision input is computed in double precision.

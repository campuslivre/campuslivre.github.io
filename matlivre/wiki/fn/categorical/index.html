categorical

Array of values from a fixed set of categories, stored as labels.

Array de valores de um conjunto fixo de categorias, armazenados como rótulos.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

C = categorical(A)

Creates categories from the unique values of A, sorted.

Cria categorias a partir dos valores únicos de A, em ordem.

C = categorical(A, valueset)

Uses the listed values as the categories, in that order.

Usa os valores listados como categorias, nessa ordem.

C = categorical(A, valueset, catnames)

Also renames the categories.

Também renomeia as categorias.

C = categorical(___, 'Ordinal', true)

Makes the categories ordered so they can be compared with < and >.

Torna as categorias ordenadas, permitindo comparar com < e >.

Description

Descrição

A categorical array stores a small integer code per element plus a list of category names, so repeated labels use little memory and comparisons are fast. Values can be tested with == against a category name, and categories, countcats and summary describe the contents.

Elements that do not belong to any category are <undefined>. When 'Ordinal' is true, the order of valueset defines the ranking.

Um array categorical guarda um pequeno código inteiro por elemento mais a lista de nomes das categorias, de modo que rótulos repetidos usam pouca memória e as comparações são rápidas. Os valores podem ser testados com == contra o nome de uma categoria, e categories, countcats e summary descrevem o conteúdo.

Elementos que não pertencem a nenhuma categoria ficam <undefined>. Com 'Ordinal' verdadeiro, a ordem de valueset define a hierarquia.

Input arguments

Argumentos de entrada

A
Numeric, logical, string, char cell array or categorical data.
Dados numéricos, lógicos, string, cell array de char ou categorical.
valueset
Values to treat as categories; values of A not in the list become undefined.
Valores a tratar como categorias; valores de A fora da lista ficam indefinidos.
catnames
Names for the categories, one per value in valueset.
Nomes das categorias, um por valor em valueset.

Output arguments

Argumentos de saída

C
categorical array of the same size as A.
Array categorical do mesmo tamanho de A.

Example

Exemplo

Labels and category list

Rótulos e lista de categorias

c = categorical({'lo','hi','lo','mid'}, {'lo','mid','hi'}, 'Ordinal', true)
categories(c)
countcats(c)
OutputSaída
c = 1×4 categorical array

     lo      hi      lo      mid 
ans = 3×1 cell

    {'lo' }
    {'mid'}
    {'hi' }
ans = 1×3

     2     1     1

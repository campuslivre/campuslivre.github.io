numRegions

Number of disjoint regions of an alpha shape.

Número de regiões disjuntas de uma alpha shape.

Category:Categoria: Mathematics > Computational Geometry

Syntax

Sintaxe

n = numRegions(shp)

Counts the connected pieces of the shape at its current Alpha.

Conta as peças conexas da forma no seu Alpha atual.

Description

Descrição

Lowering Alpha tends to split the shape into several pieces; raising it merges them. numRegions shows how many pieces the current choice gives. Combined with criticalAlpha(shp, 'one-region') it helps pick an Alpha with a single region.

Diminuir Alpha tende a dividir a forma em várias peças; aumentar as une. numRegions mostra quantas peças a escolha atual produz. Combinada com criticalAlpha(shp, 'one-region'), ajuda a escolher um Alpha com uma única região.

Input arguments

Argumentos de entrada

shp
An alphaShape object.
Um objeto alphaShape.

Output arguments

Argumentos de saída

n
Number of regions, a non-negative integer.
Número de regiões, um inteiro não negativo.

Example

Exemplo

Two clusters, two alpha values

Dois grupos, dois valores de alpha

x = [0 1 1 0 5 6 6 5]';
y = [0 0 1 1 0 0 1 1]';
shp = alphaShape(x, y, 1);
disp(numRegions(shp))
shp.Alpha = 5;
disp(numRegions(shp))
OutputSaída
     2
     1

Notes

Observações

For a polyshape the number of regions is the property NumRegions, not a function call: use P.NumRegions.

Em um polyshape o número de regiões é a propriedade NumRegions, e não uma chamada de função: use P.NumRegions.

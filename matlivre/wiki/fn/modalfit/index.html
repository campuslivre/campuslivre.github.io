modalfit

Identifies natural frequencies, damping ratios and mode shapes from a frequency response function using the least-squares complex exponential method.

Category: Vibration analysis

Syntax

[fn, dr] = modalfit(frf, f, fs, mnum)

Natural frequencies and damping ratios of mnum modes.

[fn, dr, ms] = modalfit(frf, f, fs, mnum)

Also returns the mode shapes.

[fn, dr, ms, ofrf] = modalfit(frf, f, fs, mnum)

Also returns the FRF rebuilt from the identified modes.

Description

The FRF is turned into an impulse response with an inverse FFT, a linear-prediction (Prony) model is fitted to its first samples, and the poles of that model give the natural frequencies and damping ratios. The residues are then found by least squares against the FRF.

The fit can be poor when mnum is too small for the data: in the example, two modes need mnum = 3 to be found well, and the extra entry is NaN. Always compare ofrf with frf, or try a larger mnum.

Input arguments

frf
Frequency response function, a complex column vector with one value per frequency (from 0 up to fs/2), as produced by modalfrf.
f
Frequencies of frf in hertz, evenly spaced from 0.
fs
Sample rate in hertz.
mnum
Number of modes to fit, a positive integer.

Output arguments

fn
Natural frequencies in hertz, a column with mnum entries. Entries that are not found are NaN.
dr
Damping ratios, same size as fn.
ms
Mode shapes, one row for the single FRF and one column per mode.
ofrf
FRF synthesized from the identified modes, same size as frf. Compare it with frf to judge the fit.

Example

Two modes at 50 Hz and 120 Hz

fs = 1000; N = 512; f = (0:N/2)'*fs/N; w = 2*pi*f;
H = zeros(size(f));
w1 = 2*pi*50;  H = H + 1  ./(w1^2 - w.^2 + 2i*0.02*w1*w);
w2 = 2*pi*120; H = H + 0.5./(w2^2 - w.^2 + 2i*0.03*w2*w);
[fn, dr, ms, ofrf] = modalfit(H, f, fs, 3);
disp(round(fn'*10)/10)
disp(round(dr'*100)/100)
fprintf('relative fit error %.2f\n', max(abs(ofrf - H))/max(abs(H)));
Output
    50   120   NaN
    0.0200    0.0300       NaN
relative fit error 0.03

Notes

Only the LSCE method on a single FRF is implemented: 'FitMethod' 'lsrf' and 'pp', 'FreqRange' and several FRFs at once give an error. The mode shapes ms agree with MATLAB to about 1e-5 when the fit is good and can differ when it is poor, and with 'PhysFreq' MATLAB refits the shapes for the selected modes, which is not done here. Single-precision input is solved in double precision (differences near 1e-5).

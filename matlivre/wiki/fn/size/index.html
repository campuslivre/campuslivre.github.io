size

Size of an array along each dimension.

Tamanho de um array ao longo de cada dimensão.

Category:Categoria: Language Fundamentals > Matrices and Arrays

Syntax

Sintaxe

sz = size(A)

Row vector with the length of every dimension.

Vetor linha com o comprimento de cada dimensão.

n = size(A, dim)

Length along dimension dim.

Comprimento ao longo da dimensão dim.

[r, c, ...] = size(A)

One output per dimension; the last absorbs any remaining dimensions.

Uma saída por dimensão; a última absorve as dimensões restantes.

sz = size(A, [d1 d2])

Lengths along several chosen dimensions.

Comprimentos ao longo de várias dimensões escolhidas.

Description

Descrição

A scalar is [1 1], the empty [] is [0 0], and a character vector 'hello' is [1 5]. Asking for a dimension past ndims(A) returns 1.

When there are fewer outputs than dimensions, the last output holds the product of the rest: [r, c] = size(ones(2, 3, 4)) gives r = 2 and c = 12. Use size(A, 1) for rows and size(A, 2) for columns when you need only one number.

Um escalar é [1 1], o vazio [] é [0 0], e um vetor de caracteres 'hello' é [1 5]. Pedir uma dimensão além de ndims(A) retorna 1.

Quando há menos saídas que dimensões, a última saída guarda o produto das restantes: [r, c] = size(ones(2, 3, 4)) dá r = 2 e c = 12. Use size(A, 1) para linhas e size(A, 2) para colunas quando precisar de um número só.

Input arguments

Argumentos de entrada

A
Array of any type.
Array de qualquer tipo.
dim
Dimension number, or vector of dimension numbers.
Número de dimensão, ou vetor de números de dimensão.

Output arguments

Argumentos de saída

sz
Row vector of sizes, at least two elements.
Vetor linha de tamanhos, com pelo menos dois elementos.
r, c, ...
Sizes as separate scalars.
Tamanhos como escalares separados.

Example

Exemplo

A = ones(2, 3, 4);
size(A)
size(A, 2)
[r, c] = size(A)
OutputSaída
ans = 1×3

     2     3     4
ans = 3
r = 2
c = 12

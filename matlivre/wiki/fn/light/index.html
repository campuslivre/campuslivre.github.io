light

Creates a light source in the current axes.

Cria uma fonte de luz nos eixos atuais.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

light

Adds a white, infinitely distant light at the default position [1 0 1].

Adiciona uma luz branca, infinitamente distante, na posição padrão [1 0 1].

light(Name, Value)

Sets properties such as 'Position', 'Color' and 'Style'.

Define propriedades como 'Position', 'Color' e 'Style'.

h = light(___)

Also returns the light object.

Também retorna o objeto de luz.

Description

Descrição

A light only has a visible effect on surfaces and patches whose lighting mode is not 'none'. Set it with lighting gouraud or lighting flat. Without a light object, such surfaces are not shaded.

Several lights can be added to one axes. To place a light by angles instead of coordinates, use lightangle or camlight.

Uma luz só tem efeito visível em superfícies e patches cujo modo de iluminação não seja 'none'. Defina-o com lighting gouraud ou lighting flat. Sem um objeto de luz, essas superfícies não são sombreadas.

Várias luzes podem ser adicionadas aos mesmos eixos. Para posicionar uma luz por ângulos em vez de coordenadas, use lightangle ou camlight.

Input arguments

Argumentos de entrada

Position
Three-element vector [x y z]. For the 'infinite' style it is the direction of the light; for 'local' it is a point in space.
Vetor de três elementos [x y z]. No estilo 'infinite' é a direção da luz; em 'local' é um ponto no espaço.
Color
RGB triplet or color name. Default white.
Trio RGB ou nome de cor. Padrão: branco.
Style
'infinite' (default) or 'local'.
'infinite' (padrão) ou 'local'.

Output arguments

Argumentos de saída

h
Light object, class matlab.graphics.primitive.Light.
Objeto de luz, classe matlab.graphics.primitive.Light.

Example

Exemplo

A lit surface

Uma superfície iluminada

surf(peaks(30))
shading interp
lighting gouraud
h = light('Position', [-1 -1 1]);
h.Style
h.Position
OutputSaída
ans = 'infinite'
ans = 1×3

    -1    -1     1

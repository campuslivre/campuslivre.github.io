mkpp

Builds a piecewise polynomial structure.

Constrói uma estrutura de polinômio por partes.

Category:Categoria: Mathematics > Interpolation

Syntax

Sintaxe

pp = mkpp(breaks, coefs)

Creates the structure from the break points and one row of coefficients per interval.

Cria a estrutura a partir dos pontos de quebra e de uma linha de coeficientes por intervalo.

pp = mkpp(breaks, coefs, d)

Creates a vector-valued piecewise polynomial with values of size d.

Cria um polinômio por partes vetorial com valores de tamanho d.

Description

Descrição

Each row of coefs holds the polynomial for one interval, written in powers of the offset from the left break point: the row [a b c] on the interval starting at t means a*(x-t)^2 + b*(x-t) + c.

The structure is what spline, pchip and makima return when called without query points. Evaluate it with ppval and take it apart with unmkpp.

Cada linha de coefs guarda o polinômio de um intervalo, escrito em potências do deslocamento a partir do ponto de quebra à esquerda: a linha [a b c] no intervalo que começa em t significa a*(x-t)^2 + b*(x-t) + c.

A estrutura é o que spline, pchip e makima retornam quando chamadas sem pontos de consulta. Avalie-a com ppval e desmonte-a com unmkpp.

Input arguments

Argumentos de entrada

breaks
Vector of L+1 increasing break points that define L intervals.
Vetor de L+1 pontos de quebra crescentes, que definem L intervalos.
coefs
Coefficients, one row per interval, highest power first, in the local variable x - breaks(i).
Coeficientes, uma linha por intervalo, da maior potência para a menor, na variável local x - breaks(i).
d
Optional size of the value at each point, for vector-valued functions.
Tamanho opcional do valor em cada ponto, para funções vetoriais.

Output arguments

Argumentos de saída

pp
Structure with fields form, breaks, coefs, pieces, order and dim.
Estrutura com os campos form, breaks, coefs, pieces, order e dim.

Example

Exemplo

Two quadratic pieces

Dois pedaços quadráticos

pp = mkpp([0 1 2], [1 0 0; 2 1 0]);
ppval(pp, [0.5 1.5])
pp.order
OutputSaída
ans = 1×2

    0.2500    1.0000
ans = 3

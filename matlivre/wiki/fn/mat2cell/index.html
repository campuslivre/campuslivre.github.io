mat2cell

Splits an array into a cell array of sub-blocks.

Divide um array em um cell array de subblocos.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

C = mat2cell(A, r)

Splits A along the rows into blocks of r(1), r(2), ... rows, keeping all columns.

Divide A ao longo das linhas em blocos de r(1), r(2), ... linhas, mantendo todas as colunas.

C = mat2cell(A, r, c)

Splits along rows and columns, giving a numel(r)-by-numel(c) cell array.

Divide ao longo de linhas e colunas, dando um cell array numel(r) por numel(c).

Description

Descrição

mat2cell is the inverse of concatenation: [C{:,:}] style joins undo it. It is the usual way to cut a matrix into uneven pieces. When the sums in r or c do not match the size of A, the call is an error.

mat2cell é o inverso da concatenação: juntar com [C{:,:}] o desfaz. É o modo habitual de cortar uma matriz em pedaços desiguais. Quando as somas em r ou c não batem com o tamanho de A, a chamada gera erro.

Input arguments

Argumentos de entrada

A
Array of any type.
Array de qualquer tipo.
r, c
Vectors with the number of rows, and of columns, of each block. Their sums must equal the size of A in that dimension.
Vetores com o número de linhas, e de colunas, de cada bloco. Suas somas devem ser iguais ao tamanho de A naquela dimensão.

Output arguments

Argumentos de saída

C
Cell array whose element C{i,j} is a block of A.
Cell array cujo elemento C{i,j} é um bloco de A.

Example

Exemplo

Cutting a 4-by-4 matrix

Cortando uma matriz 4 por 4

A = magic(4);
C = mat2cell(A, [2 2], [3 1]);
C{1,1}
C{2,2}
OutputSaída
ans = 2×3

    16     2     3
     5    11    10
ans = 2×1

    12
     1

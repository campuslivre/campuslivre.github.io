gamma

Gamma function, the extension of the factorial to real numbers.

Função gama, a extensão do fatorial aos números reais.

Category:Categoria: Mathematics > Elementary Math

Syntax

Sintaxe

Y = gamma(X)

Evaluates the gamma function at each element of X.

Calcula a função gama em cada elemento de X.

Description

Descrição

For positive integers, gamma(n) equals factorial(n-1). For other real values it interpolates smoothly between them, with gamma(0.5) equal to sqrt(pi). The function has poles at zero and at the negative integers, where gamma returns Inf, and it alternates in sign between consecutive negative poles.

The values grow so quickly that they overflow for large arguments. When only the logarithm is needed, gammaln avoids the overflow.

Para inteiros positivos, gamma(n) é igual a factorial(n-1). Para outros valores reais ela interpola suavemente entre eles, e gamma(0.5) vale sqrt(pi). A função tem polos em zero e nos inteiros negativos, onde gamma retorna Inf, e alterna de sinal entre polos negativos consecutivos.

Os valores crescem tão depressa que estouram para argumentos grandes. Quando só o logaritmo é necessário, gammaln evita o estouro.

Input arguments

Argumentos de entrada

X
Real array.
Array real.

Output arguments

Argumentos de saída

Y
Array of the same size as X.
Array do mesmo tamanho de X.

Example

Exemplo

Factorials and half-integers

Fatoriais e meio-inteiros

gamma(0.5)^2
gamma([0 -1.5])

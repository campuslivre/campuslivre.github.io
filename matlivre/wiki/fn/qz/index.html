qz

QZ (generalized Schur) factorization of a pair of square matrices.

Fatoração QZ (Schur generalizada) de um par de matrizes quadradas.

Category:Categoria: Mathematics > Linear Algebra

Syntax

Sintaxe

[AA, BB, Q, Z] = qz(A, B)

Returns upper quasi-triangular AA and upper triangular BB with Q*A*Z = AA and Q*B*Z = BB.

Retorna AA quase triangular superior e BB triangular superior com Q*A*Z = AA e Q*B*Z = BB.

[AA, BB, Q, Z] = qz(A, B, 'complex')

Forces the complex form, in which AA is fully upper triangular.

Força a forma complexa, em que AA é totalmente triangular superior.

Description

Descrição

The QZ algorithm is the generalized counterpart of the Schur decomposition, and it is the basis for computing generalized eigenvalues A*x = lambda*B*x. It works even when B is singular, in which case some eigenvalues are infinite.

In the real form, complex-conjugate eigenvalue pairs appear as 2-by-2 blocks on the diagonal of AA.

O algoritmo QZ é a versão generalizada da decomposição de Schur e é a base do cálculo dos autovalores generalizados A*x = lambda*B*x. Funciona mesmo quando B é singular, caso em que alguns autovalores são infinitos.

Na forma real, pares de autovalores complexos conjugados aparecem como blocos 2 por 2 na diagonal de AA.

Input arguments

Argumentos de entrada

A, B
Square matrices of the same size.
Matrizes quadradas de mesmo tamanho.

Output arguments

Argumentos de saída

AA, BB
The reduced matrices. The generalized eigenvalues are the ratios diag(AA)./diag(BB).
As matrizes reduzidas. Os autovalores generalizados são as razões diag(AA)./diag(BB).
Q, Z
Unitary transformation matrices.
Matrizes de transformação unitárias.

Example

Exemplo

Generalized eigenvalues

Autovalores generalizados

A = [1 2; 3 4];
B = [5 6; 7 8];
[AA, BB, Q, Z] = qz(A, B);
norm(Q*A*Z - AA) < 1e-10
sort(eig(A, B))'
OutputSaída
ans = logical
   1
ans = 1×2

   -0.3723    5.3723

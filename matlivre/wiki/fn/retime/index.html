retime

Changes the row times of a timetable, filling in values by interpolation or another rule.

Muda os tempos das linhas de um timetable, preenchendo os valores por interpolação ou outra regra.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

TT2 = retime(TT, newTimes, method)

Evaluates the timetable at newTimes using method.

Avalia o timetable em newTimes usando method.

TT2 = retime(TT, 'regular', method, 'TimeStep', dt)

Builds a regular time grid with step dt.

Constrói uma grade regular de tempos com passo dt.

TT2 = retime(TT, 'secondly', method)

Uses a built-in time step such as 'secondly', 'minutely' or 'daily'.

Usa um passo de tempo embutido como 'secondly', 'minutely' ou 'daily'.

Description

Descrição

When the new times are denser than the old ones, the method fills in the missing values: 'linear' interpolates, 'previous' repeats the last known value and 'fillwithmissing' leaves NaN. When they are sparser, aggregation methods such as 'mean' and 'sum' combine the rows that fall within each interval.

Use synchronize to align several timetables with each other.

Quando os novos tempos são mais densos que os antigos, o método preenche os valores que faltam: 'linear' interpola, 'previous' repete o último valor conhecido e 'fillwithmissing' deixa NaN. Quando são mais esparsos, métodos de agregação como 'mean' e 'sum' combinam as linhas que caem em cada intervalo.

Use synchronize para alinhar vários timetables entre si.

Input arguments

Argumentos de entrada

TT
Timetable.
Timetable.
newTimes
Datetime or duration vector.
Vetor datetime ou duration.
method
Rule such as 'linear', 'previous', 'next', 'nearest', 'fillwithmissing', 'fillwithconstant', 'sum' or 'mean'.
Regra como 'linear', 'previous', 'next', 'nearest', 'fillwithmissing', 'fillwithconstant', 'sum' ou 'mean'.

Output arguments

Argumentos de saída

TT2
Timetable on the new times, with the same variables.
Timetable nos novos tempos, com as mesmas variáveis.

Example

Exemplo

TT = timetable(seconds([1;2;4]), [10;20;40]);
retime(TT, seconds(1:4), 'linear')
retime(TT, seconds(1:4), 'previous')
retime(TT, seconds(1:4), 'fillwithmissing')

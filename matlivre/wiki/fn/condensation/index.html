condensation

Condensation of a digraph: each strongly connected component becomes one node.

Condensação de um dígrafo: cada componente fortemente conexo vira um nó.

Category:Categoria: Mathematics > Graph and Network Algorithms

Syntax

Sintaxe

C = condensation(G)

Returns the condensed digraph.

Retorna o dígrafo condensado.

Description

Descrição

Two nodes are in the same strongly connected component when each can reach the other. Collapsing every such component into a single node removes all cycles, so the result is always a directed acyclic graph. That makes condensation useful before an ordering or scheduling step.

Component membership of each original node comes from conncomp(G, 'Type', 'strong').

Dois nós estão no mesmo componente fortemente conexo quando cada um alcança o outro. Colapsar cada componente em um único nó elimina todos os ciclos, então o resultado é sempre um grafo acíclico dirigido. Isso torna a condensação útil antes de uma etapa de ordenação ou escalonamento.

A pertinência de cada nó original a um componente vem de conncomp(G, 'Type', 'strong').

Input arguments

Argumentos de entrada

G
A digraph.
Um digraph.

Output arguments

Argumentos de saída

C
A digraph with one node per strongly connected component of G, and an edge between two components when G has an edge from one to the other.
Um dígrafo com um nó por componente fortemente conexo de G, e uma aresta entre dois componentes quando G tem uma aresta de um para o outro.

Example

Exemplo

Collapsing a cycle

Colapsando um ciclo

D = digraph([1 2 3 3 4], [2 3 1 4 5]);
C = condensation(D);
fprintf('%d nodes, %d edges, dag: %d\n', numnodes(C), numedges(C), isdag(C))
OutputSaída
3 nodes, 2 edges, dag: 1

Notes

Observações

MatLivre returns only the condensed digraph, not the component-label vector that MATLAB gives as a second output. Get the labels from conncomp.

O MatLivre retorna apenas o dígrafo condensado, sem o vetor de rótulos de componente que o MATLAB oferece como segunda saída. Obtenha os rótulos com conncomp.

Veja também

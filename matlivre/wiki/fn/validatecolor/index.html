validatecolor

Validates a color specification and returns it as an RGB triplet.

Valida uma especificação de cor e a retorna como um trio RGB.

Category:Categoria: Programming > Functions

Syntax

Sintaxe

rgb = validatecolor(c)

Converts one color given as a name, short name, hex code or RGB row into a 1-by-3 RGB row, or errors if it is invalid.

Converte uma cor dada como nome, nome curto, código hexadecimal ou linha RGB em uma linha RGB 1 por 3, ou gera erro se for inválida.

rgb = validatecolor(c, 'multiple')

Accepts several colors (an m-by-3 matrix, a cell array or a string array) and returns an m-by-3 matrix.

Aceita várias cores (uma matriz m por 3, um cell array ou um array de strings) e retorna uma matriz m por 3.

Description

Descrição

The function accepts the same color forms that plotting functions do and normalizes them to numeric RGB, which is handy before storing or interpolating colors. A name that is not recognized, a malformed hex code or an RGB value outside the range 0 to 1 raises an error that explains what is accepted.

A função aceita as mesmas formas de cor que as funções de gráfico e as normaliza para RGB numérico, o que é útil antes de armazenar ou interpolar cores. Um nome não reconhecido, um código hexadecimal malformado ou um valor RGB fora de 0 a 1 gera um erro que explica o que é aceito.

Input arguments

Argumentos de entrada

c
A color name such as 'red', a short name such as 'r', a hex code like '#FF8000' or '#F80', or an RGB triplet with values from 0 to 1.
Um nome de cor como 'red', um nome curto como 'r', um código hexadecimal como '#FF8000' ou '#F80', ou um trio RGB com valores de 0 a 1.

Output arguments

Argumentos de saída

rgb
Double RGB values between 0 and 1, one row per color.
Valores RGB double entre 0 e 1, uma linha por cor.

Example

Exemplo

Names, hex codes and several colors

Nomes, códigos hexadecimais e várias cores

validatecolor('r')
validatecolor('#FF8000')
validatecolor([1 0 0; 0 1 0], 'multiple')
OutputSaída
ans = 1×3

     1     0     0
ans = 1×3

    1.0000    0.5020         0
ans = 2×3

     1     0     0
     0     1     0

Notes

Observações

MatLivre returns only the RGB output. The three-digit hex form such as '#0F0' is not expanded correctly, so write six digits.

O MatLivre retorna apenas a saída RGB. A forma hexadecimal de três dígitos, como '#0F0', não é expandida corretamente, então escreva seis dígitos.

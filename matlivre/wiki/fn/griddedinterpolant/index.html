griddedInterpolant

Interpolant object for data sampled on a grid.

Objeto interpolador para dados amostrados em uma grade.

Category:Categoria: Mathematics > Interpolation

Syntax

Sintaxe

F = griddedInterpolant(x, v)

Creates a 1-D interpolant over the grid vector x with values v (linear method).

Cria um interpolador 1-D sobre o vetor de grade x com valores v (método linear).

F = griddedInterpolant(X1, X2, ..., V)

Creates an interpolant on an N-D grid given by grid vectors or ndgrid arrays.

Cria um interpolador em uma grade N-D dada por vetores de grade ou arrays no formato ndgrid.

F = griddedInterpolant(..., method, extrapMethod)

Selects the interpolation method and the extrapolation method.

Seleciona o método de interpolação e o de extrapolação.

vq = F(xq)

Evaluates the interpolant at the query points.

Avalia o interpolador nos pontos de consulta.

Description

Descrição

The object stores the grid and the values once, so evaluating it many times is cheaper than repeated calls to interp1 or interpn. Evaluation uses parenthesis syntax, F(xq) for one dimension or F(xq, yq) for two.

The Values and GridVectors properties can be read and changed after creation, for instance to reuse the same grid with new data.

O objeto guarda a grade e os valores uma única vez, então avaliá-lo muitas vezes é mais barato do que chamar interp1 ou interpn repetidamente. A avaliação usa parênteses: F(xq) em uma dimensão ou F(xq, yq) em duas.

As propriedades Values e GridVectors podem ser lidas e alteradas depois da criação, por exemplo para reaproveitar a mesma grade com dados novos.

Input arguments

Argumentos de entrada

x, X1, ...
Sample coordinates along each dimension, strictly increasing.
Coordenadas de amostra em cada dimensão, estritamente crescentes.
V
Array of sample values, with one value for every grid point.
Array de valores, com um valor para cada ponto da grade.
method
'linear' (default), 'nearest', 'next', 'previous', 'pchip', 'cubic', 'spline' or 'makima'.
'linear' (padrão), 'nearest', 'next', 'previous', 'pchip', 'cubic', 'spline' ou 'makima'.
extrapMethod
Method used outside the grid; by default the interpolation method. Use 'none' to get NaN there.
Método usado fora da grade; por padrão, o método de interpolação. Use 'none' para obter NaN ali.

Output arguments

Argumentos de saída

F
Interpolant object with properties such as GridVectors, Values and Method; call it like a function.
Objeto interpolador com propriedades como GridVectors, Values e Method; é chamado como uma função.

Example

Exemplo

Linear and spline interpolants of x^2

Interpoladores linear e spline de x^2

x = 1:4;
v = x.^2;
F = griddedInterpolant(x, v, 'linear');
F(2.5)
S = griddedInterpolant(x, v, 'spline');
S(2.5)
F.Values
OutputSaída
ans = 6.5000
ans = 6.2500
ans = 1×4

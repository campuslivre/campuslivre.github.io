shrinkfaces

Shrinks each face of a patch toward its center, leaving gaps between faces.

Encolhe cada face de um patch em direção ao seu centro, deixando espaços entre as faces.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

nfv = shrinkfaces(fv, sf)

Returns face and vertex data in which every face is scaled by sf.

Retorna dados de faces e vértices em que cada face é escalada por sf.

shrinkfaces(p, sf)

Shrinks the faces of the patch with handle p in place.

Encolhe no próprio objeto as faces do patch de handle p.

Description

Descrição

Each face is scaled about its own centroid. Because neighboring faces must move independently, the vertex list is rebuilt with one copy of the vertices per face. The result helps to see the individual faces of an isosurface or a mesh.

Cada face é escalada em torno do seu próprio centroide. Como faces vizinhas precisam se mover de forma independente, a lista de vértices é refeita com uma cópia dos vértices por face. O resultado ajuda a enxergar as faces individuais de uma isosuperfície ou de uma malha.

Input arguments

Argumentos de entrada

fv
Struct with fields faces and vertices, as returned by isosurface.
Struct com os campos faces e vertices, como retornada por isosurface.
p
Handle of a patch object.
Handle de um objeto patch.
sf
Shrink factor between 0 and 1. A value of 0.5 halves each face; 1 leaves it unchanged.
Fator de redução entre 0 e 1. O valor 0,5 reduz cada face à metade; 1 a deixa como está.

Output arguments

Argumentos de saída

nfv
Struct with faces and vertices. Each original face now owns its own vertices, so vertices are no longer shared between faces.
Struct com faces e vertices. Cada face original passa a ter vértices próprios, que deixam de ser compartilhados entre faces.

Example

Exemplo

Same number of faces, smaller faces

Mesmo número de faces, faces menores

[x, y, z] = meshgrid(1:3);
fv = isosurface(x, y, z, x + y + z, 6);
fv2 = shrinkfaces(fv, 0.5);
disp(size(fv.faces, 1) == size(fv2.faces, 1))
OutputSaída
   1

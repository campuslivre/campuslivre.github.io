zsecondarylabel

Sets the secondary label of the z-axis, shown next to the tick labels.

Define o rótulo secundário do eixo z, exibido junto aos rótulos das marcas.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

zsecondarylabel(txt)

Sets the secondary label of the z-axis of the current axes.

Define o rótulo secundário do eixo z dos eixos atuais.

t = zsecondarylabel(___)

Returns the text object.

Retorna o objeto de texto.

Description

Descrição

The secondary label is a small annotation placed by the tick labels, normally holding a multiplier or a unit such as x10^3. MATLAB fills it automatically when tick values are large; this function overrides that text.

O rótulo secundário é uma pequena anotação ao lado dos rótulos das marcas, normalmente com um multiplicador ou uma unidade, como x10^3. O MATLAB o preenche automaticamente quando os valores das marcas são grandes; esta função substitui esse texto.

Input arguments

Argumentos de entrada

txt
Character vector or string.
Vetor de caracteres ou string.

Output arguments

Argumentos de saída

t
Handle of the secondary label.
Handle do rótulo secundário.

Example

Exemplo

Annotate the z tick labels

Anotar os rótulos de z

[X, Y] = meshgrid(1:5);
surf(X, Y, 1000*X.*Y)
zsecondarylabel('x1000 units')

See also

Veja também

zlabel xsecondarylabel ysecondarylabel ztickformat

kstest next release

One-sample Kolmogorov-Smirnov test: compares the empirical distribution of a sample with a reference distribution (standard normal by default).

Category: Probability Distributions and Hypothesis Tests > Hypothesis Tests

Syntax

h = kstest(x)

Tests whether x comes from the standard normal distribution.

[h, p, ksstat, cv] = kstest(x)

Also returns the p-value, the test statistic and the critical value.

[...] = kstest(x, 'CDF', cdf)

Uses a two-column matrix cdf of sample points and cumulative probabilities as the reference.

[...] = kstest(x, 'Alpha', a, 'Tail', t)

Sets the significance level and the alternative.

Description

The test compares the empirical cumulative distribution of the sample with a fully specified reference. Because the default reference is the standard normal with mean 0 and standard deviation 1, standardize your data first with zscore to test normality of arbitrary data. Estimating the mean and deviation from the same sample makes the p-value too large; for that case use lillietest.

A large p-value does not prove that the sample follows the distribution, only that the test did not find evidence against it.

Input arguments

x
Vector of observations. NaN values are ignored.
'CDF'
Matrix with two columns: values in the first, the reference cumulative probability at those values in the second. Default: the standard normal.
'Alpha'
Significance level. Default 0.05.
'Tail'
'unequal' (default), 'larger' or 'smaller': which difference between the empirical and the reference distribution is tested.

Output arguments

h
1 if the hypothesis that the sample follows the reference distribution is rejected, 0 otherwise.
p
p-value.
ksstat
Largest vertical distance between the empirical and reference cumulative distributions.
cv
Critical value of the statistic at level alpha.

Examples

A symmetric sample against the standard normal

s = (-7:7)'/4;
[h, p, ksstat, cv] = kstest(s);
fprintf('%d %.4f %.4f %.4f\n', h, p, ksstat, cv)
Output
0 0.9868 0.1080 0.3376

A shifted sample, and a custom reference distribution

s = (-7:7)'/4;
[h, p] = kstest(s + 3);
fprintf('%d %.3g\n', h, p)
[h, p] = kstest(s, 'CDF', [s normcdf(s, 0.5, 1)]);
fprintf('%d %.4f\n', h, p)
Output
1 8.8e-12
0 0.2964

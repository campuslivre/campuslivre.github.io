hilbert

Returns the analytic signal of a real signal, whose imaginary part is the Hilbert transform.

Category: Transforms

Syntax

z = hilbert(x)

Analytic signal of x.

z = hilbert(x, n)

Uses an n-point transform, padding or cutting x.

Description

The analytic signal keeps the positive frequencies of x (doubled) and drops the negative ones. Its magnitude abs(z) is the envelope of x, and angle(z) is the instantaneous phase, which instfreq uses with 'Method','hilbert'.

The imaginary part of a cosine is the matching sine, so abs(z) of a pure cosine is 1 everywhere, as in the example. Complex input has its imaginary part ignored, as in MATLAB.

Input arguments

x
Real signal, a vector or a matrix whose columns are processed.
n
Transform length. Default length(x).

Output arguments

z
Complex analytic signal, with real(z) = x and imag(z) the Hilbert transform of x.

Example

Analytic signal of a cosine

n = 0:7;
x = cos(2*pi*n/8);
z = hilbert(x);
disp(round(real(z)*1e3)/1e3)
disp(round(imag(z)*1e3)/1e3)
disp(round(abs(z)*1e3)/1e3)
Output
    1.0000    0.7070         0   -0.7070   -1.0000   -0.7070         0    0.7070
         0    0.7070    1.0000    0.7070         0   -0.7070   -1.0000   -0.7070
     1     1     1     1     1     1     1     1

Notes

Arrays with more than two dimensions are not supported and give the error N-D arrays are not supported.

TriRep

Legacy triangulation representation class, replaced by triangulation.

Classe legada de representação de triangulação, substituída por triangulation.

Category:Categoria: Mathematics > Computational Geometry

Syntax

Sintaxe

TR = TriRep(T, X)

Creates a triangulation representation from the connectivity T and the points X.

Cria uma representação de triangulação a partir da conectividade T e dos pontos X.

TR = TriRep(T, x, y)

Same, with 2-D coordinates given as separate vectors.

Igual, com coordenadas 2-D em vetores separados.

Description

Descrição

TriRep is the older class for holding a triangulation and querying it. It stores the points in X and the connectivity in Triangulation. New code should use triangulation, whose properties are named Points and ConnectivityList, and which has more methods.

TriRep é a classe antiga para guardar uma triangulação e consultá-la. Ela armazena os pontos em X e a conectividade em Triangulation. Código novo deve usar triangulation, cujas propriedades se chamam Points e ConnectivityList e que tem mais métodos.

Input arguments

Argumentos de entrada

T
Matrix of vertex indices, three or four columns.
Matriz de índices de vértices, com três ou quatro colunas.
X
Matrix of point coordinates, one point per row.
Matriz de coordenadas dos pontos, um ponto por linha.

Output arguments

Argumentos de saída

TR
A TriRep object with properties X (points) and Triangulation (connectivity).
Um objeto TriRep com as propriedades X (pontos) e Triangulation (conectividade).

Example

Exemplo

Create and read a TriRep

Criar e ler um TriRep

P = [0 0; 1 0; 1 1; 0 1];
T = [1 2 3; 1 3 4];
TR = TriRep(T, P);
disp(TR.X)
OutputSaída
     0     0
     1     0
     1     1
     0     1

Notes

Observações

MATLAB keeps TriRep only for compatibility and recommends triangulation instead.

O MATLAB mantém TriRep apenas por compatibilidade e recomenda triangulation.

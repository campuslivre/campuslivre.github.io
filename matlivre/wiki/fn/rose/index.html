rose

Angle histogram drawn on polar axes as a rose diagram.

Histograma de ângulos desenhado em eixos polares como um diagrama de rosa.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

rose(theta)

Plots a histogram of the angles theta in radians with 20 bins.

Plota um histograma dos ângulos theta em radianos com 20 bins.

rose(theta, nbins)

Uses nbins bins.

Usa nbins bins.

[tout, rout] = rose(___)

Returns the outline coordinates and draws nothing.

Retorna as coordenadas do contorno e não desenha nada.

Description

Descrição

Each wedge has radius equal to the number of angles in that interval. The diagram is a quick way to see the preferred directions in circular data. polarhistogram is the newer function and returns an object.

Cada setor tem raio igual ao número de ângulos naquele intervalo. O diagrama é uma forma rápida de ver as direções preferenciais em dados circulares. polarhistogram é a função mais nova e retorna um objeto.

Input arguments

Argumentos de entrada

theta
Angles in radians.
Ângulos em radianos.
nbins
Number of bins covering 0 to 2*pi.
Número de bins cobrindo 0 a 2*pi.

Output arguments

Argumentos de saída

tout, rout
Angles and radii of the outline of the wedges, four points per bin. A bin of count c has radius c along its two sides.
Ângulos e raios do contorno dos setores, quatro pontos por bin. Um bin de contagem c tem raio c nos seus dois lados.

Example

Exemplo

Outline of four bins

Contorno de quatro bins

theta = [0.1 0.2 1 2 3];
[t, r] = rose(theta, 4);
r(2:4:end)
OutputSaída
ans = 1×4

     3     2     0     0

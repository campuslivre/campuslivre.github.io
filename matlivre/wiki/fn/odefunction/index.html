odeFunction

Converts symbolic expressions into a numeric function handle for ODE solvers.

Converte expressões simbólicas em um function handle numérico para os solvers de EDO.

Category:Categoria: Mathematics > Equation Solving

Syntax

Sintaxe

f = odeFunction(expr, vars)

Returns a handle f(t, Y) that evaluates the vector expr for the state Y.

Retorna um handle f(t, Y) que avalia o vetor expr para o estado Y.

Description

Descrição

odeFunction does for ODEs what matlabFunction does for plain expressions: it generates a numeric function in which the state variables become the entries of Y. Parameters that are symbolic variables become extra arguments after Y.

odeFunction faz para EDOs o que matlabFunction faz para expressões comuns: gera uma função numérica em que as variáveis de estado viram elementos de Y. Parâmetros que sejam variáveis simbólicas viram argumentos extras depois de Y.

Input arguments

Argumentos de entrada

expr
Vector of symbolic expressions: the right-hand side of y' = expr.
Vetor de expressões simbólicas: o lado direito de y' = expr.
vars
Vector of symbolic functions that make up the state, such as [x(t); y(t)].
Vetor das funções simbólicas que formam o estado, como [x(t); y(t)].

Output arguments

Argumentos de saída

f
Function handle with the signature f(t, Y) expected by ode45, returning a column vector.
Function handle com a assinatura f(t, Y) esperada por ode45, que retorna um vetor coluna.

Example

Exemplo

Harmonic oscillator right-hand side

Lado direito do oscilador harmônico

syms x(t) y(t)
f = odeFunction([y; -x], [x; y]);
f(0, [1; 2])
OutputSaída
ans = 2×1

     2
    -1

Notes

Observações

Passing the output of odeToVectorField (whose state is written Y[1], Y[2]) is not accepted in MatLivre; pass the symbolic functions as vars instead.

Passar a saída de odeToVectorField (cujo estado se escreve Y[1], Y[2]) não é aceito no MatLivre; passe as funções simbólicas como vars.

designfilt

Designs a digital filter from a response type and name-value specifications, and returns a digitalFilter object you can apply with filter.

Category: FIR design

Syntax

d = designfilt(resp,Name,Value)

Designs a filter of type resp (for example 'lowpassfir' or 'lowpassiir') from the specifications given as name-value pairs.

Description

designfilt is a single entry point for the usual filter designs. Instead of choosing between fir1, firpm, butter and the others, you state the response and the specifications, and it picks the method: a window design when you give a cutoff, equiripple when you give passband and stopband edges, and Butterworth, Chebyshev or elliptic for IIR depending on which ripple and attenuation values you set.

Frequencies are normalized (the sampling rate is 2, so 1 is the Nyquist frequency) unless you set 'SampleRate'. Apply the result with filter(d,x).

Input arguments

resp
Response and implementation: 'lowpassfir', 'highpassfir', 'bandpassfir', 'bandstopfir', 'lowpassiir', 'highpassiir', 'bandpassiir' or 'bandstopiir'.
Name,Value
Specifications such as 'FilterOrder', 'CutoffFrequency', 'HalfPowerFrequency', 'PassbandFrequency', 'StopbandFrequency', 'PassbandRipple', 'StopbandAttenuation', 'SampleRate' and 'DesignMethod'. Which sets are valid depends on resp; an incomplete or excess set raises an error that lists valid sets.

Output arguments

d
A digitalFilter object. d.Coefficients holds the numerator for FIR designs and an L-by-6 second-order-section matrix for IIR designs. Its other properties repeat the specifications.

Examples

FIR lowpass by the window method

d = designfilt('lowpassfir','FilterOrder',20,'CutoffFrequency',0.3,'DesignMethod','window');
disp(size(d.Coefficients))
disp(round(d.Coefficients(9:13)*10000)/10000)
Output
     1    21
    0.1379    0.2513    0.2996    0.2513    0.1379

IIR Butterworth lowpass applied to an impulse

d = designfilt('lowpassiir','FilterOrder',4,'HalfPowerFrequency',0.3);
disp(size(d.Coefficients))
y = filter(d,[1 zeros(1,5)]);
disp(round(y*10000)/10000)
Output
     2     6
    0.0186    0.1034    0.2501    0.3441    0.2886    0.1275

Notes

Not implemented, and they raise an error: the responses 'differentiatorfir', 'hilbertfir', 'arbmagfir', 'notchiir' and 'peakiir', FIR designs with 'HalfPowerFrequency' (maxflat), the Kaiser-window minimum-order design, and editing an existing digitalFilter object. For IIR filters the transfer function agrees with MATLAB, but the way the total gain is split among the numerators of the sections in d.Coefficients differs.

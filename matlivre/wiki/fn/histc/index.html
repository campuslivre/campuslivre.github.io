histc

Counts how many values fall in each interval defined by a vector of bin edges.

Conta quantos valores caem em cada intervalo definido por um vetor de bordas.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

n = histc(x, edges)

Counts the elements of x in each bin edges(k) <= x < edges(k+1).

Conta os elementos de x em cada bin edges(k) <= x < edges(k+1).

[n, bin] = histc(x, edges)

Also returns the bin index of each element of x.

Também retorna o índice do bin de cada elemento de x.

n = histc(x, edges, dim)

Counts along dimension dim.

Conta ao longo da dimensão dim.

Description

Descrição

Every bin is closed on the left and open on the right, except for the last, which holds only values exactly equal to the final edge. Values below the first edge or above the last one are not counted. For a matrix, each column is counted separately.

histc is kept for compatibility; histcounts is the recommended replacement and its last bin includes the right edge.

Todo bin é fechado à esquerda e aberto à direita, exceto o último, que contém apenas valores exatamente iguais à última borda. Valores abaixo da primeira borda ou acima da última não são contados. Para uma matriz, cada coluna é contada separadamente.

histc é mantida por compatibilidade; histcounts é a substituta recomendada e seu último bin inclui a borda direita.

Input arguments

Argumentos de entrada

x
Vector or array of values.
Vetor ou array de valores.
edges
Monotonically non-decreasing vector of bin edges.
Vetor de bordas, monotonicamente não decrescente.
dim
Dimension along which to count; by default the first non-singleton one.
Dimensão ao longo da qual contar; por padrão a primeira não unitária.

Output arguments

Argumentos de saída

n
Counts, with as many elements along the counting dimension as edges. The last element counts values equal to edges(end).
Contagens, com tantos elementos na dimensão de contagem quanto edges. O último elemento conta valores iguais a edges(end).
bin
Bin index for each element of x, or 0 when it falls outside all bins.
Índice do bin de cada elemento de x, ou 0 quando cai fora de todos os bins.

Example

Exemplo

Counts and bin indices

Contagens e índices de bin

x = [1 2 2 3 3 3 4 4 5 9];
[n, bin] = histc(x, [0 3 6 9])
OutputSaída
n = 1×4

     3     6     0     1
bin = 1×10

     1     1     1     2     2     2     2     2     2     4

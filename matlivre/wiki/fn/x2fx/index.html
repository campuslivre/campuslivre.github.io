x2fx next release

Converts a matrix of predictors into a design matrix for a chosen model: linear, interaction, quadratic or a custom term matrix.

Category: Regression > Linear Regression > Multiple Linear Regression

Syntax

D = x2fx(X)

Linear model with a constant column.

D = x2fx(X, model)

model is 'linear', 'interaction', 'quadratic', 'purequadratic' or a terms matrix.

[D, model] = x2fx(X, model)

Also returns the terms matrix that was used.

Description

'linear' gives a constant and each predictor. 'interaction' adds the products of pairs. 'purequadratic' adds the squares. 'quadratic' has all of those. The column order follows the terms matrix.

A custom terms matrix such as [0 0; 1 0; 0 1; 1 1] means: constant, first predictor, second predictor, and their product.

Input arguments

X
n-by-p matrix of predictors.
model
Model name, or a terms matrix with one row per term and one column per predictor, whose entries are the exponents. A row of zeros is the constant.

Output arguments

D
Design matrix with one column per term, ready for regress or \.
model
The terms matrix describing the columns of D.

Examples

Interaction model for two predictors

X = [1 2; 3 4; 5 6];
D = x2fx(X, 'interaction')
Output
D = 3×4

     1     1     2     2
     1     3     4    12
     1     5     6    30

Quadratic model and its terms matrix

X = [1 2; 3 4; 5 6];
[D, m] = x2fx(X, 'quadratic');
disp(D)
disp(m)
Output
     1     1     2     2     1     4
     1     3     4    12     9    16
     1     5     6    30    25    36
     0     0
     1     0
     0     1
     1     1
     2     0
     0     2

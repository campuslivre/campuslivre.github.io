norm

Norm of a vector or matrix.

Norma de um vetor ou matriz.

Category:Categoria: Mathematics > Linear Algebra

Syntax

Sintaxe

n = norm(v)

Euclidean length of a vector, or the 2-norm of a matrix (largest singular value).

Comprimento euclidiano de um vetor, ou norma 2 de uma matriz (maior valor singular).

n = norm(X, p)

The p-norm: 1, 2, Inf, 'fro', and any p >= 1 for vectors.

A norma p: 1, 2, Inf, 'fro' e qualquer p >= 1 para vetores.

Description

Descrição

For a vector, the 1-norm is the sum of absolute values, the 2-norm is the usual length, and the infinity norm is the largest absolute value. For a matrix, the 1-norm is the largest column sum of absolute values, the infinity norm is the largest row sum, the 2-norm is the largest singular value, and the Frobenius norm is the square root of the sum of squares of all entries.

Note that for a matrix norm(A) is the 2-norm and is not the same as the Frobenius norm. The 2-norm needs a singular value computation; for large matrices normest is cheaper.

Para um vetor, a norma 1 é a soma dos valores absolutos, a norma 2 é o comprimento usual e a norma infinito é o maior valor absoluto. Para uma matriz, a norma 1 é a maior soma de colunas dos valores absolutos, a norma infinito é a maior soma de linhas, a norma 2 é o maior valor singular e a norma de Frobenius é a raiz quadrada da soma dos quadrados de todas as entradas.

Observe que, para uma matriz, norm(A) é a norma 2 e não é igual à norma de Frobenius. A norma 2 exige um cálculo de valores singulares; para matrizes grandes, normest é mais barato.

Input arguments

Argumentos de entrada

X
Vector or matrix.
Vetor ou matriz.
p
Norm type, default 2. 'fro' is the Frobenius norm.
Tipo de norma, padrão 2. 'fro' é a norma de Frobenius.

Output arguments

Argumentos de saída

n
Non-negative scalar. The norm of an empty array is 0.
Escalar não negativo. A norma de um array vazio é 0.

Example

Exemplo

Vector and matrix norms

Normas de vetor e de matriz

v = [3 4];
norm(v)
norm(v, 1)
norm(v, Inf)
A = [1 2; 3 4];
norm(A)
norm(A, 'fro')
norm(A, 1)

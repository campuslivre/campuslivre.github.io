movmean

Moving average over a sliding window.

Média móvel sobre uma janela deslizante.

Category:Categoria: Data Import and Analysis > Preprocessing Data

Syntax

Sintaxe

M = movmean(A, wlen)

Mean over a window of wlen elements centered on each element.

Média sobre uma janela de wlen elementos centrada em cada elemento.

M = movmean(A, [nb na])

Window of nb elements before and na after the current one, plus the element itself.

Janela com nb elementos antes e na depois do atual, mais o próprio elemento.

M = movmean(A, wlen, 'Endpoints', 'discard')

Drops the positions where the window does not fit entirely.

Descarta as posições em que a janela não cabe por inteiro.

Description

Descrição

movmean is the classic moving average, used to smooth noise and reveal a trend. A longer window smooths more but blurs fast changes. A centered window does not shift the signal in time, while a one-sided window such as [k 0] follows the data with a delay.

By default the window shrinks near the ends so that the output has the same length as the input.

movmean é a média móvel clássica, usada para suavizar ruído e revelar uma tendência. Uma janela maior suaviza mais, mas borra mudanças rápidas. Uma janela centrada não desloca o sinal no tempo, enquanto uma janela unilateral como [k 0] acompanha os dados com atraso.

Por padrão a janela encolhe perto das pontas, de modo que a saída tenha o mesmo comprimento da entrada.

Input arguments

Argumentos de entrada

A
Vector or matrix; operates along the first non-singleton dimension.
Vetor ou matriz; atua na primeira dimensão de tamanho diferente de 1.
wlen
Window length. For an even length the window is centered between elements, with one more element before than after.
Comprimento da janela. Se for par, a janela fica centrada entre elementos, com um elemento a mais antes do que depois.
'Endpoints'
How to treat the ends: 'shrink' (default) uses the available elements; 'discard' removes the incomplete positions.
Como tratar as pontas: 'shrink' (padrão) usa os elementos disponíveis; 'discard' remove as posições incompletas.

Output arguments

Argumentos de saída

M
Smoothed array. Same size as A unless endpoints are discarded.
Array suavizado. Mesmo tamanho de A, a menos que as pontas sejam descartadas.

Example

Exemplo

Centered, trailing and discarded ends

Centrada, à esquerda e pontas descartadas

x = [1 2 3 4 5];
movmean(x, 3)
movmean(x, [1 0])
movmean(x, 3, 'Endpoints', 'discard')
OutputSaída
ans = 1×5

    1.5000    2.0000    3.0000    4.0000    4.5000
ans = 1×5

    1.0000    1.5000    2.5000    3.5000    4.5000

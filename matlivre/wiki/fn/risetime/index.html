risetime

Measures how long a rising transition takes to go from the lower to the upper reference level, usually 10% to 90%.

Category: Pulse and transition metrics

Syntax

r = risetime(x)

Rise time of each rising transition, in samples.

r = risetime(x, t)

Rise time in the units of the time vector t.

[r, lt, ut, ll, ul] = risetime(x, ...)

Also returns the crossing times and the two reference levels.

Description

The state levels are estimated first, then the lower and upper reference levels are placed at the chosen percentages of the span between them. The rise time is the time between the crossings of these two levels, found by linear interpolation.

The optional name-value pair 'PercentReferenceLevels' (default [10 90]) sets the lower and upper reference levels as percentages of the distance between the two state levels, and 'Tolerance' (default 2) and 'StateLevels' work as in the pulse functions.

Input arguments

x
Real vector holding the waveform.
fs
Sampling rate. Times are then in seconds. Default: times are in samples.
t
Vector of sample times, instead of fs.
'PercentReferenceLevels'
Two-element vector in percent. Default [10 90].

Output arguments

r
Rise time of each rising transition.
lt, ut
Times at which the signal crosses the lower and upper reference level.
ll, ul
Lower and upper reference levels, in signal units.

Example

Rise time of a first-order step response

t = (0:0.01:1)';
y = 1 - exp(-8*t);
[r, lt, ut] = risetime(y, t);
fprintf('%.4f %.4f %.4f\n', r, lt, ut);
Output
0.2688 0.0138 0.2826

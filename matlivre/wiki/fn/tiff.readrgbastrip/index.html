Tiff.readRGBAStrip

Reads one strip converted to RGB color data.

Lê uma faixa (strip) convertida em dados de cor RGB.

Category:Categoria: Data Import and Analysis > Data Import and Export

Syntax

Sintaxe

A = readRGBAStrip(t, row)

Returns the strip that starts at image row row.

Retorna a faixa que começa na linha row da imagem.

Description

Descrição

The method acts on a Tiff object created with Tiff(filename, mode). It is the color-converted counterpart of readEncodedStrip, useful for displaying a large image in bands. The row argument must be the first row of a strip.

O método atua sobre um objeto Tiff criado com Tiff(filename, mode). É a contraparte com conversão de cor de readEncodedStrip, útil para exibir uma imagem grande em bandas. O argumento de linha deve ser a primeira linha de uma faixa.

Input arguments

Argumentos de entrada

t
Tiff object opened on a stripped image.
Objeto Tiff aberto sobre uma imagem em faixas.
row
Row number where the strip starts, counted from 1. Rows start at 1, 1 + RowsPerStrip, and so on.
Número da linha em que a faixa começa, contado a partir de 1. As faixas começam em 1, 1 + RowsPerStrip e assim por diante.

Output arguments

Argumentos de saída

A
uint8 color array covering the rows of that strip.
Array de cor uint8 que cobre as linhas dessa faixa.

Example

Exemplo

First strip as color

Primeira faixa como cor

tag.ImageLength = 8; tag.ImageWidth = 8;
tag.Photometric = Tiff.Photometric.MinIsBlack;
tag.BitsPerSample = 8; tag.SamplesPerPixel = 1; tag.RowsPerStrip = 4;
tag.PlanarConfiguration = Tiff.PlanarConfiguration.Chunky;
I = uint8(magic(8) * 3);
w = Tiff('t.tif', 'w'); w.setTag(tag); w.write(I); w.close();
r = Tiff('t.tif', 'r');
A = r.readRGBAStrip(1);
size(A, 1:2)
class(A)
r.close();
OutputSaída
ans = 1×2

     4     8
ans = 'uint8'

append

Joins text from several inputs end to end.

Une o texto de várias entradas, uma depois da outra.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

s = append(str1, ..., strN)

Concatenates the inputs in order.

Concatena as entradas em ordem.

Description

Descrição

With string arrays the join is element by element, and a scalar is repeated against every element, so append("x", ["1" "2"]) gives "x1" and "x2". A missing string in any input makes that result element missing.

Com arrays de strings a junção é elemento a elemento, e um escalar se repete contra cada elemento, de modo que append("x", ["1" "2"]) dá "x1" e "x2". Uma string ausente em qualquer entrada torna ausente o elemento do resultado.

Input arguments

Argumentos de entrada

str1, ..., strN
Strings, character vectors or arrays of them. Sizes must be compatible, or scalar.
Strings, vetores de caracteres ou arrays deles. Os tamanhos devem ser compatíveis, ou escalares.

Output arguments

Argumentos de saída

s
A string array when any input is a string, otherwise a character vector.
Um array de strings quando alguma entrada é string, caso contrário um vetor de caracteres.

Example

Exemplo

Join text

Juntar textos

append("ab", "cd")
append('a', 'b', 'c')
append("x", ["1" "2"])
OutputSaída
ans = "abcd"
ans = 'abc'
ans = 1×2 string array

    "x1"    "x2"

Notes

Observações

In MatLivre, cell array inputs are not accepted.

No MatLivre, entradas do tipo cell array não são aceitas.

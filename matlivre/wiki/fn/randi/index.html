randi

Random integers drawn uniformly from a range.

Inteiros aleatórios sorteados de forma uniforme em um intervalo.

Category:Categoria: Mathematics > Random Number Generation

Syntax

Sintaxe

r = randi(imax)

Returns one integer from 1 to imax.

Retorna um inteiro de 1 a imax.

r = randi(imax, n)

Returns an n-by-n matrix.

Retorna uma matriz n-por-n.

r = randi(imax, sz1, ..., szN)

Returns an array with the given dimensions.

Retorna um array com as dimensões indicadas.

r = randi([imin imax], ___)

Draws from imin to imax instead of starting at 1.

Sorteia de imin a imax em vez de começar em 1.

r = randi(___, classname)

Returns integers of the given class, such as 'int8' or 'uint16'.

Retorna inteiros da classe indicada, como 'int8' ou 'uint16'.

Description

Descrição

Each element is an independent draw from the discrete uniform distribution on the range. The values come from the global random stream, so rng makes them repeatable.

The result is a double by default even though the values are whole numbers. Passing an integer class gives a compact array of that type.

Cada elemento é um sorteio independente da distribuição uniforme discreta no intervalo. Os valores vêm do fluxo aleatório global, de modo que rng os torna repetíveis.

O resultado é double por padrão, embora os valores sejam inteiros. Informar uma classe inteira gera um array compacto desse tipo.

Input arguments

Argumentos de entrada

imax
Positive integer: the largest value possible.
Inteiro positivo: o maior valor possível.
[imin imax]
Two-element vector with imin <= imax; negatives are allowed.
Vetor de dois elementos com imin <= imax; negativos são permitidos.
classname
Result class: 'double' (default), 'single' or an integer class.
Classe do resultado: 'double' (padrão), 'single' ou uma classe inteira.

Output arguments

Argumentos de saída

r
Array of integers, every value in the range equally likely.
Array de inteiros, com todos os valores do intervalo igualmente prováveis.

Example

Exemplo

Dice, a range and an integer class

Dados, um intervalo e uma classe inteira

rng(1);
randi(6, 1, 8)
randi([-2 2], 2, 3)
class(randi(9, 2, 'uint8'))
OutputSaída
ans = 1×8

     3     5     1     2     1     1     2     3
ans = 2×3

    -1     0    -1
     0     1     2
ans = 'uint8'

Notes

Observações

The generator is seeded like MATLAB's, but the integers produced for a given seed may differ from the ones MATLAB gives.

O gerador é inicializado como o do MATLAB, mas os inteiros produzidos para uma dada semente podem diferir dos que o MATLAB fornece.

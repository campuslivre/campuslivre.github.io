polarbubblechart

Bubble chart in polar coordinates, with the bubble area given by a third variable.

Gráfico de bolhas em coordenadas polares, com a área da bolha dada por uma terceira variável.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

polarbubblechart(theta, r, sz)

Draws a bubble at each angle and radius, with area from sz.

Desenha uma bolha em cada ângulo e raio, com área dada por sz.

polarbubblechart(theta, r, sz, c)

Colors the bubbles with c.

Colore as bolhas com c.

polarbubblechart(___, Name, Value)

Sets properties such as 'MarkerFaceAlpha'.

Define propriedades como 'MarkerFaceAlpha'.

b = polarbubblechart(___)

Also returns the bubble chart object.

Também retorna o objeto do gráfico de bolhas.

Description

Descrição

It extends polarscatter with a size channel, so three quantities are shown at once: two by position and one by area. Sizes are scaled to a range of bubble diameters, so only their ratios matter.

Estende polarscatter com um canal de tamanho, mostrando três grandezas de uma vez: duas pela posição e uma pela área. Os tamanhos são escalados para uma faixa de diâmetros de bolha, então apenas suas razões importam.

Input arguments

Argumentos de entrada

theta
Angles in radians.
Ângulos em radianos.
r
Radii.
Raios.
sz
Values that set the bubble size, relative to each other.
Valores que definem o tamanho das bolhas, relativos entre si.
c
Color: a color spec, an RGB triplet or one value per point.
Cor: uma especificação de cor, um trio RGB ou um valor por ponto.

Output arguments

Argumentos de saída

b
BubbleChart object.
Objeto BubbleChart.

Example

Exemplo

Wind speed by direction

Velocidade do vento por direção

theta = deg2rad([0 45 90 180 270]);
r = [2 3 1 4 2];
sz = [10 30 5 40 15];
polarbubblechart(theta, r, sz)

In the app, the chart is drawn below the code.

No app, o gráfico é desenhado abaixo do código.

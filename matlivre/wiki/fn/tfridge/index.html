tfridge

Finds the ridges of a time-frequency map, the curves of highest energy over time, with an optional penalty on frequency jumps.

Category: Time-frequency analysis

Syntax

[fridge, iridge] = tfridge(tfm, f)

Finds the strongest ridge.

[fridge, iridge] = tfridge(tfm, f, penalty)

Penalizes jumps in frequency between neighbouring columns.

[fridge, iridge, lridge] = tfridge(___, 'NumRidges', nr)

Finds nr ridges; lridge holds their linear indices.

Description

A ridge is the path of a component whose frequency changes with time, such as a chirp or a rotating machine's harmonic. tfridge finds it by dynamic programming: it picks, column by column, the path that gets the most energy while paying a price for large jumps in frequency.

A penalty of 0 simply takes the maximum of every column, which can jump around in noise. Raising the penalty makes the path smoother. Combine iridge with ifsst to extract the component as a signal.

Input arguments

tfm
Time-frequency map, a real matrix with frequency along the rows and time along the columns, for example abs(s) from spectrogram or stft. The ridge follows its maximum, so larger means more energy.
f
Frequency of each row of tfm.
penalty
Nonnegative scalar. Each jump of d rows between neighbouring columns costs penalty*d^2. Default 0, which just picks the largest value in each column.
'NumRidges'
Number of ridges to extract. After each one, the rows within 'NumFrequencyBins' of it are cleared. Default 1.
'NumFrequencyBins'
Rows cleared on each side of an extracted ridge before the next search. Default 4.

Output arguments

fridge
Ridge frequencies, one row per time column of tfm and one column per ridge.
iridge
Row index of the ridge in each column, same size as fridge.
lridge
Linear index of each ridge point in tfm.

Example

Follow a chirp in a spectrogram

fs = 1000; t = (0:511)'/fs;
x = cos(2*pi*(50*t + 100*t.^2));
[s, f, tt] = spectrogram(x, hann(64), 48, 64, fs);
[fr, ir] = tfridge(abs(s), f);
disp(size(fr))
disp(round(fr(1:4:end)'))
disp(round(50 + 200*tt(1:4:end)))
Output
    29     1
    63    63    78    94   109   125   141   141
    56    69    82    95   108   120   133   146

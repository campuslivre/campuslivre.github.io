yregion

Shades a horizontal band between two y values.

Sombreia uma faixa horizontal entre dois valores de y.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

yregion(y1, y2)

Shades the band from y1 to y2 over the full width of the axes.

Sombreia a faixa de y1 a y2 em toda a largura dos eixos.

yregion(y1, y2, Name, Value)

Sets properties such as 'FaceColor' and 'FaceAlpha'.

Define propriedades como 'FaceColor' e 'FaceAlpha'.

yr = yregion(___)

Returns the region object.

Retorna o objeto da região.

Description

Descrição

The band stays attached to its y values, so it fills the whole plot width whatever the limits. It does not change the automatic limits. It is used to show a tolerance range, a safe operating band or a level of interest.

The vertical counterpart is xregion.

A faixa permanece ligada aos seus valores de y, preenchendo toda a largura do gráfico quaisquer que sejam os limites. Ela não altera os limites automáticos. É usada para mostrar uma faixa de tolerância, uma região segura de operação ou um nível de interesse.

A versão vertical é xregion.

Input arguments

Argumentos de entrada

y1, y2
Edges of the band along the y-axis. Vectors of equal length draw several bands.
Bordas da faixa ao longo do eixo y. Vetores de mesmo comprimento desenham várias faixas.

Output arguments

Argumentos de saída

yr
Constant region object, class matlab.graphics.chart.decoration.ConstantRegion, with the property Value holding [y1 y2].
Objeto de região constante, classe matlab.graphics.chart.decoration.ConstantRegion, com a propriedade Value guardando [y1 y2].

Example

Exemplo

Highlight a tolerance band

Destacar uma faixa de tolerância

y = [3 5 4 6 2 7];
plot(y)
r = yregion(3, 5, 'FaceColor', 'g');
r.Value
OutputSaída
ans = 1×2

     3     5

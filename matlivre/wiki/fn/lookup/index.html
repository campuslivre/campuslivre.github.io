lookup

Reads the value for a key in a dictionary, with an optional fallback.

Lê o valor de uma chave em um dictionary, com um valor alternativo opcional.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

v = lookup(D, key)

Returns the value stored under key. An error is raised if the key is absent.

Retorna o valor guardado sob key. Gera erro se a chave não existir.

v = lookup(D, key, FallbackValue=fv)

Returns fv for keys that are not in the dictionary.

Retorna fv para chaves que não estão no dictionary.

Description

Descrição

lookup(D, key) does the same as D(key), but the function form accepts FallbackValue, which makes it convenient for counting or default settings: lookup(D, k, FallbackValue=0) never fails on a new key. Combine it with isKey when a different action is needed for missing keys.

lookup(D, key) faz o mesmo que D(key), mas a forma de função aceita FallbackValue, o que ajuda em contagens ou configurações padrão: lookup(D, k, FallbackValue=0) nunca falha com uma chave nova. Combine com isKey quando for preciso outra ação para chaves ausentes.

Input arguments

Argumentos de entrada

D
A dictionary object.
Um objeto dictionary.
key
A key, or an array of keys.
Uma chave, ou um array de chaves.
FallbackValue
Value to return for missing keys, instead of an error.
Valor a retornar para chaves ausentes, em vez de erro.

Output arguments

Argumentos de saída

v
The value, or an array of values with the shape of key.
O valor, ou um array de valores com a forma de key.

Example

Exemplo

A lookup with fallback

Consulta com valor alternativo

d = dictionary(["a" "b"], [10 20]);
lookup(d, "a")
lookup(d, "z", FallbackValue=-1)
OutputSaída
ans = 10
ans = -1

Notes

Observações

This entry describes the dictionary method. For a containers.Map, read values with M(key) and values(M, keys).

Este verbete descreve o método de dictionary. Para um containers.Map, leia valores com M(key) e values(M, keys).

See also

Veja também

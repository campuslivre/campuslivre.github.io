setvartype

Sets the data type of variables in import options.

Define o tipo de dados de variáveis nas opções de importação.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

opts = setvartype(opts, vars, type)

Reads the variables vars as type.

Lê as variáveis vars como type.

opts = setvartype(opts, type)

Sets the type of every variable.

Define o tipo de todas as variáveis.

Description

Descrição

The detected types are only a guess from the first rows. setvartype overrides them before the file is read, for example to read an identifier column as text so that leading zeros are kept, or a number column as single to save memory.

Os tipos detectados são só um palpite feito a partir das primeiras linhas. setvartype os sobrescreve antes de ler o arquivo, por exemplo para ler uma coluna de identificadores como texto e preservar zeros à esquerda, ou uma coluna numérica como single para economizar memória.

Input arguments

Argumentos de entrada

opts
Import options from detectImportOptions.
Opções de importação de detectImportOptions.
vars
Variable name, cell array of names, or indices.
Nome de variável, cell array de nomes, ou índices.
type
Type name such as 'double', 'single', 'int8', 'string', 'categorical' or 'datetime'.
Nome de tipo como 'double', 'single', 'int8', 'string', 'categorical' ou 'datetime'.

Output arguments

Argumentos de saída

opts
The updated options. opts.VariableTypes lists the types.
As opções atualizadas. opts.VariableTypes lista os tipos.

Example

Exemplo

fid = fopen('v.csv', 'w');
fprintf(fid, 'id,score\n1,2.5\n2,3.5\n');
fclose(fid);
opts = detectImportOptions('v.csv');
opts = setvartype(opts, {'id','score'}, 'single');
opts.VariableTypes
OutputSaída
ans = 1×2 cell

    {'single'}    {'single'}

Notes

Observações

In MatLivre setvartype works on import options only, not on tables; for tables use convertvars.

No MatLivre setvartype funciona apenas com opções de importação, não com tabelas; para tabelas use convertvars.

Veja também

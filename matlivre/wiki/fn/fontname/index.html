fontname

Sets the font name of the text in a figure or graphics object.

Define o nome da fonte do texto de uma figura ou objeto gráfico.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

fontname(name)

Sets the font of the text in the current figure to name.

Define a fonte do texto da figura atual como name.

fontname(obj, name)

Sets the font for the figure, axes or other container obj and the text inside it.

Define a fonte da figura, dos eixos ou de outro contêiner obj e do texto dentro dele.

Description

Descrição

fontname is a shortcut for setting the FontName property on every object under obj that has one, so a single call restyles titles, labels and tick labels together.

The function does not draw anything by itself. It affects the text that already exists when it is called.

fontname é um atalho para definir a propriedade FontName de todo objeto sob obj que a possua, de modo que uma única chamada altera títulos, rótulos e marcas de eixo ao mesmo tempo.

A função não desenha nada por si só. Ela atua sobre o texto que já existe quando é chamada.

Input arguments

Argumentos de entrada

name
Font name as text, such as 'Arial'. The value 'default' restores the default font.
Nome da fonte como texto, como 'Arial'. O valor 'default' restaura a fonte padrão.
obj
Handle to a figure, axes or other graphics object.
Handle de uma figura, eixos ou outro objeto gráfico.

Example

Exemplo

Change the font of a plot

Mudar a fonte de um gráfico

plot(1:4)
title('Trend')
fontname('Arial')
ax = gca;
ax.Title.String
OutputSaída
ans = 'Trend'

The figure is drawn below the code.

A figura é desenhada abaixo do código.

Notes

Observações

In MatLivre, fontname with no arguments is an error and the function returns no value; the MATLAB form that returns the current font name is not available. Use the FontName property of an object to read it.

No MatLivre, fontname sem argumentos gera erro e a função não retorna valor; a forma do MATLAB que devolve o nome da fonte atual não está disponível. Leia a propriedade FontName de um objeto para obtê-la.

Veja também

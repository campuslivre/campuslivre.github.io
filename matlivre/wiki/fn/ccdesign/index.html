ccdesign next release

Central composite design for a response surface: factorial points, axial (star) points and center points, with optional blocks.

Category: Industrial Statistics > Design of Experiments (DOE)

Syntax

X = ccdesign(n)

Circumscribed design for n factors, from 2 to 26.

X = ccdesign(n, 'type', type)

Chooses 'circumscribed', 'inscribed' or 'faced'.

X = ccdesign(n, 'center', c, 'fraction', f)

Sets the number of center points and the fraction of the factorial part.

[X, blocks] = ccdesign(n, ...)

Also returns the block of each run.

Description

A central composite design lets you fit a quadratic model, which a two-level factorial cannot, by adding star points on each axis and center points to the factorial corners. Use it to find an optimum of a response in several factors.

For the circumscribed type the star points are at a distance from the center equal to the fourth root of the number of factorial runs, which makes the design rotatable.

Input arguments

n
Number of factors, an integer from 2 to 26.
'type'
'circumscribed' (default): star points lie outside the cube. 'inscribed': the design is scaled so the star points lie at -1 and +1. 'faced': star points lie on the faces of the cube.
'center'
Number of center points, or 'uniform' or 'orthogonal' to pick a number with that property. Default is a number chosen for the design.
'fraction'
Number of times the factorial part is halved: 0 for a full factorial (default), 1 for a half fraction, and so on.
'blocksize'
Largest number of runs allowed in a block.

Output arguments

X
Design matrix with one row per run and one column per factor. Rows are the factorial points, then the star points, then the center points.
blocks
Column vector with the block number of each run.

Examples

Design for two factors

X = ccdesign(2);
fprintf('%d runs, %d factors\n', size(X));
disp(round(X(1:8, :)*10000)/10000)
Output
16 runs, 2 factors
   -1.0000   -1.0000
   -1.0000    1.0000
    1.0000   -1.0000
    1.0000    1.0000
   -1.4142         0
    1.4142         0
         0   -1.4142
         0    1.4142

Types of design for three factors

for t = {'circumscribed', 'inscribed', 'faced'}
  X = ccdesign(3, 'type', t{1});
  fprintf('%s: %d runs, largest value %.4f\n', t{1}, size(X, 1), max(X(:)));
end
Output
circumscribed: 24 runs, largest value 1.6818
inscribed: 24 runs, largest value 1.0000
faced: 24 runs, largest value 1.0000

Notes

Only some combinations of number of factors and 'fraction' are available; an unsupported one raises an error, for example ccdesign(4, 'fraction', 1) or ccdesign(3, 'fraction', 1).

unmkpp

Extracts the parts of a piecewise polynomial structure.

Extrai as partes de uma estrutura de polinômio por partes.

Category:Categoria: Mathematics > Interpolation

Syntax

Sintaxe

[x, c, l, k, d] = unmkpp(pp)

Returns the break points, coefficients, number of pieces, order and dimension of pp.

Retorna os pontos de quebra, os coeficientes, o número de pedaços, a ordem e a dimensão de pp.

Description

Descrição

unmkpp is the inverse of mkpp: it reads the fields of the structure so that its coefficients can be inspected or modified, for example to differentiate each piece by hand. Reading the fields directly, as in pp.coefs, gives the same information.

unmkpp é o inverso de mkpp: lê os campos da estrutura para que seus coeficientes possam ser inspecionados ou alterados, por exemplo para derivar cada pedaço manualmente. Ler os campos diretamente, como em pp.coefs, dá a mesma informação.

Input arguments

Argumentos de entrada

pp
Piecewise polynomial structure created by mkpp, spline, pchip or makima.
Estrutura de polinômio por partes criada por mkpp, spline, pchip ou makima.

Output arguments

Argumentos de saída

x
Break points.
Pontos de quebra.
c
Coefficient matrix, one row per piece.
Matriz de coeficientes, uma linha por pedaço.
l
Number of pieces.
Número de pedaços.
k
Order of the polynomials (degree plus one).
Ordem dos polinômios (grau mais um).
d
Dimension of the function value.
Dimensão do valor da função.

Example

Exemplo

Taking a structure apart

Desmontando uma estrutura

pp = mkpp([0 1 2], [1 0 0; 2 1 0]);
[x, c, l, k, d] = unmkpp(pp)
OutputSaída
x = 1×3

     0     1     2
c = 2×3

     1     0     0
     2     1     0
l = 2
k = 3
d = 1

decimate

Lowpass-filters a signal and keeps every r-th sample, reducing the sample rate by a factor of r.

Category: Multirate and resampling

Syntax

y = decimate(x, r)

Chebyshev type I IIR filter of order 8, applied forward and backward (zero phase), then keeps every r-th sample.

y = decimate(x, r, n)

Uses an IIR filter of order n.

y = decimate(x, r, 'fir')

Uses an FIR filter instead of the IIR one.

y = decimate(x, r, n, 'fir')

FIR filter with parameter n.

Description

Keeping every r-th sample of a signal without filtering folds any content above the new Nyquist frequency back into the band (aliasing). decimate first removes that content with a lowpass filter whose cutoff is a fraction of the new Nyquist frequency, then discards the samples in between.

The IIR filter is run forward and backward with filtfilt, so it adds no delay but needs a signal long enough for the edge padding: a 20-sample signal with the default filter gave the error "Data length must be larger than 24 samples". To only drop samples with no filtering, use downsample.

Input arguments

x
Signal, a vector.
r
Decimation factor, a positive integer.
n
Filter order (IIR) or filter parameter (FIR). Default 8 for IIR.

Output arguments

y
Decimated signal, with ceil(length(x)/r) samples.

Examples

Decimate a two-tone signal by 4

n = (0:39)';
x = sin(2*pi*n/20) + sin(2*pi*0.4*n);
y = decimate(x, 4);
disp(size(y))
disp(round(y(1:6).'*1000)/1000)
Output
    10     1
    0.8170    0.8040   -0.3180   -0.9720   -0.3300    0.8410

FIR filter

n = (0:39)';
x = sin(2*pi*n/20) + sin(2*pi*0.4*n);
y = decimate(x, 4, 'fir');
disp(size(y))
disp(round(y(1:6).'*1000)/1000)
Output
    10     1
         0    0.9560    0.5900   -0.5900   -0.9560         0

Notes

Three limits come from the known-differences list. For r of 10 or more, the order-8 Chebyshev filter at cutoff 0.8/r is ill-conditioned, and its coefficients and the filtered values differ from MATLAB's from about the sixth digit. For r above 13 MATLAB decimates in stages while MatLivre applies a single filter. Single-precision input is filtered in double and rounded to single, which differs from MATLAB's single arithmetic by about 5e-5 relative.

nexttile

Creates axes in the next free tile of a tiled chart layout.

Cria eixos no próximo bloco livre de um layout em blocos.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

nexttile

Creates axes in the next empty tile of the current layout, creating a 2-by-2 layout if none exists.

Cria eixos no próximo bloco vazio do layout atual, criando um layout 2-por-2 se não houver nenhum.

nexttile(n)

Uses tile number n, counted row by row from the top left.

Usa o bloco de número n, contado linha a linha a partir do canto superior esquerdo.

nexttile(t, ___)

Works in the layout t instead of the current one.

Atua no layout t em vez do atual.

ax = nexttile(___)

Returns the axes object.

Retorna o objeto de eixos.

Description

Descrição

nexttile is the way to place plots in a layout. Without a number, it fills the grid in reading order, one tile per call. With a number, it jumps to a particular tile, which allows filling them in any order.

The axes it returns is current, so plot commands that follow draw into that tile.

nexttile é o modo de colocar gráficos em um layout. Sem número, preenche a grade em ordem de leitura, um bloco por chamada. Com número, salta para um bloco específico, o que permite preenchê-los em qualquer ordem.

Os eixos retornados passam a ser os atuais, de modo que os comandos de plotagem seguintes desenham nesse bloco.

Input arguments

Argumentos de entrada

t
Layout created by tiledlayout.
Layout criado por tiledlayout.
n
Tile number, a positive integer within the grid.
Número do bloco, um inteiro positivo dentro da grade.

Output arguments

Argumentos de saída

ax
Axes object that fills the tile and becomes the current axes.
Objeto de eixos que preenche o bloco e passa a ser os eixos atuais.

Example

Exemplo

Two plots side by side

Dois gráficos lado a lado

t = tiledlayout(1, 2);
ax1 = nexttile;
plot(1:5)
title('linear')
ax2 = nexttile;
plot((1:5).^2)
title('square')
class(ax1)
OutputSaída
ans = 'matlab.graphics.axis.Axes'

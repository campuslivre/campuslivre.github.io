phasedelay

Computes the phase delay of a digital filter, in samples, at each frequency.

Category: Filter analysis

Syntax

[phi, w] = phasedelay(b, a, n)

Phase delay at n points from 0 to pi.

[phi, f] = phasedelay(b, a, n, fs)

Same, with the frequency in hertz.

phi = phasedelay(b, a, w)

Phase delay at the frequencies in the vector w.

Description

The phase delay is the negative of the phase divided by the frequency. It tells by how many samples a sinusoid at frequency w is delayed by the filter, while the group delay does the same for the envelope of a narrow band of frequencies.

For a linear-phase FIR filter with N coefficients the phase delay is (N-1)/2 at every frequency. At w = 0 the phase is divided by zero, so the first value of the default grid comes back as NaN.

Input arguments

b
Numerator coefficients of the filter, as a vector.
a
Denominator coefficients. Use 1 for an FIR filter.
n
Number of frequency points. Default 512.
fs
Sample rate in hertz.
w
Vector of frequencies in radians per sample.

Output arguments

phi
Phase delay in samples, a column vector.
w
Frequencies as a column vector, in radians per sample or hertz.

Examples

Two-tap averager at chosen frequencies

phi = phasedelay([1 1]/2, 1, [0.5 1 2]);
disp(phi.')
Output
    0.5000
    0.5000
    0.5000

IIR filter

[phi, w] = phasedelay([1 -0.5], [1 0.3], 3);
disp(round(phi(2:3).' * 1000) / 1000)
Output
   -0.7120   -0.3010

Notes

For FIR designfilt objects, phasedelay differs from MATLAB at one point near the ends of the frequency grid, because of how the phase is rounded in the first bins.

See also

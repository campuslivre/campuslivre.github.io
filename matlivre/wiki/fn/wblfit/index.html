wblfit next release

Fits a Weibull distribution to data by maximum likelihood, with confidence intervals and optional censoring.

Category: Probability Distributions and Hypothesis Tests > Univariate Continuous Distributions

Syntax

phat = wblfit(x)

Estimated scale and shape as [a b].

[phat, pci] = wblfit(x)

Also returns 95 percent confidence intervals.

[phat, pci] = wblfit(x, alpha)

Uses the confidence level 100*(1-alpha) percent.

phat = wblfit(x, alpha, censoring, freq)

Handles right-censored observations and frequencies.

Description

wblfit finds the scale and shape that make the data most likely under a Weibull model. A shape near 1 suggests a constant failure rate, above 1 a failure rate that grows with age.

Use censoring for tests that ended before every item failed: those items are known only to have lasted at least as long as recorded.

Input arguments

x
Vector of positive data.
alpha
Significance level for the intervals. Default 0.05.
censoring
Vector of the same size as x: 1 for a censored observation, 0 for an observed one.
freq
Vector of counts, how many times each element of x occurs.

Output arguments

phat
Row vector [a b] with the scale and shape estimates.
pci
2-by-2 matrix. The first column is the interval for the scale, the second for the shape; the first row holds the lower limits and the second the upper limits.

Examples

Fit with confidence intervals

w = [1.2 2.3 0.8 3.1 1.9 2.7 1.5 2.2];
[p, ci] = wblfit(w);
fprintf('%.4f %.4f\n', p)
disp(round(ci*10000)/10000)
Output
2.2022 3.0612
    1.7355    1.7427
    2.7943    5.3772

Last observation censored

w = [1.2 2.3 0.8 3.1 1.9 2.7 1.5 2.2];
p = wblfit(w, 0.05, [0 0 0 0 0 0 0 1]);
fprintf('%.4f %.4f\n', p)
Output
2.2896 2.8971

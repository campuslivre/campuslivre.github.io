realmax

Largest finite floating-point number.

Maior número de ponto flutuante finito.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

realmax

Largest finite double, about 1.7977e+308.

Maior double finito, cerca de 1.7977e+308.

realmax('single')

Largest finite single, about 3.4028e+38.

Maior single finito, cerca de 3.4028e+38.

Description

Descrição

Results above realmax overflow to Inf. The value is the end of the representable range, not the largest integer that is stored exactly; for that, see flintmax.

Resultados acima de realmax estouram para Inf. O valor é o fim da faixa representável, não o maior inteiro guardado com exatidão; para isso, veja flintmax.

Input arguments

Argumentos de entrada

classname
'double' (default) or 'single'.
'double' (padrão) ou 'single'.

Output arguments

Argumentos de saída

x
Scalar of the requested class.
Escalar da classe pedida.

Example

Exemplo

realmax
realmax('single')
class(realmax('single'))
realmax * 10
OutputSaída
ans = 1.7977e+308
ans = single
   3.4028e+38
ans = 'single'
ans = Inf

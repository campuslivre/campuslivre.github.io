bar

Draws a bar chart.

Desenha um gráfico de barras.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

bar(y)

One bar per element of vector y, at positions 1:n. For a matrix, each row becomes a group and each column a series.

Uma barra por elemento do vetor y, nas posições 1:n. Para uma matriz, cada linha vira um grupo e cada coluna uma série.

bar(x, y)

Places the bars at the positions in x.

Posiciona as barras nas posições de x.

bar(___, Name, Value)

Sets properties such as 'FaceColor' or 'BarWidth'.

Define propriedades como 'FaceColor' ou 'BarWidth'.

b = bar(___)

Also returns the bar objects, one per column of y.

Também retorna os objetos de barra, um por coluna de y.

Description

Descrição

Bars start at the baseline (0 by default) and reach the value of each element. A matrix produces grouped bars, with one color per column; each series is a separate Bar object, which is how legend labels them.

Use barh for horizontal bars, bar3 for 3-D bars and histogram when counting data into bins.

As barras partem da linha de base (0 por padrão) e chegam ao valor de cada elemento. Uma matriz produz barras agrupadas, com uma cor por coluna; cada série é um objeto Bar separado, e é assim que legend as identifica.

Use barh para barras horizontais, bar3 para barras 3-D e histogram para contar dados em intervalos.

Input arguments

Argumentos de entrada

x
Increasing positions of the bars.
Posições crescentes das barras.
y
Heights of the bars: a vector or a matrix.
Alturas das barras: um vetor ou uma matriz.
'FaceColor'
Fill color, as a color name or an RGB triplet.
Cor de preenchimento, como nome de cor ou tripla RGB.
'BarWidth'
Relative width of each bar, 0.8 by default.
Largura relativa de cada barra, 0.8 por padrão.

Output arguments

Argumentos de saída

b
Array of Bar objects; read or change their properties with dot syntax.
Array de objetos Bar; leia ou altere suas propriedades com sintaxe de ponto.

Example

Exemplo

Single and grouped bars

Barras simples e agrupadas

subplot(1, 2, 1)
bar([3 5 2 8 4])
title('One series')
subplot(1, 2, 2)
bar(1:3, [2 4; 3 1; 5 6])
legend('A', 'B')
title('Two series')

In the app, the figure is drawn below the code.

No app, a figura é desenhada abaixo do código.

Notes

Observações

The style strings 'stacked' and 'grouped' are not accepted, a numeric second argument is read as x (not as a width; use 'BarWidth'), and categorical or cell-array x values are not supported. Matrix columns are always drawn grouped.

As strings de estilo 'stacked' e 'grouped' não são aceitas, um segundo argumento numérico é lido como x (não como largura; use 'BarWidth'), e valores de x categóricos ou em cell array não são suportados. As colunas da matriz são sempre desenhadas agrupadas.

controlrules next release

Applies Western Electric and Nelson run rules to a control chart and flags the points that break each rule.

Category: Industrial Statistics > Statistical Process Control

Syntax

R = controlrules(rules, x, cl, se)

Returns a logical matrix marking the points of x that violate each rule.

[R, names] = controlrules(rules, x, cl, se)

Also returns the names of the rules, one per column of R.

Description

A point beyond three standard errors is the classic signal that a process is out of control ('we1'), but patterns inside the limits matter too: for example eight points in a row on the same side of the center line ('we4') or two out of three points beyond two standard errors ('we2'). 'we1' to 'we4' watch the upper side and 'we5' to 'we8' the lower side.

The output tells you which points to investigate. NaN values in x, cl or se are never flagged.

Input arguments

rules
A rule name or a cell array of names: 'we1' to 'we10' (Western Electric), 'n1' to 'n8' (Nelson), or 'we' and 'n' for the whole set.
x
Plotted values of the chart, a vector (for example sample means).
cl
Center line, a scalar or a vector with the same length as x.
se
Standard error of the plotted values, a scalar or a vector with the same length as x. The control limits are cl plus or minus multiples of se.

Output arguments

R
Logical matrix with one row per point and one column per rule. An entry is true where the point violates the rule.
names
Cell array with the name of the rule of each column.

Example

Western Electric rules on a short series

x = [10.1 9.9 10.0 10.2 9.8 10.0 11.8 10.1 10.3 10.4 10.5 10.6 10.7 10.8 10.9 9.9 9.8 9.7 9.6 9.5 9.4 9.3 10.0];
[R, names] = controlrules({'we1', 'we2', 'we4'}, x, 10, 0.3);
for j = 1:size(R, 2)
  fprintf('%s: %s\n', names{j}, mat2str(find(R(:, j))'));
end
Output
we1: 7
we2: [14 15]
we4: [14 15]

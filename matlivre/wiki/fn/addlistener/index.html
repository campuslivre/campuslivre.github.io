addlistener

Attaches a callback to an event or property change of a handle object.

Associa um callback a um evento ou a uma mudança de propriedade de um objeto handle.

Category:Categoria: Programming > Classes

Syntax

Sintaxe

lh = addlistener(obj, 'EventName', callback)

Calls callback whenever obj triggers the event.

Chama callback sempre que obj dispara o evento.

lh = addlistener(obj, 'PropName', 'PostSet', callback)

Calls callback after the observable property PropName is set.

Chama callback depois que a propriedade observável PropName é definida.

Description

Descrição

Events let objects announce that something happened without knowing who is interested. A class declares an event in its events block and fires it with notify(obj, 'EventName'). Any number of listeners may be attached from outside, each with its own callback, and they run in the order they were created.

Unlike listener, addlistener ties the listener to the life of the source object: you do not have to keep lh in a variable for it to stay active.

Eventos permitem que objetos anunciem que algo aconteceu sem saber quem se interessa. Uma classe declara um evento no bloco events e o dispara com notify(obj, 'EventName'). Qualquer número de listeners pode ser anexado de fora, cada um com seu próprio callback, e eles são executados na ordem em que foram criados.

Ao contrário de listener, addlistener prende o listener à vida do objeto de origem: não é preciso guardar lh numa variável para que ele continue ativo.

Input arguments

Argumentos de entrada

obj
Handle object that defines the event.
Objeto handle que define o evento.
'EventName'
Name of an event declared in the events block of the class.
Nome de um evento declarado no bloco events da classe.
callback
Function handle called as callback(src, evtdata), where src is the object and evtdata carries event information.
Handle de função chamado como callback(src, evtdata), em que src é o objeto e evtdata traz informações do evento.

Output arguments

Argumentos de saída

lh
An event.listener object. The listener lives as long as lh or the source object exists; delete(lh) removes it.
Um objeto event.listener. O listener existe enquanto lh ou o objeto de origem existir; delete(lh) o remove.

Example

Exemplo

Listening to a built-in event

Escutando um evento embutido

m = containers.Map();
lh = addlistener(m, 'ObjectBeingDestroyed', @(src, evt) disp('map destroyed'));
class(lh)
lh.EventName
event.hasListener(m, 'ObjectBeingDestroyed')
OutputSaída
ans = 'event.listener'
ans = 'ObjectBeingDestroyed'
ans = logical
   1

Notes

Observações

Events declared in a classdef work and run their callbacks when notified. The built-in ObjectBeingDestroyed event is registered but its callback is not run when the object is deleted. Example code in this wiki uses a built-in class because a script cannot define its own class.

Eventos declarados em uma classdef funcionam e executam seus callbacks quando notificados. O evento embutido ObjectBeingDestroyed é registrado, mas seu callback não é executado quando o objeto é apagado. O exemplo usa uma classe embutida porque um script não consegue definir sua própria classe.

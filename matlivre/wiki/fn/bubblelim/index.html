bubblelim

Sets the range of data values that the bubble sizes cover.

Define a faixa de valores de dados coberta pelos tamanhos das bolhas.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

bubblelim([lo hi])

Maps data values from lo to hi onto the bubble size range.

Mapeia os valores de dados de lo a hi para a faixa de tamanhos das bolhas.

lims = bubblelim

Returns the current limits.

Retorna os limites atuais.

Description

Descrição

By default the data range comes from the plotted sizes. Fixing it with bubblelim makes several charts share the same size scale, so equal values look equal across plots. Data outside the limits are drawn at the smallest or largest size.

Por padrão a faixa de dados vem dos tamanhos plotados. Fixá-la com bubblelim faz vários gráficos compartilharem a mesma escala de tamanho, de modo que valores iguais pareçam iguais entre os gráficos. Dados fora dos limites são desenhados no menor ou no maior tamanho.

Input arguments

Argumentos de entrada

[lo hi]
Two-element vector with the lower and upper data limits, lo < hi.
Vetor de dois elementos com os limites inferior e superior dos dados, lo < hi.

Output arguments

Argumentos de saída

lims
Current limits as a two-element vector.
Limites atuais como vetor de dois elementos.

Example

Exemplo

Fix the size scale

Fixar a escala de tamanho

bubblechart(1:3, [1 3 2], [5 50 20]);
lims = bubblelim([1 100])
OutputSaída
lims = 1×2

     1   100

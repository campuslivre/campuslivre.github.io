spectrogram

Computes the short-time Fourier transform of a signal and returns it with the frequencies, the times and the power spectral density of each segment.

Category: Time-frequency analysis

Syntax

s = spectrogram(x)

Uses eight segments with 50 percent overlap and a Hamming window.

s = spectrogram(x, window, noverlap, nfft)

Sets the window, the overlap and the number of FFT points.

[s, f, t, p] = spectrogram(x, window, noverlap, nfft, fs)

Uses the sample rate fs (hertz) for f and t; p is the power spectral density.

[s, f, t, p] = spectrogram(___, freqrange, spectrumtype)

Chooses the frequency range and 'psd' or 'power'.

Description

The signal is split into segments of the window length that overlap by noverlap samples. Each segment is multiplied by the window and transformed with an FFT of nfft points. The columns of s therefore show how the spectrum changes with time.

A longer window separates close frequencies better but smears events in time; a shorter one does the opposite. For a real signal, s has nfft/2+1 rows. Use abs(s).^2 or p to see where the energy is.

Input arguments

x
Signal, a real or complex vector.
window
Window vector, or a length (then a Hamming window of that length is used). The default makes eight segments.
noverlap
Samples shared by consecutive segments. Default is 50 percent of the window length.
nfft
Number of FFT points, a scalar. Default is the larger of 256 and the window length rounded up to a power of two.
fs
Sample rate in hertz. Without it, f is in radians per sample and t in samples.
freqrange
'onesided' (default for real x), 'twosided' or 'centered'. 'yaxis' is accepted and does not change the numbers.
spectrumtype
'psd' (default) or 'power'.

Output arguments

s
Complex short-time Fourier transform: one row per frequency, one column per segment.
f
Frequency of each row of s.
t
Time at the middle of each segment, in seconds when fs is given.
p
Power spectral density (or power, for 'power') of each segment, same size as s.

Examples

Two tones in a signal

fs = 1000; t = (0:255)'/fs;
x = sin(2*pi*100*t) + 0.5*sin(2*pi*250*t);
[s, f, tt, p] = spectrogram(x, hann(64), 32, 64, fs);
disp(size(s))
disp(tt')
[~, i] = max(p(:, 3));
fprintf('strongest bin in segment 3: %.2f Hz\n', f(i));
Output
    33     7
    0.0320
    0.0640
    0.0960
    0.1280
    0.1600
    0.1920
    0.2240
strongest bin in segment 3: 93.75 Hz

Density versus power for a single tone

fs = 1000; t = (0:255)'/fs;
x = sin(2*pi*100*t);
[~, ~, ~, p1] = spectrogram(x, hann(64), 32, 64, fs);
[~, ~, ~, p2] = spectrogram(x, hann(64), 32, 64, fs, 'power');
fprintf('psd peak %.4f, power peak %.4f\n', max(p1(:, 3)), max(p2(:, 3)));
Output
psd peak 0.0172, power peak 0.4086

Notes

Not implemented: the centroid outputs fc and tc, a frequency vector in place of nfft, the 'reassigned' option, and plotting when called without output arguments (an error is raised, so always request outputs).

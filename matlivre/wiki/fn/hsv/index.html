hsv

Colormap that sweeps through the hue circle at full saturation and value.

Mapa de cores que percorre o círculo de matizes com saturação e valor máximos.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

map = hsv

Returns an hsv colormap with the default number of rows.

Retorna um mapa de cores hsv com o número padrão de linhas.

map = hsv(m)

Returns an hsv colormap with m rows.

Retorna um mapa de cores hsv com m linhas.

Description

Descrição

The hue runs from 0 to just below 1 in equal steps, so the colors go from red through yellow, green, cyan, blue and magenta, nearly back to red. The first and last colors are close but not identical, and the map is cyclic, which suits angles and phases.

It is built as hsv2rgb([h' ones(m,1) ones(m,1)]) with evenly spaced hues h.

O matiz vai de 0 até um pouco abaixo de 1 em passos iguais, e as cores passam do vermelho ao amarelo, verde, ciano, azul e magenta, quase voltando ao vermelho. A primeira e a última cor são próximas mas não idênticas, e o mapa é cíclico, o que combina com ângulos e fases.

Ele é construído como hsv2rgb([h' ones(m,1) ones(m,1)]), com matizes h igualmente espaçados.

Input arguments

Argumentos de entrada

m
Number of colors, a nonnegative integer.
Número de cores, um inteiro não negativo.

Output arguments

Argumentos de saída

map
m-by-3 matrix of RGB values between 0 and 1.
Matriz m-por-3 de valores RGB entre 0 e 1.

Example

Exemplo

Four hues

Quatro matizes

hsv(4)
OutputSaída
ans = 4×3

    1.0000         0         0
    0.5000    1.0000         0
         0    1.0000    1.0000
    0.5000         0    1.0000

trimesh

Plots a triangular mesh as wireframe edges.

Plota uma malha triangular como arestas em wireframe.

Category:Categoria: Mathematics > Computational Geometry

Syntax

Sintaxe

trimesh(T, x, y, z)

Draws the triangles listed in T as a 3-D mesh, with vertex coordinates x, y and heights z.

Desenha os triângulos listados em T como uma malha 3-D, com coordenadas x, y e alturas z.

trimesh(T, x, y)

Draws the triangles in the plane.

Desenha os triângulos no plano.

trimesh(TR)

Draws the mesh of a triangulation object.

Desenha a malha de um objeto triangulation.

h = trimesh(___)

Also returns the handle of the mesh.

Também retorna o handle da malha.

Description

Descrição

trimesh draws only the edges of each triangle, with the faces left transparent, which makes it a quick way to inspect a mesh. For shaded faces, use trisurf. For a flat 2-D mesh, triplot is the usual choice.

When z is given, the vertices are lifted to those heights and the axes switch to a 3-D view.

trimesh desenha apenas as arestas de cada triângulo, deixando as faces transparentes, o que o torna uma forma rápida de inspecionar uma malha. Para faces coloridas, use trisurf. Para uma malha plana 2-D, triplot é a escolha comum.

Quando z é informado, os vértices são elevados a essas alturas e os eixos passam para visão 3-D.

Input arguments

Argumentos de entrada

T
m-by-3 matrix; each row holds three vertex indices.
Matriz m por 3; cada linha tem três índices de vértices.
x, y, z
Vectors with the coordinates of the vertices.
Vetores com as coordenadas dos vértices.

Output arguments

Argumentos de saída

h
Handle to the patch object that draws the mesh.
Handle do objeto patch que desenha a malha.

Example

Exemplo

A mesh lifted into 3-D

Uma malha elevada para 3-D

x = [0 1 0 1]';
y = [0 0 1 1]';
z = [0 1 1 2]';
T = [1 2 3; 2 4 3];
trimesh(T, x, y, z);

Notes

Observações

In MatLivre the 3-argument call trimesh(T, x, y) without z raises "Not enough input arguments."; pass z (even zeros) or use triplot for flat meshes.

No MatLivre, a chamada trimesh(T, x, y) sem z gera o erro "Not enough input arguments."; informe z (mesmo zeros) ou use triplot para malhas planas.

Veja também

findnode

Index of a node given its name.

Índice de um nó a partir do seu nome.

Category:Categoria: Mathematics > Graph and Network Algorithms

Syntax

Sintaxe

idx = findnode(G, name)

Returns the index of the node called name.

Retorna o índice do nó chamado name.

idx = findnode(G, names)

For a cell array of names, returns one index per name.

Para um cell array de nomes, retorna um índice por nome.

Description

Descrição

Node names are stored in G.Nodes.Name. findnode is the lookup from name to position, useful because most graph functions return numeric indices.

Os nomes dos nós ficam em G.Nodes.Name. findnode faz a busca de nome para posição, útil porque a maioria das funções de grafo devolve índices numéricos.

Input arguments

Argumentos de entrada

G
A graph with node names.
Um grafo com nomes de nós.
name
Character vector, or cell array of them.
Vetor de caracteres, ou cell array deles.

Output arguments

Argumentos de saída

idx
Node index, or 0 for a name that is not in the graph.
Índice do nó, ou 0 para um nome que não está no grafo.

Example

Exemplo

Names to indices

De nomes para índices

G = graph({'a','b','c'}, {'b','c','a'});
findnode(G, 'b')
findnode(G, {'c','a'})
findnode(G, 'zz')
OutputSaída

     3
     1
ans = 0

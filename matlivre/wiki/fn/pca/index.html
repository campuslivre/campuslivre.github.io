pca next release

Principal component analysis of a data matrix: returns the component directions, the scores, the variances and the share of variance of each component.

Category: Dimensionality Reduction and Feature Extraction

Syntax

coeff = pca(X)

Principal component coefficients (loadings) of X.

[coeff, score, latent] = pca(X)

Also returns the scores and the variances of the components.

[coeff, score, latent, tsquared, explained, mu] = pca(X)

Adds Hotelling's T-squared for each row, the percentage of variance explained and the column means.

[...] = pca(X, Name, Value)

Options such as 'NumComponents', 'Centered', 'Algorithm' and 'VariableWeights'.

Description

pca finds orthogonal directions along which the data vary the most. The first component is the direction of largest variance, the second is the largest one perpendicular to it, and so on. The explained output tells how many components you need to keep most of the variability.

Variables on different scales dominate the result if they have larger variance. When the units differ, use 'VariableWeights', 'variance' or standardize with zscore first. The sign of each column of coeff is arbitrary.

Input arguments

X
Data matrix with n observations in rows and p variables in columns.
'NumComponents'
Number of components to return. Default: all that are meaningful.
'Centered'
If false, the column means are not subtracted. Default true.
'Algorithm'
'svd' (default) or 'eig'.
'VariableWeights'
'variance' to weight variables by the inverse of their variance (analysis of the correlation matrix), or a vector of weights.

Output arguments

coeff
p-by-k matrix. Each column is a principal component direction, with unit length, ordered by decreasing variance.
score
n-by-k matrix of the data expressed in the new axes.
latent
Variance of each component, in decreasing order (eigenvalues of the covariance matrix).
tsquared
Hotelling's T-squared statistic of each observation, a distance from the center that is large for outliers.
explained
Percentage of the total variance explained by each component.
mu
Mean of each column of X.

Examples

Variances and explained percentage of three variables

A = [2 4 1; 3 5 2; 5 8 3; 4 7 2; 6 9 5; 7 12 4];
[coeff, score, latent, tsquared, explained, mu] = pca(A);
disp(round(latent'*1000)/1000)
disp(round(explained'*100)/100)
disp(mu)
Output
   13.3670    0.5900    0.0100
   95.7000    4.2200    0.0700
    4.5000    7.5000    2.8333

Keeping two components

A = [2 4 1; 3 5 2; 5 8 3; 4 7 2; 6 9 5; 7 12 4];
[coeff, score] = pca(A, 'NumComponents', 2);
disp(size(coeff))
disp(size(score))
Output
     3     2
     6     2

Notes

The 'als' algorithm is not implemented and raises an error. For single-precision input the result is computed in double precision and rounded, so it can differ from MATLAB's single-precision arithmetic at about the 1e-6 level. With 'Economy', false on data with fewer rows than columns, the extra columns of coeff span a null space and MatLivre may pick a different basis than MATLAB.

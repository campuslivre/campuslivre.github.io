createns next release

Creates a nearest neighbor searcher object for a data set, a k-d tree or an exhaustive searcher depending on the distance.

Category: Classification > Nearest Neighbors

Syntax

ns = createns(X)

Creates a searcher for the rows of X: a KDTreeSearcher with Euclidean distance.

ns = createns(X, 'NSMethod', method)

Forces 'kdtree' or 'exhaustive'.

ns = createns(X, 'Distance', dist)

Chooses the distance. Distances that a k-d tree cannot use give an ExhaustiveSearcher.

Description

createns builds the object once so you can run many neighbor queries against the same data. Which kind of object you get is decided by the distance and by 'NSMethod'.

Forcing 'NSMethod' to 'kdtree' with a distance that a k-d tree cannot use, such as 'cosine', raises an error that lists the valid distances.

Input arguments

X
n-by-p matrix: one row per point.
'NSMethod'
'kdtree' or 'exhaustive'. Default: 'kdtree' for 'euclidean', 'cityblock', 'chebychev' and 'minkowski', and 'exhaustive' for the other distances.
'Distance'
Distance name, such as 'euclidean' (default), 'cityblock', 'chebychev', 'minkowski' (with 'P'), 'seuclidean' (with 'Scale'), 'mahalanobis' (with 'Cov'), 'cosine', 'correlation', 'spearman', 'hamming' or 'jaccard'.
'BucketSize'
Maximum number of points in a leaf of the k-d tree. Default 50.

Output arguments

ns
A KDTreeSearcher or ExhaustiveSearcher object, with properties X, Distance and DistParameter. Use it with knnsearch and rangesearch.

Examples

Default and exhaustive searchers

X = [0 0; 1 0; 0 1; 1 1; 5 5; 6 5];
Y = [0.2 0.1; 5.5 5.2];
ns = createns(X);
disp(class(ns))
ne = createns(X, 'Distance', 'cosine');
disp(class(ne))
[idx, d] = knnsearch(ns, Y, 'K', 2);
disp(idx)
Output
KDTreeSearcher
ExhaustiveSearcher
     1     2
     5     6

Choose the method

X = [0 0; 1 0; 0 1; 1 1; 5 5; 6 5];
Y = [0.2 0.1; 5.5 5.2];
ns = createns(X, 'NSMethod', 'exhaustive', 'Distance', 'cityblock');
disp(class(ns))
disp(ns.Distance)
idx = rangesearch(ns, Y, 2);
disp(idx{2})
Output
ExhaustiveSearcher
cityblock
     5     6

im2double

Converts an image to class double, rescaling integer data to the range 0 to 1.

Converte uma imagem para a classe double, reescalando dados inteiros para o intervalo de 0 a 1.

Category:Categoria: Graphics > Images

Syntax

Sintaxe

I2 = im2double(I)

Returns a double version of I scaled to the standard image range.

Retorna uma versão double de I na escala padrão de imagens.

Description

Descrição

Image code often assumes double data in [0, 1]. im2double gets there from uint8 by dividing by 255, from uint16 by dividing by 65535, and from int16 by shifting so that -32768 maps to 0. A double input is returned unchanged, even if its values fall outside [0, 1].

This differs from double(I), which converts the class only and keeps the original numbers.

O código de imagens costuma assumir dados double em [0, 1]. im2double chega lá a partir de uint8 dividindo por 255, de uint16 dividindo por 65535 e de int16 deslocando de modo que -32768 vá para 0. Uma entrada double é devolvida sem mudança, mesmo com valores fora de [0, 1].

Isso difere de double(I), que converte apenas a classe e mantém os números originais.

Input arguments

Argumentos de entrada

I
Image of class uint8, uint16, int16, single, double or logical.
Imagem da classe uint8, uint16, int16, single, double ou lógica.

Output arguments

Argumentos de saída

I2
Double image. Integer inputs map to [0, 1]; logical becomes 0 and 1.
Imagem double. Entradas inteiras são mapeadas para [0, 1]; lógicas viram 0 e 1.

Example

Exemplo

Scale by class

Escala por classe

im2double(uint8([0 128 255]))
im2double(uint16(65535))
im2double([0.5 2])
OutputSaída

         0    0.5020    1.0000
ans = 1
ans = 1×2

    0.5000    2.0000

pbaspect

Gets or sets the relative lengths of the x, y and z sides of the axes box.

Obtém ou define os comprimentos relativos dos lados x, y e z da caixa dos eixos.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

pbaspect([rx ry rz])

Sets the plot box aspect ratio of the current axes.

Define a razão de aspecto da caixa de plotagem dos eixos atuais.

r = pbaspect

Returns the current ratio as a three-element vector.

Retorna a razão atual como um vetor de três elementos.

pbaspect auto

Returns control to the automatic mode, where the box fills the available space.

Devolve o controle ao modo automático, em que a caixa preenche o espaço disponível.

pbaspect(ax, ___)

Acts on the axes ax.

Atua nos eixos ax.

Description

Descrição

pbaspect controls the shape of the box that encloses the axes, independently of the data units. pbaspect([1 1 1]) makes a cubic box for 3-D plots and a square one for 2-D plots, whatever the data ranges are.

It differs from daspect, which fixes the ratio of data units per unit of length. Setting pbaspect stores the value in the PlotBoxAspectRatio property and switches the matching mode property to manual.

pbaspect controla a forma da caixa que envolve os eixos, independentemente das unidades dos dados. pbaspect([1 1 1]) produz uma caixa cúbica em gráficos 3-D e quadrada em 2-D, quaisquer que sejam as faixas dos dados.

Difere de daspect, que fixa a razão de unidades de dados por unidade de comprimento. Definir pbaspect guarda o valor na propriedade PlotBoxAspectRatio e passa a propriedade de modo correspondente para manual.

Input arguments

Argumentos de entrada

[rx ry rz]
Three positive numbers. Only their ratios matter.
Três números positivos. Só importam as razões entre eles.

Output arguments

Argumentos de saída

r
Current aspect ratio, a 1-by-3 vector.
Razão de aspecto atual, um vetor 1-por-3.

Example

Exemplo

Make the plot box twice as wide as tall

Caixa de plotagem com o dobro da largura em relação à altura

plot(1:10)
pbaspect([2 1 1])
r = pbaspect
OutputSaída
r = 1×3

     2     1     1

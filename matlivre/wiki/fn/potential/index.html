potential

Potential function of a vector field.

Função potencial de um campo vetorial.

Category:Categoria: Mathematics > Calculus

Syntax

Sintaxe

P = potential(V, X)

Finds a scalar function P whose gradient with respect to X is the field V.

Encontra uma função escalar P cujo gradiente em relação a X é o campo V.

Description

Descrição

A field has a potential only if it is conservative, meaning that the Jacobian of V is symmetric. Then the work along any path depends only on the end points. potential integrates the components one at a time and matches the terms. For [y x] the potential is x*y.

Um campo só tem potencial se for conservativo, isto é, se a jacobiana de V é simétrica. Então o trabalho ao longo de qualquer caminho depende apenas dos extremos. potential integra as componentes uma a uma e confere os termos. Para [y x], o potencial é x*y.

Input arguments

Argumentos de entrada

V
Vector of symbolic expressions: the field.
Vetor de expressões simbólicas: o campo.
X
Vector of variables with the same length as V.
Vetor de variáveis com o mesmo comprimento de V.

Output arguments

Argumentos de saída

P
Symbolic potential, with the constant set to zero.
Potencial simbólico, com a constante igual a zero.

Example

Exemplo

A conservative field

Um campo conservativo

syms x y
P = potential([y x], [x y])
OutputSaída
P = x*y

Veja também

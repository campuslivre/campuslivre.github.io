parula

Default colormap: a smooth progression from dark blue through teal and green to yellow.

Mapa de cores padrão: uma progressão suave do azul escuro ao amarelo, passando por verde-azulado e verde.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

map = parula

Returns a parula colormap with the default number of rows.

Retorna um mapa de cores parula com o número padrão de linhas.

map = parula(m)

Returns a parula colormap with m rows.

Retorna um mapa de cores parula com m linhas.

Description

Descrição

Parula is the colormap that new figures start with. Its lightness rises steadily and its hue changes gradually, so equal steps in the data look like equal steps in color, and the map degrades gracefully in grayscale.

The returned matrix is interpolated from a fixed table of base colors to reach the requested length.

Parula é o mapa de cores com que as figuras novas começam. Sua luminosidade cresce de modo contínuo e seu matiz muda gradualmente, de modo que passos iguais nos dados parecem passos iguais em cor, e o mapa se comporta bem em escala de cinza.

A matriz retornada é interpolada a partir de uma tabela fixa de cores-base para atingir o comprimento pedido.

Input arguments

Argumentos de entrada

m
Number of colors, a nonnegative integer.
Número de cores, um inteiro não negativo.

Output arguments

Argumentos de saída

map
m-by-3 matrix of RGB values between 0 and 1.
Matriz m-por-3 de valores RGB entre 0 e 1.

Exemplo

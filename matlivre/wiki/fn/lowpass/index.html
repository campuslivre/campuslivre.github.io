lowpass next release

Filters a signal to keep the frequencies below a passband edge, using a zero-phase filter designed for you.

Category: Filtering

Syntax

y = lowpass(x, wpass)

Passband edge wpass in normalized frequency (1 is the Nyquist frequency).

y = lowpass(x, fpass, fs)

Passband edge in hertz for sample rate fs.

y = lowpass(___, Name, Value)

Options 'Steepness', 'StopbandAttenuation' and 'ImpulseResponse' ('auto', 'fir' or 'iir').

[y, d] = lowpass(___)

Also returns the filter used, as a digitalFilter object.

Description

lowpass designs a minimum-order filter from the passband edge and the steepness, then applies it forward and backward so the output has no phase shift. You do not have to choose the order or the window.

Use it to remove high-frequency noise or to isolate a slow trend. When you need control over the exact design, build the filter with designfilt or fir1 and apply it with filtfilt.

Input arguments

x
Real signal. A vector, or a matrix whose columns are filtered independently.
fpass
Passband edge, a positive scalar below half the sample rate.
fs
Sample rate in hertz.
Steepness
Transition steepness, from 0.5 to below 1. Default 0.85. Higher values give a sharper and longer filter.
StopbandAttenuation
Minimum attenuation in the stopband, in dB, at least 10. Default 60.
ImpulseResponse
'auto' (default), 'fir' or 'iir'.

Output arguments

y
Filtered signal, the same size as x.
d
The digitalFilter object used.

Example

Keep a 5 Hz tone, drop a 60 Hz tone

t = (0:199)' / 200;
x = sin(2*pi*5*t) + sin(2*pi*60*t);
[y, d] = lowpass(x, 20, 200);
fprintf('RMS before: %.2f\n', sqrt(mean(x.^2)));
fprintf('RMS after: %.2f\n', sqrt(mean(y.^2)));
fprintf('Filter length: %d\n', numel(d.Coefficients));
Output
RMS before: 1.00
RMS after: 0.71
Filter length: 65

Notes

With 'ImpulseResponse', 'iir' the section gains are distributed differently from MATLAB. In one test the last output sample differs by about 4e-9, from rounding in the ill-conditioned cascade.

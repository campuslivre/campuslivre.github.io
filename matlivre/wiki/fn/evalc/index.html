evalc

Evaluates code and returns its printed output as text instead of showing it.

Avalia código e retorna sua saída impressa como texto em vez de exibi-la.

Category:Categoria: Programming > Programming Utilities

Syntax

Sintaxe

T = evalc(expression)

Runs expression and returns everything it would have printed as a character vector.

Executa expression e retorna tudo que ele imprimiria como vetor de caracteres.

T = evalc(expression, catchExpr)

Runs catchExpr if expression raises an error, and captures its output too.

Executa catchExpr se expression gerar erro, e captura também a saída dele.

Description

Descrição

Everything that would appear in the command window, such as disp output, unsuppressed results and warnings, is collected into T. Variables created by the code still land in the caller's workspace. Typical uses are capturing the display of an object to put it in a label or a log, and testing what a function prints.

The captured text ends with a newline for each printed line, so apply strtrim when comparing.

Tudo que apareceria na janela de comandos, como a saída de disp, resultados sem ponto e vírgula e avisos, é reunido em T. As variáveis criadas pelo código continuam indo para o workspace de quem chamou. Usos típicos são capturar a exibição de um objeto para colocá-la em um rótulo ou log e testar o que uma função imprime.

O texto capturado termina com uma quebra de linha para cada linha impressa, então use strtrim ao comparar.

Input arguments

Argumentos de entrada

expression
Text with the code to run.
Texto com o código a executar.
catchExpr
Text with code to run if expression fails.
Texto com código a executar se expression falhar.

Output arguments

Argumentos de saída

T
Character vector with the captured output, including line breaks.
Vetor de caracteres com a saída capturada, incluindo quebras de linha.

Example

Exemplo

Capturing printed output

Capturando a saída impressa

s = evalc('disp(pi); x = 3')
t = strtrim(evalc('disp(1); disp(2);'));
fprintf('[%s]\n', t)
OutputSaída
s = 
    '    3.1416
     x = 3
     '
[1
     2]

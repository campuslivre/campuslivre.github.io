axis

Sets axis limits and scaling, or gets the current limits.

Define limites e escala dos eixos, ou obtém os limites atuais.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

axis([xmin xmax ymin ymax])

Sets the x and y limits (add zmin zmax for 3-D).

Define os limites de x e y (acrescente zmin zmax em 3-D).

lims = axis

Returns the current limits.

Retorna os limites atuais.

axis style

Applies a style such as tight, equal, square, image, padded, ij, xy, auto, manual.

Aplica um estilo como tight, equal, square, image, padded, ij, xy, auto, manual.

axis on / axis off

Shows or hides the axis lines, ticks and labels.

Mostra ou oculta linhas, marcas e rótulos dos eixos.

Description

Descrição

axis tight fits the limits to the data, axis equal gives all axes the same unit length so circles look round, and axis square makes the axes box square. axis ij puts the origin at the upper left, as for matrices and images.

The individual limits are also available through xlim, ylim and zlim.

axis tight ajusta os limites aos dados, axis equal dá o mesmo comprimento unitário a todos os eixos para que círculos pareçam redondos, e axis square torna a caixa dos eixos quadrada. axis ij coloca a origem no canto superior esquerdo, como em matrizes e imagens.

Os limites individuais também estão disponíveis por xlim, ylim e zlim.

Input arguments

Argumentos de entrada

limits
Vector of limits. Use -inf or inf to leave a bound automatic.
Vetor de limites. Use -inf ou inf para manter um limite automático.
style
Option word, given in command form: axis equal.
Palavra de opção, em forma de comando: axis equal.

Output arguments

Argumentos de saída

lims
Row vector [xmin xmax ymin ymax], with the z limits added for 3-D axes.
Vetor linha [xmin xmax ymin ymax], com os limites de z acrescentados em eixos 3-D.

Example

Exemplo

Setting and reading the limits

Definindo e lendo os limites

plot(1:10)
axis([0 5 0 20])
disp(axis)
OutputSaída
     0     5     0    20

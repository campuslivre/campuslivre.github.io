newUnitSystem

Defines a new system of units.

Define um novo sistema de unidades.

Category:Categoria: Symbolic Computations in MATLAB > Units of Measurement

Syntax

Sintaxe

newUnitSystem(name, base)

Creates the system name with the given base units.

Cria o sistema name com as unidades base dadas.

newUnitSystem(name, base, derived)

Also names the derived units of the system.

Também nomeia as unidades derivadas do sistema.

Description

Descrição

A unit system is the choice of a set of base units from which all the others can be built. Once defined, the name appears in unitSystems and can be used as the target of unitConvert, which rewrites a quantity using that system's units.

The system lasts until removeUnitSystem is called or the session ends.

Um sistema de unidades é a escolha de um conjunto de unidades base a partir das quais todas as outras podem ser construídas. Depois de definido, o nome aparece em unitSystems e pode ser usado como destino de unitConvert, que reescreve uma grandeza com as unidades desse sistema.

O sistema dura até removeUnitSystem ser chamada ou a sessão terminar.

Input arguments

Argumentos de entrada

name
Name of the new system.
Nome do novo sistema.
base
Base units, taken from baseUnits of an existing system.
Unidades base, tiradas de baseUnits de um sistema existente.
derived
Derived units, for example from derivedUnits.
Unidades derivadas, por exemplo de derivedUnits.

Example

Exemplo

Registering a system

Registrando um sistema

newUnitSystem('MySys', baseUnits('SI'), derivedUnits('SI'));
unitSystems
removeUnitSystem('MySys');
OutputSaída
ans = 1×7 string array

    "CGS"    "EMU"    "ESU"    "GU"    "MySys"    "SI"    "US"

Notes

Observações

In MatLivre the base units must be given as the output of baseUnits('SI'); an array built by hand from symunit is not accepted. A new system is listed by unitSystems, but baseUnits and derivedUnits cannot query it, and unitConvert to it returns SI units.

No MatLivre as unidades base devem ser dadas como a saída de baseUnits('SI'); um array montado à mão a partir de symunit não é aceito. Um novo sistema aparece em unitSystems, mas baseUnits e derivedUnits não conseguem consultá-lo, e unitConvert para ele devolve unidades do SI.

Veja também

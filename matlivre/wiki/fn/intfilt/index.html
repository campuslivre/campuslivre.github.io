intfilt

Designs a bandlimited interpolation FIR filter for raising the sampling rate by an integer factor.

Category: FIR design

Syntax

b = intfilt(l,n,alpha)

Interpolation filter for factor l that uses n original samples on each side, for signals that occupy the fraction alpha of the band.

Description

The filter leaves the original samples unchanged and computes the new ones in between from their neighbours, so it is an interpolator and not a general lowpass. Its input is the signal with l-1 zeros inserted between samples, for example with upsample. The filter delay is l*n-1 samples.

A smaller alpha assumes a more strongly bandlimited signal, which allows a better estimate of the points in between.

Input arguments

l
Interpolation factor, a positive integer.
n
Number of original samples used on each side of an interpolated point, a positive integer.
alpha
Fraction of the Nyquist band occupied by the signal, between 0 and 1.

Output arguments

b
Row vector of 2*l*n-1 coefficients. Apply it to the signal after inserting l-1 zeros between samples.

Example

Interpolate a sine by 2

b = intfilt(2,3,0.9);
disp(round(b*10000)/10000)
x = sin(2*pi*0.05*(0:19));
xu = upsample(x,2);
y = filter(b,1,[xu zeros(1,5)]);
y = y(6:end);
t = sin(2*pi*0.05*(0:0.5:19.5));
k = 11:30;
fprintf('error at the new points: %.4f\n', max(abs(y(k)-t(k))))
fprintf('error at the original points: %.4f\n', max(abs(y(1:2:end)-t(1:2:end))))
Output
    0.1031         0   -0.1972         0    0.6316    1.0000    0.6316         0   -0.1972         0    0.1031
error at the new points: 0.0414
error at the original points: 0.0000

Notes

The 'lagrange' form is not supported (intfilt(2,3,'lagrange') raises an error); only the numeric alpha form is.

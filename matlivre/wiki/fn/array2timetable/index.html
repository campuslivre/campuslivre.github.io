array2timetable

Converts an array into a timetable with given row times.

Converte um array em uma timetable com instantes de linha dados.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

TT = array2timetable(A, 'RowTimes', t)

Builds a timetable with one row per row of A and times from the datetime or duration vector t.

Cria uma timetable com uma linha por linha de A e instantes do vetor datetime ou duration t.

TT = array2timetable(___, 'VariableNames', names)

Also names the variables.

Também dá nomes às variáveis.

TT = array2timetable(A, 'SampleRate', fs)

Generates evenly spaced times from a sample rate in hertz.

Gera instantes igualmente espaçados a partir de uma taxa de amostragem em hertz.

Description

Descrição

This is how a plain matrix of measurements becomes time-indexed data. Row times are required unless a sample rate or time step is given. The result supports retime, synchronize and time-based indexing.

É assim que uma matriz simples de medições vira dados indexados no tempo. Os instantes das linhas são obrigatórios, a menos que se dê uma taxa de amostragem ou um passo de tempo. O resultado aceita retime, synchronize e indexação por tempo.

Input arguments

Argumentos de entrada

A
2-D array; each column becomes a variable.
Array 2-D; cada coluna vira uma variável.
'RowTimes'
datetime or duration vector with one entry per row, in increasing order.
Vetor datetime ou duration com uma entrada por linha, em ordem crescente.
'SampleRate'
Sampling rate in hertz, as an alternative to RowTimes.
Taxa de amostragem em hertz, como alternativa a RowTimes.

Output arguments

Argumentos de saída

TT
A timetable.
Uma timetable.

Example

Exemplo

Matrix with second-based times

Matriz com tempos em segundos

A = [1 2; 3 4];
TT = array2timetable(A, 'RowTimes', seconds([1; 2]), 'VariableNames', {'a', 'b'})
OutputSaída
TT = 2×2 timetable

    Time     a    b
    _____    _    _

    1 sec    1    2
    2 sec    3    4

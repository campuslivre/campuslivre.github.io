runstest next release

Runs test for randomness: checks whether the sequence of values above and below a threshold looks random.

Category: Probability Distributions and Hypothesis Tests > Hypothesis Tests

Syntax

h = runstest(x)

Tests whether x is random around its mean.

[h, p, stats] = runstest(x, v)

Uses the threshold v, or 'ud' to count runs of increases and decreases.

[...] = runstest(x, v, Name, Value)

Options 'Alpha', 'Method' and 'Tail'.

Description

A run is a maximal stretch of consecutive values on the same side of the threshold. Too few runs suggest clustering or a trend, and too many suggest alternation. The test compares the observed number of runs with what a random order would give.

It is useful, for example, to check the residuals of a model for leftover structure, in the order of the observations.

Input arguments

x
Vector of observations in the order they were collected. NaN values are ignored.
v
Threshold that splits the values into above and below, or 'ud'. Default: the mean of x.
'Alpha'
Significance level. Default 0.05.
'Method'
'exact' or 'approximate' (normal approximation).
'Tail'
'both' (default), 'right' or 'left'.

Output arguments

h
1 if randomness is rejected, 0 otherwise.
p
p-value.
stats
Structure with nruns (number of runs), n1 (values above the threshold), n0 (values below it) and z (normal statistic).

Examples

A binary sequence

x = [1 0 1 1 0 0 1 0 1 1 1 0 0 1 0 0 0 1 1 0];
[h, p, stats] = runstest(x, 0.5);
fprintf('%d %.4f\n', h, p)
disp(stats.nruns)
Output
0 0.8281
    12

A sine wave is far from random

x = sin(1:30);
[h, p, stats] = runstest(x);
fprintf('%d %.4f\n', h, p)
fprintf('%d runs, z = %.4f\n', stats.nruns, stats.z)
Output
1 0.0398
10 runs, z = -2.0439

Notes

With 'ud' the counts nruns, n1, n0 and z agree with MATLAB, but the p-value follows a distribution that was not matched, so it can differ.

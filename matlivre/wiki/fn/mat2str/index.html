mat2str

Converts a matrix to text that evaluates back to the matrix.

Converte uma matriz em texto que, avaliado, recria a matriz.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

s = mat2str(A)

Returns a character vector such as '[1 2;3 4]'.

Retorna um vetor de caracteres como '[1 2;3 4]'.

s = mat2str(A, n)

Uses n significant digits for each number (15 by default).

Usa n dígitos significativos em cada número (15 por padrão).

Description

Descrição

Columns are separated by spaces and rows by semicolons. Logical values appear as true and false, complex numbers as 1+2i, and integer classes are wrapped in their constructor, as in int8([1 2]). A char vector is returned in quotes.

With the default 15 digits the text reproduces ordinary doubles; a smaller n gives a shorter, rounded form.

As colunas são separadas por espaços e as linhas por ponto e vírgula. Valores lógicos aparecem como true e false, números complexos como 1+2i, e as classes de inteiros vêm dentro do construtor, como em int8([1 2]). Um vetor de char é devolvido entre aspas.

Com os 15 dígitos padrão o texto reproduz doubles comuns; um n menor dá uma forma mais curta, arredondada.

Input arguments

Argumentos de entrada

A
Numeric, logical or char matrix (two dimensions at most).
Matriz numérica, lógica ou de char (no máximo duas dimensões).
n
Number of significant digits.
Número de dígitos significativos.

Output arguments

Argumentos de saída

s
Character vector. Passing it to eval rebuilds A.
Vetor de caracteres. Passá-lo a eval reconstrói A.

Example

Exemplo

Matrices as text

Matrizes como texto

mat2str([1 2; 3 4.5])
mat2str([true false])
mat2str(pi, 4)
mat2str(int8([1 2]))
OutputSaída
ans = '[1 2;3 4.5]'
ans = '[true false]'
ans = '3.142'
ans = 'int8([1 2])'

Notes

Observações

For single input MATLAB wraps the text in single(...); MatLivre prints the bare number.

Para entrada single, o MATLAB envolve o texto em single(...); o MatLivre imprime apenas o número.

isocolors

Computes the colors of isosurface vertices from a second volume of data.

Calcula as cores dos vértices de uma isosuperfície a partir de um segundo volume de dados.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

cdata = isocolors(X, Y, Z, C, verts)

Interpolates the volume C at the vertices verts.

Interpola o volume C nos vértices verts.

cdata = isocolors(C, verts)

Uses the grid 1:n in each direction.

Usa a grade 1:n em cada direção.

isocolors(___, p)

Sets the colors of the patch p directly.

Define diretamente as cores do patch p.

Description

Descrição

The shape of an isosurface comes from one variable, but you may want to color it by another, such as temperature over a pressure surface. isocolors samples that second volume at each vertex by interpolation. Assign the result to the FaceVertexCData property of the patch.

A forma de uma isosuperfície vem de uma variável, mas pode-se querer colori-la por outra, como a temperatura sobre uma superfície de pressão. isocolors amostra esse segundo volume em cada vértice por interpolação. Atribua o resultado à propriedade FaceVertexCData do patch.

Input arguments

Argumentos de entrada

X, Y, Z
Coordinate arrays of the volume.
Arrays de coordenadas do volume.
C
3-D array of color values, or an m-by-n-by-p-by-3 array of RGB values.
Array 3-D de valores de cor, ou array m-por-n-por-p-por-3 de valores RGB.
verts
n-by-3 matrix of vertices, typically fv.vertices from isosurface.
Matriz n-por-3 de vértices, tipicamente fv.vertices de isosurface.

Output arguments

Argumentos de saída

cdata
One color value per vertex: a column vector for scalar data, or n-by-3 for RGB data.
Um valor de cor por vértice: vetor coluna para dados escalares, ou n-por-3 para dados RGB.

Example

Exemplo

Color by a second field

Cor por um segundo campo

[x, y, z] = meshgrid(-1:0.5:1);
v = x.^2 + y.^2 + z.^2;
fv = isosurface(x, y, z, v, 0.5);
c = isocolors(x, y, z, x, fv.vertices);
size(c)
min(c), max(c)
OutputSaída

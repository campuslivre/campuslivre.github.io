pi

The constant pi, the ratio of a circle's circumference to its diameter.

A constante pi, razão entre a circunferência de um círculo e seu diâmetro.

Category:Categoria: Mathematics > Elementary Math

Syntax

Sintaxe

x = pi

Returns the double-precision value closest to pi, 3.141592653589793.

Retorna o valor em precisão dupla mais próximo de pi, 3.141592653589793.

X = pi(n)

Returns an n-by-n matrix in which every element is pi.

Retorna uma matriz n-por-n em que todo elemento é pi.

X = pi(sz1, ..., szN)

Returns an array of the given size in which every element is pi.

Retorna um array do tamanho dado em que todo elemento é pi.

Description

Descrição

pi is a function, not a true constant, but it takes no arguments in normal use and is written without parentheses. It is a floating-point approximation: sin(pi) is about 1.2246e-16, not zero, because pi itself is slightly off. When exact results at multiples of pi matter, use the degree functions (sind, cosd) or sinpi and cospi.

Since pi can be overwritten by assigning a variable with that name, avoid using it as a variable.

pi é uma função, não uma constante verdadeira, mas em uso normal não recebe argumentos e é escrita sem parênteses. É uma aproximação em ponto flutuante: sin(pi) vale cerca de 1.2246e-16, não zero, porque o próprio pi é ligeiramente impreciso. Quando resultados exatos em múltiplos de pi importam, use as funções em graus (sind, cosd) ou sinpi e cospi.

Como pi pode ser sobrescrita ao atribuir uma variável com esse nome, evite usá-la como variável.

Input arguments

Argumentos de entrada

n, sz1, ..., szN
Optional dimensions of the result.
Dimensões opcionais do resultado.

Output arguments

Argumentos de saída

x
Double value or array filled with pi.
Valor double ou array preenchido com pi.

Example

Exemplo

Area, angle conversion and rounding error

Área, conversão de ângulo e erro de arredondamento

r = 2;
area = pi * r^2
rad2deg(pi/3)
sin(pi)
sinpi(1)
OutputSaída
area = 12.5664
ans = 60.0000
ans = 1.2246e-16
ans = 0

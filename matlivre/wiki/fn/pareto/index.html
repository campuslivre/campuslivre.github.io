pareto

Pareto chart: bars sorted in descending order with a line of the cumulative percentage.

Gráfico de Pareto: barras em ordem decrescente com uma linha da porcentagem acumulada.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

pareto(y)

Sorts the values y from largest to smallest, plots them as bars and adds the cumulative total as a line.

Ordena os valores y do maior para o menor, plota como barras e acrescenta o total acumulado como linha.

pareto(y, names)

Labels the bars with names (cell array or string array).

Rotula as barras com names (cell array ou array de strings).

pareto(y, x)

Labels the bars with the numeric vector x.

Rotula as barras com o vetor numérico x.

pareto(___, threshold)

Shows only the bars needed to reach the fraction threshold of the total, 0.95 by default.

Mostra apenas as barras necessárias para atingir a fração threshold do total, 0.95 por padrão.

Description

Descrição

The chart supports the rule of thumb that a few causes account for most of the total. The bars show each cause, largest first, and the right-hand axis shows the running percentage. Only the bars that bring the total up to the threshold are drawn.

O gráfico apoia a regra prática de que poucas causas respondem pela maior parte do total. As barras mostram cada causa, da maior para a menor, e o eixo da direita mostra a porcentagem acumulada. Só as barras que levam o total até o limite são desenhadas.

Input arguments

Argumentos de entrada

y
Vector of non-negative values, for instance the number of defects per cause.
Vetor de valores não negativos, por exemplo o número de defeitos por causa.
names
Labels, one per value.
Rótulos, um por valor.

Example

Exemplo

Causes of defects

Causas de defeitos

defects = [24 5 40 9 3 19];
causes = {'Scratch','Dent','Crack','Stain','Burr','Chip'};
pareto(defects, causes)

In the app, the chart is drawn below the code.

No app, o gráfico é desenhado abaixo do código.

Notes

Observações

In MatLivre pareto returns only the graphics handle: the two-output form [h, ax] = pareto(...) of MATLAB is not available.

No MatLivre, pareto retorna apenas o handle gráfico: a forma com duas saídas [h, ax] = pareto(...) do MATLAB não está disponível.

pagesvd

Singular value decomposition of every page of a 3-D array.

Decomposição em valores singulares de cada página de um array 3-D.

Category:Categoria: Mathematics > Linear Algebra

Syntax

Sintaxe

S = pagesvd(A)

Returns the singular values of each page A(:,:,k), in descending order.

Retorna os valores singulares de cada página A(:,:,k), em ordem decrescente.

[U, S, V] = pagesvd(A)

Returns the factors of each page, so that every page satisfies A(:,:,k) = U(:,:,k)*S(:,:,k)*V(:,:,k)'.

Retorna os fatores de cada página, de modo que cada página satisfaz A(:,:,k) = U(:,:,k)*S(:,:,k)*V(:,:,k)'.

[U, S, V] = pagesvd(A, 'econ')

Computes the economy-size factors of each page.

Calcula os fatores de tamanho econômico de cada página.

Description

Descrição

pagesvd applies svd independently to each m-by-n page of an m-by-n-by-p array. It avoids writing a loop over the third dimension and returns the results stacked in the same page order.

With one output the result is a stack of column vectors, which is convenient for comparing the spectra of many matrices at once.

pagesvd aplica svd de forma independente a cada página m-por-n de um array m-por-n-por-p. Evita escrever um laço sobre a terceira dimensão e devolve os resultados empilhados na mesma ordem das páginas.

Com uma saída o resultado é uma pilha de vetores coluna, útil para comparar os espectros de várias matrizes de uma vez.

Input arguments

Argumentos de entrada

A
Numeric array whose pages (the first two dimensions) are the matrices to decompose.
Array numérico cujas páginas (as duas primeiras dimensões) são as matrizes a decompor.
'econ'
Optional flag that drops the singular vectors that do not correspond to a singular value.
Opção que descarta os vetores singulares que não correspondem a um valor singular.

Output arguments

Argumentos de saída

S
With one output, an array of size min(m,n)-by-1-by-p holding the singular values of each page. With three outputs, the diagonal matrices of singular values, one per page.
Com uma saída, um array de tamanho min(m,n)-por-1-por-p com os valores singulares de cada página. Com três saídas, as matrizes diagonais de valores singulares, uma por página.
U, V
Orthogonal (unitary) factors of each page.
Fatores ortogonais (unitários) de cada página.

Example

Exemplo

Singular values of two pages

Valores singulares de duas páginas

A = cat(3, [1 2; 3 4], [2 0; 0 1]);
S = pagesvd(A);
disp(S(:,:,1)')
disp(S(:,:,2)')
OutputSaída
    5.4650    0.3660
     2     1

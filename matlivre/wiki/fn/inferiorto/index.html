inferiorto

Declares that a class has lower precedence than other classes.

Declara que uma classe tem precedência menor que a de outras classes.

Category:Categoria: Other public functions: datatypes

Syntax

Sintaxe

inferiorto('class1', 'class2', ...)

Marks the class being defined as inferior to the named classes.

Marca a classe em definição como inferior às classes indicadas.

Description

Descrição

When an operation or function receives objects of two different classes, MATLAB decides whose method to call. If the class being defined is inferior to the other, the other class's method wins. inferiorto records that ranking and is called only from inside the constructor of a class.

It matters for classes that overload operators such as + and need a clear rule for mixed arguments. superiorto states the opposite ranking.

Quando uma operação ou função recebe objetos de duas classes diferentes, o MATLAB decide qual método chamar. Se a classe em definição é inferior à outra, vale o método da outra classe. inferiorto registra essa hierarquia e só é chamada dentro do construtor de uma classe.

Importa para classes que sobrecarregam operadores como + e precisam de uma regra clara para argumentos mistos. superiorto declara a hierarquia oposta.

Input arguments

Argumentos de entrada

'class1', ...
Names of classes, as text.
Nomes de classes, como texto.

Example

Exemplo

Outside a class method

Fora de um método de classe

try
    inferiorto('double')
catch err
    disp(err.message)
end
OutputSaída
Function 'INFERIORTO' can only be called from within a method.

The function only makes sense inside a class constructor, so a script gets an error.

A função só faz sentido no construtor de uma classe, então um script recebe um erro.

Notes

Observações

This is the old-style class mechanism; in a script it always raises an error.

É o mecanismo de classes do estilo antigo; em um script sempre gera um erro.

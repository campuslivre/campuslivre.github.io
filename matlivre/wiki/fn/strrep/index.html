strrep

Replaces every occurrence of a substring with another.

Substitui toda ocorrência de uma substring por outra.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

s = strrep(str, old, new)

Replaces each old in str with new.

Substitui cada old em str por new.

Description

Descrição

The search is literal and case sensitive, scanning left to right without overlap: strrep('aaa', 'aa', 'b') is 'ba'. If old is empty or does not occur, str is returned unchanged.

For patterns, case-insensitive replacement or capture groups, use regexprep; replace is the newer function for strings.

A busca é literal e diferencia maiúsculas, percorrendo da esquerda para a direita sem sobreposição: strrep('aaa', 'aa', 'b') é 'ba'. Se old for vazio ou não ocorrer, str é devolvida sem alteração.

Para padrões, substituição sem distinção de caixa ou grupos de captura, use regexprep; replace é a função mais nova para strings.

Input arguments

Argumentos de entrada

str
Character vector, string array, or cell array of character vectors.
Vetor de caracteres, array de strings ou cell array de vetores de caracteres.
old
Literal text to find.
Texto literal a encontrar.
new
Replacement text; may be empty to delete.
Texto de substituição; pode ser vazio para apagar.

Output arguments

Argumentos de saída

s
Text of the same type and shape as str.
Texto do mesmo tipo e forma de str.

Example

Exemplo

Characters, cells and overlap

Caracteres, células e sobreposição

strrep('hello world', 'o', '0')
strrep({'aa','ba'}, 'a', 'xy')
strrep('aaa', 'aa', 'b')
OutputSaída
ans = 'hell0 w0rld'
ans = 1×2 cell

    {'xyxy'}    {'bxy'}
ans = 'ba'

bubblecloud

Draws a packed cloud of circles whose areas are proportional to the data values.

Desenha uma nuvem compacta de círculos com áreas proporcionais aos valores dos dados.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

bubblecloud(sz)

Draws one bubble per element of the vector sz.

Desenha uma bolha por elemento do vetor sz.

bubblecloud(sz, labels)

Labels each bubble.

Rotula cada bolha.

bubblecloud(tbl, sizevar, labelvar)

Takes sizes and labels from variables of a table.

Obtém tamanhos e rótulos de variáveis de uma tabela.

b = bubblecloud(___)

Also returns the BubbleCloud object.

Também retorna o objeto BubbleCloud.

Description

Descrição

A bubble cloud shows the relative weight of categories. Each category is a circle whose area follows its value, and the circles are packed together with no axes. It reads quickly but values are hard to compare precisely, so label the bubbles.

Uma nuvem de bolhas mostra o peso relativo de categorias. Cada categoria é um círculo cuja área segue o seu valor, e os círculos são agrupados sem eixos. Lê-se rapidamente, mas é difícil comparar valores com precisão, então rotule as bolhas.

Input arguments

Argumentos de entrada

sz
Vector of non-negative values; a bigger value gives a bigger circle.
Vetor de valores não negativos; um valor maior dá um círculo maior.
labels
Cell array or string array with one label per bubble.
Cell array ou array de strings com um rótulo por bolha.
tbl
A table, with sizevar and labelvar naming its variables.
Uma tabela, com sizevar e labelvar nomeando suas variáveis.

Output arguments

Argumentos de saída

b
The BubbleCloud object.
O objeto BubbleCloud.

Example

Exemplo

Labeled bubbles

Bolhas rotuladas

sales = [120 80 45 200 60];
names = {'North', 'South', 'East', 'West', 'Center'};
bubblecloud(sales, names)
title('Sales by region')

In the app, the figure is drawn below the code.

No app, a figura é desenhada abaixo do código.

Notes

Observações

The circle layout is an approximation of MATLAB's, so positions can differ.

O arranjo dos círculos é uma aproximação do do MATLAB, então as posições podem diferir.

treeplot

Draws a tree from its parent vector.

Desenha uma árvore a partir do vetor de pais.

Category:Categoria: Mathematics > Sparse Matrices

Syntax

Sintaxe

treeplot(p)

Plots the tree whose parent vector is p.

Desenha a árvore cujo vetor de pais é p.

treeplot(p, nodeSpec, edgeSpec)

Sets the style of the node markers and of the edges.

Define o estilo dos marcadores dos nós e das arestas.

Description

Descrição

Nodes are placed with treelayout: the root is at the top and each level of the tree is one row lower. The format is the same one returned by etree, so treeplot(etree(A)) shows the elimination tree of a matrix.

Os nós são posicionados com treelayout: a raiz fica no topo e cada nível da árvore fica uma linha abaixo. O formato é o mesmo retornado por etree, então treeplot(etree(A)) mostra a árvore de eliminação de uma matriz.

Input arguments

Argumentos de entrada

p
Parent vector: p(j) is the parent of node j, 0 for a root, with p(j) < j.
Vetor de pais: p(j) é o pai do nó j, 0 para uma raiz, com p(j) < j.
nodeSpec, edgeSpec
Optional line specifications, for example 'ko' and 'r-'.
Especificações de linha opcionais, por exemplo 'ko' e 'r-'.

Example

Exemplo

A binary tree

Uma árvore binária

p = [0 1 1 2 2 3 3];
treeplot(p)

Notes

Observações

The form that returns coordinates, [x, y] = treeplot(p), is not supported; use treelayout for that.

A forma que retorna coordenadas, [x, y] = treeplot(p), não é suportada; use treelayout para isso.

See also

Veja também

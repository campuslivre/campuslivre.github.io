idealfilter

Applies an ideal frequency-domain filter to a timeseries.

Aplica um filtro ideal no domínio da frequência a uma timeseries.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

tsout = idealfilter(ts, interval, 'pass')

Keeps the frequencies inside each interval.

Mantém as frequências dentro de cada intervalo.

tsout = idealfilter(ts, interval, 'notch')

Removes the frequencies inside each interval.

Remove as frequências dentro de cada intervalo.

Description

Descrição

The filter works in the frequency domain: the data are transformed with an FFT, the unwanted frequency bins are set to zero, and the inverse transform gives the filtered signal. The cut is perfectly sharp, which is why it is called ideal, but also why it can ring near abrupt changes.

O filtro atua no domínio da frequência: os dados passam por uma FFT, as frequências indesejadas são zeradas e a transformada inversa fornece o sinal filtrado. O corte é perfeitamente abrupto, daí o nome ideal, mas também por isso pode oscilar perto de mudanças bruscas.

Input arguments

Argumentos de entrada

ts
timeseries object.
Objeto timeseries.
interval
Two-column matrix of frequency bands [low high], in cycles per time unit of the series.
Matriz de duas colunas com as faixas de frequência [baixa alta], em ciclos por unidade de tempo da série.
'pass' | 'notch'
Whether the bands are kept or removed.
Se as faixas são mantidas ou removidas.

Output arguments

Argumentos de saída

tsout
Filtered timeseries with the same time vector.
timeseries filtrada com o mesmo vetor de tempo.

Example

Exemplo

Low-pass of two tones

Passa-baixas de dois tons

t = (0:7)';
y = sin(2*pi*0.05*t) + sin(2*pi*0.4*t);
f = idealfilter(timeseries(y, t), [0 0.2], 'pass');
disp(round(f.Data' * 1000) / 1000)
OutputSaída
   -0.4450   -0.4260   -0.1580    0.2030    0.4450    0.4260    0.1580   -0.2030

quadv

Adaptive Simpson quadrature of a vector-valued function of one variable.

Quadratura adaptativa de Simpson de uma função de uma variável com valores vetoriais.

Category:Categoria: Mathematics > Numerical Integration and Differential Equations

Syntax

Sintaxe

Q = quadv(fun, a, b)

Integrates fun from a to b, where fun(x) returns an array for a scalar x.

Integra fun de a a b, onde fun(x) retorna um array para x escalar.

Q = quadv(fun, a, b, tol)

Uses the absolute tolerance tol.

Usa a tolerância absoluta tol.

Description

Descrição

All components are integrated together on a shared subdivision of the interval, which is faster than calling quad once per component. The function is evaluated one point at a time, so it does not need to be vectorized in x.

The modern equivalent is integral(fun, a, b, 'ArrayValued', true).

Todas as componentes são integradas juntas em uma subdivisão comum do intervalo, o que é mais rápido que chamar quad uma vez por componente. A função é avaliada um ponto por vez, então não precisa ser vetorizada em x.

O equivalente moderno é integral(fun, a, b, 'ArrayValued', true).

Input arguments

Argumentos de entrada

fun
Handle called with a scalar x that returns a scalar, vector or array.
Handle chamado com x escalar que retorna um escalar, vetor ou array.
a, b
Finite limits.
Limites finitos.
tol
Absolute tolerance. Default 1e-6.
Tolerância absoluta. Padrão 1e-6.

Output arguments

Argumentos de saída

Q
Array of the same size as fun(x), holding the integrals of every component.
Array do mesmo tamanho de fun(x), com as integrais de todas as componentes.

Example

Exemplo

Two integrals at once

Duas integrais de uma vez

Q = quadv(@(x) [x, x.^2], 0, 1)
OutputSaída
Q = 1×2

    0.5000    0.3333

rpmfreqmap

Computes a frequency-RPM map: the spectrum of a vibration signal versus the shaft speed, to see which frequencies follow the rotation.

Category: Vibration analysis

Syntax

map = rpmfreqmap(x, fs, rpm)

Map with the default frequency resolution of fs/128.

[map, f, r, t] = rpmfreqmap(x, fs, rpm, res)

Targets the frequency resolution res, in hertz.

[map, f, r, t] = rpmfreqmap(___, Name, Value)

Sets the amplitude type, scale, overlap or window.

Description

The signal is cut into segments, and each one is tagged with the shaft speed at its center. Components tied to the rotation, such as the harmonics of the shaft frequency, appear as lines that slope upward as the speed rises, while resonances stay at a fixed frequency.

Use it to tell the two apart before looking at orders with rpmordermap.

Input arguments

x
Vibration signal, a vector.
fs
Sample rate in hertz.
rpm
Shaft speed in revolutions per minute, one positive value per sample of x.
res
Wanted frequency resolution in hertz. A smaller value gives a longer window. Default fs/128.
'Amplitude'
'rms' (default), 'peak' or 'power'.
'Scale'
'linear' (default) or 'dB'.
'OverlapPercent'
Overlap between segments, from 0 to 100. Default 50.
'Window'
'flattopwin' (default), 'hann', 'hamming', 'kaiser', 'rectwin' or 'chebwin'.

Output arguments

map
Map with one row per frequency and one column per time segment.
f
Frequency of each row, in hertz, from 0 to fs/2.
r
Shaft speed of each column, in rpm (the speed at the center of the segment).
t
Time of each column, in seconds.

Example

A harmonic that follows the speed

fs = 1000; n = 1024; t = (0:n-1)'/fs;
rpm = 600 + 300*t;
ph = 2*pi*cumtrapz(t, rpm/60);
x = cos(ph) + 0.6*cos(3*ph);
[map, f, r, tt] = rpmfreqmap(x, fs, rpm, 10);
disp(size(map))
for c = [1 size(map, 2)]
  [~, i] = max(map(:, c));
  fprintf('%.0f rpm (%.1f Hz): strongest at %.1f Hz\n', r(c), r(c)/60, f(i));
end
Output
   129    12
623 rpm (10.4 Hz): strongest at 11.7 Hz
870 rpm (14.5 Hz): strongest at 15.6 Hz

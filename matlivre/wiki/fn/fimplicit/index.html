fimplicit

Plots an implicit curve defined by f(x,y) = 0.

Plota uma curva implícita definida por f(x,y) = 0.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

fimplicit(f)

Plots the set where f(x,y) = 0 over the default region -5 < x < 5, -5 < y < 5.

Plota o conjunto em que f(x,y) = 0 na região padrão -5 < x < 5, -5 < y < 5.

fimplicit(f, [min max])

Uses the same interval for x and y.

Usa o mesmo intervalo para x e y.

fimplicit(f, [xmin xmax ymin ymax])

Sets each interval.

Define cada intervalo.

h = fimplicit(___)

Also returns the line handle.

Também retorna o handle da linha.

Description

Descrição

Curves that cannot be solved for y, such as a circle or an ellipse, can be drawn directly. To plot g(x,y) = c, pass @(x,y) g(x,y) - c.

Curvas que não podem ser resolvidas para y, como um círculo ou uma elipse, podem ser desenhadas diretamente. Para plotar g(x,y) = c, passe @(x,y) g(x,y) - c.

Input arguments

Argumentos de entrada

f
Function handle of x and y. The curve is where its value is zero.
Handle de função de x e y. A curva é onde seu valor é zero.
interval
Two or four numbers that set the region.
Dois ou quatro números que definem a região.

Output arguments

Argumentos de saída

h
Handle to the implicit function line.
Handle da linha da função implícita.

Example

Exemplo

Circle and ellipse

Círculo e elipse

fimplicit(@(x,y) x.^2 + y.^2 - 1, [-2 2])
hold on
fimplicit(@(x,y) x.^2/4 + y.^2 - 1)
hold off
axis equal

In the app, the figure is drawn below the code.

No app, a figura é desenhada abaixo do código.

Veja também

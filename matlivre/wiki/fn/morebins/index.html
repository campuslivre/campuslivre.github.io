morebins next releasepróxima versão

Increases the number of bins of an existing histogram object.

Aumenta o número de bins de um objeto de histograma existente.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

morebins(h)

Makes the histogram h use more, narrower bins.

Faz o histograma h usar mais bins, mais estreitos.

n = morebins(h)

Also returns the new number of bins.

Também retorna o novo número de bins.

Description

Descrição

The binning of h is changed in place and the figure is redrawn with finer bins. Each call raises the bin count by one step, so it can be repeated until the detail you want shows. fewerbins does the opposite.

Os bins de h são alterados no próprio objeto e a figura é redesenhada com bins mais finos. Cada chamada aumenta o número de bins em um passo, então pode ser repetida até aparecer o detalhe desejado. fewerbins faz o oposto.

Input arguments

Argumentos de entrada

h
Histogram object created by histogram.
Objeto de histograma criado por histogram.

Output arguments

Argumentos de saída

n
Number of bins after the change.
Número de bins depois da alteração.

Example

Exemplo

Finer bins

Bins mais finos

h = histogram(1:100);
before = h.NumBins
after = morebins(h)
OutputSaída
before = 5
after = 6

Veja também

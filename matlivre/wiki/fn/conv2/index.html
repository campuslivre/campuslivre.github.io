conv2

Two-dimensional convolution of two matrices.

Convolução bidimensional de duas matrizes.

Category:Categoria: Mathematics > Fourier Analysis and Filtering

Syntax

Sintaxe

C = conv2(A, B)

Returns the full convolution, of size size(A)+size(B)-1.

Retorna a convolução completa, de tamanho size(A)+size(B)-1.

C = conv2(A, B, shape)

Returns the part selected by shape: 'full', 'same' or 'valid'.

Retorna a parte escolhida por shape: 'full', 'same' ou 'valid'.

C = conv2(u, v, A)

Convolves the columns of A with the vector u and then the rows with the vector v.

Convolui as colunas de A com o vetor u e depois as linhas com o vetor v.

Description

Descrição

Each output element is a sum of products of A with the kernel B rotated by 180 degrees, with A treated as zero outside its edges. Convolution is the operation behind blurring, edge detection and other image filters.

The three-argument form with two vectors is a separable filter: it gives the same result as convolving with the outer product u*v.', but costs fewer operations.

Cada elemento da saída é uma soma de produtos de A com o kernel B girado em 180 graus, com A tratada como zero fora de suas bordas. A convolução é a operação por trás de desfoque, detecção de bordas e outros filtros de imagem.

A forma de três argumentos com dois vetores é um filtro separável: dá o mesmo resultado que convoluir com o produto externo u*v.', mas com menos operações.

Input arguments

Argumentos de entrada

A, B
Numeric matrices. B is usually the smaller kernel.
Matrizes numéricas. B costuma ser o kernel menor.
shape
'full' (default) returns every point; 'same' returns the central part with the size of A; 'valid' returns only points computed without zero padding.
'full' (padrão) retorna todos os pontos; 'same' retorna a parte central com o tamanho de A; 'valid' retorna apenas os pontos calculados sem preenchimento com zeros.

Output arguments

Argumentos de saída

C
Convolution result.
Resultado da convolução.

Example

Exemplo

Full, same and valid

Full, same e valid

A = [1 2 3; 4 5 6; 7 8 9];
conv2([1 2; 3 4], ones(2))
conv2(A, [0 1 0; 1 1 1; 0 1 0], 'same')
conv2(A, [1 0; 0 -1], 'valid')

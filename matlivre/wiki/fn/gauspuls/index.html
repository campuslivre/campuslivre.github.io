gauspuls

Generates a Gaussian-modulated sinusoidal pulse, and can return its quadrature part, its envelope or the time at which it falls below a level.

Category: Waveforms

Syntax

yi = gauspuls(t, fc, bw)

Pulse with center frequency fc (Hz) and fractional bandwidth bw, evaluated at t.

yi = gauspuls(t, fc, bw, bwr)

Also sets the level bwr (dB) at which the bandwidth is measured.

[yi, yq, ye] = gauspuls(___)

Also returns the quadrature component and the envelope.

tc = gauspuls('cutoff', fc, bw, bwr, tpe)

Returns the cutoff time at which the trailing pulse envelope falls tpe dB below the peak.

Description

The pulse is a cosine at fc multiplied by a Gaussian envelope centered at t = 0. The bandwidth bw is the fraction of fc that the pulse spectrum occupies, measured where its magnitude has dropped to bwr dB.

Use the 'cutoff' form to decide how long a time vector to build: it gives the time after which the envelope is below tpe dB, so the pulse is negligible beyond [-tc, tc].

Input arguments

t
Time instants in seconds.
fc
Center frequency in hertz. Default 1000.
bw
Fractional bandwidth, a positive number. Default 0.5.
bwr
Reference level for bw, in dB, negative. Default -6.
tpe
Trailing pulse envelope level in dB, negative, used by the 'cutoff' form. Default -60.

Output arguments

yi
In-phase (cosine) part of the pulse, same size as t.
yq
Quadrature (sine) part of the pulse.
ye
Envelope of the pulse: the Gaussian that multiplies the carrier.
tc
Cutoff time in seconds, returned by the 'cutoff' form.

Examples

Pulse and envelope samples

t = -0.002:0.001:0.002;
[yi, yq, ye] = gauspuls(t, 1000, 0.5);
disp(round(yi*1000)/1000)
disp(round(ye*1000)/1000)
Output
    0.0280    0.4090    1.0000    0.4090    0.0280
    0.0280    0.4090    1.0000    0.4090    0.0280

Cutoff time

tc = gauspuls('cutoff', 1000, 0.5, -6, -40);
fprintf('%.6f\n', tc)
Output
0.002271

Notes

A complex time input is rejected with an error. MATLAB returns Inf in that case.

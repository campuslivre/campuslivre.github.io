streamribbon

Draws 3-D stream ribbons that twist with the flow.

Category: Graphics > 2-D and 3-D Plots

Syntax

h = streamribbon(verts, X, Y, Z, cav, spd)

Draws ribbons along verts, twisted by the curl angular velocity cav.

h = streamribbon(X, Y, Z, U, V, W, startx, starty, startz, width)

Computes the paths and draws ribbons of the given width.

Description

A ribbon is a thin surface laid along a streamline. Its rotation about the line shows the local rotation of the flow, so a twisting ribbon reveals vorticity that a plain line hides.

Input arguments

verts
Cell array of vertices from stream3.
X, Y, Z
Grid coordinates.
cav
Curl angular velocity, which sets how fast the ribbon twists.
spd
Flow speed.

Output arguments

h
Handles of the ribbon surfaces.

Example

Ribbon along one path

[x, y, z] = meshgrid(-2:1:2);
u = -y;
v = x;
w = 0*z + 0.1;
verts = stream3(x, y, z, u, v, w, 1, 0, 0);
h = streamribbon(verts, x, y, z, 0*x, 0*x + 1);
view(3)
disp(numel(h))
Output
     1

contourc

Computes contour line coordinates without drawing them.

Calcula as coordenadas das curvas de nível sem desenhá-las.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

C = contourc(Z)

Contour matrix for automatically chosen levels of Z.

Matriz de contorno para níveis de Z escolhidos automaticamente.

C = contourc(Z, levels)

Uses the given number of levels or level values.

Usa o número de níveis ou valores de níveis informados.

C = contourc(x, y, Z, levels)

Uses the coordinate vectors x and y.

Usa os vetores de coordenadas x e y.

Description

Descrição

contourc is the numerical core behind contour. Use it when you need the line coordinates as data, for example to measure a level curve or to plot it with plot. A closed curve repeats its first point at the end.

contourc é o núcleo numérico por trás de contour. Use-o quando precisar das coordenadas das linhas como dados, por exemplo para medir uma curva de nível ou plotá-la com plot. Uma curva fechada repete o primeiro ponto no final.

Input arguments

Argumentos de entrada

Z
Matrix of values, at least 2 by 2.
Matriz de valores, de pelo menos 2 por 2.
x, y
Coordinate vectors matching the columns and rows of Z.
Vetores de coordenadas correspondentes às colunas e linhas de Z.
levels
Number of levels, or a vector of level values. Repeat a value, as in [v v], to get a single level.
Número de níveis, ou vetor de valores. Repita um valor, como em [v v], para obter um único nível.

Output arguments

Argumentos de saída

C
Two-row matrix. Each line starts with a column holding the level (row 1) and the number of points (row 2), followed by that many columns of x (row 1) and y (row 2) coordinates.
Matriz de duas linhas. Cada curva começa com uma coluna contendo o nível (linha 1) e o número de pontos (linha 2), seguida de tantas colunas de coordenadas x (linha 1) e y (linha 2).

Example

Exemplo

Coordinates of one level

Coordenadas de um nível

[X, Y] = meshgrid(-2:2);
Z = X.^2 + Y.^2;
C = contourc(Z, [1 1])
OutputSaída
C = 2×6

     1     3     2     3     4     3
     5     2     3     4     3     2

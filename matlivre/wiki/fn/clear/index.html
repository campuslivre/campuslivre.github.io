clear

Removes variables from the workspace.

Remove variáveis do workspace.

Category:Categoria: Data Import and Analysis > Data Import and Export

Syntax

Sintaxe

clear

Removes every variable from the current workspace.

Remove todas as variáveis do workspace atual.

clear name1 name2

Removes the named variables. Wildcards such as x* are accepted.

Remove as variáveis indicadas. Curingas como x* são aceitos.

clear all

Removes variables and also resets cached functions and state.

Remove as variáveis e também redefine funções em cache e estado.

clear('name')

Function form, convenient when the name is held in a string.

Forma de função, útil quando o nome está guardado em uma string.

Description

Descrição

clear is usually written in command syntax, without parentheses or quotes. Clearing a name that does not exist is not an error. After clearing, using the variable raises the usual undefined-variable error.

To drop everything except a few variables, use clearvars with -except.

clear costuma ser escrito na sintaxe de comando, sem parênteses nem aspas. Limpar um nome que não existe não gera erro. Depois de limpar, usar a variável provoca o erro habitual de variável indefinida.

Para apagar tudo menos algumas variáveis, use clearvars com -except.

Input arguments

Argumentos de entrada

name
Variable name or pattern. * matches any run of characters.
Nome de variável ou padrão. * casa qualquer sequência de caracteres.

Example

Exemplo

Clear by name and pattern

Limpar por nome e padrão

xa = 1; xb = 2; yy = 3;
clear x*
exist('xa')
exist('yy')
clear yy
exist('yy')
OutputSaída
ans = 0
ans = 1
ans = 0

Notes

Observações

The -regexp option is not supported: it leaves the variables in place.

A opção -regexp não é suportada: as variáveis continuam no lugar.

binofit next release

Estimates the success probability of a binomial distribution from counts and returns Clopper-Pearson confidence intervals.

Category: Probability Distributions and Hypothesis Tests > Univariate Discrete Distributions

Syntax

phat = binofit(x, n)

Estimate x./n of the success probability.

[phat, pci] = binofit(x, n)

Also returns 95% confidence intervals.

[phat, pci] = binofit(x, n, alpha)

Uses a 100*(1-alpha)% confidence level.

Description

binofit answers: given x successes in n trials, what success probability is plausible? The point estimate is x/n. The interval is the exact Clopper-Pearson interval, which is conservative: it covers the true value at least 100*(1-alpha)% of the time.

Values of x that are negative or larger than n are errors.

Input arguments

x
Number of observed successes, a non-negative integer or a vector of them.
n
Number of trials, a positive integer. A scalar is used for every element of x, otherwise the same length as x.
alpha
Significance level. Default 0.05.

Output arguments

phat
Estimated success probabilities, the same size as x.
pci
Confidence limits. One row per element of x, lower limit in the first column and upper limit in the second.

Examples

Estimate with a 95% interval

[phat, pci] = binofit(7, 20);
fprintf('phat = %.4f\n', phat);
disp(round(pci*1e4)/1e4)
Output
phat = 0.3500
    0.1539    0.5922

Several experiments at once

[phat, pci] = binofit([2 4], [10 10]);
disp(phat)
disp(round(pci*1e4)/1e4)
Output
    0.2000    0.4000
    0.0252    0.5561
    0.1216    0.7376

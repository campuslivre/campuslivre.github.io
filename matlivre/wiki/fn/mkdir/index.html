mkdir

Creates a folder, including any missing parent folders.

Cria uma pasta, inclusive as pastas pai que faltarem.

Category:Categoria: Programming > Files and Folders

Syntax

Sintaxe

mkdir(folder)

Creates folder.

Cria folder.

mkdir(parent, name)

Creates name inside parent.

Cria name dentro de parent.

[status, message, messageid] = mkdir(___)

Returns the outcome instead of only acting.

Retorna o resultado em vez de apenas agir.

Description

Descrição

Creating a folder that already exists is not an error: the call reports success and, if outputs are requested, a message saying that the directory already exists. This makes mkdir safe to call at the top of a script that saves results.

The command form mkdir results works like the function call.

Criar uma pasta que já existe não é erro: a chamada informa sucesso e, se houver saídas, uma mensagem dizendo que o diretório já existe. Isso torna mkdir seguro no começo de um script que salva resultados.

A forma de comando mkdir results funciona como a chamada de função.

Input arguments

Argumentos de entrada

folder
Folder to create, relative or absolute. Intermediate folders are created too.
Pasta a criar, relativa ou absoluta. As pastas intermediárias também são criadas.
parent, name
Parent folder and new folder name, as separate arguments.
Pasta pai e nome da nova pasta, como argumentos separados.

Output arguments

Argumentos de saída

status
true if the folder exists afterwards.
true se a pasta existe depois.
message
Text such as 'Directory already exists.', empty on a plain success.
Texto como 'Directory already exists.', vazio em um sucesso simples.
messageid
Message identifier, for instance 'MATLAB:MKDIR:DirectoryExists'.
Identificador da mensagem, por exemplo 'MATLAB:MKDIR:DirectoryExists'.

Example

Exemplo

Nested folders and a repeat call

Pastas aninhadas e uma chamada repetida

mkdir out/2024/jan
isfolder('out/2024/jan')
[status, msg, id] = mkdir('out/2024/jan')
OutputSaída
ans = logical
   1
status = logical
   1
msg = 'Directory already exists.'
id = 'MATLAB:MKDIR:DirectoryExists'

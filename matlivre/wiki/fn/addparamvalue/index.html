addParamValue

Older name of addParameter for adding a name-value argument.

Nome antigo de addParameter para adicionar um argumento nome-valor.

Category:Categoria: Programming > Functions

Syntax

Sintaxe

addParamValue(p, name, default)

Declares a name-value argument with a default.

Declara um argumento nome-valor com um padrão.

addParamValue(p, name, default, validationFcn)

Also validates the value.

Também valida o valor.

Description

Descrição

addParamValue was the original way to declare a name-value argument and still works. New code should use addParameter, which behaves the same in this respect and is the form the documentation uses today.

addParamValue era a forma original de declarar um argumento nome-valor e ainda funciona. Código novo deve usar addParameter, que se comporta do mesmo modo neste ponto e é a forma usada hoje na documentação.

Input arguments

Argumentos de entrada

p
An inputParser object.
Um objeto inputParser.
name
Parameter name, as text.
Nome do parâmetro, como texto.
default
Value used when the parameter is not given.
Valor usado quando o parâmetro não é fornecido.
validationFcn
Validation function handle.
Handle da função de validação.

Example

Exemplo

Same effect as addParameter

Mesmo efeito que addParameter

p = inputParser;
addParamValue(p, 'Scale', 1);
parse(p, 'Scale', 3);
p.Results.Scale
OutputSaída
ans = 3

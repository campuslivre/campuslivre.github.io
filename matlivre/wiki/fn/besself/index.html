besself

Designs an analog Bessel filter (lowpass, highpass, bandpass or bandstop) with maximally flat group delay.

Category: Analog filters

Syntax

[b,a] = besself(n,wo)

Lowpass filter of order n as numerator b and denominator a.

[b,a] = besself(n,wo,ftype)

Chooses the type: 'low', 'high', 'bandpass' or 'stop'.

[z,p,k] = besself(___)

Returns zeros, poles and gain instead of polynomials.

[A,B,C,D] = besself(___)

Returns the state-space matrices.

Description

besself builds the Bessel prototype with besselap and moves it to the requested band. The result is an analog filter, so wo is in rad/s and the response is evaluated on the imaginary axis, for example with freqs.

The filter trades sharpness for waveform fidelity: the group delay is nearly constant in the passband, but the transition is gentle. The frequency wo is where the delay-normalized prototype is scaled to, not a 3 dB point, so the magnitude at wo is below 0.707. To get a digital filter, pass the result through bilinear or impinvar.

Input arguments

n
Filter order, a positive integer. Bandpass and bandstop filters have order 2*n.
wo
Frequency in rad/s. A scalar for lowpass and highpass, a two-element vector [w1 w2] for bandpass and bandstop.
ftype
Filter type: 'low', 'high', 'bandpass' or 'stop'. A scalar wo defaults to 'low', a two-element wo to 'bandpass'.

Output arguments

b, a
Numerator and denominator polynomial coefficients, in descending powers of s.
z, p, k
Zeros, poles and gain of the filter.
A, B, C, D
State-space matrices of the filter.

Example

Fourth-order lowpass at 1000 rad/s

[b,a] = besself(4,1000);
fprintf('%.4g ', a); fprintf('\n');
[h,w] = freqs(b,a,[100 1000 5000]);
fprintf('%.4f\n', abs(h))
Output
1 3124 4.392e+06 3.201e+09 1e+12 
0.9927
0.4179
0.0016

Notes

For the 'high', 'bandpass' and 'stop' designs, MATLAB's result carries rounding noise (1e-15 to 1e-8) where the exact value is zero. MatLivre returns exact zeros there.

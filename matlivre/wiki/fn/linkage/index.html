linkage next release

Builds an agglomerative hierarchical cluster tree from data rows or from a vector of pairwise distances.

Category: Cluster Analysis and Anomaly Detection > Hierarchical Clustering

Syntax

Z = linkage(Y)

Single linkage on the distance vector Y from pdist.

Z = linkage(Y, method)

Chooses how distances between clusters are computed.

Z = linkage(X, method, metric)

Takes the data matrix X and computes the distances with metric.

Description

At the start every observation is its own cluster. At each step linkage merges the two closest clusters, until one cluster remains. The method decides what close means between clusters: the nearest pair of points ('single'), the farthest pair ('complete'), the mean of all pairs ('average'), or the increase in within-cluster variance ('ward').

The 'centroid', 'median' and 'ward' methods are meant for Euclidean distances. Cut the tree with cluster or clusterdata, or check its quality with cophenet.

Input arguments

Y
Vector of pairwise distances in the order of pdist, with m*(m-1)/2 elements for m observations.
X
Data matrix, one observation per row. Used instead of Y when you pass a metric.
method
'single' (default), 'complete', 'average', 'weighted', 'centroid', 'median' or 'ward'.
metric
Distance name accepted by pdist, for example 'cityblock'. Default 'euclidean'.

Output arguments

Z
Matrix with m-1 rows and three columns. Each row is a merge: the numbers of the two clusters joined and the distance between them. Original observations are numbered 1 to m and each new cluster gets the next number.

Examples

Single linkage on data rows

X = [1 2; 1.3 1.8; 0.8 2.4; 5 5; 5.5 4.9; 4.6 5.3; 9 1; 9.2 1.5];
Z = linkage(X, 'single');
disp(round(Z*1000)/1000)
Output
    1.0000    2.0000    0.3610
    3.0000    9.0000    0.4470
    4.0000    6.0000    0.5000
    5.0000   11.0000    0.5100
    7.0000    8.0000    0.5390
   10.0000   12.0000    4.7800
   13.0000   14.0000    5.0250

Ward linkage heights from a distance vector

X = [1 2; 1.3 1.8; 0.8 2.4; 5 5; 5.5 4.9; 4.6 5.3; 9 1; 9.2 1.5];
Z = linkage(pdist(X), 'ward');
disp(round(Z(:,3)'*1000)/1000)
Output
    0.3610    0.5000    0.5390    0.7050    0.8580    8.6400   11.2630

Notes

When several pairs of clusters are at exactly the same distance, the order of the merges can differ from MATLAB for the complete, average, weighted and Ward methods: MatLivre scans the pairs in order, while MATLAB follows its own nearest-neighbor chain. On data without exact ties the result is the same.

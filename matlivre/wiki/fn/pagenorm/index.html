pagenorm

Norm of each page of a 3-D array.

Norma de cada página de um array 3-D.

Category:Categoria: Mathematics > Linear Algebra

Syntax

Sintaxe

n = pagenorm(A)

Returns the 2-norm of every page A(:,:,k).

Retorna a norma 2 de cada página A(:,:,k).

n = pagenorm(A, p)

Uses the norm type p: 1, 2, Inf or 'fro'.

Usa o tipo de norma p: 1, 2, Inf ou 'fro'.

Description

Descrição

pagenorm applies norm to each 2-D page without a loop, returning the results along the third dimension. Use squeeze to turn them into a vector.

pagenorm aplica norm a cada página 2-D sem laço, retornando os resultados ao longo da terceira dimensão. Use squeeze para transformá-los em vetor.

Input arguments

Argumentos de entrada

A
Array whose pages are matrices.
Array cujas páginas são matrizes.
p
Norm type, default 2.
Tipo de norma, padrão 2.

Output arguments

Argumentos de saída

n
Array of size 1-by-1-by-p, one norm per page.
Array de tamanho 1 por 1 por p, uma norma por página.

Example

Exemplo

Norms of two row-vector pages

Normas de duas páginas de vetor linha

A = cat(3, [3 4], [6 8]);
n = pagenorm(A);
squeeze(n)'
size(n)
OutputSaída
ans = 1×2

     5    10
ans = 1×3

     1     1     2

ddensd

Solves neutral delay differential equations with state-dependent delays.

Resolve equações diferenciais neutras com atraso dependente do estado.

Category:Categoria: Mathematics > Numerical Integration and Differential Equations

Syntax

Sintaxe

sol = ddensd(ddefun, dely, delyp, history, tspan)

Solves y'(t) = ddefun(t, y, ydel, ypdel), where ydel holds delayed values of y and ypdel delayed values of y'.

Resolve y'(t) = ddefun(t, y, ydel, ypdel), em que ydel contém valores atrasados de y e ypdel valores atrasados de y'.

sol = ddensd(ddefun, dely, delyp, history, tspan, options)

Also applies options from ddeset.

Aplica também opções de ddeset.

Description

Descrição

A neutral equation contains delayed derivatives, which makes it more delicate than an ordinary delay equation. Delays may depend on time and on the solution itself.

When the equation has no delayed derivative term, pass [] for delyp and ignore the fourth argument of ddefun; this reduces to the problem handled by ddesd.

Uma equação neutra contém derivadas atrasadas, o que a torna mais delicada que uma equação de atraso comum. Os atrasos podem depender do tempo e da própria solução.

Quando a equação não tem termo de derivada atrasada, passe [] em delyp e ignore o quarto argumento de ddefun; o problema se reduz ao tratado por ddesd.

Input arguments

Argumentos de entrada

ddefun
Handle dydt = ddefun(t, y, ydel, ypdel).
Handle dydt = ddefun(t, y, ydel, ypdel).
dely
Delay for y: a constant, or a function dely(t, y).
Atraso para y: uma constante, ou uma função dely(t, y).
delyp
Delay for y', or [] if the equation has no delayed derivative term.
Atraso para y', ou [] se a equação não tem termo de derivada atrasada.
history
Constant vector or function giving the solution before t0.
Vetor constante ou função que dá a solução antes de t0.
tspan
Interval [t0 tf].
Intervalo [t0 tf].

Output arguments

Argumentos de saída

sol
Solution structure with sol.x and sol.y, usable with deval.
Estrutura de solução com sol.x e sol.y, utilizável com deval.

Example

Exemplo

A plain delay problem

Um problema de atraso simples

sol = ddensd(@(t, y, ydel, ypdel) -ydel, 1, [], 1, [0 2]);
fprintf('%.4f\n', sol.y(end))
OutputSaída
-0.5000

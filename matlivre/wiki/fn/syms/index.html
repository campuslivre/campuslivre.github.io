syms

Creates symbolic variables and functions in the workspace.

Cria variáveis e funções simbólicas no workspace.

Category:Categoria: Symbolic Computations in MATLAB > Symbolic Variables, Expressions, Functions, and Preferences

Syntax

Sintaxe

syms x y z

Creates the symbolic variables x, y and z.

Cria as variáveis simbólicas x, y e z.

syms x y real

Creates variables with an assumption such as real, positive or integer.

Cria variáveis com uma suposição como real, positive ou integer.

syms f(x, y)

Creates a symbolic function with arguments x and y.

Cria uma função simbólica com argumentos x e y.

syms

With no arguments, lists the symbolic variables in the workspace.

Sem argumentos, lista as variáveis simbólicas do workspace.

Description

Descrição

syms x is a command-syntax shorthand for x = sym('x'): it puts a symbolic variable named x in the workspace so that expressions such as x^2 + 1 stay symbolic instead of being evaluated. Without an assumption, a variable is treated as an arbitrary complex number.

Assumptions let functions simplify more: for a variable declared real, conj(x) is just x. They are stored with the variable and queried with assumptions.

syms x é uma abreviação em sintaxe de comando para x = sym('x'): coloca no workspace uma variável simbólica chamada x, de modo que expressões como x^2 + 1 permaneçam simbólicas em vez de serem avaliadas. Sem suposição, uma variável é tratada como um número complexo qualquer.

Suposições permitem simplificar mais: para uma variável declarada real, conj(x) é simplesmente x. Ficam guardadas com a variável e são consultadas com assumptions.

Input arguments

Argumentos de entrada

x y z
Names of the variables to create, separated by spaces.
Nomes das variáveis a criar, separados por espaços.
assumption
Optional trailing word: real, positive, integer, rational, or clear to drop assumptions.
Palavra final opcional: real, positive, integer, rational, ou clear para remover suposições.

Example

Exemplo

Variables and a symbolic function

Variáveis e uma função simbólica

syms a b
expand((a + b)^2)
syms g(t)
g(t) = t^2;
g(3)
OutputSaída
ans = a^2 + 2*a*b + b^2
ans = 9

Notes

Observações

In MatLivre only the real assumption is recorded; positive and integer are accepted, but assumptions reports real and simplify does not use the extra information.

No MatLivre apenas a suposição real é registrada; positive e integer são aceitas, mas assumptions informa real e simplify não usa a informação extra.

chi2gof next release

Chi-square goodness-of-fit test: compares the counts of a sample in bins with the counts expected from a distribution, normal by default.

Category: Probability Distributions and Hypothesis Tests > Univariate Continuous Distributions

Syntax

h = chi2gof(x)

Tests whether x follows a normal distribution whose mean and standard deviation are estimated from x.

[h, p, stats] = chi2gof(x, 'nbins', n)

Uses n bins and also returns the p-value and a structure with the details.

[h, p, stats] = chi2gof(x, 'cdf', f, 'nparams', k)

Tests against the distribution with cumulative function f, where k parameters were estimated from the data.

[h, p, stats] = chi2gof(x, 'edges', e, 'expected', ex)

Uses your own bin edges and expected counts.

Description

The test splits the data into bins, counts how many observations fall in each and compares those counts with the counts the hypothesized distribution would give. A large chi-square statistic, and so a small p-value, means the data do not fit.

Bins with a small expected count make the test unreliable, so neighbors are merged until each expected count reaches 'emin'. The degrees of freedom are the number of bins minus 1 minus 'nparams'; if too few bins remain, the test cannot be done and p is NaN.

Input arguments

x
Sample, a numeric vector.
'nbins'
Number of bins. Chosen automatically when omitted. Give only one of 'nbins', 'ctrs' and 'edges'.
'ctrs'
Bin centers.
'edges'
Bin edges, in increasing order.
'cdf'
Hypothesized cumulative distribution: a function handle, or a cell array such as {@normcdf, 4.5, 3.5} with the function followed by its parameters.
'expected'
Expected counts per bin, as an alternative to 'cdf'.
'nparams'
Number of distribution parameters estimated from the data. It lowers the degrees of freedom. Needed with a function handle in 'cdf'.
'emin'
Minimum expected count per bin. Bins below it are merged with neighbors. Default 5; use 0 to disable merging.
'alpha'
Significance level. Default 0.05.

Output arguments

h
1 when the null hypothesis that the data follow the distribution is rejected, 0 otherwise. It is 0 with p = NaN when there are no degrees of freedom left.
p
p-value of the test.
stats
Structure with chi2stat (the statistic), df (degrees of freedom), edges, O (observed counts) and E (expected counts).

Examples

Normal fit with estimated parameters

z = 4.5 + 3.5*norminv(((1:80) - 0.5)/80);
[h, p, st] = chi2gof(z);
fprintf('h = %d, p = %.4f, df = %d\n', h, p, st.df);
disp(st.O)
disp(round(st.E*100)/100)
Output
h = 0, p = 0.9994, df = 5
     5     8    12    15    15    12     8     5
    5.3300    7.3400   11.9900   15.3300   15.3300   11.9900    7.3400    5.3300

Known distribution and chosen bin edges

z = 4.5 + 3.5*norminv(((1:80) - 0.5)/80);
f = @(t) normcdf(t, 4.5, 3.5);
[h, p, st] = chi2gof(z, 'edges', [-20 0 3 6 9 30], 'cdf', f, 'nparams', 0);
fprintf('h = %d, p = %.4f, df = %d\n', h, p, st.df);
disp(st.O)
Output
h = 0, p = 1.0000, df = 4
     8    19    26    19     8

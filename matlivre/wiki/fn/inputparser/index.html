inputParser

Parses and validates the arguments of a function.

Analisa e valida os argumentos de uma função.

Category:Categoria: Programming > Functions

Syntax

Sintaxe

p = inputParser

Creates an empty parser object.

Cria um objeto analisador vazio.

parse(p, args...)

Matches args against the declared arguments and fills p.Results.

Associa args aos argumentos declarados e preenche p.Results.

p.Results, p.UsingDefaults, p.Unmatched

Read the parsed values, the names left at their defaults, and the unrecognized pairs.

Leem os valores analisados, os nomes que ficaram no padrão e os pares não reconhecidos.

Description

Descrição

An inputParser is a handle object. You declare the arguments with addRequired, addOptional and addParameter, then call parse(p, varargin{:}) inside your function. Required arguments are positional and must come first, optional ones follow, and name-value pairs come last.

A failed validation raises an error that names the argument and the validation function. p.Results lists fields in alphabetical order, p.UsingDefaults names the arguments that were not supplied, and p.Unmatched holds the unrecognized pairs when KeepUnmatched is on.

Um inputParser é um objeto handle. Você declara os argumentos com addRequired, addOptional e addParameter e então chama parse(p, varargin{:}) dentro da função. Os argumentos obrigatórios são posicionais e vêm primeiro, os opcionais vêm depois, e os pares nome-valor por último.

Uma validação que falha gera um erro que cita o argumento e a função de validação. p.Results lista os campos em ordem alfabética, p.UsingDefaults nomeia os argumentos não fornecidos, e p.Unmatched guarda os pares não reconhecidos quando KeepUnmatched está ligado.

Input arguments

Argumentos de entrada

FunctionName
Property: name shown in error messages.
Propriedade: nome mostrado nas mensagens de erro.
CaseSensitive
Property: match parameter names with case (default false).
Propriedade: diferencia maiúsculas nos nomes de parâmetros (padrão false).
KeepUnmatched
Property: when true, unknown name-value pairs go to Unmatched instead of causing an error (default false).
Propriedade: quando true, pares nome-valor desconhecidos vão para Unmatched em vez de causar erro (padrão false).
PartialMatching
Property: accept unique abbreviations of parameter names (default true).
Propriedade: aceita abreviações únicas dos nomes de parâmetros (padrão true).
StructExpand
Property: accept a struct in place of name-value pairs (default true).
Propriedade: aceita uma struct no lugar de pares nome-valor (padrão true).

Output arguments

Argumentos de saída

p
The parser object. After parse, p.Results is a struct with one field per declared argument.
O objeto analisador. Depois de parse, p.Results é uma struct com um campo por argumento declarado.

Example

Exemplo

Required, optional and name-value arguments

Argumentos obrigatórios, opcionais e nome-valor

p = inputParser;
p.FunctionName = 'demo';
addRequired(p, 'n', @isnumeric);
addOptional(p, 'mode', 'fast', @ischar);
addParameter(p, 'Tol', 1e-3, @(x) x > 0);
parse(p, 4, 'slow', 'Tol', 0.1);
r = p.Results
p.UsingDefaults
try
    parse(p, 4, 'fast', 'Tol', -1);
catch err
    disp(err.message)
end
OutputSaída
r = struct with fields:

     Tol: 0.1000
    mode: 'slow'
       n: 4
ans =

  0×0 empty cell array
The value of 'Tol' is invalid. It must satisfy the function: @(x)x>0.

Notes

Observações

MatLivre does not provide addSwitch.

O MatLivre não oferece addSwitch.

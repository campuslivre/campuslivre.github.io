remove

Deletes an entry from a dictionary or a containers.Map by key.

Apaga uma entrada de um dictionary ou de um containers.Map pela chave.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

D = remove(D, key)

Returns the dictionary D without the entry for key.

Retorna o dictionary D sem a entrada de key.

remove(M, key)

Deletes key from the containers.Map M, in place.

Apaga key do containers.Map M, no próprio objeto.

Description

Descrição

A dictionary behaves like an ordinary value, so remove returns a new dictionary and the original is unchanged until you assign the result. A containers.Map is a handle object: remove changes the map itself.

Asking to remove a key that does not exist is an error for both types; test with isKey first if the key may be missing.

Um dictionary se comporta como um valor comum, então remove retorna um novo dictionary e o original não muda até você atribuir o resultado. Um containers.Map é um objeto handle: remove altera o próprio mapa.

Pedir para remover uma chave que não existe é erro nos dois tipos; teste com isKey antes se a chave puder faltar.

Input arguments

Argumentos de entrada

D / M
A dictionary or a containers.Map object.
Um objeto dictionary ou containers.Map.
key
A key, or an array of keys, to delete.
Uma chave, ou um array de chaves, a apagar.

Output arguments

Argumentos de saída

D
The updated dictionary. Dictionaries are values, so the result must be assigned.
O dictionary atualizado. Dictionaries são valores, então o resultado precisa ser atribuído.

Example

Exemplo

d = dictionary(["a" "b"], [1 2]);
d = remove(d, "a")
m = containers.Map({'a','b'}, [1 2]);
remove(m, 'a');
m.keys
OutputSaída
d = 
  dictionary (string --> double) with 1 entry:

    "b" --> 2
ans = 1×1 cell

    {'b'}

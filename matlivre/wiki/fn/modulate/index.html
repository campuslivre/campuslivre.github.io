modulate

Modulates a message signal onto a carrier using amplitude, frequency, phase or quadrature schemes.

Category: Modulation and framing

Syntax

y = modulate(x, fc, fs)

Amplitude modulation: x multiplied by a cosine carrier of frequency fc.

y = modulate(x, fc, fs, method)

Chooses the scheme: 'am', 'amdsb-sc', 'amdsb-tc', 'amssb', 'fm', 'pm', 'pwm', 'ppm' or 'qam'.

y = modulate(x, fc, fs, method, opt)

Adds the method parameter, such as the deviation constant for 'fm' and 'pm'.

[y, t] = modulate(___)

Also returns the time vector.

Description

The time axis is (0:N-1)/fs, with N the length of the message. Choose fc well above the highest frequency in x so the sidebands do not overlap.

Use demod to recover the message. For 'fm' and 'pm', pass the same opt to both functions.

Input arguments

x
Message signal, a vector or a matrix whose columns are channels.
fc
Carrier frequency in hertz, less than fs/2.
fs
Sampling rate in hertz.
method
Modulation scheme. Default 'am', which is the same as 'amdsb-sc'.
opt
Method parameter (for 'qam', the second message signal).

Output arguments

y
Modulated signal, same size as x.
t
Time instants of the samples, in seconds, starting at 0.

Example

AM and FM of a 10 Hz tone

fs = 1000; t = (0:9)'/fs;
x = sin(2*pi*10*t);
[y, tt] = modulate(x, 100, fs);
disp(round(y'*1000)/1000)
disp(tt(1:3)')
y = modulate(x, 100, fs, 'fm');
disp(round(y'*1000)/1000)
Output
         0    0.0510    0.0390   -0.0580   -0.2010   -0.3090   -0.2980   -0.1320    0.1490    0.4330
         0    0.0010    0.0020
    1.0000    0.7640    0.0930   -0.6850   -0.9950   -0.4590    0.5510    0.9900    0.2350   -0.8520

Notes

Complex input is not implemented. In single precision the results agree with MATLAB only to about 1e-7.

kaiserord

Estimates the order and Kaiser-window parameter needed for an FIR filter that meets given band edges and ripples.

Category: FIR design

Syntax

[n,Wn,beta,ftype] = kaiserord(f,a,dev)

Estimates the parameters for normalized frequencies.

[n,Wn,beta,ftype] = kaiserord(f,a,dev,fs)

Takes the frequencies in hertz for sampling rate fs.

Description

kaiserord gives the inputs for a window-method design with fir1: the order, the cutoffs, the window parameter and the filter type. The order is an estimate, so check the response of the result and raise n a little if the tolerance is missed.

The same deviation must hold in all bands, so the smallest value in dev is used for the whole design.

Input arguments

f
Band edges: the adjacent edges of each pair of neighbouring bands, without 0 and the Nyquist frequency.
a
Desired amplitude in each band (for example [1 0] for a lowpass).
dev
Largest allowed deviation in each band, as a linear value. The smallest one sets the design.
fs
Sampling rate. Default 2, so that f is normalized.

Output arguments

n
Estimated filter order.
Wn
Cutoff frequency or frequencies, normalized, to pass to fir1.
beta
Shape parameter of the Kaiser window (kaiser(n+1,beta)).
ftype
Filter type as text (such as 'low'), to pass to fir1.

Example

Lowpass for 8 kHz sampling

[n,Wn,beta,ftype] = kaiserord([1500 1600],[1 0],[0.01 0.01],8000);
fprintf('order %d, Wn %.4f, beta %.4f, type %s\n', n, Wn, beta, ftype);
b = fir1(n,Wn,ftype,kaiser(n+1,beta),'noscale');
fprintf('%d coefficients\n', numel(b));
Output
order 179, Wn 0.3875, beta 3.3953, type low
180 coefficients

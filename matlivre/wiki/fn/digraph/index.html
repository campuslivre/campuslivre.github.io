digraph

Creates a directed graph from edges or an adjacency matrix.

Cria um grafo dirigido a partir de arestas ou de uma matriz de adjacência.

Category:Categoria: Mathematics > Graph and Network Algorithms

Syntax

Sintaxe

D = digraph(s, t)

Edge k goes from node s(k) to node t(k).

A aresta k vai do nó s(k) ao nó t(k).

D = digraph(s, t, w)

Also gives the edges weights w.

Também dá às arestas os pesos w.

D = digraph(s, t, w, names)

Names the nodes.

Dá nomes aos nós.

D = digraph(A)

Builds the digraph from a square adjacency matrix; nonzero entries are edges and their values are weights.

Constrói o dígrafo a partir de uma matriz de adjacência quadrada; entradas diferentes de zero são arestas e seus valores são pesos.

Description

Descrição

Unlike graph, each edge has a direction, and s -> t and t -> s are different edges that can coexist. D.Edges is a table whose first column EndNodes holds the pairs and which gains a Weight column when weights are given. D.Nodes holds node properties such as Name.

Directed graphs model one-way relations: dependencies, flows, links. Functions such as successors, predecessors, indegree, isdag and conncomp(..., 'Type', 'strong') only make sense with directions.

Diferente de graph, cada aresta tem um sentido, e s -> t e t -> s são arestas diferentes que podem coexistir. D.Edges é uma tabela cuja primeira coluna EndNodes guarda os pares e que ganha uma coluna Weight quando há pesos. D.Nodes guarda propriedades dos nós, como Name.

Grafos dirigidos modelam relações de mão única: dependências, fluxos, links. Funções como successors, predecessors, indegree, isdag e conncomp(..., 'Type', 'strong') só fazem sentido com direções.

Input arguments

Argumentos de entrada

s, t
Source and target nodes: positive integers, or node names given as cell arrays of text.
Nós de origem e destino: inteiros positivos, ou nomes de nós dados como cell arrays de texto.
w
Numeric weights, one per edge.
Pesos numéricos, um por aresta.
A
Square matrix. A(i,j) ~= 0 makes an edge from i to j.
Matriz quadrada. A(i,j) ~= 0 cria uma aresta de i para j.

Output arguments

Argumentos de saída

D
A digraph object with the properties Edges and Nodes, both tables.
Um objeto digraph com as propriedades Edges e Nodes, ambas tabelas.

Example

Exemplo

From edge lists and from a matrix

De listas de arestas e de uma matriz

D = digraph([1 2], [2 3], [5 6]);
disp(D.Edges)
E = digraph([0 1 0; 0 0 1; 1 0 0]);
disp(E.Edges)
OutputSaída
    EndNodes    Weight
    ________    ______

     1    2       5   
     2    3       6   
    EndNodes    Weight
    ________    ______

     1    2       1   
     2    3       1   
     3    1       1

Notes

Observações

Building a graph from an edge table, as in digraph(EdgeTable), is not supported in MatLivre; use the s, t, w or matrix forms.

Construir o grafo a partir de uma tabela de arestas, como em digraph(EdgeTable), não é suportado no MatLivre; use as formas s, t, w ou com matriz.

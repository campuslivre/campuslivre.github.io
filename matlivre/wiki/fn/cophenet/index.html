cophenet next release

Measures how faithfully a hierarchical cluster tree preserves the original pairwise distances, using the cophenetic correlation coefficient.

Category: Cluster Analysis and Anomaly Detection > Hierarchical Clustering

Syntax

c = cophenet(Z, Y)

Correlation between the tree heights and the distances in Y.

[c, d] = cophenet(Z, Y)

Also returns the cophenetic distances.

Description

The cophenetic distance between two observations is the height of the link where they first fall in the same cluster. cophenet correlates these heights with the true distances. A high value suggests the tree is a good summary of the data, and you can use it to compare linkage methods on the same distances.

Input arguments

Z
Linkage matrix from linkage, with m-1 rows for m observations.
Y
Original distances as a vector in the order of pdist, with m*(m-1)/2 elements.

Output arguments

c
Cophenetic correlation coefficient. Values close to 1 mean the tree reflects the distances well.
d
Cophenetic distances as a vector in the same order as Y. Each one is the height at which two observations first join.

Examples

Cophenetic correlation of average linkage

X = [1 2; 1.3 1.8; 0.8 2.4; 5 5; 5.5 4.9; 4.6 5.3; 9 1; 9.2 1.5];
D = pdist(X);
Z = linkage(D, 'average');
c = cophenet(Z, D);
fprintf('%.4f\n', c)
Output
0.9448

Cophenetic distances of single linkage

X = [1 2; 1.3 1.8; 0.8 2.4; 5 5; 5.5 4.9; 4.6 5.3; 9 1; 9.2 1.5];
D = pdist(X);
Z = linkage(D, 'single');
[c, d] = cophenet(Z, D);
fprintf('%.4f\n', c)
disp(size(d))
disp(round(d(1:4)*1000)/1000)
Output
0.9117
     1    28
    0.3610    0.4470    4.7800    4.7800

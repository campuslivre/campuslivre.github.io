rref

Reduced row echelon form of a matrix, by Gauss-Jordan elimination.

Forma escalonada reduzida por linhas de uma matriz, por eliminação de Gauss-Jordan.

Category:Categoria: Mathematics > Linear Algebra

Syntax

Sintaxe

R = rref(A)

Returns the reduced row echelon form.

Retorna a forma escalonada reduzida por linhas.

[R, p] = rref(A)

Also returns the pivot column indices.

Retorna também os índices das colunas de pivô.

[R, p] = rref(A, tol)

Uses tol to decide when an entry is treated as zero.

Usa tol para decidir quando uma entrada é tratada como zero.

Description

Descrição

Elimination with partial pivoting brings the matrix to a form in which each pivot is 1 and is the only nonzero entry of its column. Applied to an augmented matrix [A b] it solves a linear system and shows whether it has no solution, one, or infinitely many.

Because it relies on a tolerance to detect zeros, rref is a teaching tool rather than a robust numerical method for large or ill-conditioned matrices.

A eliminação com pivotamento parcial leva a matriz a uma forma em que cada pivô vale 1 e é a única entrada não nula de sua coluna. Aplicada à matriz aumentada [A b], resolve um sistema linear e mostra se ele não tem solução, tem uma ou infinitas.

Por depender de uma tolerância para detectar zeros, rref é uma ferramenta didática, não um método numérico robusto para matrizes grandes ou mal condicionadas.

Input arguments

Argumentos de entrada

A
Numeric matrix.
Matriz numérica.
tol
Pivot tolerance. The default is eps * max(size(A)) * norm(A, inf).
Tolerância de pivô. O padrão é eps * max(size(A)) * norm(A, inf).

Output arguments

Argumentos de saída

R
Matrix of the same size as A with leading ones in the pivot columns and zeros elsewhere in those columns.
Matriz do mesmo tamanho de A, com uns de liderança nas colunas de pivô e zeros no resto dessas colunas.
p
Row vector of the pivot columns; numel(p) is the rank.
Vetor linha das colunas de pivô; numel(p) é o posto.

Example

Exemplo

Solving a system

Resolvendo um sistema

Ab = [1 1 3; 1 -1 1];
[R, p] = rref(Ab)
OutputSaída
R = 2×3

     1     0     2
     0     1     1
p = 1×2

     1     2

sym

Creates symbolic variables, numbers and arrays.

Cria variáveis, números e arrays simbólicos.

Category:Categoria: Symbolic Computations in MATLAB > Symbolic Variables, Expressions, Functions, and Preferences

Syntax

Sintaxe

x = sym('x')

Creates the symbolic variable x.

Cria a variável simbólica x.

n = sym(num)

Converts a number to an exact symbolic value; sym(1/3) gives 1/3.

Converte um número em um valor simbólico exato; sym(1/3) dá 1/3.

n = sym(num, flag)

Chooses how a floating-point value is converted: 'r' rational (default), 'd' decimal, 'e' estimate with error, 'f' exact binary fraction.

Escolhe como um valor de ponto flutuante é convertido: 'r' racional (padrão), 'd' decimal, 'e' estimativa com erro, 'f' fração binária exata.

A = sym('A', [m n])

Creates an m-by-n matrix of variables A1_1, A1_2, ...

Cria uma matriz m por n de variáveis A1_1, A1_2, ...

Description

Descrição

sym is the entry point to the Symbolic Math Toolbox. A string argument creates a variable with that name; a numeric argument is turned into an exact value that arithmetic will keep exact. Floating-point conversion uses the nearest simple rational by default, so sym(0.1) is 1/10 and sym(pi) stays the symbol pi.

To create several variables at once, syms x y z is shorter. Mixing a sym with a double in an expression converts the double with sym first, so sym(1)/3 is the exact 1/3 while 1/3 alone is a rounded double.

sym é a porta de entrada do Symbolic Math Toolbox. Um argumento string cria uma variável com esse nome; um argumento numérico vira um valor exato que a aritmética manterá exato. A conversão de ponto flutuante usa por padrão o racional simples mais próximo, então sym(0.1) é 1/10 e sym(pi) continua sendo o símbolo pi.

Para criar várias variáveis de uma vez, syms x y z é mais curto. Misturar um sym com um double em uma expressão converte o double com sym antes, então sym(1)/3 é o 1/3 exato, enquanto 1/3 sozinho é um double arredondado.

Input arguments

Argumentos de entrada

x
Name of the variable, a valid identifier.
Nome da variável, um identificador válido.
num
Numeric array to convert exactly.
Array numérico a converter de forma exata.
[m n]
Size of the symbolic matrix to generate.
Tamanho da matriz simbólica a gerar.

Output arguments

Argumentos de saída

S
Symbolic variable, number or array.
Variável, número ou array simbólico.

Example

Exemplo

Variables, exact numbers and matrices

Variáveis, números exatos e matrizes

x = sym('x');
x^2 + 1
sym(1)/3
sym(0.1)
A = sym('A', [2 2])
OutputSaída
ans = x^2 + 1
ans = 1/3
ans = 1/10
A = 
[A1_1, A1_2]
[A2_1, A2_2]

Notes

Observações

In MatLivre the flags 'f' and 'e' give the same rational result as 'r', so sym(0.1, 'f') is 1/10 and not the exact binary fraction. The pattern form sym('a%d', [1 3]) is not expanded. Positivity and similar assumptions given as sym('y', 'positive') are not tracked, and assumptions reports only real.

No MatLivre os flags 'f' e 'e' dão o mesmo resultado racional que 'r', então sym(0.1, 'f') é 1/10 e não a fração binária exata. A forma com padrão sym('a%d', [1 3]) não é expandida. Suposições como positividade, dadas em sym('y', 'positive'), não são rastreadas, e assumptions informa apenas real.

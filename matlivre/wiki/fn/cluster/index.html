cluster next release

Cuts a hierarchical cluster tree made by linkage into clusters, by a number of clusters or by a distance or inconsistency cutoff.

Category: Cluster Analysis and Anomaly Detection > Hierarchical Clustering

Syntax

T = cluster(Z, 'maxclust', k)

Cuts the tree into at most k clusters.

T = cluster(Z, 'cutoff', c)

Cuts where the inconsistency coefficient exceeds c.

T = cluster(Z, 'cutoff', c, 'Criterion', 'distance')

Cuts where the link distance exceeds c.

T = cluster(Z, 'cutoff', c, 'Depth', d)

Sets the number of levels used for the inconsistency coefficient.

Description

linkage builds the full tree; cluster decides where to cut it. With 'maxclust' the cut is placed so that there are k clusters, which is the usual choice when you know how many you want. With 'cutoff' and 'Criterion' set to 'distance', observations that merge below the distance c stay together.

The default criterion, 'inconsistent', compares each link with the links below it. A cutoff on the wrong scale (for example a distance value used with the inconsistency criterion) can put all observations in a single cluster, so check the number of clusters you get.

Input arguments

Z
(m-1)-by-3 cluster tree from linkage, for m observations.
'maxclust'
Maximum number of clusters: a positive integer, or a vector of them.
'cutoff'
Cutoff value, a positive number or a vector of them. Needed when 'maxclust' is not given.
'Criterion'
'inconsistent' (default) or 'distance'. Applies to 'cutoff'.
'Depth'
Number of tree levels for the inconsistency coefficient. Default 2.

Output arguments

T
m-by-1 cluster number of each observation. With a vector of cutoffs or of 'maxclust' values it has one column per value.

Examples

Cut into three clusters

X = [1 1; 1.5 2; 2 1.2; 1.2 1.8; 5 5; 5.5 4.6; 4.8 5.4; 5.2 5.1; 9 1; 9.5 1.4];
Z = linkage(X, 'average');
T = cluster(Z, 'maxclust', 3);
disp(T')
Output
     2     2     2     2     1     1     1     1     3     3

Cut at a distance

X = [1 1; 1.5 2; 2 1.2; 1.2 1.8; 5 5; 5.5 4.6; 4.8 5.4; 5.2 5.1; 9 1; 9.5 1.4];
Z = linkage(X, 'average');
T = cluster(Z, 'cutoff', 3, 'Criterion', 'distance');
disp(T')
disp(max(T))
Output
     3     3     3     3     1     1     1     1     2     2
     3

wvd

Computes the Wigner-Ville distribution of a signal, a time-frequency map with high resolution that is not limited by a window.

Category: Time-frequency analysis

Syntax

[d, f, t] = wvd(x)

Distribution with normalized frequencies and times in samples.

[d, f, t] = wvd(x, fs)

Uses the sample rate fs (hertz) for f and t.

[d, f, t] = wvd(___, 'MinThreshold', thr)

Sets distribution values below thr to zero.

Description

The Wigner-Ville distribution multiplies the signal by a reversed, shifted copy of itself and takes a Fourier transform over the lag. It needs no window, so a single chirp appears as a thin line. The price is cross terms: when the signal has more than one component, extra oscillating terms show up between them.

Use it to see the instantaneous frequency of a single, well-behaved component. For signals with several components, a spectrogram or tfridge on a smoothed map is usually easier to read.

Input arguments

x
Signal, a real or complex vector. A real signal is converted to its analytic version first.
fs
Sample rate in hertz.
'MinThreshold'
Threshold in the units of the distribution; values below it are set to zero.

Output arguments

d
Distribution: one row per frequency and two columns per input sample (the time axis is sampled at half-sample steps). The values can be negative.
f
Frequencies of the rows. From 0 to fs/2 for real x with fs; from 0 to 1 without fs.
t
Times of the columns, in seconds with fs, in samples otherwise.

Example

Follow a linear chirp

fs = 100; n = (0:31)';
y = exp(1j*2*pi*(5*n/fs + 20*(n/fs).^2));
[d, f, t] = wvd(y, fs);
disp(size(d))
for c = [8 32 56]
  [~, i] = max(d(:, c));
  fprintf('t = %.3f s: %.0f Hz (expected %.0f)\n', t(c), f(i), 5 + 40*t(c));
end
Output
    32    64
t = 0.035 s: 6 Hz (expected 6)
t = 0.155 s: 11 Hz (expected 11)
t = 0.275 s: 16 Hz (expected 16)

Notes

The 'smoothedPseudo' form is not implemented and raises an error. Single-precision input is computed in double precision, so values differ from MATLAB at about 1e-7.

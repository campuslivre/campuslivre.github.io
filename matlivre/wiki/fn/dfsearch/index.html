dfsearch

Depth-first search: nodes in the order a depth-first traversal discovers them.

Busca em profundidade: nós na ordem em que um percurso em profundidade os descobre.

Category:Categoria: Mathematics > Graph and Network Algorithms

Syntax

Sintaxe

v = dfsearch(G, s)

Returns the nodes reachable from s in depth-first order.

Retorna os nós alcançáveis a partir de s em ordem de profundidade.

E = dfsearch(G, s, 'edgetonew')

Returns the edges that lead to newly discovered nodes.

Retorna as arestas que levam a nós recém-descobertos.

Description

Descrição

The search follows one path as far as it goes, then backs up to the most recent node that still has an unvisited neighbor and continues from there. Neighbors are tried in index order. Only nodes reachable from s are returned.

Depth-first search underlies topological sorting, cycle detection and the computation of strongly connected components.

A busca segue um caminho até onde ele vai e depois volta ao nó mais recente que ainda tem um vizinho não visitado, continuando dali. Os vizinhos são tentados em ordem de índice. Apenas nós alcançáveis a partir de s são retornados.

A busca em profundidade está na base da ordenação topológica, da detecção de ciclos e do cálculo de componentes fortemente conexos.

Input arguments

Argumentos de entrada

G
A graph or digraph.
Um graph ou digraph.
s
Start node, as index or name.
Nó inicial, como índice ou nome.
events
Event name that selects what is reported, such as 'edgetonew'.
Nome de evento que escolhe o que é informado, como 'edgetonew'.

Output arguments

Argumentos de saída

v
Column vector of node indices, starting with s.
Vetor coluna de índices de nós, começando por s.
E
Two-column matrix for the 'edgetonew' form.
Matriz de duas colunas na forma 'edgetonew'.

Example

Exemplo

Depth-first order

Ordem em profundidade

D = digraph([1 1 2 3 4], [2 3 4 4 5]);
dfsearch(D, 1)'
dfsearch(D, 1, 'edgetonew')
OutputSaída
ans = 1×5

     1     2     4     5     3
ans = 4×2

     1     2
     2     4
     4     5
     1     3

Notes

Observações

MatLivre returns plain node lists for event names such as 'allevents' instead of the event table that MATLAB builds. Use the default and 'edgetonew' forms for portable code.

O MatLivre retorna listas simples de nós para nomes de evento como 'allevents', em vez da tabela de eventos que o MATLAB monta. Use a forma padrão e 'edgetonew' para código portável.

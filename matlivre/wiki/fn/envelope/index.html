envelope

Returns the upper and lower envelopes of a signal, from its analytic signal or from rms or peak smoothing.

Category: Descriptive statistics

Syntax

[up, lo] = envelope(x)

Analytic envelope: upper and lower curves that follow the signal amplitude.

[up, lo] = envelope(x, n, 'rms')

Envelope from a moving rms of length n.

[up, lo] = envelope(x, n, 'peak')

Envelope that joins the local peaks, with peaks at least n samples apart.

Description

With no extra arguments the envelope is the magnitude of the analytic signal built with the Hilbert transform, added to and subtracted from the mean of the signal. It works well for a narrowband signal such as an amplitude-modulated tone.

The 'rms' option follows the local energy, and 'peak' interpolates through the local maxima and minima. Use 'peak' when the signal is not narrowband.

Input arguments

x
Real vector or matrix. Each column of a matrix is a channel.
n
Positive integer. Window length for 'rms', or minimum peak separation in samples for 'peak'.

Output arguments

up
Upper envelope, same size as x.
lo
Lower envelope, same size as x.

Example

Envelope of an amplitude-modulated tone

n = (0:31)';
x = (1 + 0.5*cos(2*pi*n/32)) .* cos(2*pi*n*0.25);
[up, lo] = envelope(x);
disp(round(up(1:6)' * 100) / 100)
disp(round(lo(1:6)' * 100) / 100)
Output
    1.5000    1.4900    1.4600    1.4200    1.3500    1.2800
   -1.5000   -1.4900   -1.4600   -1.4200   -1.3500   -1.2800

Notes

The form with an n-tap Hilbert filter, envelope(x, n, 'analytic'), is not implemented and gives an error. The default analytic form uses the FFT-based Hilbert transform.

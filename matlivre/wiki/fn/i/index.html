i

Imaginary unit, the square root of -1.

Unidade imaginária, a raiz quadrada de -1.

Category:Categoria: Mathematics > Elementary Math

Syntax

Sintaxe

z = i

The imaginary unit, the complex number 0 + 1i.

A unidade imaginária, o número complexo 0 + 1i.

z = a + b*i

Builds a complex number from its real part a and imaginary part b.

Constrói um número complexo a partir da parte real a e da imaginária b.

Description

Descrição

i is a built-in function that returns the imaginary unit. Because it is only a name, assigning to a variable called i (a very common loop index) hides it, and 2 + 3*i then uses the variable instead. The imaginary literals 1i, 3j and 2.5i are immune to this: a number followed directly by i or j is always imaginary, so they are the safer way to write complex constants.

j is an equivalent alias, popular in engineering.

i é uma função interna que retorna a unidade imaginária. Como é apenas um nome, atribuir a uma variável chamada i (um índice de laço muito comum) a oculta, e 2 + 3*i passa a usar a variável. Os literais imaginários 1i, 3j e 2.5i são imunes a isso: um número seguido diretamente de i ou j é sempre imaginário, sendo a forma mais segura de escrever constantes complexas.

j é um sinônimo equivalente, popular na engenharia.

Output arguments

Argumentos de saída

z
Complex scalar of class double.
Escalar complexo da classe double.

Exemplo

vecnorm

Vector norm of each column or row of a matrix.

Norma vetorial de cada coluna ou linha de uma matriz.

Category:Categoria: Mathematics > Linear Algebra

Syntax

Sintaxe

N = vecnorm(A)

Returns the 2-norm of each column of A.

Retorna a norma 2 de cada coluna de A.

N = vecnorm(A, p)

Uses the p-norm.

Usa a norma p.

N = vecnorm(A, p, dim)

Takes the norm along dimension dim; dim = 2 works on rows.

Calcula a norma ao longo da dimensão dim; dim = 2 opera nas linhas.

Description

Descrição

Unlike norm, which treats a matrix as an operator, vecnorm treats every column (or row) as a separate vector and returns all the lengths at once. It replaces the common idiom sqrt(sum(abs(A).^2)).

With p = Inf it returns the largest absolute value, and with p = 1 the sum of absolute values.

Ao contrário de norm, que trata a matriz como um operador, vecnorm trata cada coluna (ou linha) como um vetor separado e devolve todos os comprimentos de uma vez. Substitui o idioma comum sqrt(sum(abs(A).^2)).

Com p = Inf retorna o maior valor absoluto, e com p = 1 a soma dos valores absolutos.

Input arguments

Argumentos de entrada

A
Numeric array.
Array numérico.
p
Positive real scalar or Inf. Default 2.
Escalar real positivo ou Inf. Padrão 2.
dim
Dimension along which to operate. Default: the first non-singleton dimension.
Dimensão em que operar. Padrão: a primeira dimensão não singleton.

Output arguments

Argumentos de saída

N
Array of norms; the operated dimension has size 1.
Array de normas; a dimensão operada tem tamanho 1.

Example

Exemplo

Columns and rows

Colunas e linhas

A = [3 4; 6 8];
vecnorm(A)
vecnorm(A, 1, 2)
vecnorm(A, Inf, 2)

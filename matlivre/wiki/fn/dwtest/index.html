dwtest next release

Durbin-Watson test for first-order autocorrelation in the residuals of a linear regression.

Category: Probability Distributions and Hypothesis Tests > Hypothesis Tests

Syntax

p = dwtest(r, X)

Returns the p-value for the residual vector r of a regression with design matrix X.

[p, dw] = dwtest(r, X)

Also returns the Durbin-Watson statistic.

[p, dw] = dwtest(r, X, method)

Chooses 'exact' or 'approximate' for the p-value.

[p, dw] = dwtest(r, X, 'Method', method, 'Tail', tail)

Sets the method and the alternative hypothesis with name-value pairs.

Description

Ordinary least squares assumes the errors are not correlated with each other. The Durbin-Watson statistic compares each residual with the previous one, so it is only meaningful when the observations are in a natural order such as time.

Pass the residuals and the same design matrix used in the fit, because the null distribution of the statistic depends on X.

Input arguments

r
Residuals of the regression, a vector with one value per observation, in time order.
X
Design matrix of the regression, with one row per observation. Include a column of ones if the model has an intercept.
'Method'
'exact' or 'approximate'. The default is 'exact' for fewer than 400 observations and 'approximate' otherwise.
'Tail'
Alternative hypothesis: 'both' (default), 'right' for positive autocorrelation or 'left' for negative autocorrelation.

Output arguments

p
p-value of the test.
dw
Durbin-Watson statistic, between 0 and 4. Values near 2 mean no first-order autocorrelation, values near 0 mean positive autocorrelation and values near 4 mean negative autocorrelation.

Examples

Residuals with a leftover trend

t = (1:20)';
y = 2 + 0.5*t + sin(0.7*t);
X = [ones(20,1) t];
r = y - X*(X\y);
[p, dw] = dwtest(r, X);
fprintf('dw = %.4f, p = %.2g\n', dw, p);
Output
dw = 0.4292, p = 1.1e-06

Residuals that alternate in sign

t = (1:20)';
e = [0.3 -0.2 0.4 -0.5 0.1 -0.3 0.5 -0.1 0.2 -0.4 0.3 -0.2 0.4 -0.3 0.1 -0.5 0.2 0.3 -0.2 0.1]';
X = [ones(20,1) t];
y = 2 + 0.5*t + e;
r = y - X*(X\y);
[p, dw] = dwtest(r, X, 'approximate');
fprintf('dw = %.4f, p = %.4f\n', dw, p);
Output
dw = 3.3102, p = 0.0043

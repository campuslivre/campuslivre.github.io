hmmdecode next release

Computes the posterior probability of each hidden state at every step of an observed sequence, given a hidden Markov model.

Category: Cluster Analysis and Anomaly Detection > Hidden Markov Models

Syntax

PSTATES = hmmdecode(seq, TRANS, EMIS)

Posterior state probabilities for the sequence seq.

[PSTATES, logpseq] = hmmdecode(seq, TRANS, EMIS)

Also returns the log probability of the whole sequence.

[PSTATES, logpseq, FORWARD, BACKWARD, S] = hmmdecode(...)

Also returns the forward and backward variables and their scale factors.

[...] = hmmdecode(seq, TRANS, EMIS, 'Symbols', symbols)

Names the symbols when seq is a cell array of text.

Description

A hidden Markov model has states that you cannot see, which move according to TRANS and emit the symbols you do see according to EMIS. The model starts in state 1 before the first symbol. hmmdecode uses the forward and backward algorithms to say, for each step, how likely each state is given all of the data, before and after that step.

This is a soft answer: probabilities per step. For the single most likely path of states, use hmmviterbi.

Input arguments

seq
Observed sequence: integers from 1 to the number of symbols, or a cell array of text when 'Symbols' is given.
TRANS
m-by-m transition matrix: TRANS(i,j) is the probability of going from state i to state j. Rows add up to 1.
EMIS
m-by-n emission matrix: EMIS(i,k) is the probability that state i emits symbol k. Rows add up to 1.
'Symbols'
Names of the n symbols: a numeric vector or a cell array of text. Default: 1:n.

Output arguments

PSTATES
m-by-L matrix: PSTATES(i,t) is the probability that the model was in state i at step t, given the whole sequence. Each column adds up to 1.
logpseq
Natural logarithm of the probability of the sequence under the model.
FORWARD
m-by-(L+1) scaled forward probabilities, the first column being the start.
BACKWARD
m-by-(L+1) scaled backward probabilities.
S
1-by-(L+1) scale factors.

Examples

State probabilities of a dice sequence

TR = [0.9 0.1; 0.1 0.9];
EM = [1/6 1/6 1/6 1/6 1/6 1/6; 1/10 1/10 1/10 1/10 1/10 1/2];
seq = [1 2 6 6 6 3 4 6 6 6 2 6 6 6 1 6 5 6 6 6];
[PS, logp] = hmmdecode(seq, TR, EM);
disp(size(PS))
disp(round(PS(:,1:4)*10000)/10000)
fprintf('log p = %.4f\n', logp)
Output
     2    20
    0.8580    0.6338    0.2555    0.1377
    0.1420    0.3662    0.7445    0.8623
log p = -27.0467

Text symbols

TR = [0.5 0.5; 0.5 0.5];
EM = [0.9 0.1; 0.2 0.8];
PS = hmmdecode({'a','b','a'}, TR, EM, 'Symbols', {'a','b'});
disp(round(PS*10000)/10000)
Output
    0.8182    0.1111    0.8182
    0.1818    0.8889    0.1818

ansaribradley next release

Ansari-Bradley two-sample test that two samples come from distributions with the same dispersion, with no assumption of normality about the shape.

Category: Probability Distributions and Hypothesis Tests > Hypothesis Tests

Syntax

h = ansaribradley(x, y)

Tests at the 5% level that x and y have the same dispersion.

[h, p, stats] = ansaribradley(x, y, 'Tail', tail)

Sets the alternative hypothesis and returns the p-value and statistics.

[h, p, stats] = ansaribradley(x, y, 'Alpha', alpha, 'Method', method)

Sets the significance level and uses 'exact' or 'approximate' for the p-value.

Description

The test ranks the combined sample from both ends toward the middle, so that the most extreme values get the lowest scores. If one sample is more spread out, its extreme values collect low scores and the statistic moves away from what equal dispersion would give.

It assumes both samples have the same median, or that it was subtracted beforehand. It is a rank test, so it does not require the data to be normal.

Input arguments

x, y
The two samples, numeric vectors that can have different lengths.
'Alpha'
Significance level. Default 0.05.
'Tail'
'both' (default), 'right' or 'left'. With 'right' the alternative is that x has a larger dispersion than y.
'Method'
'exact' or 'approximate' (normal approximation) for the p-value.

Output arguments

h
1 when the hypothesis of equal dispersion is rejected, 0 otherwise.
p
p-value of the test.
stats
Structure with W, the Ansari-Bradley statistic, and Wstar, its standardized version.

Example

Two samples with different spread

a = [-1.2 0.3 0.8 -0.4 1.1 -0.9 0.2 0.5 -0.1 0.7 -0.6 0.0];
b = [-3.1 2.8 -2.2 3.5 -1.9 2.4 -3.3 1.7 2.9 -2.6 3.0 -2.0];
[h, p, st] = ansaribradley(a, b);
fprintf('h = %d, p = %.2g\n', h, p);
fprintf('W = %d, W* = %.4f\n', st.W, st.Wstar);
Output
h = 1, p = 7.4e-07
W = 114, W* = 4.1678

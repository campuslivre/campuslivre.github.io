figure

Creates a figure window, or makes an existing one the current figure.

Cria uma janela de figura ou torna uma figura existente a figura atual.

Category:Categoria: Graphics > Formatting and Annotation

Syntax

Sintaxe

figure

Creates a new figure with the next free number and makes it current.

Cria uma nova figura com o próximo número livre e a torna atual.

figure(n)

Makes figure number n current, creating it if it does not exist.

Torna a figura de número n atual, criando-a se não existir.

figure(Name, Value)

Creates a figure with properties such as 'Name' set.

Cria uma figura com propriedades como 'Name' definidas.

f = figure(___)

Also returns the figure object.

Também retorna o objeto da figura.

Description

Descrição

Plotting commands draw in the current figure, creating one if none exists. Calling figure explicitly lets a script keep several plots apart: each call to figure without an argument opens a new window, and figure(n) goes back to an earlier one to add more to it.

The figure object can be stored and changed through its properties, which is the usual way to set a title or a background color.

Os comandos de plotagem desenham na figura atual, criando uma se não houver nenhuma. Chamar figure explicitamente permite manter vários gráficos separados: cada chamada sem argumento abre uma nova janela, e figure(n) volta a uma anterior para acrescentar mais conteúdo.

O objeto da figura pode ser guardado e alterado por suas propriedades, que é o modo usual de definir um nome ou uma cor de fundo.

Input arguments

Argumentos de entrada

n
Positive integer, the figure number.
Inteiro positivo, o número da figura.
Name, Value
Figure properties, for example 'Name', 'Color' or 'Position'.
Propriedades da figura, por exemplo 'Name', 'Color' ou 'Position'.

Output arguments

Argumentos de saída

f
Figure object (class matlab.ui.Figure). Its Number property holds the figure number.
Objeto da figura (classe matlab.ui.Figure). Sua propriedade Number guarda o número da figura.

Example

Exemplo

Named figure and its number

Figura nomeada e seu número

f = figure('Name', 'Demo');
plot(1:5, (1:5).^2)
f.Name
f.Number
OutputSaída
ans = 'Demo'
ans = 1

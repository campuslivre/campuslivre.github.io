grp2idx next release

Converts a grouping variable into integer group indices, with the name of each group.

Category: Descriptive Statistics and Visualization > Managing Data

Syntax

[g, gn] = grp2idx(s)

Returns the group index of each element of s and the group names as a cell array of character vectors.

[g, gn, gl] = grp2idx(s)

Also returns the distinct values (levels) in the same type as s.

Description

grp2idx gives every distinct value of a grouping variable a number, so the labels can be used as indices into per-group arrays. For numeric input the groups are numbered in increasing order of value. For text labels they are numbered in the order of first appearance.

The result gn(g) rebuilds the original labels as text, which is handy for labelling plots and tables of group statistics.

Input arguments

s
Grouping variable: a numeric or logical vector, or a cell array of character vectors. Missing values (NaN, empty text) belong to no group.

Output arguments

g
Column vector of group indices, from 1 to the number of groups, with NaN where s is missing.
gn
Cell array with the name of each group, as text.
gl
Distinct values of s, in the order of the group indices.

Examples

Text labels

s = {'b','a','b','c','a'}';
[g, gn] = grp2idx(s);
disp(g')
disp(gn')
Output
     1     2     1     3     2
    {'b'}    {'a'}    {'c'}

Numeric labels with a missing value

s = [30 10 30 20 NaN]';
[g, gn, gl] = grp2idx(s);
disp(g')
disp(gl')
Output
     3     1     3     2   NaN
    10    20    30

Notes

Categorical arrays (categorical) are not supported as input.

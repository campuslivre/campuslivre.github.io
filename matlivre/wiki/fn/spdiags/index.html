spdiags

Extracts diagonals from a matrix, or builds a matrix from diagonals.

Extrai diagonais de uma matriz, ou monta uma matriz a partir de diagonais.

Category:Categoria: Mathematics > Sparse Matrices

Syntax

Sintaxe

B = spdiags(A)

Returns the nonzero diagonals of A as the columns of B.

Retorna as diagonais não nulas de A como as colunas de B.

[B, d] = spdiags(A)

Also returns the diagonal numbers d.

Também retorna os números das diagonais d.

S = spdiags(B, d, m, n)

Builds an m-by-n sparse matrix whose diagonals d are taken from the columns of B.

Monta uma matriz esparsa m-por-n cujas diagonais d são tiradas das colunas de B.

S = spdiags(B, d, A)

Replaces the diagonals d of A with the columns of B.

Substitui as diagonais d de A pelas colunas de B.

Description

Descrição

A band matrix such as the second-difference operator is written compactly by listing its diagonals. A column of B shorter than the diagonal is padded: for a square matrix, a superdiagonal uses the entries of B from the bottom, and a subdiagonal uses them from the top, so the first entries of an upper diagonal and the last entries of a lower diagonal are ignored.

Extraction is the inverse: spdiags(A) finds which diagonals are not empty and returns them in the same layout, ready to be fed back to the building form.

Uma matriz em banda, como o operador de segunda diferença, é escrita de forma compacta listando suas diagonais. Uma coluna de B mais curta que a diagonal é completada: em uma matriz quadrada, uma superdiagonal usa os elementos de B a partir do final, e uma subdiagonal usa-os a partir do início, de modo que os primeiros elementos de uma diagonal superior e os últimos de uma inferior são ignorados.

A extração é o inverso: spdiags(A) descobre quais diagonais não estão vazias e as devolve no mesmo formato, pronto para a forma de construção.

Input arguments

Argumentos de entrada

A
Matrix to extract from, or to modify.
Matriz da qual extrair, ou a modificar.
B
Matrix whose columns hold the diagonal values.
Matriz cujas colunas guardam os valores das diagonais.
d
Vector of diagonal numbers: 0 is the main diagonal, positive values are above it, negative below.
Vetor de números de diagonais: 0 é a diagonal principal, valores positivos ficam acima, negativos abaixo.
m, n
Size of the matrix to create.
Tamanho da matriz a criar.

Output arguments

Argumentos de saída

B
Matrix with one diagonal per column, padded with zeros.
Matriz com uma diagonal por coluna, completada com zeros.
S
Sparse matrix with the requested diagonals.
Matriz esparsa com as diagonais pedidas.

Example

Exemplo

Second-difference matrix

Matriz de segunda diferença

e = ones(4, 1);
A = spdiags([-e 2*e -e], -1:1, 4, 4);
full(A)
[B, d] = spdiags(A);
d

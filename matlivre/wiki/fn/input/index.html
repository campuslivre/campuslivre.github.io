input

Prompts the user for a value or text at the command window.

Pede um valor ou um texto ao usuário na janela de comandos.

Category:Categoria: Programming > Scripts

Syntax

Sintaxe

x = input(prompt)

Shows prompt, evaluates what the user types as an expression and returns the result.

Exibe prompt, avalia o que o usuário digita como expressão e retorna o resultado.

txt = input(prompt, 's')

Returns the typed characters as text, without evaluating them.

Retorna os caracteres digitados como texto, sem avaliá-los.

Description

Descrição

input stops the script and waits for a line of keyboard input. In the default form the line is evaluated as MATLAB code, so typing 2*pi returns 6.2832. With 's' the line is returned untouched as a character vector, which is the safe choice for names and free text.

Because it blocks until someone answers, input suits interactive sessions rather than programs that must run unattended.

input interrompe o script e espera uma linha digitada. Na forma padrão, a linha é avaliada como código MATLAB, então digitar 2*pi retorna 6.2832. Com 's', a linha volta intacta como vetor de caracteres, a escolha segura para nomes e texto livre.

Por bloquear até alguém responder, input serve a sessões interativas, não a programas que precisam rodar sem supervisão.

Input arguments

Argumentos de entrada

prompt
Text shown before the cursor.
Texto exibido antes do cursor.
's'
Option that returns the raw text instead of evaluating it.
Opção que retorna o texto bruto em vez de avaliá-lo.

Output arguments

Argumentos de saída

x
The value of the typed expression, or the typed text when 's' is used.
O valor da expressão digitada, ou o texto digitado quando 's' é usado.

Example

Exemplo

Calling input without a console

Chamando input sem console

try
    x = input('Value: ');
catch err
    disp(err.message)
end
OutputSaída
input is not supported: MatLivre runs scripts without an interactive command window.

MatLivre has no interactive command window, so the call fails with a message that this snippet prints.

O MatLivre não tem janela de comandos interativa, então a chamada falha com uma mensagem que este trecho exibe.

Notes

Observações

MatLivre runs scripts without an interactive command window, so input raises an error instead of waiting. Pass values through variables or function arguments instead.

O MatLivre executa scripts sem janela de comandos interativa, então input gera um erro em vez de esperar. Passe os valores por variáveis ou argumentos de função.

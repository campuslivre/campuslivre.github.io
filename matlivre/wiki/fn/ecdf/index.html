ecdf next release

Empirical cumulative distribution function of a sample, with optional survivor or cumulative hazard form, censoring, frequencies and confidence bounds.

Category: Probability Distributions and Hypothesis Tests > Univariate Discrete Distributions

Syntax

[f, x] = ecdf(y)

Empirical CDF f evaluated at the distinct sorted values x.

[f, x, flo, fup] = ecdf(y)

Also returns lower and upper confidence bounds for f.

[f, x] = ecdf(y, 'Function', fun)

Chooses 'cdf' (default), 'survivor' or 'cumulative hazard'.

[f, x] = ecdf(y, 'Censoring', c, 'Frequency', w, 'Alpha', a, 'Bounds', 'on')

Name-value options for censored data, counts, confidence level and bounds.

Description

ecdf builds the step function that, at each x, is the fraction of observations less than or equal to x. It needs no assumption about the distribution, so it is the usual first look at the shape of a sample, and the basis of the Kolmogorov-Smirnov test.

With censored data (for example survival times where some subjects are still alive) the function becomes the Kaplan-Meier estimate. The 'survivor' form is 1 - f, and 'cumulative hazard' gives the accumulated hazard.

Input arguments

y
Vector of observations.
'Function'
Which function to compute: 'cdf', 'survivor' or 'cumulative hazard'.
'Censoring'
Vector the same length as y; 1 marks a censored observation, 0 an observed one.
'Frequency'
Vector of counts, the same length as y.
'Alpha'
Significance level for the bounds. Default 0.05.
'Bounds'
'on' to compute confidence bounds, 'off' (default) otherwise.

Output arguments

f
Function values, a column vector. The first element is for the point before the smallest observation, so it is 0 for the CDF.
x
Column vector with the distinct sorted values of y where f is evaluated. The smallest value appears twice, at the start.
flo, fup
Lower and upper confidence bounds for f, the same size as f. The first and last entries can be NaN where no bound is defined.

Examples

Empirical CDF of a small sample

y = [1 2 2 3 5 7 8];
[f, x] = ecdf(y);
disp([x f])
Output
    1.0000         0
    1.0000    0.1429
    2.0000    0.4286
    3.0000    0.5714
    5.0000    0.7143
    7.0000    0.8571
    8.0000    1.0000

Survivor function with censored values

y = [1 2 2 3 5 7 8];
c = [0 0 1 0 0 1 0];
[f, x] = ecdf(y, 'Function', 'survivor', 'Censoring', c);
disp(round([x f]*1e4)/1e4)
Output
    1.0000    1.0000
    1.0000    0.8571
    2.0000    0.7143
    3.0000    0.5357
    5.0000    0.3571
    8.0000         0

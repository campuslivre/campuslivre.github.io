ezcontourf

Filled contour plot of a function of two variables given as a handle or expression.

Gráfico de contorno preenchido de uma função de duas variáveis dada como handle ou expressão.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

ezcontourf(f)

Draws filled contours of f(x,y) over the default domain, -2*pi to 2*pi in both variables.

Desenha contornos preenchidos de f(x,y) no domínio padrão, de -2*pi a 2*pi nas duas variáveis.

ezcontourf(f, domain)

Restricts the plot to [min max] or [xmin xmax ymin ymax].

Restringe o gráfico a [min max] ou [xmin xmax ymin ymax].

h = ezcontourf(___)

Also returns the graphics handle.

Também retorna o handle gráfico.

Description

Descrição

The function is sampled on an automatic grid and the regions between level curves are filled with colors from the current colormap. It is the filled counterpart of ezcontour; fcontour with 'Fill','on' is the modern equivalent.

A função é amostrada em uma grade automática e as regiões entre as curvas de nível são preenchidas com cores do colormap atual. É a versão preenchida de ezcontour; fcontour com 'Fill','on' é o equivalente moderno.

Input arguments

Argumentos de entrada

f
Function handle or character vector in x and y, written with element-wise operators.
Handle de função ou vetor de caracteres em x e y, escrito com operadores elemento a elemento.
domain
Two or four numbers that set the plotting region.
Dois ou quatro números que definem a região do gráfico.

Output arguments

Argumentos de saída

h
Handle to the contour object.
Handle do objeto de contorno.

Example

Exemplo

Filled saddle

Sela preenchida

ezcontourf(@(x,y) x.^2 - y.^2, [-2 2])
colorbar

In the app, the figure is drawn below the code.

No app, a figura é desenhada abaixo do código.

Veja também

kmeans next release

Partitions the rows of a data matrix into k clusters by k-means, returning labels, centroids and distances.

Category: Cluster Analysis and Anomaly Detection > k-Means and k-Medoids Clustering

Syntax

idx = kmeans(X, k)

Cluster index of each row, using squared Euclidean distance.

[idx, C] = kmeans(X, k)

Also returns the k centroids.

[idx, C, sumd, D] = kmeans(X, k)

Also returns the within-cluster sums of distances and the distance from every point to every centroid.

[...] = kmeans(X, k, Name, Value)

Options such as 'Start', 'Replicates', 'Distance' and 'MaxIter'.

Description

kmeans alternates between assigning each point to its nearest centroid and moving each centroid to the mean of its points, until the assignment stops changing. The result depends on the starting centroids and can be a local optimum, so use 'Replicates' or pass your own 'Start' matrix when the answer matters.

The cluster numbers are arbitrary labels. With the default 'plus' start the initial centroids are random, so repeated calls can number the clusters differently.

Input arguments

X
Data matrix, one observation per row.
k
Number of clusters.
'Start'
Initial centroids: 'plus' (default), 'sample', 'uniform', 'cluster', or a k-by-p matrix.
'Replicates'
How many times to repeat the clustering from new starting points. The best result (lowest total distance) is kept. Default 1.
'Distance'
'sqeuclidean' (default), 'cosine' or 'correlation'.

Output arguments

idx
Column vector with the cluster number (1 to k) of each row.
C
k-by-p matrix of cluster centroids.
sumd
Column vector with the sum of point-to-centroid distances inside each cluster.
D
n-by-k matrix of distances from each point to each centroid.

Examples

Fixed starting centroids, so the result is reproducible

X = [1 2; 1.3 1.8; 0.8 2.4; 5 5; 5.5 4.9; 4.6 5.3; 9 1; 9.2 1.5];
[idx, C, sumd] = kmeans(X, 3, 'Start', X([1 4 7],:));
disp(idx')
disp(round(C*1000)/1000)
disp(round(sumd'*1000)/1000)
Output
     1     1     1     2     2     2     3     3
    1.0330    2.0670
    5.0330    5.0670
    9.1000    1.2500
    0.3130    0.4930    0.1450

Random starts with replicates: only sizes are printed

X = [1 2; 1.3 1.8; 0.8 2.4; 5 5; 5.5 4.9; 4.6 5.3; 9 1; 9.2 1.5];
[idx, C] = kmeans(X, 2, 'Replicates', 5);
disp(size(idx))
disp(size(C))
disp(sort(unique(idx))')
Output
     8     1
     2     2
     1     2

Notes

The 'cityblock' and 'hamming' distances are not implemented and raise an error. Random starting points ('plus', 'sample', 'uniform') do not follow MATLAB's random streams, so results from random starts will not match MATLAB even with the same seed; pass a 'Start' matrix for a reproducible run. With 'correlation' distance and data where points tie exactly, the assignment of tied points can differ from MATLAB.

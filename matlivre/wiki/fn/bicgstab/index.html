bicgstab

Solves a square linear system with the stabilized biconjugate gradients method.

Resolve um sistema linear quadrado pelo método dos gradientes biconjugados estabilizado.

Category:Categoria: Mathematics > Sparse Matrices

Syntax

Sintaxe

x = bicgstab(A, b)

Solves A*x = b with default tolerance and iteration limit.

Resolve A*x = b com a tolerância e o limite de iterações padrão.

x = bicgstab(A, b, tol, maxit)

Sets the relative residual tolerance and the maximum number of iterations.

Define a tolerância do resíduo relativo e o número máximo de iterações.

x = bicgstab(A, b, tol, maxit, M1, M2, x0)

Adds a preconditioner M = M1*M2 and an initial guess x0.

Acrescenta um pré-condicionador M = M1*M2 e uma estimativa inicial x0.

[x, flag, relres, iter, resvec] = bicgstab(___)

Also returns the convergence flag, final relative residual, iteration count and residual history.

Também retorna o indicador de convergência, o resíduo relativo final, o número de iterações e o histórico de resíduos.

Description

Descrição

bicgstab is a smoother variant of biconjugate gradients that avoids products with A'. It uses two products with A per full iteration and its residuals usually decrease more regularly than those of cgs. The returned iter can end in .5 because the method counts half iterations.

When called with fewer than two outputs it prints a one-line message about whether it converged. With a flag output it stays silent, so check flag yourself. A good preconditioner such as an incomplete factorization (ilu, ichol) can cut the iteration count a lot.

bicgstab é uma variante mais suave dos gradientes biconjugados que evita produtos com A'. Usa dois produtos com A por iteração completa e seus resíduos costumam diminuir de forma mais regular que os do cgs. O iter retornado pode terminar em .5, pois o método conta meias iterações.

Quando chamado com menos de duas saídas, imprime uma linha dizendo se convergiu. Com a saída flag, fica em silêncio, então verifique flag por conta própria. Um bom pré-condicionador, como uma fatoração incompleta (ilu, ichol), pode reduzir bastante o número de iterações.

Input arguments

Argumentos de entrada

A
Square coefficient matrix (usually sparse), or a function handle that returns A*x.
Matriz de coeficientes quadrada (em geral esparsa), ou handle de função que retorna A*x.
b
Right-hand side column vector with size(A,1) entries.
Vetor coluna do lado direito, com size(A,1) elementos.
tol
Relative residual tolerance; the default is 1e-6.
Tolerância do resíduo relativo; o padrão é 1e-6.
maxit
Maximum number of iterations.
Número máximo de iterações.
M1, M2
Preconditioner factors, as matrices or function handles; the solver works with M1*M2.
Fatores do pré-condicionador, como matrizes ou handles de função; o solver trabalha com M1*M2.
x0
Initial guess. The default is a vector of zeros.
Estimativa inicial. O padrão é um vetor de zeros.

Output arguments

Argumentos de saída

x
The computed solution, a column vector.
A solução calculada, um vetor coluna.
flag
0 if it converged within maxit iterations, 1 if it ran out of iterations, 2 if the preconditioner was ill-conditioned, 3 if it stagnated, and other values for a breakdown.
0 se convergiu em até maxit iterações, 1 se acabaram as iterações, 2 se o pré-condicionador era mal condicionado, 3 se estagnou, e outros valores para uma falha numérica.
relres
Relative residual norm(b - A*x)/norm(b) at the returned iterate.
Resíduo relativo norm(b - A*x)/norm(b) na iteração retornada.
iter
Iteration at which x was computed.
Iteração em que x foi calculado.
resvec
History of residual norms.
Histórico das normas dos resíduos.

Example

Exemplo

Tridiagonal system

Sistema tridiagonal

A = sparse(diag(4*ones(5,1)) + diag(ones(4,1),1) + diag(ones(4,1),-1));
b = (1:5)';
[x, flag, relres, iter] = bicgstab(A, b, 1e-10, 100);
fprintf('flag = %d, iterations = %g\n', flag, iter)
disp(x')
OutputSaída
flag = 0, iterations = 4.5

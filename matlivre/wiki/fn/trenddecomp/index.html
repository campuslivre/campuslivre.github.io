trenddecomp

Splits a time series into long-term trend, seasonal and remainder parts.

Separa uma série temporal em tendência de longo prazo, partes sazonais e resíduo.

Category:Categoria: Data Import and Analysis > Preprocessing Data

Syntax

Sintaxe

LT = trenddecomp(A)

Long-term trend of the vector A.

Tendência de longo prazo do vetor A.

[LT, ST, R] = trenddecomp(A)

Long-term trend, seasonal trend and the remainder.

Tendência de longo prazo, tendência sazonal e o resíduo.

Description

Descrição

trenddecomp separates what changes slowly, what repeats with a period, and what is left over, so that each part can be studied on its own. The components add up to the original data. It is used on measurements with a daily or yearly cycle, such as temperature or sales.

The decomposition can use a method such as singular spectrum analysis, which finds the dominant oscillatory patterns in the series.

trenddecomp separa o que muda devagar, o que se repete com um período e o que sobra, para que cada parte possa ser estudada isoladamente. Os componentes somam os dados originais. É usada em medições com ciclo diário ou anual, como temperatura ou vendas.

A decomposição pode usar um método como a análise espectral singular, que encontra os padrões oscilatórios dominantes da série.

Input arguments

Argumentos de entrada

A
Numeric vector holding a regularly sampled series.
Vetor numérico com uma série amostrada regularmente.

Output arguments

Argumentos de saída

LT
Long-term trend.
Tendência de longo prazo.
ST
Seasonal (periodic) component.
Componente sazonal (periódico).
R
Remainder: A - LT - ST.
Resíduo: A - LT - ST.

Example

Exemplo

Calling it in MatLivre

Chamando no MatLivre

x = (1:20) + sin(1:20);
try
  LT = trenddecomp(x);
  disp(size(LT))
catch err
  disp(err.message)
end
OutputSaída
trenddecomp is not supported in this version.

Notes

Observações

trenddecomp is not available in MatLivre yet: calling it reports 'trenddecomp is not supported in this version.' The example above shows that message. Use smoothdata or detrend for a simple trend estimate.

trenddecomp ainda não está disponível no MatLivre: a chamada informa 'trenddecomp is not supported in this version.' O exemplo acima mostra essa mensagem. Use smoothdata ou detrend para uma estimativa simples de tendência.

mode

Most frequent value in a sample.

Valor mais frequente em uma amostra.

Category:Categoria: Data Import and Analysis > Descriptive Statistics

Syntax

Sintaxe

M = mode(A)

Most frequent value of a vector, or of each column of a matrix.

Valor mais frequente de um vetor, ou de cada coluna de uma matriz.

M = mode(A, dim)

Along dimension dim.

Ao longo da dimensão dim.

[M, F, C] = mode(___)

Also returns the occurrence count F and the tied values C (MATLAB only; see notes).

Também retorna a contagem F e os valores empatados C (só no MATLAB; veja as notas).

Description

Descrição

When several values tie for the highest count, mode returns the smallest of them. The statistic is mostly meaningful for discrete data, since in continuous data it is rare for a value to repeat.

Empty input gives NaN.

Quando vários valores empatam na maior contagem, mode retorna o menor deles. A estatística faz mais sentido para dados discretos, já que em dados contínuos é raro um valor se repetir.

Entrada vazia dá NaN.

Input arguments

Argumentos de entrada

A
Numeric or logical array.
Array numérico ou lógico.
dim
Dimension to operate along.
Dimensão em que operar.

Output arguments

Argumentos de saída

M
The most frequent value.
O valor mais frequente.
F
Number of occurrences of M.
Número de ocorrências de M.
C
Cell array holding every value that ties for most frequent.
Cell array com todos os valores empatados como mais frequentes.

Example

Exemplo

Ties go to the smallest

Empates ficam com o menor

mode([1 2 2 3 3])
mode([4 4 4 1 2])
mode([1 2; 1 3; 2 3])
OutputSaída
ans = 2
ans = 4
ans = 1×2

     1     3

Notes

Observações

MatLivre's mode returns only the first output; asking for F or C raises a 'Too many output arguments' error.

O mode do MatLivre retorna apenas a primeira saída; pedir F ou C gera o erro 'Too many output arguments'.

trimmean next release

Trimmed mean: the mean after discarding a percentage of the smallest and largest values.

Category: Descriptive Statistics and Visualization > Descriptive Statistics

Syntax

m = trimmean(x, percent)

Trimmed mean of a vector, or of each column of a matrix.

m = trimmean(x, percent, flag)

flag is 'round' (default), 'floor' or 'weighted' and says how a non-integer number of values to trim is handled.

m = trimmean(x, percent, dim)

Along dimension dim.

Description

trimmean(x, 40) sorts the data, removes 20% of the values from each end and averages the rest. It sits between the mean (percent = 0) and the median (percentages close to 100), and resists outliers much better than the mean.

The percentage is of the total count, so for 10 values, percent = 20 removes the single smallest and the single largest.

Input arguments

x
Numeric array. NaN values are ignored.
percent
Total percentage of values to remove, from 0 up to but not including 100. Half comes from each end.
flag
Rule for a fractional number of values to trim. Default 'round'.
dim
Dimension to operate along. Default: first non-singleton dimension.

Output arguments

m
Trimmed mean, with the size of x reduced to 1 along the chosen dimension.

Examples

Resisting an outlier

x = [1 2 3 4 100];
disp(mean(x))
disp(trimmean(x, 40))
disp(median(x))
Output
    22
     3
     3

Per column

A = [1 5; 2 6; 3 7; 4 8; 100 9];
disp(trimmean(A, 40))
Output
     3     7

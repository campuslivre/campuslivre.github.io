what

Lists the MATLAB files in a folder, grouped by type.

Lista os arquivos MATLAB de uma pasta, agrupados por tipo.

Category:Categoria: Programming > Files and Folders

Syntax

Sintaxe

what

Displays the code files, MAT-files and class folders of the current folder.

Exibe os arquivos de código, MAT-files e pastas de classe da pasta atual.

what folder

Does the same for folder.

Faz o mesmo para folder.

s = what(folder)

Returns a struct with one field per file type.

Retorna uma struct com um campo por tipo de arquivo.

Description

Descrição

what filters a folder down to the files that matter to the program: scripts and functions (.m), live scripts (.mlx), data (.mat) and so on, hiding everything else. With an output, the struct fields can be passed to other functions, for instance s.m to loop over the function files.

what filtra uma pasta e deixa só os arquivos que interessam ao programa: scripts e funções (.m), live scripts (.mlx), dados (.mat) e assim por diante, escondendo o resto. Com uma saída, os campos da struct podem ser passados a outras funções, por exemplo s.m para percorrer os arquivos de função.

Input arguments

Argumentos de entrada

folder
Folder name; relative to the current folder or a folder on the path.
Nome da pasta; relativo à pasta atual ou uma pasta do path.

Output arguments

Argumentos de saída

s
Struct with fields path, m, mlx, mat, mex, p, classes, packages and others; each is a cell array of names.
Struct com os campos path, m, mlx, mat, mex, p, classes, packages e outros; cada um é um cell array de nomes.

Example

Exemplo

Only the code files are listed

Somente os arquivos de código são listados

mkdir lib
writelines('function y = f(x), y = x; end', 'lib/f.m');
writelines('plain', 'lib/notes.txt');
s = what('lib');
s.m
OutputSaída
ans = 1×1 cell

    {'f.m'}

voronoin

Voronoi vertices and cells for points in n dimensions.

Vértices e células de Voronoi para pontos em n dimensões.

Category:Categoria: Mathematics > Computational Geometry

Syntax

Sintaxe

[V, C] = voronoin(X)

Returns the Voronoi vertices V and a cell array C of the cells for the points X.

Retorna os vértices de Voronoi V e um cell array C com as células dos pontos X.

Description

Descrição

Each cell holds the indices of the vertices of the Voronoi region around one input point. If the region is unbounded, its list contains 1, which refers to the infinite vertex in the first row of V. Only cells without 1 are closed polygons.

In the example below, the four corner points have unbounded cells, while the central point has a bounded cell made from the four finite vertices.

Cada célula guarda os índices dos vértices da região de Voronoi ao redor de um ponto de entrada. Se a região é ilimitada, sua lista contém 1, que se refere ao vértice infinito na primeira linha de V. Só as células sem 1 são polígonos fechados.

No exemplo abaixo, os quatro pontos dos cantos têm células ilimitadas, enquanto o ponto central tem uma célula limitada formada pelos quatro vértices finitos.

Input arguments

Argumentos de entrada

X
m-by-n matrix with one point per row.
Matriz m por n com um ponto por linha.

Output arguments

Argumentos de saída

V
Voronoi vertices, one per row. The first row is all Inf.
Vértices de Voronoi, um por linha. A primeira linha é toda Inf.
C
Cell array. C{k} lists the rows of V that form the cell of point X(k,:).
Cell array. C{k} lista as linhas de V que formam a célula do ponto X(k,:).

Example

Exemplo

Voronoi cells of five points

Células de Voronoi de cinco pontos

X = [0 0; 1 0; 1 1; 0 1; 0.5 0.5];
[V, C] = voronoin(X);
V
C{5}
OutputSaída
V = 5×2

       Inf       Inf
    1.0000    0.5000
    0.5000         0
         0    0.5000
    0.5000    1.0000
ans = 1×4

     2     3     4     5

num2str

Converts numbers to a character array.

Converte números em um array de caracteres.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

s = num2str(A)

Converts using a precision chosen from the magnitude of the values (about five significant digits).

Converte com uma precisão escolhida a partir da magnitude dos valores (cerca de cinco dígitos significativos).

s = num2str(A, precision)

Uses the given number of significant digits.

Usa o número de dígitos significativos dado.

s = num2str(A, formatSpec)

Formats each element with a sprintf-style format.

Formata cada elemento com um formato no estilo de sprintf.

Description

Descrição

Integers print without a decimal point. For non-integers the default keeps four digits after the leading digit, so pi becomes '3.1416'; the precision argument changes that, and formatSpec gives full control. Complex values print as 3+4i.

For a vector or matrix, the elements are laid out in aligned columns separated by two spaces. To combine numbers with other text, sprintf or string(x) are more flexible.

Inteiros são impressos sem ponto decimal. Para não inteiros, o padrão mantém quatro dígitos após o primeiro, então pi vira '3.1416'; o argumento precision muda isso, e formatSpec dá controle total. Valores complexos saem como 3+4i.

Para um vetor ou matriz, os elementos são dispostos em colunas alinhadas, separadas por dois espaços. Para combinar números com outros textos, sprintf ou string(x) são mais flexíveis.

Input arguments

Argumentos de entrada

A
Numeric, logical or char array.
Array numérico, lógico ou char.
precision
Number of significant digits.
Número de dígitos significativos.
formatSpec
Format such as '%8.3f'.
Formato como '%8.3f'.

Output arguments

Argumentos de saída

s
Char array. A matrix input gives one row of text per row of A.
Array de char. Uma matriz de entrada gera uma linha de texto por linha de A.

Example

Exemplo

num2str(pi)
num2str(pi, 8)
num2str([1 2 3])
num2str(3.14159, '%8.3f')
OutputSaída
ans = '3.1416'
ans = '3.1415927'
ans = '1  2  3'
ans = '   3.142'

sos2ss

Converts second-order sections into a state-space model.

Category: Filter conversions

Syntax

[A, B, C, D] = sos2ss(sos)

State-space matrices of the cascade of the sections in sos.

[A, B, C, D] = sos2ss(sos, g)

Includes an overall gain g.

Description

The state-space model describes the same filter as the sections: with [b, a] = ss2tf(A, B, C, D) you get the same transfer function as sos2tf(sos, g). State space is the form used to analyse controllability and observability, to simulate with matrices, or to pass to routines that expect A, B, C, D.

The model has one state for each unit delay of the whole cascade, so two sections of second order give a 4-by-4 A.

Input arguments

sos
L-by-6 matrix, one section per row, [b0 b1 b2 a0 a1 a2].
g
Optional overall gain, a scalar (default 1).

Output arguments

A
State matrix, square, with one state per delay in the cascade.
B
Input matrix, a column.
C
Output matrix, a row.
D
Direct feedthrough, a scalar.

Example

Two sections as a state-space model

sos = [1 2 1 1 -0.5 0.1; 1 0 -1 1 0.2 0.3];
[A, B, C, D] = sos2ss(sos, 0.5);
disp(size(A))
[b, a] = ss2tf(A, B, C, D);
disp(round(b*1e4)/1e4)
disp(round(a*1e4)/1e4)
Output
     4     4
    0.5000    1.0000         0   -1.0000   -0.5000
    1.0000   -0.3000    0.3000   -0.1300    0.0300

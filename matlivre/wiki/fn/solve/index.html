solve

Method of the ode object: integrates the differential equation it defines.

Método do objeto ode: integra a equação diferencial que ele define.

Category:Categoria: Mathematics > Numerical Integration and Differential Equations

Syntax

Sintaxe

S = solve(F, t0, tf)

Solves the problem of the ode object F from t0 to tf.

Resolve o problema do objeto ode F de t0 a tf.

S = solve(F, tspan)

Solves over tspan, a vector of times at which to report the result.

Resolve em tspan, um vetor de instantes em que reportar o resultado.

Description

Descrição

With the object interface, the problem and its settings live together in one variable: set the properties, then call solve. If no solver is named, one is chosen automatically from the problem, so stiffness need not be known in advance.

Events, mass matrices and Jacobians are attached as objects (odeEvent, odeMassMatrix, odeJacobian) rather than through odeset.

Na interface por objeto, o problema e suas configurações ficam juntos em uma só variável: definem-se as propriedades e chama-se solve. Se nenhum solver é indicado, um é escolhido automaticamente a partir do problema, então não é preciso saber de antemão se há rigidez.

Eventos, matrizes de massa e Jacobianos são anexados como objetos (odeEvent, odeMassMatrix, odeJacobian) em vez de passarem por odeset.

Input arguments

Argumentos de entrada

F
An ode object with ODEFcn and InitialValue set (and optionally Solver, InitialTime, RelativeTolerance, EventDefinition).
Um objeto ode com ODEFcn e InitialValue definidos (e opcionalmente Solver, InitialTime, RelativeTolerance, EventDefinition).
t0, tf
Start and end of the interval.
Início e fim do intervalo.

Output arguments

Argumentos de saída

S
A results object whose Time and Solution properties hold the time points and the solution, one column per time point.
Um objeto de resultados cujas propriedades Time e Solution guardam os instantes e a solução, uma coluna por instante.

Example

Exemplo

Solve y' = -y

Resolver y' = -y

F = ode;
F.ODEFcn = @(t, y) -y;
F.InitialTime = 0;
F.InitialValue = 1;
S = solve(F, 0, 1);
fprintf('%.4f %.4f\n', S.Solution(end), exp(-1))
OutputSaída
0.3679 0.3679

Notes

Observações

solve is also the name of a method on other object types. This entry covers the ode object.

solve também é o nome de um método em outros tipos de objeto. Esta entrada trata do objeto ode.

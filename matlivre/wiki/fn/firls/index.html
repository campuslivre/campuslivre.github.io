firls

Designs a linear-phase FIR filter by least squares: it minimizes the squared error between the filter and the desired response over the bands.

Category: FIR design

Syntax

b = firls(n,f,a)

Order n filter that fits amplitude a at the band edges f.

b = firls(n,f,a,w)

Adds a weight w per band.

b = firls(n,f,a,'hilbert')

Designs a Hilbert transformer (or 'differentiator').

Description

A least-squares fit keeps the total energy of the error small. It gives a smooth fit with a lower average error than firpm, but a larger worst-case ripple, mostly near the band edges. Leave a gap between the passband and stopband edges for a transition band, which improves the fit a great deal.

With 'hilbert' or 'differentiator' the filter has odd symmetry, for the 90-degree phase shift.

Input arguments

n
Filter order. The result has n+1 coefficients.
f
Band edges in pairs, increasing, from 0 to 1 (1 is half the sampling rate). The gaps between bands are not constrained.
a
Desired amplitude at each band edge. The target is a straight line between the two edges of a band.
w
Optional weight per band. A larger weight lowers the error in that band.

Output arguments

b
Row vector of n+1 coefficients.

Example

Lowpass and a Hilbert transformer

b = firls(20,[0 0.3 0.4 1],[1 1 0 0]);
disp(round(b*10000)/10000)
bh = firls(15,[0 1],[0 1],'hilbert');
disp(round(bh*10000)/10000)

Notes

Fits that are nearly singular can differ from MATLAB: bands that leave most of the response unconstrained (for example firls(20,[0 0.5],[0 1])) and differentiator fits with a band that starts at zero with nonzero amplitude or no stopband (for example firls(30,[0 0.5],[0 1],'differentiator')). The solution then depends on rounding.

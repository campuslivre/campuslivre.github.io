bvp5c

Solves boundary value problems with a fourth-order method that controls the true error.

Resolve problemas de valor de contorno com um método de quarta ordem que controla o erro verdadeiro.

Category:Categoria: Mathematics > Numerical Integration and Differential Equations

Syntax

Sintaxe

sol = bvp5c(odefun, bcfun, solinit)

Solves the system y' = odefun(x, y) with boundary conditions bcfun(y(a), y(b)) = 0.

Resolve o sistema y' = odefun(x, y) com condições de contorno bcfun(y(a), y(b)) = 0.

sol = bvp5c(odefun, bcfun, solinit, options)

Also applies options from bvpset.

Aplica também opções de bvpset.

Description

Descrição

bvp5c has the same calling pattern as bvp4c, so one can often be swapped for the other. The difference is in the error control: bvp4c limits the residual of the collocation polynomial, while bvp5c limits the error in the solution itself, which can matter when a tight tolerance is required.

If one solver stalls on a hard problem, try the other, and improve the initial guess.

bvp5c tem o mesmo padrão de chamada de bvp4c, então muitas vezes uma pode ser trocada pela outra. A diferença está no controle do erro: bvp4c limita o resíduo do polinômio de colocação, enquanto bvp5c limita o erro na própria solução, o que pode importar quando se exige tolerância apertada.

Se um solver trava em um problema difícil, experimente o outro e melhore o palpite inicial.

Input arguments

Argumentos de entrada

odefun, bcfun
Function handles for the equations and for the boundary residuals, as for bvp4c.
Handles de função para as equações e para os resíduos de contorno, como em bvp4c.
solinit
Initial mesh and guess from bvpinit.
Malha inicial e palpite de bvpinit.
options
Structure from bvpset.
Estrutura de bvpset.

Output arguments

Argumentos de saída

sol
Structure with the fields x, y, yp and stats, usable with deval.
Estrutura com os campos x, y, yp e stats, utilizável com deval.

Example

Exemplo

Same problem as bvp4c

Mesmo problema de bvp4c

odefun = @(x, y) [y(2); -y(1)];
bcfun = @(ya, yb) [ya(1); yb(1) - 1];
solinit = bvpinit(linspace(0, 1, 5), [0; 1]);
sol = bvp5c(odefun, bcfun, solinit);
y = deval(sol, 0.5);
fprintf('%.4f\n', y(1))
OutputSaída
0.5697

version

Returns the version of the running MATLAB.

Retorna a versão do MATLAB em execução.

Category:Categoria: Environment and Settings > Platform and License

Syntax

Sintaxe

v = version

Version number with build, release name and update level.

Número de versão com build, nome da versão e nível de atualização.

v = version('-release')

Only the release, as a text like '2023b'.

Apenas a versão, como um texto do tipo '2023b'.

[v, d] = version

Also returns the release date.

Também retorna a data da versão.

Description

Descrição

The plain call returns something like '23.2.0.2409890 (R2023b) Update 3': the version number, the build and the release name. Use the options to get one piece at a time; for comparisons, verLessThan and isMATLABReleaseOlderThan are safer than parsing the text.

The version number of MATLAB R2023b is 23.2.

A chamada simples retorna algo como '23.2.0.2409890 (R2023b) Update 3': o número de versão, o build e o nome da versão. Use as opções para obter uma parte por vez; para comparações, verLessThan e isMATLABReleaseOlderThan são mais seguros do que analisar o texto.

O número de versão do MATLAB R2023b é 23.2.

Input arguments

Argumentos de entrada

option
'-release', '-date' or '-java'.
'-release', '-date' ou '-java'.

Output arguments

Argumentos de saída

v
Version text.
Texto da versão.
d
Release date as text.
Data da versão como texto.

Example

Exemplo

Version, release and date

Versão, release e data

version
version('-release')
[v, d] = version
OutputSaída
ans = '23.2.0.2409890 (R2023b) Update 3'
ans = '2023b'
v = '23.2.0.2409890 (R2023b) Update 3'
d = 'October 4, 2023'

Notes

Observações

version('-java') reports 'Java is not enabled', since MatLivre has no Java virtual machine.

version('-java') informa 'Java is not enabled', pois o MatLivre não tem máquina virtual Java.

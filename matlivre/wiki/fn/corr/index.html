corr next release

Linear, Spearman or Kendall correlation between the columns of one or two matrices, with p-values.

Category: Descriptive Statistics and Visualization > Descriptive Statistics

Syntax

rho = corr(X)

Matrix of correlations between all pairs of columns of X.

rho = corr(X, Y)

Correlations between each column of X and each column of Y.

[rho, pval] = corr(___)

Also returns the p-value of the test that each correlation is zero.

[rho, pval] = corr(___, Name, Value)

Options: 'type' ('Pearson', 'Spearman', 'Kendall'), 'rows' ('all', 'complete', 'pairwise') and 'tail' ('both', 'right', 'left').

Description

Unlike corrcoef, corr works column by column on two matrices and can compute rank correlations. A correlation near 1 or -1 means a strong linear (or monotone, for the rank types) relationship, and near 0 means none. A small p-value is evidence that the true correlation is not zero.

Two column vectors give a scalar. A constant column has no defined correlation and gives NaN.

Input arguments

X
Matrix with observations in rows and variables in columns.
Y
Second matrix with the same number of rows as X.
'type'
Kind of correlation. Default 'Pearson'. 'Spearman' and 'Kendall' use ranks, so they measure monotone association.
'rows'
How to treat NaN: 'all' (default) uses every row, 'complete' drops rows with any NaN, 'pairwise' drops rows separately for each pair of columns.
'tail'
Alternative hypothesis for the p-value: 'both' (default), 'right' (correlation greater than 0) or 'left'.

Output arguments

rho
Correlation matrix. It is size(X,2)-by-size(X,2) for corr(X) and size(X,2)-by-size(Y,2) for corr(X,Y).
pval
Matrix of p-values, the same size as rho.

Examples

Correlation matrix and one p-value

A = [2 4 6; 3 1 8; 5 7 2; 9 3 4; 1 6 5];
disp(round(corr(A)*10000)/10000)
[r, p] = corr(A(:,1), A(:,2));
fprintf('%.4f %.4f\n', r, p)
Output
    1.0000   -0.1656   -0.4596
   -0.1656    1.0000   -0.7961
   -0.4596   -0.7961    1.0000
-0.1656 0.7902

Rank correlation and missing values

N = [1 2; NaN 3; 4 6; 5 NaN; 7 9];
disp(round(corr(N, 'rows', 'pairwise')*10000)/10000)
x = (1:6)'; y = [2 1 4 3 7 5]';
fprintf('%.4f\n', corr(x, y, 'type', 'Spearman'))
Output
    1.0000    0.9966
    0.9966    1.0000
0.8286

readlines

Reads the lines of a text file into a string array.

Lê as linhas de um arquivo de texto em um array de strings.

Category:Categoria: Data Import and Analysis > Data Import and Export

Syntax

Sintaxe

lines = readlines(filename)

Returns one string per line, as a column.

Retorna uma string por linha, em uma coluna.

Description

Descrição

This is the shortest way to loop over the lines of a file: for ln = readlines(f)'. Because the result is a string array, you can use contains, startsWith, split and str2double on all lines at once.

É a maneira mais curta de percorrer as linhas de um arquivo: for ln = readlines(f)'. Como o resultado é um array de strings, é possível usar contains, startsWith, split e str2double em todas as linhas de uma vez.

Input arguments

Argumentos de entrada

filename
Name of a text file.
Nome de um arquivo de texto.

Output arguments

Argumentos de saída

lines
Column string array, one element per line, without line terminators.
Array de strings em coluna, um elemento por linha, sem terminadores de linha.

Example

Exemplo

Filter lines

Filtrar linhas

fid = fopen('log.txt', 'w');
fprintf(fid, 'ok 1\nerror 2\nok 3\nerror 4');
fclose(fid);
L = readlines('log.txt')
L(startsWith(L, 'error'))
OutputSaída
L = 4×1 string array

    "ok 1"
    "error 2"
    "ok 3"
    "error 4"
ans = 2×1 string array

    "error 2"
    "error 4"

Notes

Observações

When the file ends with a newline, MatLivre includes a final empty string in the result.

Quando o arquivo termina com quebra de linha, o MatLivre inclui uma string vazia no fim do resultado.

cellfun

Applies a function to the contents of each cell of a cell array.

Aplica uma função ao conteúdo de cada célula de um cell array.

Category:Categoria: Language Fundamentals > Data Types

Syntax

Sintaxe

A = cellfun(func, C)

Calls func on each cell and collects scalar results in an array.

Chama func em cada célula e reúne os resultados escalares em um array.

A = cellfun(func, C1, C2, ...)

Passes the contents of matching cells of several arrays to func.

Passa o conteúdo de células correspondentes de vários arrays para func.

[A, B, ...] = cellfun(___)

Collects several outputs of func.

Reúne várias saídas de func.

B = cellfun(___, 'UniformOutput', false)

Returns a cell array, so results of any size or class are allowed.

Retorna um cell array, permitindo resultados de qualquer tamanho ou classe.

Description

Descrição

cellfun is the cell array counterpart of a loop over C{k}. With uniform output the scalars are joined into a numeric, logical or char array; if one result is not a scalar, or the classes differ, an error says to set 'UniformOutput' to false.

It is typically used with an anonymous function, as in cellfun(@(s) numel(s), names) to get the length of each name.

cellfun é o equivalente, para cell arrays, de um laço sobre C{k}. Com saída uniforme os escalares são reunidos num array numérico, lógico ou char; se algum resultado não for escalar, ocorre um erro orientando a definir 'UniformOutput' como false.

É usado tipicamente com função anônima, como em cellfun(@(s) numel(s), nomes) para obter o comprimento de cada nome.

Input arguments

Argumentos de entrada

func
Function handle, or a legacy name such as 'isempty', 'length' or 'numel'.
Function handle, ou um nome legado como 'isempty', 'length' ou 'numel'.
C
Cell array. Several cell arrays must have the same size.
Cell array. Vários cell arrays devem ter o mesmo tamanho.
'UniformOutput'
Logical. With true (default) each result must be a scalar; with false results are stored in cells.
Lógico. Com true (padrão) cada resultado deve ser escalar; com false os resultados são guardados em células.

Output arguments

Argumentos de saída

A
Array with the size of C (uniform output) or a cell array of that size.
Array com o tamanho de C (saída uniforme) ou cell array desse tamanho.

Example

Exemplo

Counting and transforming

Contando e transformando

names = {'ab','c',''};
cellfun(@numel, names)
cellfun(@(x) upper(x), {'a','b'}, 'UniformOutput', false)
[mx, ix] = cellfun(@max, {[1 5 2], [7 3]})
OutputSaída
ans = 1×3

     2     1     0
ans = 1×2 cell

    {'A'}    {'B'}
mx = 1×2

     5     7
ix = 1×2

     2     1

Notes

Observações

The 'ErrorHandler' option is not applied in MatLivre: an error inside func stops cellfun.

A opção 'ErrorHandler' não é aplicada no MatLivre: um erro dentro de func interrompe o cellfun.

Veja também

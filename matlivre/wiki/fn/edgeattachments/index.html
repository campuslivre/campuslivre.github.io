edgeAttachments

Triangles or tetrahedra attached to given edges of a triangulation.

Triângulos ou tetraedros ligados a arestas dadas de uma triangulação.

Category:Categoria: Mathematics > Computational Geometry

Syntax

Sintaxe

T = edgeAttachments(TR, v1, v2)

For each edge from vertex v1(i) to v2(i), lists the simplices that contain the edge.

Para cada aresta do vértice v1(i) ao v2(i), lista os simplexes que contêm a aresta.

T = edgeAttachments(TR, E)

The edges are given as the rows of the two-column matrix E.

As arestas são dadas como linhas da matriz E de duas colunas.

Description

Descrição

An interior edge of a planar mesh belongs to two triangles, an edge on the outline belongs to one. Looking at how many simplices come back therefore tells whether an edge is on the boundary. In a 3-D tetrahedral mesh an edge can be shared by many tetrahedra.

Uma aresta interna de uma malha plana pertence a dois triângulos; uma aresta do contorno pertence a um. Ver quantos simplexes retornam diz, portanto, se a aresta está no contorno. Em uma malha tetraédrica 3-D, uma aresta pode ser compartilhada por muitos tetraedros.

Input arguments

Argumentos de entrada

TR
A triangulation or delaunayTriangulation object.
Um objeto triangulation ou delaunayTriangulation.
v1, v2
Column vectors of vertex indices that define the edges.
Vetores coluna de índices de vértices que definem as arestas.
E
Edges as a two-column matrix of vertex indices.
Arestas como matriz de duas colunas de índices de vértices.

Output arguments

Argumentos de saída

T
Cell array with one entry per edge, each a row vector of simplex indices. An edge that is not in the triangulation gives an empty entry.
Cell array com uma entrada por aresta, cada uma um vetor linha de índices de simplexes. Uma aresta que não está na triangulação dá uma entrada vazia.

Example

Exemplo

Triangles on two edges

Triângulos em duas arestas

x = [0 1 1 0 0.5]';
y = [0 0 1 1 0.5]';
DT = delaunayTriangulation(x, y);
ea = edgeAttachments(DT, [1 2; 2 3])
OutputSaída
ea = 2×1 cell

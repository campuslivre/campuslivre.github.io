fitglm next release

Fits a generalized linear regression model (normal, binomial, Poisson, gamma, inverse Gaussian) to a predictor matrix and a response.

Category: Regression > Generalized Linear Models > Generalized Linear Regression

Syntax

mdl = fitglm(X, y)

Linear model with an intercept and a normal response.

mdl = fitglm(X, y, modelspec)

Chooses the terms: 'constant', 'linear', 'interactions', 'purequadratic' or 'quadratic'.

mdl = fitglm(X, y, modelspec, 'Distribution', dist)

Sets the response distribution of the model.

mdl = fitglm(___, 'Link', link, 'Intercept', tf)

Sets the link function and whether to include an intercept.

Description

A generalized linear model relates the mean of the response to a linear combination of the predictors through a link function. With a binomial response and the default logit link it is logistic regression; with a Poisson response and a log link it models counts.

Read Coefficients.Estimate on the scale of the link (for logit, log odds) and compare Deviance between models of the same data.

Input arguments

X
n-by-p matrix of predictors, one row per observation.
y
Response vector with n elements. For 'binomial' it can also be an n-by-2 matrix [successes trials].
'Distribution'
'normal' (default), 'binomial', 'poisson', 'gamma' or 'inverse gaussian'.
'Link'
Link function name such as 'identity', 'log', 'logit', 'probit' or 'reciprocal'. Each distribution has a default.
'Intercept'
true (default) includes a constant term.

Output arguments

mdl
Fitted model object. Useful properties: Coefficients (with Estimate, SE, tStat, pValue), Deviance, Dispersion, LogLikelihood, Fitted, Residuals, NumCoefficients, Distribution, Link. Use predict(mdl, Xnew) and coefCI(mdl) on it.

Examples

Logistic regression

x = (1:8)';
yb = [0 0 0 1 0 1 1 1]';
m = fitglm(x, yb, 'Distribution', 'binomial');
fprintf('%.4f\n', m.Coefficients.Estimate)
fprintf('deviance %.4f\n', m.Deviance)
disp(round(predict(m, [2; 7]) * 10000) / 10000)
Output
-5.7703
1.2823
deviance 5.0061
    0.0390
    0.9610

Poisson regression for counts

x = (1:8)';
yc = [1 0 2 1 3 2 4 3]';
m = fitglm(x, yc, 'Distribution', 'poisson');
fprintf('%.4f\n', m.Coefficients.Estimate)
disp(m.Link.Name)
Output
-0.4537
0.2259
log

Notes

Only matrix input is supported: table input and formula strings such as 'y ~ x1' raise an error, and so does the 'Weights' option. For a binomial response given as [successes trials], the SSR property differs from MATLAB (its definition was not recovered). With a Poisson response and the identity link, the coefficients differ from MATLAB at about 1e-6 because MATLAB stops the iteration one step earlier.

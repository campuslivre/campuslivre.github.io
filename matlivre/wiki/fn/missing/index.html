missing

Creates a missing value placeholder that works for any data type.

Cria um marcador de valor ausente que funciona para qualquer tipo de dado.

Category:Categoria: Data Import and Analysis > Preprocessing Data

Syntax

Sintaxe

m = missing

Returns a scalar missing value.

Retorna um valor ausente escalar.

Description

Descrição

missing is a type-independent way to say that a value is absent. When it is placed in an array, it is converted to the standard missing marker of that array: NaN for numbers, <missing> for strings, NaT for datetimes. ismissing detects all of these uniformly.

It is handy when building a string array with gaps, or when filling a table whose columns have different types.

missing é uma forma independente de tipo de dizer que um valor está ausente. Quando colocado em um array, é convertido para o marcador padrão de ausência desse array: NaN para números, <missing> para strings, NaT para datetimes. ismissing detecta todos eles de modo uniforme.

É útil ao montar um array de strings com lacunas, ou ao preencher uma tabela cujas colunas têm tipos diferentes.

Output arguments

Argumentos de saída

m
The missing value. It prints as <missing>.
O valor ausente. É exibido como <missing>.

Example

Exemplo

A gap in a string array

Uma lacuna em um array de strings

s = ["a" missing "c"]
ismissing(s)
ismissing([1 NaN 3])
OutputSaída
s = 1×3 string array

    "a"    <missing>    "c"
ans = 1×3 logical array

   0   1   0
ans = 1×3 logical array

   0   1   0

Notes

Observações

In MatLivre class(missing) reports 'string', whereas in MATLAB it is 'missing'. Assigning missing into a numeric array is not supported; use NaN.

No MatLivre, class(missing) informa 'string', enquanto no MATLAB é 'missing'. Atribuir missing dentro de um array numérico não é suportado; use NaN.

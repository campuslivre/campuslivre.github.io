heatmap

Heatmap chart that shows a matrix, or two table variables, as colored cells.

Gráfico de mapa de calor que mostra uma matriz, ou duas variáveis de uma tabela, como células coloridas.

Category:Categoria: Graphics > 2-D and 3-D Plots

Syntax

Sintaxe

heatmap(cdata)

Draws one cell per element of the matrix cdata, colored by its value.

Desenha uma célula por elemento da matriz cdata, colorida pelo valor.

heatmap(xvalues, yvalues, cdata)

Labels the columns with xvalues and the rows with yvalues.

Rotula as colunas com xvalues e as linhas com yvalues.

heatmap(tbl, xvar, yvar)

Counts the rows of the table tbl for each pair of values of the variables xvar and yvar.

Conta as linhas da tabela tbl para cada par de valores das variáveis xvar e yvar.

h = heatmap(___)

Also returns the chart object, whose properties (Title, Colormap, ColorData) can be changed.

Também retorna o objeto do gráfico, cujas propriedades (Title, Colormap, ColorData) podem ser alteradas.

Description

Descrição

A heatmap is a good way to read a correlation matrix, a confusion matrix or any grid of numbers, because the color gives a quick overview while the labels keep the cells identifiable. The color scale is set by the smallest and largest values and follows the current colormap.

Unlike imagesc, heatmap is a chart: it has category labels, not numeric axes.

Um mapa de calor é uma boa forma de ler uma matriz de correlação, uma matriz de confusão ou qualquer grade de números, pois a cor dá uma visão geral rápida enquanto os rótulos mantêm as células identificáveis. A escala de cor é definida pelo menor e pelo maior valor e segue o colormap atual.

Ao contrário de imagesc, heatmap é um gráfico de categorias, com rótulos e não com eixos numéricos.

Input arguments

Argumentos de entrada

cdata
Numeric matrix, one value per cell.
Matriz numérica, um valor por célula.
xvalues, yvalues
Labels for the columns and rows: cell array of character vectors, string array or numeric vector.
Rótulos das colunas e linhas: cell array de vetores de caracteres, array de strings ou vetor numérico.
tbl, xvar, yvar
Table and the names of two of its variables.
Tabela e os nomes de duas de suas variáveis.

Output arguments

Argumentos de saída

h
HeatmapChart object.
Objeto HeatmapChart.

Example

Exemplo

Labelled matrix

Matriz com rótulos

cdata = [10 2 0; 3 12 1; 0 4 9];
h = heatmap({'A','B','C'}, {'A','B','C'}, cdata);
h.Title = 'Confusion matrix';

In the app, the chart is drawn below the code.

No app, o gráfico é desenhado abaixo do código.

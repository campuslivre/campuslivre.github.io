Getting started

Primeiros passos

MatLivre runs on Windows 10 and 11. Download the installer or the portable ZIP from the download section. The installer needs no administrator rights and keeps itself up to date from the project’s GitHub releases. The ZIP runs from any folder: unzip it and start MatLivre.exe. If Windows shows a warning about an unknown publisher, see Troubleshooting.

O MatLivre roda no Windows 10 e 11. Baixe o instalador ou o ZIP portátil na seção de download. O instalador não exige direitos de administrador e se mantém atualizado a partir das versões do projeto no GitHub. O ZIP roda de qualquer pasta: descompacte e abra o MatLivre.exe. Se o Windows mostrar um aviso de editor desconhecido, veja Solução de problemas.

Your first live script

Seu primeiro live script

  1. Start MatLivre. It opens an empty live script named untitled.mlx.
  2. Click in the code area and type a few lines, for example:
  1. Abra o MatLivre. Ele abre um live script vazio chamado untitled.mlx.
  2. Clique na área de código e digite algumas linhas, por exemplo:
x = linspace(0, 2*pi, 200);
plot(x, sin(x))
title('Sine')
  1. Press Ctrl+Enter to run the current section. The figure appears right below the code. Press F5 to run the whole script.
  2. Open … › Getting started for a sample live script with text, tables, plots and functions, ready to run and edit.
  1. Pressione Ctrl+Enter para executar a seção atual. A figura aparece logo abaixo do código. Pressione F5 para executar o script inteiro.
  2. Abra … › Getting started para ver um live script de exemplo, com texto, tabelas, gráficos e funções, pronto para executar e editar.

Statements without a semicolon show their value, exactly as in MATLAB.

Comandos sem ponto e vírgula mostram o valor, exatamente como no MATLAB.

The window

A janela

Everything is in one window, with a toolbar on top and three panels you can show or hide.

Tudo fica em uma só janela, com uma barra de ferramentas no topo e três painéis que você pode mostrar ou ocultar.

  • Tabs in the title bar, one per open file. Switch with Ctrl+Tab and Ctrl+Shift+Tab, close with Ctrl+W. Tabs can be dragged between MatLivre windows.
  • Abas na barra de título, uma por arquivo aberto. Alterne com Ctrl+Tab e Ctrl+Shift+Tab, feche com Ctrl+W. As abas podem ser arrastadas entre janelas do MatLivre.
  • Toolbar. New, Open, Save and Insert menus; Run section, Run and advance, Run all and Stop; buttons for the Claude panel and the command window; and the … menu (clear all output, dark theme, code completions, connect Claude Code, getting started).
  • Barra de ferramentas. Menus New, Open, Save e Insert; Run section, Run and advance, Run all e Stop; botões do painel do Claude e da janela de comandos; e o menu … (limpar toda a saída, tema escuro, completar código, conectar o Claude Code, primeiros passos).
  • Files panel. Open a folder as the project root and browse it like in VS Code. Click a file to open it.
  • Painel de arquivos. Abra uma pasta como raiz do projeto e navegue como no VS Code. Clique em um arquivo para abri-lo.
  • Workspace panel. Lists your variables with name, value and size after you run code. It has a button to clear the workspace.
  • Painel do espaço de trabalho (workspace). Lista suas variáveis, com nome, valor e tamanho, depois que você executa código. Tem um botão para limpar o workspace.
  • Command window. Type a command after >> and press Enter. The up and down arrows recall earlier commands. Toggle it with Ctrl+`.
  • Janela de comandos. Digite um comando depois de >> e pressione Enter. As setas para cima e para baixo recuperam comandos anteriores. Mostre ou oculte com Ctrl+`.
  • Themes. Light and dark, from the … menu. Your layout and theme are remembered between sessions.
  • Temas. Claro e escuro, no menu …. O layout e o tema são lembrados entre as sessões.

Live scripts

Live scripts

A live script (.mlx) mixes formatted text, code and results in one document. It is divided into sections, and each section can be run on its own.

Um live script (.mlx) mistura texto formatado, código e resultados em um só documento. Ele é dividido em seções, e cada seção pode ser executada sozinha.

Running code

Executando o código

  • Ctrl+Enter: run the current section.
  • Ctrl+Enter: executar a seção atual.
  • Ctrl+Shift+Enter: run the current section and move to the next one.
  • Ctrl+Shift+Enter: executar a seção atual e passar para a próxima.
  • F5: run the whole script.
  • F5: executar o script inteiro.
  • Ctrl+C or the Stop button: stop. A script stops between statements.
  • Ctrl+C ou o botão Stop: parar. O script para entre um comando e outro.

Code runs on its own engine thread, so the editor never freezes while a script is running. Results appear below the code or on its right, and figures are drawn inline.

O código roda em uma thread própria do motor, então o editor nunca trava durante a execução. Os resultados aparecem abaixo do código ou à direita dele, e as figuras são desenhadas na própria página.

Montando um documento

Use the Insert menu to add a block:

Use o menu Insert para adicionar um bloco:

  • Text, Title, Heading and Subheading for the prose.
  • Text, Title, Heading e Subheading para o texto.
  • Code for a block of code.
  • Code para um bloco de código.
  • Section break (Ctrl+Alt+Enter) to split a section in two.
  • Section break (Ctrl+Alt+Enter) para dividir uma seção em duas.
  • Control for interactive controls (next section).
  • Control para controles interativos (próxima seção).

Saving and exporting

Salvando e exportando

Save (Ctrl+S) and Save as (Ctrl+Shift+S) write a .mlx file. Export as script (.m) writes the code as a plain script. PDF export is not available yet.

Save (Ctrl+S) e Save as (Ctrl+Shift+S) gravam um arquivo .mlx. Export as script (.m) grava o código como um script comum. A exportação para PDF ainda não está disponível.

Good to know: outputs saved inside an .mlx file are not restored when you open it (run the script to regenerate them) and are not written back. Rich text such as bold runs, links, equations and images is shown as plain text.

Bom saber: as saídas salvas dentro de um arquivo .mlx não são restauradas ao abri-lo (execute o script para gerá-las de novo) e não são gravadas de volta. Texto formatado, como negrito, links, equações e imagens, aparece como texto simples.

Plain scripts (.m)

Scripts comuns (.m)

Open any .m file and it is shown with its %% sections, which you run one at a time. A comment right after %% becomes the section title, and comment lines below it become formatted text. Create one with New › Script (.m) (Ctrl+Alt+N).

Abra qualquer arquivo .m e ele aparece com suas seções %%, que você executa uma por vez. Um comentário logo após o %% vira o título da seção, e as linhas de comentário abaixo dele viram texto formatado. Crie um com New › Script (.m) (Ctrl+Alt+N).

Functions defined at the end of a script can be called from any section. Function files and classes in the same folder as the script are found automatically, as in MATLAB.

Funções definidas no fim de um script podem ser chamadas de qualquer seção. Arquivos de função e classes na mesma pasta do script são encontrados automaticamente, como no MATLAB.

%% Solving a linear system
% Results appear right below the code.
A = [4 -2 1; -2 4 -2; 1 -2 4];
rhs = [11; -16; 17];
sol = A \ rhs
residual = norm(A*sol - rhs)

%% A local function
n = 1:10;
f = arrayfun(@fib, n)

function r = fib(n)
    if n <= 2
        r = 1;
    else
        r = fib(n - 1) + fib(n - 2);
    end
end

Live controls

Controles interativos

In a live script, Insert › Control places an interactive control inside a line of code. It stands for a value, so the code that uses it runs with whatever you set. The kinds are:

Em um live script, Insert › Control coloca um controle interativo dentro de uma linha de código. Ele representa um valor, então o código que o usa executa com o que você definir. Os tipos são:

  • Slider, with a minimum, a maximum and a step.
  • Slider, com mínimo, máximo e passo.
  • Drop-down, with a list of items written as code literals, separated by commas.
  • Drop-down, com uma lista de itens escritos como literais de código, separados por vírgulas.
  • Check box and Edit field.
  • Check box e Edit field.
  • Button, with a label.
  • Button, com um rótulo.

Controls are stored in the .mlx file, so they also appear when the file is opened in MATLAB’s Live Editor.

Os controles são gravados no arquivo .mlx, então também aparecem quando o arquivo é aberto no Live Editor do MATLAB.

Figures

Figuras

Figures are drawn next to the code that creates them, and each one can also open in a floating window. Hover a plot and a crosshair reads values off it.

As figuras são desenhadas ao lado do código que as cria, e cada uma também pode abrir em uma janela flutuante. Passe o mouse sobre um gráfico e uma mira lê os valores nele.

  • Plots: 2-D and 3-D lines and scatter plots, surfaces with lighting, contours, images, bar, pie, histogram, polar plots and more.
  • Gráficos: linhas e dispersão 2-D e 3-D, superfícies com iluminação, contornos, imagens, barras, pizza, histogramas, gráficos polares e mais.
  • Charts: heatmaps, box, swarm and bubble charts, pie and donut charts, word clouds, stacked plots and parallel coordinates.
  • Charts: mapas de calor, box, swarm e bubble charts, gráficos de pizza e rosca, nuvens de palavras, gráficos empilhados e coordenadas paralelas.
  • Layout and decoration: two y axes (yyaxis, plotyy), tiled layouts and subplots, annotations, legends, colorbars, date ticks and data tips.
  • Layout e decoração: dois eixos y (yyaxis, plotyy), tiled layouts e subplots, anotações, legendas, colorbars, datas nos eixos e data tips.
  • Handles: graphics objects are handles, so get, set, findobj and arrays of handles work as in MATLAB.
  • Handles: objetos gráficos são handles, então get, set, findobj e arrays de handles funcionam como no MATLAB.
  • Saving: saveas, print and exportgraphics write PNG and SVG.
  • Salvando: saveas, print e exportgraphics gravam PNG e SVG.
x = linspace(0, 2*pi, 200);
plot(x, sin(x), 'LineWidth', 2)
hold on
plot(x, cos(x), '--', 'LineWidth', 2)
hold off
grid on
title('Sine and cosine')
legend('sin', 'cos')
exportgraphics(gcf, 'sine.png')

Files and folders

Arquivos e pastas

  • Open › File (Ctrl+O) opens a .mlx or .m file. Folder sets the project root shown in the files panel. You can also pass a file when starting the program: MatLivre.exe script.mlx.
  • Open › File (Ctrl+O) abre um arquivo .mlx ou .m. Folder define a raiz do projeto mostrada no painel de arquivos. Você também pode passar um arquivo ao iniciar o programa: MatLivre.exe script.mlx.
  • Files changed by another program (a text editor, Claude Code, git) reload in their tab. A tab with unsaved changes asks instead whether to reload the file or keep your version, and MatLivre never saves over a change it has not shown you.
  • Arquivos alterados por outro programa (um editor de texto, o Claude Code, o git) são recarregados na sua aba. Uma aba com alterações não salvas pergunta se você quer recarregar o arquivo ou manter a sua versão, e o MatLivre nunca grava por cima de uma alteração que não mostrou a você.
  • Data files: text and CSV, Excel workbooks (readtable, xlsread, writetable), MAT files, images, audio, JSON, XML, and zip and tar archives.
  • Arquivos de dados: texto e CSV, planilhas do Excel (readtable, xlsread, writetable), arquivos MAT, imagens, áudio, JSON, XML e arquivos zip e tar.
  • Settings are kept in %APPDATA%\matlivre.
  • As configurações ficam em %APPDATA%\matlivre.

Command line

Linha de comando

Building from source also gives you matlivre-cli, which runs a script without opening a window and prints its output:

Compilar a partir do código-fonte também gera o matlivre-cli, que executa um script sem abrir janela e imprime a saída:

cargo build --release
target\release\matlivre-cli.exe script.m

The CLI starts in 0.03 s on a first launch, which makes it handy for batch jobs and tests. See the build instructions.

A CLI inicia em 0,03 s na primeira execução, o que a torna prática para tarefas em lote e testes. Veja as instruções de compilação.

Working with Claude

Trabalhando com o Claude

If you have Claude Code installed, MatLivre can work with it. No API key is needed, since it uses the Claude Code already on your computer. This is optional: everything else works without it.

Se você tem o Claude Code instalado, o MatLivre pode trabalhar com ele. Não é preciso chave de API, pois ele usa o Claude Code que já está no seu computador. É opcional: todo o resto funciona sem isso.

  • Claude panel (Ctrl+L): chat with Claude, which can run code in your workspace, see your figures, and read and edit the open documents. It asks before it runs or changes anything.
  • Painel do Claude (Ctrl+L): converse com o Claude, que pode executar código no seu workspace, ver suas figuras e ler e editar os documentos abertos. Ele pergunta antes de executar ou alterar qualquer coisa.
  • Code completions: after a pause in typing, Claude suggests the rest of the line or block in grey. Tab inserts it, Esc dismisses it, Alt+\ asks at once. Turn them on or off in the … menu.
  • Completar código: depois de uma pausa na digitação, o Claude sugere o resto da linha ou do bloco em cinza. Tab insere, Esc descarta, Alt+\ pede na hora. Ative ou desative no menu ….
  • MCP server: … › Connect Claude Code copies a claude mcp add command. After you run it, Claude Code in a terminal works in the open MatLivre window.
  • Servidor MCP: … › Connect Claude Code copia um comando claude mcp add. Depois de executá-lo, o Claude Code em um terminal trabalha na janela aberta do MatLivre.

The language

A linguagem

MatLivre follows MATLAB R2023b: semantics, display format and error messages. The engine is an independent implementation, so no MATLAB installation or licence is needed. It supports:

O MatLivre segue o MATLAB R2023b: semântica, formato de exibição e mensagens de erro. O motor é uma implementação independente, então não é preciso ter o MATLAB instalado nem licença. Ele suporta:

  • Data: N-D arrays of every numeric type, logical, char and strings, with implicit expansion, saturating integer arithmetic and complex numbers. Cell arrays, struct arrays, table, timetable, categorical, datetime with time zones, duration, containers.Map and dictionary.
  • Dados: arrays N-D de todos os tipos numéricos, logical, char e strings, com expansão implícita, aritmética inteira saturada e números complexos. Cell arrays, arrays de struct, table, timetable, categorical, datetime com fusos horários, duration, containers.Map e dictionary.
  • Programming: function handles, anonymous functions, local functions, classdef classes (properties, methods, inheritance, handle and value semantics, operator overloading, events, enumerations), argument validation, inputParser and Name=Value arguments, error identifiers, regular expressions and timer objects.
  • Programação: function handles, funções anônimas, funções locais, classes classdef (propriedades, métodos, herança, semântica de handle e de valor, sobrecarga de operadores, eventos, enumerações), validação de argumentos, inputParser e argumentos Name=Value, identificadores de erro, expressões regulares e objetos timer.
  • Mathematics: linear algebra and factorizations, polynomials and interpolation, ODE solvers (nonstiff, stiff, DAEs), delay and boundary value problems, parabolic PDEs, integration, optimisation and root finding, statistics, FFT and filtering, sparse matrices and iterative solvers, graphs and networks, computational geometry, special functions.
  • Matemática: álgebra linear e fatorações, polinômios e interpolação, resolvedores de EDO (não rígidas, rígidas, DAEs), problemas com atraso e de valor de contorno, EDPs parabólicas, integração, otimização e busca de raízes, estatística, FFT e filtragem, matrizes esparsas e solvers iterativos, grafos e redes, geometria computacional, funções especiais.
  • Symbolic Math Toolbox: exact arithmetic, diff, int, limit, taylor, solve, simplify, Laplace, Z and Fourier transforms, symbolic matrices, dsolve for linear equations, units of measurement and more.
  • Symbolic Math Toolbox: aritmética exata, diff, int, limit, taylor, solve, simplify, transformadas de Laplace, Z e Fourier, matrizes simbólicas, dsolve para equações lineares, unidades de medida e mais.

Every function it covers is listed in the function reference. Not covered: Simulink, the other toolboxes, app building and external-language interfaces.

Todas as funções cobertas estão na referência de funções. Não cobertos: Simulink, as outras toolboxes, criação de apps e interfaces com outras linguagens.

Examples

Exemplos

The repository ships three scripts to open and run: welcome.m (the sample behind Getting started), graphics.m (plots and charts) and features.m (language features). Download one, open it with Open › File and press F5.

O repositório traz três scripts para abrir e executar: welcome.m (o exemplo de Getting started), graphics.m (gráficos e charts) e features.m (recursos da linguagem). Baixe um, abra com Open › File e pressione F5.

Known limits

Limites conhecidos

MatLivre is young. The ones that matter most day to day:

O MatLivre é jovem. Os que mais importam no dia a dia:

  • Windows is the only tested platform.
  • O Windows é a única plataforma testada.
  • Saved outputs in .mlx files are not restored on open and rich text is shown as plain text.
  • As saídas salvas em arquivos .mlx não são restauradas ao abrir, e o texto formatado aparece como texto simples.
  • Sparse matrices are stored densely, and matrices with more than 2e8 elements are refused.
  • Matrizes esparsas são armazenadas de forma densa, e matrizes com mais de 2e8 elementos são recusadas.
  • randn with the default transform does not reproduce MATLAB’s values for a given seed (rand, randi and randperm do).
  • randn com a transformação padrão não reproduz os valores do MATLAB para uma semente (rand, randi e randperm reproduzem).
  • The symbolic engine solves single linear differential equations, not systems or nonlinear ones, and some transforms cover only the common pairs.
  • O motor simbólico resolve equações diferenciais lineares isoladas, não sistemas nem equações não lineares, e algumas transformadas cobrem só os pares comuns.

The full, current list is in the README, and functions still to implement are in the coverage checklist.

A lista completa e atual está no README, e as funções que ainda faltam estão na lista de cobertura.

Troubleshooting

Solução de problemas

Windows says “Windows protected your PC”

O Windows mostrou “O Windows protegeu o computador”

The installer is not code-signed yet, so SmartScreen warns about it. Click More info, then Run anyway. Browsers may also ask you to confirm the download. The step-by-step guide covers Edge, Chrome and Firefox.

O instalador ainda não tem assinatura digital, então o SmartScreen avisa sobre ele. Clique em Mais informações e depois em Executar assim mesmo. Os navegadores também podem pedir para confirmar o download. O passo a passo cobre Edge, Chrome e Firefox.

A function says it is undefined

Uma função aparece como indefinida

Check the function reference. If it is not there, it is not implemented yet. Open an issue with a small example so it can be prioritised, or implement it yourself: pull requests are welcome.

Consulte a referência de funções. Se não estiver lá, ainda não foi implementada. Abra uma issue com um exemplo pequeno para ela ser priorizada, ou implemente você mesmo: pull requests são bem-vindos.

The output differs from MATLAB

A saída é diferente da do MATLAB

That is a bug: matching MATLAB is the goal. Please report it with the code and the expected output.

Isso é um bug: igualar o MATLAB é o objetivo. Relate, por favor, com o código e a saída esperada.

Something else

Outro problema

Ask or report on the issue tracker. The project is open source and every report helps.

Pergunte ou relate no rastreador de issues. O projeto é de código aberto e todo relato ajuda.

MatLivre

An open, free and faster alternative.

A free, open-source alternative to MATLAB and GNU Octave: a fast live script editor and runtime for MATLAB code. Open, edit and run .mlx live scripts and plain .m files with results, tables and figures inline, in a native Windows app. The language engine is an independent clean-room implementation written in Rust: no MATLAB installation, no licence, no Java.

Free does not mean slower. On our benchmarks MatLivre matches or beats MATLAB R2023b: faster in 10 of 12 language tests, within 1.4× in the other two, and about 43× faster on live scripts.

Open source, MIT licence. The code is on GitHub for anyone to read, use and improve. Issues and pull requests are welcome.

Why MatLivre exists

Decades of scientific code should not depend on a licence server.

A huge amount of teaching material, thesis code and lab tooling is written in MATLAB's language. Running it normally means a paid licence, tied to a vendor in another country that can reprice, restrict or withdraw access.

MatLivre lets that work keep running: on a student's laptop, in a school with no budget, in a lab that has just lost its seats. It reads the same files, produces the same displayed output and costs nothing.

Why choose MatLivre over Octave.

Octave is a respected free alternative to MATLAB and we owe it a lot. If you want one that also runs live scripts, is faster and looks like a modern notebook, this is where MatLivre is better:

Octave cannot open live scripts. MatLivre can.

Octave has no support for .mlx files and no live editor with inline output. MatLivre opens, edits and runs them, with results, tables and figures next to the code. It also keeps your .m files working.

Faster, in 11 of the 12 benchmarks we ran.

MatLivre was faster than Octave in 11 of 12 language benchmarks, 54× faster on the geometric mean, with identical results. Loops, recursion, array growth and struct updates are compiled to machine code instead of interpreted.

A notebook, not a command window.

In Octave, %% sections print to the command window and figures open in separate windows. In MatLivre, each section runs on its own, with live controls (sliders, drop-downs, check boxes), a workspace browser and figures inline.

Ready in a blink, even the first time.

The app is ready in 0.97 s on a first launch (0.31 s after). Octave’s command line takes 2.56 s on a first launch, and its GUI stopped at a setup wizard when we first started it.

Built to match MATLAB’s output.

Display format, error messages and semantics are checked against MATLAB R2023b, for 1,837 functions including the Symbolic Math Toolbox, classdef and table. The goal is that code written for MATLAB gives the same output, not just similar output.

Where Octave is still the better choice: it runs on macOS too, it has decades of maturity, and it has a large package ecosystem (Octave Forge). MatLivre is young: Windows is its main platform, Linux is newer and less tested, and there is no macOS build yet. Benchmarks and methods are in the repository.

The app

A notebook that feels like a native tool.

  • Live scripts. Formatted text, code and results inline or on the right. Run a section, run and advance, or run all, and stop between statements.
  • Live controls. Sliders, drop-downs, check boxes and edit fields in .mlx files.
  • Plots. 2-D and 3-D, surfaces with lighting, contours, images, heatmaps, box and bubble charts, two y axes, tiled layouts. Export to PNG and SVG.
  • Workspace. Files panel, workspace browser, command window, draggable tabs, light and dark themes.
  • Never frozen. Code runs on its own thread; files changed by another program reload, and unsaved edits are never overwritten.

An optional AI assistant, on your terms

If you already have Claude Code installed, MatLivre can add a chat panel, code completions and an MCP server that work through it. This is optional: the editor and the language engine never need it, there is no API key, and it can be switched off from the app's menu.

The language

MATLAB compatibility is the rule.

Semantics, display format and error messages follow MATLAB R2023b, and the test suite compares MatLivre's output with MATLAB's for each function family.

Core language

N-D arrays of every numeric type, strings, complex numbers, cell and struct arrays, classdef with inheritance, events and enumerations, table, timetable, datetime, containers.Map.

Mathematics

Linear algebra, ODE and PDE solvers, optimisation, statistics, FFT and filtering, sparse matrices and iterative solvers, graphs and networks, computational geometry.

Symbolic Math

Exact arithmetic, diff, int, limit, taylor, solve, Laplace transforms, simplify, special functions, orthogonal polynomials, and symbolic units.

Browse and search every function MatLivre covers, each with its own page. The status of every function of the MATLAB and Symbolic Math Toolbox references is in the coverage checklist.

Clean-room

Built from behaviour, not from source.

MatLivre was written from observed behaviour only. The live script format is documented in a public specification produced by inspecting .mlx data files and the public behaviour of the Live Editor. Language behaviour is checked by running code and comparing outputs. No MathWorks source code was read or copied.

Honest limits

What it does not do yet.

MatLivre is young (version 0.1.x). It will not run every MATLAB program yet, and we would rather say so than let you find out at a deadline.

  • Windows is the main platform. Linux (AppImage) was tested on Ubuntu 24.04 only, and there is no macOS build yet.
  • Saved outputs in .mlx files are not restored on open or written back; run the script to regenerate them.
  • Rich text in live scripts (bold, italics, links, equations, images) is shown as plain text.
  • Some functions are missing, including dsolve and symbolic code generation. Toolboxes beyond Symbolic Math are not covered.
  • Some random-number streams, chart layouts and dithering details differ from MATLAB's.

The complete, current list is under Known limits in the README.

Two rules that keep the project safe

  • Clean-room only. Learn MATLAB’s behaviour from its documentation and from running code. Never read or copy MathWorks source code, including the .m files in a MATLAB installation.
  • Compatibility needs evidence. New functions come with tests whose expected output was recorded from MATLAB R2023b. See the contributor notes for the workflow.

Installing on Linux

Linux gets a single AppImage: one file that runs without installing anything system-wide and without root. It was tested on Ubuntu 24.04 (GNOME, Wayland); other distributions may work but are not tested yet. If something fails, please tell us which distribution you use.

1. From the terminal

mkdir -p ~/.local/bin
curl -L -o ~/.local/bin/matlivre https://github.com/campuslivre/matlivre/releases/latest/download/matlivre.AppImage
chmod +x ~/.local/bin/matlivre
matlivre

This keeps the file in ~/.local/bin, which most distributions already have on the PATH (log out and in once if matlivre is not found). Running the same curl line again later replaces it with the newest version.

2. From the file manager

  1. Download matlivre.AppImage with the Install button above.
  2. Right-click the file, open Properties, and in Permissions allow executing the file as a program.
  3. Double-click it.

If it does not start and the message mentions FUSE, install your distribution's libfuse2 package (libfuse2t64 on recent Ubuntu), or run matlivre --appimage-extract-and-run. Menu names vary between desktops. Prefer to build it yourself? Use the commands above; the build needs build-essential pkg-config libgtk-3-dev libxkbcommon-dev libwayland-dev on Ubuntu or Debian.

Windows says “Windows protected your PC”? That is expected.

MatLivre is a young, independent project and the installer is not code-signed yet. Code-signing certificates cost money every year, and Microsoft SmartScreen warns about any program that is unsigned or not yet widely downloaded. The warning is about reputation, not about a problem found in the file. You can read every line of the source code, or build it yourself.

1. Windows SmartScreen

  1. Open the downloaded installer.
  2. On the blue “Windows protected your PC” window, click More info.
  3. Click Run anyway.

2. Browser download warning

  1. Edge: in the downloads list, open the … menu next to the file, choose Keep, then Show more and Keep anyway.
  2. Chrome: open the downloads list and click Keep next to the file (or the arrow, then Keep anyway).
  3. Firefox: in the downloads panel, choose Allow download if it asks.

Menu names vary a little between Windows and browser versions and languages. Only run files you downloaded from this site or from the project’s GitHub releases page. Prefer not to trust a binary? Build from source with the commands above.

About the initiative

Campus Livre

MatLivre is the first project of Campus Livre, an initiative that builds free, open-source software for academic and scientific work, made in Brazil. We believe that knowledge software should not sit behind paywalls, because that slows down the progress of knowledge and technology, and that no country should depend on a commercial product that a foreign vendor or government can cut off.

Our projects are free, run on your own machine, read and write the formats you already have, are built without copying anyone's code, and are honest about what they cannot do yet.
